# linger

**释义**：v. ①（人）**逗留、徘徊、磨蹭不走** ②（气味、记忆、感觉）**持续、萦绕不散** ③（病）**拖延、缠绵** ④（不快之物）拖长｜ to stay or remain in a place longer than necessary; to be slow to disappear; to persist

**例句**
- _The smell of coffee lingered in the kitchen._ 咖啡的香气在厨房里久久不散。
- _She lingered by the door, reluctant to leave._ 她在门边徘徊，舍不得走。
- _The memory of that day lingered for years._ 那天的记忆萦绕多年。

**词源 / 构词**
- **拆解**：**linger** ← 中古英语 **lenger**（**c. 1300**），是**英格兰北部**方言 **lengen**（「to tarry 逗留」）的**反复动词（frequentative）**——加 **-er (4)** 后缀构成；lengen 上溯古英语 **lengan**「延长、使长」，← 原始日耳曼 **\*langjan**「使长」（同族：古弗里斯兰 lendza、古高地德语 lengan、荷兰 lengen，皆「使长」），再上溯 **\*langaz**「长」（见 long）（据 etymonline）。
- **演变**：**c. 1300** 作 lenger，义「reside, dwell（居住、停留）」；不及物义「**delay going, depart slowly and unwillingly**（迟迟不走、不情愿地慢慢离开）」见 **1520s**；「**remain long in sickness, be near death**（久病不愈、弥留）」见 **1530s**（据 etymonline）。etymonline 提示：linger 与 **long / prolong / lengthen** 分担保「延长」之职——语义分工。
- **同族 / 派生**：**lingered / lingerer / lingering**（etymonline 列出）；同 **\*langaz** 族：**long**（adj.）、**lengthen**、**prolong**、**belong**（← 古英语 gelang「属于」，同「long」根）。
- **记忆钩**：底层就是 **long（长）**——把时间「拉长」就是 linger：**拉长停留**（逗留）、**拉长消散**（萦绕）、**拉长病期**（缠绵）。

**同义 / 搭配 / 易混**
- 搭配：linger on；linger over（a meal / coffee）；lingering doubts / smell / effects；linger in the memory
- 同义：remain、stay、dawdle、loiter、tarry、persist
- 易混 / 辨析：**linger vs loiter**——loiter 含「闲荡、游手好闲」的贬义且常与「滞留禁地」有关，linger 中性偏「不舍 / 持续」；**linger vs [[wear-on]]**——[[wear-on]]（时间）「恼人地持续、拖长」，linger 更多「（美好或难忘地）萦绕」，二者皆「持续」，语气一负一中。
