# brass

**释义**：n. ①黄铜（铜锌合金）；（广义）铜合金、青铜 ②（常用复数 / 集合）黄铜制品、黄铜管乐器（the brass / brass section）③（the brass，口语）高级官员、头目们 ④（口语）厚脸皮、无礼、放肆（effrontery）｜ adj. 黄铜的、黄铜制的（c. 1400）｜ v. 镀黄铜、用黄铜包覆（1865）｜ n. an alloy of copper and zinc; (figurative) impudence; (slang) high-ranking officials; brass instruments of a band.

**例句**
- _The door handle was polished brass._ 门把手是抛光的黄铜。
- _The brass section came in a beat too late._ 铜管乐组晚了一拍才进来。
- _He had the brass to ask for a raise on his first day._ 他竟有脸头一天上班就张口要求加薪。

**词源 / 构词**
- **拆解**：**brass** ← 古英语 **bræs**「黄铜、青铜」，**词源不明**——etymonline 明确记「**英语之外无同源词（no cognates outside English）**」。曾有一说联系法语 **brasser**「酿造」（理由：brass 是**合金**），或比古瑞典语 **brasa**「火」，或联系拉丁 **ferrum**「铁」（本身来源亦不明）——**均无确证**
- **演变**：古英语 **bræs** 本指**任何铜合金**，在英格兰常指**铜锡合金**（即今之 bronze 青铜）；后世专指「铜约二、锌约一」的合金。**公元 1 世纪** Strabo 已提及 brass，但 Homer 未提——故英语《圣经》译本等处所译 brass **多半实指 bronze（青铜）**。**罗马人**最早有意生产黄铜；OED 指出：当古典时期 brass 器物被分析、确认材质后，「意大利语表 brass 的 **bronzo / bronze** 一词被启用来区别此『古代 brass』与当时的合金」。**引申义**（均据 etymonline）：**hardness / durability / obduracy（坚硬、耐固、顽固）**——**late 14c.**；**effrontery / impudence（厚颜无耻）**——**1620s**；**「高官们」**——**1899**（源自其**徽章**）；**「管乐队的铜管乐器」**——**1832**。形容词「黄铜制的」**c. 1400**（比较 **brazen**）。短语 **brass tacks**（「直奔要点」）**1897**，约 1910 起流行（或指**钉在布店柜台上**供量布的铜钉，喻精确，但意象从未明确）；**brass monkey**（「冻得连铜猴尾巴都掉」）**1843** 已见
- **同族 / 派生**：**brazen**（adj. 黄铜的，古英语 **bræsen** ＝ bræs + -en；喻「厚颜」**1570s**，见 brazen-faced；动词 brazen it **1550s**）、**braze**（v.2，古英语 **brasian**「做黄铜活 / 用黄铜制」；比较 glaze ← glass）、**brazier**（黄铜匠 / 火盆，联想）、**brassware**、**brass band**（**1827**）
- **记忆钩**：古英语 **bræs** 一脉**独苗**（无外族同源词）——先记 brass 的「铜锌合金」本色，其余义全是引申：**厚脸皮**继自其「硬」，**高官**继自**铜徽章**，**铜管乐**继自**材质**

**同义 / 搭配 / 易混**
- 搭配：**brass band / section / instruments**（铜管乐队 / 铜管乐组）；**brass fittings / doorknob / plate**（黄铜配件 / 门把 / 名牌）；**the top brass**（高层）；**brass tacks**（实质要点）；**bold as brass**（胆大包天）
- 同义：黄铜色——gold-colored；厚脸皮——effrontery、nerve、gall（口语）；高官——top brass、officials
- 易混 / 辨析：**brass vs bronze vs copper**——**copper** 是纯铜（元素），**brass** ＝ 铜 + **锌**（色偏黄、较硬），**bronze** ＝ 铜 + **锡**（色偏红棕、耐磨）；古英语 bræs 因本指「任何铜合金」，故早期英语文献的 brass 常**实为 bronze**；**brass vs brazen**——brass 名词（金属），brazen 形容词（黄铜制的 / 厚颜的）
