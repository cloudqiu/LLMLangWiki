# furnace

**释义**：n. 熔炉、冶金炉；（旧时）取暖火炉、锅炉；（比喻）酷热之地、苦难的熔炉 ｜ an enclosed structure in which intense heat is produced, as for melting ore, burning fuel, or (formerly) heating a building

**例句**
- _The blast furnace turns iron ore into molten iron._ 高炉把铁矿石炼成铁水。
- _In older houses, a furnace in the basement heated the whole building._ 老房子里，地下室的一台火炉给整栋楼供暖。
- _The pottery is fired in a furnace at over 1,200°C._ 陶器在 1200 摄氏度以上的炉中烧成。

**词源 / 构词**
- **拆解**：英语经**古法语 fornais**「炉、烤箱」（12c.；同世纪亦用作比喻「爱之焰」）← **拉丁 fornacem**（主格 **fornax**）「炉、窑」。拉丁同族 **fornus / furnus**「炉」与 **formus**「暖」；再上溯 **PIE \*gwher-**「加热、使暖」（etymonline）
- **演变**：英语 **early 13c.** 首见（etymonline）。本义为「炉、窑」——先指实体火炉（暖房、冶铁），后专指**高温工业炉**（blast furnace「高炉」、reverberatory furnace「反射炉」）；比喻义如 *furnace of affliction*（苦难的熔炉）
- **关键交叉——与 thermo- 一族共祖**：**同一个 PIE 根 \*gwher-**「加热、使暖」既生**拉丁 fornax / formus**（→ furnace），又生**希腊 thermos**（→ [[thermostat]] / [[thermoregulate]] / **thermal** / **thermometer**）——etymonline 在 furnace 与 thermo- 两条下**各自独立**指向 \*gwher-。故 furnace 与 thermostat 是**共祖（同源非借入）**，而非彼此借入。同根还牵连古英语 **bærnan**「点燃」（→ burn）。至于英语 **warm**：etymonline 明记其「来源不明」，**仅把 \*gwher- 列为两种猜测之一**（另一说系于斯拉夫语 goriti「烧」、varŭ「热」等）——**须并列不折中**
- **同族 / 派生**：拉丁 **fornax** 在英语中的直系后代主要即 furnace；拉丁近亲 **fornus / furnus**「炉」、**formus**「暖」；科学命名中的 **Fornax**＝天炉座（**待验证**：命名人与年代）。PIE \*gwher- 大族的横向分布：希腊 **thermos / thermē**（→ thermo- 一族）、拉丁 **formus / fornax**（→ furnace）、古英语 **bærnan**（→ burn）
- **记忆钩**：furnace（走拉丁）与 thermostat（走希腊）是**同一个爷爷的两个孙子**——PIE \*gwher-「加热」。钉住 \*gwher-，furnace 与 thermal 就不再是两个孤立的词，而是**同一条根的两条路**

**同义 / 搭配 / 易混**
- 搭配：blast furnace（高炉）、reverberatory furnace（反射炉，见 [[reverberate]]）、electric / gas furnace、furnace room、oil / coal furnace、furnace of affliction（苦难的熔炉）
- 易混 / 辨析：**furnace vs stove vs oven vs kiln**——furnace 是**产高温**的炉（工业熔炼 / 旧式暖房）；stove 是**灶、取暖炉**（家用，多可明火）；oven 是**烤箱**（封闭、烹饪）；kiln 是**窑**（烧石灰 / 陶 / 砖——参 [[limestone]]「煅烧可得石灰」）。**furnace vs heater / boiler**——现代家用「暖气炉」美式多称 furnace、英式多称 boiler，但词源上 furnace 本指实体火炉而非整套供暖系统（**待验证**：该英美用词差异的权威表述）
- 「热」零件链条：[[thermostat]]（控温）、[[thermoregulate]]（调体温）、[[evaporate]]（vapor 蒸汽——散热机制）
