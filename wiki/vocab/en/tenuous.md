# tenuous

**释义**：adj. ①纤细的、细薄的（字面义，少用）②（引申）**薄弱的、牵强的、站不住脚的**——a tenuous link / argument / grasp｜ thin, slender; (figuratively) having little substance, weak, insubstantial

**例句**
- _The connection between the two events is tenuous at best._ 两件事之间的联系充其量也很牵强。
- _She clung to a tenuous hope that he would return._ 她抱着一线微弱的希望，盼他回来。
- _The evidence is too tenuous to support such a claim._ 证据太薄弱，撑不起这样的结论。

**词源 / 构词**
- **拆解**：**tenuis**（拉丁「细薄、纤细；微弱、不显著」）+ **-ous**（形容词后缀）。**注意**：此为**不规则构词**——正规拉丁式应为 **tenuious**（late 15c. 确有此形）；tenuous 是把 **-ous 直接加到 tenuis** 上（据 etymonline）。
- **演变**：**字面义**首见 **1590s**，义「thin, unsubstantial（细薄、不实在）」；**引申义**「slight importance, not substantial（无足轻重、不扎实）」见 **1817**（据 etymonline）。词根拉丁 **tenuis** 出自 PIE **\*ten-**「拉伸」（etymonline 引 Watkins）——「拉得细长 → 单薄」。
- **同族 / 派生**：**tenuously**、**tenuousness**；**tenuious**（late 15c.）、**tenuity**（early 15c.，← 古法语 tenuite ← 拉丁 tenuitas）；同 **PIE \*ten-** 词根：tendon、tension、tent、extend、[[tendonitis]]（同批词条）——全含「拉 / 伸」。
- **记忆钩**：**\*ten-「拉」→ 拉得又细又长 → 单薄**。物理上「细」→ 逻辑上「牵强」。同批 [[tendonitis]] 与本词共享 \*ten-。

**同义 / 搭配 / 易混**
- 搭配：a tenuous link / connection / argument / grasp / hold；tenuous at best
- 同义：flimsy、fragile、thin、slight、insubstantial、weak；far-fetched（论证牵强）
- 易混 / 辨析：**tenuous vs [[vehement]]**——二者皆拉丁借词层，但 [[vehement]] 表「强烈」（← vehere「搬运」，情绪被「带动」），tenuous 表「薄弱」（← tenuis），义几乎相反，可作拉丁借词**「强 / 弱对照」**记忆对。
