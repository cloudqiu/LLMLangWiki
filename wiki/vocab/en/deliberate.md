# deliberate

**释义**：adj. 故意的、存心的；**从容不迫的、不慌不忙的**（带「刻意放慢」的意味）｜ v. 仔细考虑、权衡；**审议**（正式，多用于委员会、陪审团） ｜ adj. done on purpose; slow and unhurried. v. to think about or discuss something carefully, especially in a formal body

**例句**
- _It was a deliberate attempt to mislead the court._ 那是蓄意误导法庭的行为。
- _She spoke in a slow, deliberate voice._ 她用缓慢而从容的语调说话。
- _The jury deliberated for three days before returning a verdict._ 陪审团审议了三天才作出裁决。

**词源 / 构词**
- **拆解**：**de-**（此处通说解为「完全、彻底」）+ **librare**「称量、使平衡」（← **libra**「天平、秤」）+ **-ate**（拉丁过去分词 / 动词词尾）。整体 **deliberare** ＝「好好称一称」（字面 weigh well）。etymonline 并提示 -liberare 这一形式**很可能是受 liberare「释放、使自由」的影响而改形**——**待验证**。
- **演变（两个词性年代不同，且英语最早的记录是动词）**
  - 形容词 **early 15c.**，义「done with careful consideration（经慎重考虑的）」；另一常用义「**从容不迫、刻意不急**」到 **1590s** 才见（etymonline）。
  - 动词：**更早的英语形式**是 **deliberen（late 14c.）**，借自古法语 **deliberer**，也直接来自拉丁 deliberare；**现代动词形 deliber-ate** 首见 **1540s**（「在心中权衡」），**1550s** 义为「讨论、审议正反理由」（etymonline）。
  - **对 inbox 提示「adj. 先于 v.」的修正（两说并记、不折中）**：若只看现代动词形，确在形容词之后（1540s vs. early 15c.）；但**英语中最早的动词记录 deliberen（late 14c.）反而早于形容词**——故「先 v. 还是先 adj.」取决于算不算 deliberen 这个早期借入形。
  - 副词 **deliberately**：late 15c.「with due consideration, with a set purpose（经充分考量、有意地）」（etymonline）。
- **易混词源：两条 libr- 线务必分清**
  - **libra「天平」一线** → **deliberate**（← librare）、**equilibrium**、**level**（← 拉丁 libella，libra 的指小形式）、**Libra**（天秤座，晚期古英语入英）。etymonline 的 libra 条还列出 *libra* 可追至原始意大利语 \*leithra-「磅」（重量单位），并收「pound / lira / livre / liter」等同族支。
  - **library / librarian 一线**：走的是拉丁 **liber「书（原指树内皮、纸）」→ librarium「书库」**——etymonline 的 **libra 条完全未言及** libra 与 library 的关系，**二者不同源**（**liber「书」的更深来源待验证**）。**别因为拼写都有 libr- 就把 library 挂到「天平」上。**
- **同族 / 派生**：deliberation、deliberately、deliberative、deliberateness（etymonline 仅另收 deliberateness；deliberation / deliberative 该页未给独立条目——其细节**待验证**）；拉丁亲族：libra、librare、libella、level、equilibrium、Libra；法语同源见下。
- **记忆钩**：**de- + libra（天平）**——把选项放上天平，**称一称再定**：称的过程是 v. deliberate（审议），称完「掂量过的」是 adj. deliberate（蓄意的 / 从容的）。记住 libra 这杆秤，顺带握住 deliberate / equilibrium / level 一串——但**别把 library 拉进来**。

**同义 / 搭配 / 易混**
- 搭配：a deliberate act / attempt / lie / choice；deliberate speed；in a deliberate manner；**deliberate on / over / upon**（就……进行审议）；a deliberative body（审议机构）；the jury deliberated
- 同义：adj. **intentional**（有意的——最中性）、**calculated**（精心算计的，含机心）、**purposeful**（有目的的，可褒）；「从容」义：**unhurried**、**measured**（有节制的、从容的）。v. **weigh**、**consider**、**ponder**、**debate**
- 易混：**intentional** 只讲「有意」，不含「从容」；deliberate 两义靠语境分辨——_a deliberate pace_ 是从容的步子，_a deliberate insult_ 却是蓄意侮辱，**同一个词，两个方向**。（相关近义词见 [[orderly]]：orderly 强调「有序、守纪律」，deliberate 强调「有意」或「刻意放慢」，别混用。）
- French（**同源**；法语页均未建——待回补）：法 **délibérer**（审议）、**délibéré**（故意的；从容的）、**délibération** 均源自拉丁 deliberare，与英语**同源（共祖）**；同时英语早期动词形 deliberen（late 14c.）**经古法语 deliberer 借入**——故英法之间是**借入（英 ← 古法）＋共祖（同出拉丁）**双重关系。英语现代动词形是否主要由拉丁直接塑造、古法语只提供早期形式，**待验证**。
