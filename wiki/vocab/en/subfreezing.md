# subfreezing

**释义**：adj. **冰点以下的、零度以下的**（低于水的冰点，约 0 °C / 32 °F）｜ below the freezing point; (of temperature) less than 0 °C

**例句**
- _Pipes can burst in subfreezing temperatures._ 零度以下的气温会使水管爆裂。
- _Overnight lows will be subfreezing across the region._ 全区夜间最低气温将降到冰点以下。
- _The crop was damaged by a stretch of subfreezing weather._ 持续一段零下低温毁坏了庄稼。

**词源 / 构词**
- **拆解**：**sub-**（拉丁介词 sub「在下、低于」；派生前缀义含「在下 / 低于 / 次一等 / 略带」，如 subantarctic「亚南极」）+ **freezing**（← 动词 **freeze** 的现在分词）。
- **演变**：**subfreezing** 在 etymonline **无独立条目**（本页按成分回落核实，据 etymonline 的 **sub-** 与 **freeze** 两条）。**freeze**（v.）为古英语 **freosan**「结冰」（II 类强动词）的变体（经 freese / friese），← 原始日耳曼 **\*freusan**，← PIE 词根 **\*preus-**「冻结（亦含『烧灼』义）」；名词 **freezing**「冰冻条件」见 **c. 1400**。**sub-** 表「**低于**」的用法（如 subantarctic、subnormal）是现代英语的主要功能之一（据 etymonline）。
- **同族 / 派生**：**freeze / freezing / frozen / freezer**；**sub-** 表「低于 / 次一」族：subzero、subnormal、subantarctic、subscribe（原义「在下签署」）；**热工 / 温度簇互链**：[[thermostat]]、[[insulate]]、[[furnace]]。
- **记忆钩**：**sub（在下）+ freezing（结冰）= 结冰线以下 = 零下**。与 [[thermostat]] / [[insulate]] / [[furnace]] 同属「温度控制」意象场。

**同义 / 搭配 / 易混**
- 搭配：subfreezing temperatures / weather / conditions；subfreezing lows
- 同义：**subzero**（零下）；below freezing、frosty
- 易混 / 辨析：**subfreezing vs subzero**——subfreezing 指「冰点以下」（即 0 °C 以下），**subzero** 通常指「零度以下」（美式常指华氏 0° 以下 = −18 °C），**门槛不同**，勿混。互链：[[thermostat]]、[[insulate]]、[[furnace]]。
