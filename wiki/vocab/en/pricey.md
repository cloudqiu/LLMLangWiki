# pricey

**释义**：adj.（口语）昂贵的、价钱高的（亦作 **pricy**；比较级 pricier，最高级 priciest） ｜ (informal) expensive

**例句**
- _That restaurant is good, but a bit pricey for a weeknight._ 那家餐厅不错，但工作日晚上吃有点贵。
- _Housing in the city has gotten prohibitively pricey._ 这座城市的房价已经贵到让人望而却步。
- _The repairs turned out pricier than the car is worth._ 修车费比车本身还值钱。

**词源 / 构词**
- **拆解**：price（名词「价格」；← 古法语 **pris**「价格、价值、报酬；荣誉、名声、称赞、奖品」← 晚期拉丁 **precium** ← 拉丁 **pretium**「报酬、奖品、价值」）+ **-y**（形容词后缀，此处表「多…的、以…为特征的」）。**pricey** **1932** 首见（etymonline）——**美国口语**；更早另有诙谐复合词 **high-pricey**，**1923** 年见于 F. P. Adams 一首与 spicy 押韵的打油诗（etymonline）
- **演变**（etymonline）：名词 **price** **c. 1200** 首见、形作 **pris**，早期义为「（非货币的）价值、价值；称赞」，继而「报酬、奖品、奖赏」；**mid-13c.** 起指「卖方索要的货款」。其来源古法语 **pris** 一身兼义「价格、价值、工资、报酬」与「荣誉、名声、称赞、奖品」——正是这种多义在法语中**分化**：**praise / price / prize** 三词在古法语里分家，**praise** 于 14c. 初进入中古英语，**prize** 的 **-z-** 拼写于 **late 1500s** 定型（etymonline）。现代名词 price「收回」了拉丁原有的**货币义**，抛掉了荣誉／称赞诸义。更上溯：拉丁 **pretium** 是 PIE 词根 **\*per- (5)**「to traffic in, to sell（买卖、出售）」的带后缀形式 **\*pret-yo-**。
- **同族 / 派生（pretium 一族——「价格 → 珍贵 → 看重 → 称赞」语义链）**：**precious**（珍贵的 ← 古法语 precios ← 拉丁 pretiosus ← pretium）、**appreciate**（欣赏、感激、增值——ad- + pretium，「给…定价 → 看重 → 欣赏」）、**appraise**（估价）、**appreciable**（可观的）、**depreciate**（贬值——de- + pretium）、**praise**（称赞 ← 古法语 preisier「估价、称赞」）、**prize**（奖品；珍视）、**price** 本身。**法语一侧**：**prix**（价格、奖项）、**précieux**（珍贵的，见 [[precieux]]）、**apprécier**（欣赏、评估）、**déprécier**（贬低）——**pretium 一源多路**分别进入英语与法语，两条支线各自分化。
- **记忆钩**：一条「价 → 贵 → 看重 → 称赞」的链：**pretium**（价格）分身为 price / prize / praise / precious / appreciate——「把东西看得很贵」自然就「称赞」它。pricey 是这条链上最口语、最年轻的一支（1932）。
- **法语对照**：见 [[precieux]]——法语 **précieux**（珍贵）与英语 **precious** 同出拉丁 **pretiosus**，法语 **prix**（价格）与英语 **price** 同出拉丁 **pretium**：**同一 pretium 根分别进英语与法语**，「价」与「贵」在两种语言里都由它生出。

**同义 / 搭配 / 易混**
- 搭配：a bit / rather / pretty pricey、pricey for + 场合（pricey for a Tuesday）、prohibitively pricey、pricey real estate / neighbourhood
- 近义：**expensive**（标准词，中性）、**costly**（代价高——可指非金钱的代价）、**dear**（英式口语「贵」；亦「亲爱的」）、**steep**（价格离谱——口语，多修饰 price / fee）、**exorbitant**（高得离谱——正式，强烈贬义）
- 语用：pricey 属**口语**，比 expensive 轻、比 exorbitant 温和，常带「东西不错但偏贵」的**半调侃**口吻；正式书面语少用
- 易混：**pricey ≠ priceless**——priceless 是「无价的、极珍贵的」（beyond price），**不能**用来指「贵」；**pricey vs precious**——precious 表「珍贵」（主观价值），pricey 表「贵」（标价高）
- 拼写：**pricey / pricy** 并见（同义异拼）
