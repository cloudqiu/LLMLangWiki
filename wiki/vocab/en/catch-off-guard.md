# catch off guard

**释义**：idiom ——**（在某人毫无防备 / 猝不及防时）打个措手不及、乘其不备**；常作 **catch sb off guard** / **be caught off guard**，指**因突然、出乎意料而一时应对不及**（措手不及、懵了、忙乱）｜ to surprise someone when they are not prepared or on their guard, so that they cannot react properly

**例句**
- _The question caught me completely off guard._ 那个问题打得我完全措手不及。
- _He was caught off guard by the sudden resignation._ 突如其来的辞职让他猝不及防。
- _Friendly at first, she tried to catch him off guard._ 她先摆出亲切的样子，想让他放松戒备再下手。

**词源 / 构词**
- **多词单位 / 收录说明**：本词为**习语（idiom）**，**etymonline 无「catch off guard」整条独立条目**——按惯例**回落其核心成分 guard / off (one's) guard** 核实（据 etymonline /word/guard 条），并说明如下
- **拆解**：**catch**（v.「抓住；撞见；使猝不及防」）+ **off (one's) guard**（「未设防的、松懈了戒备的」）——全片＝「**趁人松开防备时把他抓住**」
- **演变（off (one's) guard，据 etymonline /word/guard）**：**guard**（**n.**）**early 15c.** 首见（← 法语 **garde** ← 古法语 **garder**「守、护、保」；bodyguard 之「守」义亦 early 15c.）。其**击剑 / 拳斗义**（「防守姿势」）**1590s** 起——正是 guard 在**近身格斗中「护住自身」**之义，由此生出：**on (one's) guard**（**1640s**，保持防守 → 保持警惕）与 **off (one's) guard**（**1680s**，**未防守 → 麻痹、不设防**）。**catch** 加于其上，即「**在对方 off guard 时 catch（抓住）之**」——打他个措手不及。etymonline 记 **guard**（**v.**）**mid-15c.** 首见（或自名词 guard，或直接借古法语 garder），上溯**法兰克 \*wardon** ← 原始日耳曼 **\*wardon**「守」← PIE 词根 **\*wer-（3）**「觉察、提防」——英语另有整族同源的 **ward、wary、ware、warrant、guardian、regard、reward**
- **「catch」的成分**：**catch**（v.）借自古北法 / 古法 **cachier**「追逐、猎捕」← **俗拉丁 \*captiare** ← 拉丁 **captare**「试图抓取」（与 capere「拿、抓」同族）——与本义「**抓**」合得上（catch sb off guard = 「抓他个不设防」）。**词尾说明**：etymonline **无 catch off guard 整条**，故 catch 的**这段词源为通行推论，标待验证**
- **同族 / 派生**：off (one's) guard（1680s）、on (one's) guard（1640s）、guard（n. early 15c. / v. mid-15c.）、guarded（谨慎的）、guardian、regard、reward、ward、wary、ware（adj.「警觉的」）、warrant；**PIE \*wer-（3）「觉察、提防」**——etymonline 记「守护」族皆出此根
- **记忆钩**：**guard = 防卫姿势**（拳脚里护住要害）；**off guard = 松了架势、门户大开**；**catch = 一把抓住**——「趁对方架势一松就把他抓住」＝**打个措手不及**。反手：**on (one's) guard**＝防着点儿

**同义 / 搭配 / 易混**
- 搭配：**catch sb off guard**、**be / get caught off guard (by sth)**、**catch sb napping / on the hop / unawares**、take sb by surprise、be off one's guard
- 同义：**catch sb unawares**（乘其不备——最贴）、**take sb by surprise**（使吃惊）、**catch sb napping**（逮个正着 / 抓其疏忽）、**blindside**（措手不及地突袭——含「从背后 / 冷门方向」义）
- 易混 / 辨析：**catch off guard vs catch on the hop**——**语域 / 地域**：catch on the hop 为**英式**口语（「乘其不备、使人措手不及」），catch off guard 通用；**catch off guard vs be off one's guard**——**词性 / 用法**：前者为**动词习语**（须有 catch 的宾语 sb，「使人不备」），后者为**形容词性短语**（表**状态**，「（自己）不设防」，常作 be off one's guard）；**off guard vs on guard**——**反义对**：off (one's) guard（不设防）vs on (one's) guard（保持警惕；亦作口令「准备 / 起手式」）；**勿混 guard 的其它义**——guard（守卫者 / 列车员）与**格斗「架势」**同源，但 off guard 只用后者义
