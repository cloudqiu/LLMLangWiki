# intricate

**释义**：adj. ①错综复杂的、繁复难解的——an intricate pattern / plot ②（结构）盘根错节的、纠结交织的 ｜ very complicated or detailed; perplexingly entangled; hard to understand

**例句**
- _The watch contains an intricate mechanism of tiny gears._ 这块表内含一套由微小齿轮组成的精密复杂机构。
- _They uncovered an intricate web of corruption._ 他们揭开了一张盘根错节的腐败网络。
- _The plot is too intricate to summarize in a sentence._ 情节太复杂，难以一句话概括。

**词源 / 构词**
- **拆解**：**intricate** ← 拉丁 **intricatus**（动词 **intricare** 的过去分词，「to entangle, perplex, embarrass（使纠缠、使困惑）」）← **in-**「in（在内）」+ **tricae**（复数名词，「perplexities, hindrances, toys, tricks（纠葛、阻碍、玩物、诡计）」；etymonline 明注 **「a word of uncertain origin（词源不明）」**）
- **演变**：**intricate** 首见 **early 15c.**，见于**医学文献**，义「perplexingly physically entangled; complex in structure; hard to understand（身体上纠缠难解；结构复杂；难以理解）」（据 etymonline）。即由拉丁「使纠缠」的过去分词**直接借入**，无中间法语阶段。tricae 本身词源不明：**extricate**（**1610s**「disentangle, disengage, set free（解出、脱身）」）出拉丁 **extricare**，或为 **ex-**「out of」+ **tricae**——与 intricate **共享同一 tricae 词族线**（etymonline 亦将 **trick / intrigue** 列于本页同族）
- **谨慎说明**：任务提示「与 trick 同根」——etymonline 把 trick、intrigue 列为 intricate 的**相关条目**，但 **tricae 词源不明**，故只能记作「同一 tricae 词族线，具体同根关系**待验证**」，不宜断言
- **同族 / 派生**：**intricacy**（n.，**c. 1600**「state of being complex」；**1610s**「an intricate situation or condition」＝ intricate + **-cy**）、**intricately**、**intricateness**、**extricate**（1610s）、trick、intrigue
- **记忆钩**：拉丁 **tricae =「纠葛 / 诡计」**（词源不明）——**in-（在内）+ tricae = 陷在纠葛里 → 错综复杂**；反义操作 **ex-（在外）+ tricae = extricate**（从纠葛里脱身）。**in- / ex- 一对**，正好把两个词一起记牢

**同义 / 搭配 / 易混**
- 搭配：an intricate design / pattern / mechanism / carving；an intricate plot / web / network / relationship；intricate details
- 同义：complex、complicated、convoluted、elaborate、detailed、tangled、labyrinthine
- 反义：simple、plain、straightforward、elementary
- 易混 / 辨析：**intricate vs complex**——intricate 强调**细部繁多、盘绕交织**（似织锦 / 蛛网），complex 更中性、可指任何多部件系统；**intricate vs complicated**——complicated 强调**难懂 / 麻烦（主体感受）**，intricate 强调**结构本身的繁复精密（客体属性）**
