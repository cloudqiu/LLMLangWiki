# unattainable

**释义**：adj. 无法达到的、不可企及的、难以实现的 ｜ not able to be achieved, reached, or obtained

**例句**
- _The standard she set for herself was unattainable._ 她为自己设定的标准根本无法达到。
- _Perfect fairness in such a system is all but unattainable._ 在这样的制度里，完全的公平几乎不可企及。
- _He spent his life chasing an unattainable ideal._ 他一生都在追逐一个无法企及的理想。

**词源 / 构词**
- **拆解**：**un-**（否定前缀，古英语 un-）+ **attain**（← 古法语 **ataindre**「达到、触及」）+ **-able**（「能…的」后缀，← 拉丁 -abilis）。三层均为英语能产的构词成分——**attainable** **1640s**（attain + -able，etymonline）；**un-** 与 attainable 结合成 unattainable 是更晚的**英语内部构词**（etymonline **无 unattainable 独立条目**，其确切首见年代**待验证**）
- **演变**（etymonline）：**attain** **c. 1300** 首见，义「成功到达、接近到能触及」——原文 "succeed in reaching, come so near as to touch"；源自**古法语 ataindre** 的词干（11c.；现代法语 **atteindre**），上溯**俗拉丁 \*attangere**，对应**拉丁 attingere**「触；到达」＝ **ad-**「向」+ **tangere**「触」（PIE 词根 **\*tag-**「触、握」）。etymonline 强调 attingere 义域很宽：「to attack, to strike, to appropriate, to manage（攻击、击打、据为己有、处置管理）」——都从「触」这一具体动作引申。词义由**具体的「伸手够到」** → **抽象的「（目标、成就）达到」**，unattainable 承的正是这条抽象义。
- **同族 / 派生**：attain、attainable、attainment、**attainder**（法律「剥夺公权」——同出古法语 ataindre 的名词用法，mid-15c.，etymonline）；**同一 tangere「触」词根的大家族**：**tangent**（切线——几何上「只触及一点」）、**tangible**（可触的 → 可感的、实质的）、**intangible**（无形的）、**contact**（← con- + tangere「共同接触」）、**contagious**（传染的——「接触传染」）、**tact**（得体、分寸——由「触」的手感引申为社交的「触觉」）、**tactile**（触觉的）、**contiguous**（邻接的）。**tango** 亦常被系于此根——**存疑／待验证**
- **记忆钩**：tangere「触」＝伸手能碰到：**attain** 是「够到」，**un- + attain + -able** ＝「够不到的」。同一「触」根生出 tangent（切点）、tangible（摸得着）、contact（接触）——一串词都围着「碰得到碰不到」转。
- **法语对照**：法语 **atteindre**（达到）与英语 attain 同出古法语 **ataindre**——**共祖（同源），非借入**（英语在 13c. 借自法语，法语自身则由拉丁继承同一词）；「不可企及」法语说 **inaccessible**、**irréalisable**（无法实现）、**hors de portée**（够不着）。

**同义 / 搭配 / 易混**
- 搭配：an unattainable goal / dream / standard / ideal、virtually / seemingly unattainable、prove unattainable
- 近义：**unreachable**（够不到——最贴字面，偏物理或通俗）、**inaccessible**（无法接近／接触——偏物理、权利或情感上的「进不去」）、**unfeasible / impracticable**（不可行——讲方案本身行不通）、**impossible**（不可能——最绝对、最口语）、**out of reach**（够不着——短语）
- 易混：**unattainable vs unattained**——前者「达不到（不可能）」，后者「尚未达到（事实状态）」；**attain vs obtain**——attain 偏「达到（目标、境界）」，obtain 偏「取得（实物、许可）」，两者皆可加 -able，但 obtainable（可获得的）与 unattainable 侧重不同
- 反义：attainable、reachable、achievable、feasible
