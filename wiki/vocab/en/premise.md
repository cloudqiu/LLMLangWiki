# premise

**释义**：n.（推理的）**前提**、（大 / 小）前提；复数 **premises** ＝**房屋及地基、经营场所** ｜ v. 以……为前提；作为……的引言（正式） ｜ n. a statement assumed true and used as a basis for reasoning; (pl.) premises: a building and its land. v. to base an argument on something; to state as an introduction

**例句**
- _The argument rests on a false premise: that demand never falls._ 这个论证建立在一个错误前提上：需求永不下降。
- _The company is moving its premises to the outskirts._ 公司要把经营场所搬到市郊。
- _No alcohol is allowed on the premises._ 场内禁止饮酒。
- _The report premises its conclusions on data from 2020._ 这份报告的结论以 2020 年的数据为前提。

**词源 / 构词**
- **拆解**：**prae-**（前）+ **mittere**（送）→ **praemittere**「预先送出、置于前面」→ 其阴性过去分词 **praemissa**，用在逻辑术语 *(propositio) praemissa*「**被置于前面的**（命题）」里；经古法语 **premisse**（14c.）入英。同族拉丁动词线（皆出 mittere「送」）：**mission、emit、permit、submit、transmit、admit、remit、intermittent**。
- **演变（一条线，两义分化）**
  - **逻辑义（前提）late 14c.**，英语首见（经古法语 premisse ← 中世纪拉丁 praemissa）——etymonline。
  - **法律义 15c. 早期**：「matter previously stated（前述事项）」；在**契据、遗嘱**里，开头「前述」的段落常用来描述**房屋或建筑物**，于是 **1730 年**由这一用法生出扩展义「**house or building, with grounds（房屋及地基）**」（etymonline）。
  - **重点：premises「房舍」与「前提」是同源分化，不是两个词**——逻辑里「先说定的那句话」→ 法律文书里「上文所述的那处房产」→ 现代地产 / 法律意义上的 **the premises**（营业场所）。语义从「前述（的文字）」滑到「所述之物」，再固定到「那处不动产」。现代规范用法中**「场所」义一律用复数 premises**（单数 premise 表场所不合规范）。
  - **动词 mid-15c.**，由名词转出，义「to state before something else, set forth or make known as introductory to the main subject（先陈述、作为引言）」（etymonline）——注意此义与现代常用义「**以……为前提**」并不完全等同，后者为后起的引申（**年代待验证**）。
- **同族 / 派生**：**premiss**——同词的**异拼**（英式传统，逻辑 / 法律文本仍见，作名词「前提」）；**etymonline 的 premise 条未收录该拼写**，其年代与语域**待验证**。premises（场所）、premise（前提）；拉丁亲族见上（mittere 一族）。法语见下。
- **记忆钩**：**prae-（前）+ mittere（送）＝「先送出去的那一句」**——辩论前你先抛出、大家默认成立的那句，就是**前提**；法律文书开头先声明的那处地，就是 **premises（场所）**。同一条 mittere 送你一串词：mission（送出的事）、emit（送出光）、submit（送到下面＝呈交）、transmit（送到对面＝传送）。

**同义 / 搭配 / 易混**
- 搭配：**on the premise that…**（以……为前提）；a false / basic / underlying premise；the major / minor premise（大 / 小前提，三段论）；**on the premises / off the premises**（场内 / 场外）；business / licensed premises（营业 / 持牌场所）
- 同义：n. **assumption**（假设——可以无据）、**presupposition**（预先设定）、**postulate**（公设，学术）、**hypothesis**（待检验的假说）；premise 强调「被当作推理出发点」
- 易混（**本词条最该记的一条**）：**premise（前提）vs. premises（场所）**——只差一个 s，意思却横跨「逻辑」与「房产」两个域，是英语里最经典的「单复数不同义」之一。写作时 **on the premises**（在场内）与 **on the premise that…**（以……为前提）千万别写混。
- French（**同源**；法语页均未建——待回补）：法 **prémisse**（前提）同出**中世纪拉丁 praemissa**，与英语同源（英语且经古法语 premisse 中转）——二者都指回 praemissa，属**共祖 / 同借自中世纪拉丁**，**非一方借另一方**。另注意法 **prémices**「最初的成果、初熟之物」——**近形异义，别与 prémisse 混**（其词源通说 ← 拉丁 primitiae「初熟祭品」，**待验证**）。
