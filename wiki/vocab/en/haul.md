# haul

**释义**：v. ①（用力）拖、拉、拽——haul a rope / a sled ②（用车）运输、搬运——haul freight / coal ③（口语）传讯、拘捕（到法庭）——haul sb into court；n. ①拖、拉（的动作）②（一次的）运输量、路程——a long / short haul ③渔获；（引申）一大笔收获、赃物——a big / good haul ｜ to pull or drag with effort; to transport by vehicle; (n.) the act of pulling, a distance travelled, or the amount gained (as of fish or loot)

**例句**
- _They hauled the boat up onto the beach._ 他们把船拖上了沙滩。
- _Trucks haul freight across the country._ 卡车在全国各地运送货物。
- _The burglars made off with a haul worth thousands._ 窃贼带着价值数千的赃物逃走。
- _It has been a long haul, but the project is finally done._ 这一路漫长艰辛，但项目终于完成了。

**词源 / 构词**
- **拆解**：**haul**（v.）← 中古英语 **halen**「to drag, pull（拖、拉）」（见 **hale**）+ 古法 **haler**「to pull, haul, tow, tug（拉、拽、拖曳）」
- **演变**：**haul**（v.）首见 **1580s**，原拼 **hall**，是中古英语 **halen** 的变体；**-au- / -aw-** 拼法 **early 1600s** 出现（据 etymonline）。底词 **hale**（v.）**c. 1200**「drag, pull」，中古英语用于箭、弓弦、缰绳、剑、锚等；← 古法 **haler**（12c.），再溯**法兰克 \*halon** / 古荷兰 halen 等日耳曼源，终极溯原始日耳曼 **\*halon**「to call（呼叫）」← PIE 词根 **\*kele- (2)**「to shout（呼喊）」。hale 的比喻义「to draw (someone) from one condition to another（把人从一种境地拖到另一种）」见 **late 14c.**
- **名词 haul (n.)**：**1660s**「act of pulling（拉的动作）」由动词而来；**1776** 起有「something gained（所得 / 收获）」义，为比喻，etymonline 记其来源或为**一网所获之鱼量（the amount of fish landed in a single net-haul）**，或为「draw（取得）利润」之念——当代的「a big haul（赃物 / 大鱼 / 一大笔收获）」即由此而来（etymonline **未单列「big haul」的独立义项年代**）；「须拖运的距离」义 **1873** 见铁路用语（与运距定价「long hauls = lower rate per mile」相关）
- **同族 / 派生**：**hale**（v. 拖 / adj. 健壮的）、**haulage**（**1826**，运费 / 拖运）、**keelhaul**（**1660s**，荷 kielhalen「拖过船底」→「严厉申斥」）、**overhaul**（**1620s**，航海「反向松绳」，后「彻底检修」）、**halyard**（帆索）
- **记忆钩**：一条线全是「拉」：**hale / haul / halyard / keelhaul / overhaul**。**a big haul = 一网拉上来的收获** → 赃物 / 战利品；**long haul = 长途拖运** → 漫长艰苦的过程

**同义 / 搭配 / 易混**
- 搭配：haul a rope / a net / a sled / a catch；haul freight / goods / coal / timber；haul sb into court；a big / rich / record haul；a long / short haul；haul off（**1802**，AmE，抡拳前先向后一抽 / 撤退）；haul up（拉上来 / 停下 / 传讯）
- 同义：拖——drag、pull、tow、tug、lug；运输——transport、convey、carry、cart；收获 / 赃物——catch、yield、take、booty、loot
- 易混 / 辨析：**haul vs drag vs tow**——haul＝用力拖 / 搬运（**含运输义，用法最广**），drag＝**贴着地面费力拖**，tow＝**用绳 / 车牵引**；**hale vs haul**——今 **hale** 主要作形容词「健壮的（hale and hearty）」或法律「传唤」，**拖 / 拉义多已让位给 haul**
