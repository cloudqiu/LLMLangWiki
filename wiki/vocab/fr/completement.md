# complètement

**释义**：完全地、彻底地；（口语）十足地、非常（Il est complètement fou 他彻底疯了） ｜ d'une manière complète ; tout à fait, entièrement

**例句**
- _Il a complètement oublié notre rendez-vous._ 他把我们的约会完全忘了。
- _La ville a été complètement détruite._ 这座城市被彻底摧毁了。
- _Tu es complètement fou !_ 你真是疯了！（口语强调用法）

**形态要点**
- 副词，**无变化**（不随性、数变化）
- 构成：形容词 **complet** 的阴性 **complète** + **-ment**（以元音结尾的形容词用阴性形式构成副词：complète + -ment；同类：seule → seulement、sûre → sûrement）
- **拼写要点**：complet → complètement 词干元音加 accent grave（è）；别与形容词 **complet / complète**（完整的）混写——副词永远以 **-ment** 结尾
- 位置：一般跟在动词后（il a complètement changé 他彻底变了）；修饰形容词/副词时前置（complètement fou 完全疯了）

**词源 / 构词**
- **拆解**：**complet**（← 拉丁 **completus**「被填满的」——**complere** 的过去分词）阴性 + **-ment**（拉丁 **mente**「以……的方式」语法化而成的副词后缀）
- **演变**：拉丁 **complere**「填满、完成」＝ **com-**（完全）+ **plere**「填」（PIE \*pele-「满」）→ 过去分词 **completus** → 法语形容词 **complet**（**14c.**，Académie 9e——2026-10-03 经检索转引）→ 副词 **complètement**（complet + -ment）；**副词本身的首次出现年代检索未见明证——待验证**
- **同族 / 派生（法语）**：complet（adj. 完整的）、compléter（补足）、complément（补充物）、complétude（完备性）；「满」线另见 plein（满的）、plénitude（满盈）；英语一侧见下节
- **记忆钩**：complet 家族＝「装得满满」——com-（完全）+ ple（满，同 plein 的 plen-）＝「填满 → 完整 → 完全地」；complète + -ment 的 -èt- 音（/ɛ/）是听写常考点

**英法交叉核对（受影响的英语词）**
- **借入英语**：**complete**（adj. **late 14c.**「无欠缺的、完美的」← 古法语 **complet** 或直承拉丁 **completus**〔etymonline；OED 另注：古法语通行形式为 compli / complite，complet 系再拉丁化形式，Palsgrave 1530 载 complet——两说并列〕）；**complete**（v. late 14c.「使完整、完成」）；**completion**（late 14c. ← 中世纪拉丁 completionem）；**replete**（← 古法语 replet ← 拉丁 repletus，同出 plere「填」）
- **共祖未借入**：**completely**（adv. **early 15c.**「fully, entirely, wholly」＝ complete + **-ly**——**英语自构**；它与法语 complètement 是「同模型平行构词」（拉丁系形容词 + 本族副词后缀），**互不借贷**）
- 核对：已核实（etymonline / Académie 9e，2026-10-03 经检索转引）——英 complete（adj./v.）late 14c.、completion late 14c.、completely early 15c.（complete + -ly 自构，非借自法语）〔etymonline〕；法 complet 14c. ← 拉丁 completus（Académie 9e）；complètement 与 completely 构词平行；**待验证**：complètement 副词首证年代（检索未见明证）

**同义 / 搭配 / 易混**
- 搭配：`complètement oublier / changer / détruire`（完全忘记 / 彻底改变 / 摧毁）；`pas complètement`（不完全是）；口语强调 `complètement fou / complètement perdu`（彻底疯了 / 彻底迷路）
- **辨析（「完全」三档）**：**complètement**（彻底地——程度拉满，常修饰极端或负面状态：complètement fou / détruit）vs **tout à fait**（完全、一点不差——偏「恰好、绝对」的确认，由 [[tout]] 构成的固定短语，可独立应答：Tout à fait ! 完全同意）vs **entièrement**（整个地——强调整体、毫无保留：entièrement d'accord，语域偏书面）
- **faux ami**：complètement（adv.）≠ complet（adj.）——「完整的」是形容词（un repas complet 一顿完整的饭），「完全地」是副词；英语 completely 与 complete 的分工同构，别把形容词当副词用（别写 il a complet oublié）
