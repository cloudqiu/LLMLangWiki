# épice

**释义**：n.f.（厨）**香料、调味品**——用于调味、主要用于提味的植物部分。上位词 *condiment* ｜ partie de plante utilisée en cuisine pour assaisonner

**例句**
- _Cette recette demande plusieurs épices._ 这道菜谱需要好几种香料。
- _J'ajoute des épices à la sauce._ 我往酱里加香料。
- _Le safran est une épice très chère._ 藏红花是一种很贵的香料。

**形态要点**
- 名词：`l'épice`（**f.**）；复数 **épices**（规则）。亦为动词 *épicer* 的变位形
- 复数 **épices** 常泛指「香料」（多种）
- 方言变体：日内瓦 *espice*

**词源 / 构词**
- 拆解：拉丁 ***species***「种类」——该词在拉丁中**已扩展出「货品、药材」义**，再专指「**芳香料、香料**」（药剂师以 *species* 称其药料，意大利语因称药剂师为 *speziale*）→ 法语 *espice* → **épice**
- **⚠️ 少数说（照录不论断）**：少数来源主张阿拉伯语 **أبزار / أبازير**（*abzâr / abâzir*）——但 fr.wiktionary **已驳**：西班牙语 *abacería* 另有词源、且西语有 *especia*，故此说**属少数派**
- 首证：**约 1140 年**（fr.wiktionary）
- 同族 / 派生：**épicerie**（食品杂货店）、**épicier / épicière**（杂货商——与「香料商」同源）、**épicé**（加香料的；辣的）、**épicer**
- 记忆钩：**species「种类」→ 货品 → 香料**——中世纪**药剂师**把药料按「种类」分装，*species* 于是成了「香料」

**英法交叉核对（受影响的英语词）**
- **借入（英 ← 法）**：英语 **spice**（**c.1200**）← **盎格鲁-法语 *spece* / 古法语 *espice*** ← 晚期拉丁 *species*（复数，义「货品、香料」）
- **共祖（非经法语，直接拉丁）**：英语 **species**（**直接拉丁借入**）——与 *spice* 构成**同源双式词（doublet）**；同族另有 *special / especial / specimen / specify* 等，皆**直接溯拉丁 species**
- **核对要点**：**spice 走法语、species 走拉丁直借**——**同一拉丁 species 两度入英**，是本库可复用的「双式词」样本
- **反向借入**：无

**同义 / 搭配 / 易混**
- 同义：**condiment**（调味品，上位）、**aromate**（芳香料）
- 搭配：**épices**（复数泛指）、**épices au marché**、**mélange d'épices**（混合香料）；*épicerie*（食品杂货店）
- 易混：**épice**（香料）vs **épicé**（加香料的 / 辣的，形容词）vs **épicéa**（云杉，近形异义）
- **本库调味品簇互链**：[[piment]]（辣椒 / 辛香料）、[[moutarde]]（芥末）、[[sauce]]（酱汁）、[[recette]]、[[cuisine]]——*épice* 是这一簇的上位词
