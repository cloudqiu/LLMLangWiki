# meilleur

> 收录说明：inbox 原写作 **`meilleyr`**（手误 / 拼写变体）——按词典形 **meilleur** 编译建页，**待用户确认**。

**释义**：（1）**adj.（bon 的比较级）更好的**（Ce vin est meilleur que l'autre 这酒比那瓶好）；（2）**（带定冠词 le/la/les）最好的、最佳的**（le meilleur restaurant 最好的餐馆）；（3）**n.m. 最好的部分 / 最优秀者**（Que le meilleur gagne ! 愿最优秀者胜出）｜ comparatif et superlatif de bon ; qui a plus de qualités ／ (avec article) qui surpasse tout dans son genre

**例句**
- _C'est le meilleur restaurant de la ville._ 这是城里最好的餐馆。
- _Ce vin est meilleur que l'autre._ 这酒比那瓶好。
- _Elle travaille mieux que lui._ 她工作做得比他好。（**注意：这里是副词 mieux，不是 meilleur**）

**形态要点**
- 形容词：阳性 **meilleur** ｜ 阴性 **meilleure** ｜ 阳复 **meilleurs** ｜ 阴复 **meilleures**（-eur / -eure 型，屈折规则）
- 名词化：`le meilleur`（最好的东西 / 最优秀者）
- **异干补充（supplétion）——本词的核心语法点**：bon / meilleur / le meilleur 三形来自**三个不同的拉丁词根**（bonus / melior / optimus），与英语 **good / better / best** 完全平行——**类型学共性，非共同来源**
- **易混体系（必记）**：
  - **形容词**：bon → **meilleur** → le meilleur
  - **副词**：bien → **mieux** → le mieux
  - _Il est meilleur que moi._（他比我强——**形**，修饰人）｜ _Il travaille mieux que moi._（他工作比我好——**副**，修饰动词）
- 结构：`meilleur que`（比…好）｜ `le/la meilleure de`（…中最好的）｜ `de meilleur(e)(s)`（副词性用法：「（天气）更宜人」）｜ `meilleurs vœux`（祝福语）

**词源 / 构词**
- **拆解**：法语 **meilleur** ← 拉丁 **melior**（= bonus 的比较级）——经**宾格单数 meliorem 形式的一般化**而来；无前缀、无派生后缀（比较级词干 + 法语形容词屈折）
- **首证**：**Académie 9e：「xᵉ siècle」（10 世纪）**，注「Issu du latin melior, de même sens」；fr.wiktionary 该条标「**Date à préciser**」（**未定年**）——**两源不一**；古法语形 **meillor / meillur**（**待验证**：10 世纪对形容词偏早，暂记「Académie 9e：xᵉ siècle；待核」）
- **演变**：拉丁 melior（比较级）→ 古法 meillor → 现代 meilleur。词根 PIE **\*mel-**（「强、大」）另生拉丁 **multus / multi-**（multitude、multiply）与希腊 μᾶλλον
- **词源争议**：melior 的 IE 构拟存疑（\*mel- 的零级难解释其 e 元音）——属 bonus–melior–optimus 异干系列的**已知难题**，**并列存录**
- **同族 / 派生（法语）**：**améliorer / s'améliorer**（← 晚期拉丁 meliorare ← melior）、**amélioration**、meilleurement；短语 meilleur marché、meilleurs vœux、meilleur ouvrier de France（MOF）
- **记忆钩**：meilleur 与 bon **不同根**——「更好」的好是**另借来的一个词**（melior），正如英语 better 也不是 good 加后缀

**英法交叉核对（受影响的英语词）**
- **共祖（同出拉丁 melior，非法语借入）**：英语 **ameliorate**（v. 1728 ← 法语 améliorer / 中世纪拉丁 ameliorare ← melior）、**meliorate**（中古英语即见）、**amelioration**（1650s）、**melioration**（c.1400）、**meliorism**——**英语 wiki 尚未收录**
- **无关**：英语 **better** 与 melior **非共祖**（better ← 原始日耳曼 \*batizô）——与法语 bon / meilleur 属**平行异干**而非同源
- 核对：英语侧经检索转引 etymonline（2026-10-13）；法语侧 xᵉ siècle 据 Académie 9e 转引（**待验证**）

**同义 / 搭配 / 易混**
- 同义：supérieur（更好的）；反义：**pire**（更坏 / 最坏——← 拉丁 pejor，与 meilleur 恰成异干对）
- 搭配：`le meilleur ami`（最好的朋友）｜ `meilleurs vœux`（祝福）｜ `pour le meilleur et pour le pire`（无论祸福）｜ `du meilleur effet`｜ `c'est la meilleure !`（这下可好！——讽刺）
- **易混**：**meilleur**（形，修饰名词）vs **mieux**（副，修饰动词）——法语最高频错误点之一；相关 [[bon]]（本词的正级）
