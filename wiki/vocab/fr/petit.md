# petit

**释义**：（1）小的（un petit village 小村庄）；（2）年幼的（mon petit frère 我弟弟；quand j'étais petit 我小时候）；（3）微小的、微不足道的（un petit problème 小问题）；（4）（前置）亲昵 / 轻量色彩（mon petit chéri 我的小宝贝；un petit café 来杯咖啡）；（5）名物化：`le petit` 幼崽（le petit du loup 狼崽）；`un petit` 小家伙 ｜ de petite taille ; jeune ; peu important ; (前置) 表亲昵或弱化

**例句**
- _Ils habitent dans un petit village près de la mer._ 他们住在海边的一个小村子里。
- _J'ai un petit problème avec mon ordinateur._ 我的电脑有点小问题。
- _Petit à petit, l'oiseau fait son nid._ 循序渐进，水到渠成。（谚语：鸟儿一点一点筑成巢）

**形态要点**
- 形容词：阳性单数 `petit` ／ 阴性 `petite` ／ 阳性复数 `petits` ／ 阴性复数 `petites`——读 /pə.ti/ – /pə.tit/（petit 尾 -t 不发音，petite 发音）
- **位置效应（petit 的关键语感点）**：**前置**——常带「轻量、亲昵、不重要」的主观色彩（un petit problème 小问题〔几乎不算问题〕；un petit café 来杯咖啡；mon petit frère 弟弟）；**后置**——强调客观尺寸（une maison petite 一栋（客观上）小的房子——语法正确但少用，多用于对举：petite mais confortable）；常规语序为**前置**（与 grand / beau / jeune 同列主观评价类形容词）
- 比较级 / 最高级**规则**：plus petit（更小）、le plus petit（最小）——对照 bon → meilleur 的异干（petit 走规则线）
- 名物化 / 固定短语：`le petit`（动物**幼崽**——le petit du loup 狼崽）；`un petit`（小家伙——昵称）；`petit à petit`（渐渐地）；`un petit peu`（一点点）；`ma petite / mon petit`（亲爱的——称呼）；`au petit matin`（清晨）；`en petit`（小规模地 / 迷你版）；`petit déjeuner`（早餐——petit 已固化）；`petit ami / petite amie`（男朋友 / 女朋友）；`le petit prince`（小王子——见 [[prince]]）

**词源 / 构词**
- **拆解**：通俗拉丁 **\*pittittus / \*pettittus**「小」——属**表意 / 儿语层**（词根 \*pitt-「小」；对照晚期拉丁 **pitinnus**「小男孩」、意大利方言 pelo / piletto 等）；或作 Gallo-Romance \*pittīttus〔Dictionnaire historique、Revue de linguistique romane、Collins / WordReference 转引，2026-10-03〕
- **演变**：古法语 **petit** 约 **980** 首见，义「年幼」→ 现代法语 petit（小、年幼）〔检索转引，2026-10-03〕
- **另说（并列）**：1929《Revue de linguistique romane》曾驳「凯尔特来源说」，并提通俗拉丁 **\*pedetectus**（← pede tectus「以脚覆之」）——**少数派提议**；主流仍取表意 / 儿语来源的 \*pittittus——**无完全定论处如实并列，待验证**
- **同族 / 派生（法语）**：petite（阴性）、petitesse（渺小、琐碎）、rapetisser（缩小）、petiot（小家伙——口语）、petitement（拮据地、小气地）；英语一侧见下节
- **记忆钩**：petit 本身就是「儿语词」——pitt- 的叠音（pittittus）是大人在对孩子说话的语气；法语 petit 天然带亲昵色彩（mon petit），**词源与语用同频**

**英法交叉核对（受影响的英语词）**
- **借入英语**：
  - **petty**（adj.「琐碎的、小气的」——Middle English 14c（1325–75）← 古法语 **petit**「小」，原义仅「小」，后**语义贬化**：渺小 → 琐碎 → 小气；`petty cash`（备用金）、`petty theft`（小偷小摸）、`petty officer`（海军下士）等搭配中仍守中性「小」义〔Free Dictionary / Collins / WordReference 转引，2026-10-03〕）——**faux ami 警示**：法语 petit 中性 / 亲昵，英语 petty 说人时几乎必为贬义（"never a compliment"）
  - **petite**（adj.「（女子）娇小的」；女装尺码——英语直接借法语**阴性**形式；单独入英年代**待验证**）
  - **petit 修饰的借词**：**petit four**（n. 1884「小糕点」← 法语，字面「小炉子」——原指用低温「小炉火」烤出的精致小点；four ← 古法语 four ← 拉丁 furnus「炉」〔etymonline，2026-10-03 经检索转引〕）；**petit mal**（癫痫小发作）、**petit jury**（小陪审团）；法律术语 **petit larceny** 与 **petty larceny** 并存——同一词的法语形与英语形各行其道（petit larceny 与 petty theft 词源上同一）
- **共祖未借入**：无常用对应——英语本土「小」各出另源（**small** ← 古英语 smæl；**little** ← 古英语 lȳtel），与 \*pittittus 无关（英语词源未直连核——**待验证**）
- 核对：已核实（etymonline + 词典转引，2026-10-03）——petty ME 14c（1325–75）← 古法语 petit ← 俗拉丁 \*pittittus（表意来源）、后语义贬化出「trivial / 小气」；petit four 1884 ← 法语（four ← 拉丁 furnus）；法语 petit 约 980 首见（义「年幼」）；petite 为法语阴性形式借入。**待验证**：英语 petite 单独借入年代；\*pittittus 的凯尔特说之驳与 \*pedetectus 少数派说（1929 论文）学界现状；small / little 词源

**同义 / 搭配 / 易混**
- 搭配：`un petit peu`（一点点）；`petit à petit`（渐渐地）；`ma petite / mon petit`（亲爱的）；`au petit matin`（清晨）；`en petit`（迷你版）；`petit déjeuner`（早餐）；`petit ami / petite amie`（男朋友 / 女朋友）；`le petit prince`（《小王子》——见 [[prince]]）
- **易混（「小」的层级）**：**petit**（小——通用，可亲昵）vs **menu**（细小的——偏「细」）vs **minuscule**（微小的——程度更强）；对举 **[[grand]]**（大——petit 的头号反义；占位页，本库已登记待建）
- **位置辨析（进阶）**：un petit problème（轻描淡写：小问题，没事）vs un problème petit（客观尺寸小——几乎不说）；une petite ville（小城——常规，含亲切感）vs une ville petite（对举 / 强调尺寸）；**通则**：前置＝主观评价（grand / petit / beau / joli / jeune / vieux…），后置＝客观分类（颜色、国籍、学科等）
- **faux ami**：英语 **petty** 的贬义色彩（琐碎、小气、心胸窄）——法语 petit **无**此贬义；「a petty problem」≠「un petit problème」的语气（前者含嫌弃），翻译时 petty 常用 `mesquin / insignifiant` 对译
