# fois

**释义**：（1）次、回——表示动作重复的次数（deux fois par jour 每天两次）；（2）倍——表示倍数（deux fois plus grand 大两倍）；（3）用于固定短语表「同时／一旦／从前」等（à la fois 同时；une fois 一旦；il était une fois 从前） ｜ reprise, occasion ; multiplication ; dans des locutions (à la fois, une fois)

**例句**
- _Je vais au cinéma deux fois par mois._ 我每月去看两次电影。
- _Il était une fois un roi et une reine._ 从前有一位国王和王后。（故事固定开头，见 [[reine]]）
- _À la fois, il rit et il pleure._ 他同时又笑又哭。
- _Ne parlez pas tous à la fois !_ 别大家同时说话！
- _Cette table est deux fois plus grande que l'autre._ 这张桌子比那张大一倍（大两倍）。

**形态要点**
- 名词（n.f.）：`la fois`
- **复数不变**：`la fois / les fois`——词尾 **-s** 本已含（法语 fois 直接承自拉丁**复数** vices，**单复数同形**，永远不加第二个 -s）
- 阴性（la fois）；「次数」义**几乎总与数词或限定词同现**：une fois, deux fois, trois fois…, chaque fois, la première / dernière fois, combien de fois
- 量词式结构：`X fois par jour / par semaine`（每天／每周 X 次）；`X fois plus / moins … que`（比……大／小 X 倍）；`une fois sur deux`（两次里有一次、一半概率）

**词源 / 构词**
- **拆解**：拉丁 **vicis**——**缺项名词**（défectif，只存零散格形），义「轮次、交替、更迭、替代」；法语 fois 不来自单数，而**径直承自它的复数宾格／主格 vices**「一连串（可数的）轮次」——故法语 fois **天生是复数形**，单复数同形
- **演变（CNRTL/TLFi，2026-10-04 经 WebSearch 转引）**：
  - 拉丁 **vices** → 古法语 **feiz**（**xe s.**，Académie française 定；T-L / AND 作 *feiz1*）／**foiz**（TLF、Godefroy、DÉCT 形）→ 现代 **fois**
  - **v- → f- 之变（难点，诸说并列不折中）**：拉丁 v- 变 f- **难以解释**——一说 v 在**高频搭配**中受前接 -s 清化（*duas vices, tres vices, tantas vices, numerosas vices*）而成 f-（Wiktionnaire 说「malaisé à expliquer」）；一说经中间形 **vez**（*L'Étudiant* 转述）。⚠️ 关键：**同一拉丁 vicis 在 vicissitude / vice- / 前缀 vi- 中并未发生此变**——此变只见于 fois 一线
  - **语义分层（Ernout et Meillet 引于博士论文）**：vicis **单数**表「轮流、替换」（一物对另一物）；**复数** vices 表「一连串可数、可辨识的相似情境」，带时间与数量值——正是法语「次」义的来源；**晚期拉丁**已有「次」义（*altérā vice*「第二次」，ap. saint Jérôme）
  - **法语内的语义转移**：拉丁 vicis 的「**职位替换**」义在法语中**不再属于 fois**，而移给了前缀 **vi-** 与复合 **vice-**（vice-président 副总统）；「**轮流、轮次**」义残存于带单数主有形容词的构造 **sa fois / chacun sa fois**（沿用到 17c.）
- **同族 / 派生（法语）**：**parfois**（有时 ＝ par + fois，见 [[parfois]]）；**quelquefois**（偶尔）；**toutefois**（然而 ＝ toute + fois，义由「所有时候」转「尽管如此」，见 [[tout]]）；**autrefois**（从前 ＝ autre + fois）；**à la fois**（同时）；**une fois**（一次；一旦）；**il était une fois**（从前——童话固定开头）；**une fois pour toutes**（一劳永逸）；**à la fois… et…**（既……又……）
- **记忆钩**：fois 的「次」＝拉丁复数 vices「一轮一轮」——**「次」原本是「轮」**；记 **fois 单复数同形**（天生就带 -s，别再 +s）

**英法交叉核对（受影响的英语词）**
- **共祖未借入（拉丁 vicis 一线，本页核心）**：英语 **`vicissitude`**（n. **mid-15c**「（事物内部的）变动、盛衰交替」← 古法语 **vicissitude**（14c.）← 拉丁 **vicissitudinem**/vicissitudo「变化、更替」← 副词 **vicissim**「轮流地、反过来」← **vicis**「轮次、变更」← PIE **\*weik-**「弯曲、缠绕」）
  - ⚠️ 要点：vicissitude **确经古法语**入英，但它承的是拉丁 vicis 的**「更迭」义**，与法语 fois 的**「次」义**是**同一拉丁词的两条语义支**——**同源异义**（同根，非同义）
  - 同出 vicis 的英语词：**`vice-`**（vice-president 副总统 ＝「替代」义）、**`vice versa`**（← 拉丁 vice versā「位置互换」）——皆与 fois 共祖于 vicis
- **非同源对照（最易混，必记）**：英语表示「次」用 **`time`**（three times），但 **`time`** ← 古英语 **tima**「时间」← 原始日耳曼 **\*tima-** ← PIE **\*da-**「分割」——**日耳曼语来源，与拉丁 vicis 毫无亲缘**；且英语 time 的「一次、一回」（one of a number of repeated instances）义 **mid-14c** 才出现。**结论：法语「次」＝拉丁 vicis 一线，英语「次」＝日耳曼 tima 一线——同义异源**（与 [[vie]]↔life 的「同义不同源」同型）
- **另一对照**：英语 **`-fold`**（twofold 两倍 ← 古英语 **-feald**）对应法语的「倍」义（deux fois 两倍），但 **-fold 亦为日耳曼来源，与 fois 无亲缘**
- 罗曼语同源（共祖，横向对照）：义大利语 **`volta`**（「次」义用 volta，而 **vece** 只留「替换」义）；西语 **`vez`**（«vez» ← vices，**保留 v-**，与法语 fois 的 f- 相对照，正可见 v→f 是法语独有之变）；葡语 **vez**、加泰语 **vegada**
- 核对：英语侧（vicissitude mid-15c ← 古法 vicissitude 14c ← 拉丁 vicissitudinem ← vicissim ← vicis ← PIE \*weik-；time ← 古英语 tima ← 日耳曼 \*tima- ← PIE \*da-，「次」义 mid-14c）2026-10-04 经 **etymonline 直读／检索**；法语侧（étymon「latin vices, pluriel de vicis」、古法 feiz xe s. / foiz、v→f 诸说、Ernout et Meillet 的语义分层、晚期拉丁 altérā vice「第二次」）2026-10-04 经 **WebSearch 转引 CNRTL/TLFi 与 Académie française**（CNRTL 直连仍失败）

**同义 / 搭配 / 易混**
- 搭配：`une fois / deux fois / …`（一／两次）｜ `X fois par jour / semaine / mois`（每天／每周／每月 X 次）｜ `à la fois`（同时）｜ `une fois`（一次；一旦）｜ `une fois que`（一旦……就……）｜ `chaque fois que`（每当）｜ `toutes les fois que`（每次）｜ `il était une fois`（从前——童话开头）｜ `une fois pour toutes`（一劳永逸）｜ `deux fois plus grand`（大两倍）｜ `à la fois… et…`（既……又……）
- **易混（同音三词，写作高频失分点）**：**fois**（次，n.f.）/fwa/ ｜ **`foie`**（肝，n.m.）/fwa/ ｜ **`foi`**（信念、信仰，n.f.——la foi 信仰、ma foi 说真的）/fwa/——**三词同音异形**（同 [[quand]] 页 quand / quant / qu'en 之例）
- **易混（同族副词）**：**parfois**（有时，不定）｜ **quelquefois**（偶尔，偏书面）｜ **toutefois**（然而，书面）｜ **autrefois**（从前）——皆 fois 加限定成分的复合副词，注意语义各异（见 [[parfois]]）
- 相关：[[parfois]]（par + fois）；[[tout]]（toutefois 含 tout）；[[quand]]（同音陷阱同型）；[[heure]]（时间轴词汇）

**n.f.** 次、回（deux fois par jour 每天两次）；倍（deux fois plus grand 大两倍）
**形态**：la fois；**复数不变 les fois**（词尾 -s 本已含，← 拉丁复数 vices，单复数同形）；常与数词同现
**词源**：拉丁 vicis「轮次、交替」（缺项名词）的**复数 vices** → 古法 feiz（**xe s.**）/ foiz → fois；**v- → f- 成因有争议**（受前接 -s 清化说 ／ 经 vez 说）
**英法交叉**：英 `vicissitude`（**mid-15c** ← 古法 vicissitude 14c ← 拉丁 vicis）与 fois **同源异义**；`vice-` / `vice versa` 同出 vicis；英 `time`（「次」义，mid-14c）← 古英语 tima（日耳曼 \*tima-）与 fois **同义异源**；西语 `vez` 保留 v-
**同音**：fois（次）＝ `foie`（肝）＝ `foi`（信仰）——均 /fwa/
==la== fois（阴性 n.f.；**复数不变**）
