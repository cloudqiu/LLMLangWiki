# diplôme

**释义**：（1）文凭、毕业证书（le diplôme du baccalauréat 高中毕业文凭）；（2）学位、学历资格（un diplôme d'ingénieur 工程师文凭）；（3）（旧）文书、证书 ｜ titre ou certificat officiel délivré par une autorité

**例句**
- _Elle a obtenu son diplôme de médecine l'an dernier._ 她去年拿到了医学文凭。
- _Il prépare un diplôme d'ingénieur._ 他在攻读工程师学位。
- _Passer un diplôme demande beaucoup de travail._ 考取文凭需要下很多功夫。

**形态要点**
- 名词：`le diplôme`（m.）；复数 `les diplômes`
- **拼写**：ô 为长音记号（1990 拼写改革不动 â / ê / ô——保留 diplôme 写法）；勿写 diplome
- 派生：**diplômé(e)**（n./adj. 毕业生；持文凭的：un diplômé en droit 法学毕业生 ／ elle est diplômée de la Sorbonne 她毕业于索邦）
- 搭配动词：**obtenir / passer / préparer / décrocher** un diplôme；être diplômé de + 学校

**词源 / 构词**
- **拆解**：拉丁 **diploma**（-atis）「官方文书、通行推荐状」← 希腊 **diplôma**「对折之物（纸/板）」＝ **di-**（双）+ **plo-**（折，同 plier / ployer 的折线；希腊 diploûs「双的」）+ -ma（名词后缀）——「对折的文书」
- **演变**：希腊 diplôma → 拉丁 diploma（帝国时期「特许状、官方文书」）→ 法语：**1617** diplomat「敕令」（CNRTL）；**1721**「charte 文书」（Trévoux）；**1810**「授予头衔、学位的官方证书」（Staël, De l'Allemagne——CNRTL）；Académie 9e：18 世纪首见（「charte」义）
- **同族 / 派生（法语）**：**diplômé(e)**（毕业生）；**diplomatique**（文书学 → 外交的；← 近代拉丁 diplomaticus，1680s）；**diplomate**（外交官——19 世纪初由 diplomatique 逆行构词）；**diplomatie**（外交——由 diplomate 构成）
- **记忆钩**：diplôme ＝ di-（二）+ plo-（折）——文凭就是一张「对折的官方文书」；同一条「折叠文书 → 国书 → 外交」的线延伸到 diplomate / diplomatie

**英法交叉核对（受影响的英语词）**
- **借入英语**：**diploma**（n. **1640s**「state paper, official document」← 拉丁 **diploma**（复数 diplomata）← 希腊 diplôma；现代「文凭」义 **1680s**）；**diplomat**（**1813** ← 法语 **diplomate**）；**diplomacy**（**1793** ← 法语 **diplomatie**）——etymonline，2026-10-03 经检索转引
- **共祖未借入**：**diplomatic**（adj. 外交的——经法语 **diplomatique** ← 近代拉丁 **diplomaticus**（1680s）「文书学的」；英法同出拉丁线；英语首证年代未核——**待验证**）
- 核对：已核实（CNRTL / Académie 9e / etymonline，2026-10-03 经检索转引）——法 diplôme 各义见载 1617（diplomat 敕令）/ 1721（charte）/ 1810（学位证书）；英 diploma 1640s（文凭义 1680s）← 拉丁 diploma；diplomat 1813、diplomacy 1793 ← 法语；**待验证**：英 diplomatic 首证年代

**同义 / 搭配 / 易混**
- 搭配：`obtenir / passer / préparer / décrocher un diplôme`；`un diplôme universitaire`（大学文凭）；`être diplômé de…`（毕业于……）；具体学位名：le baccalauréat、la licence、le master、le doctorat
- **易混**：**diplôme**（文凭）vs **diplômé(e)**（持文凭者——多一个 -é 变名词/形容词）：un diplômé a obtenu un diplôme；求职 / 职场簇见 [[postuler]]、[[carriere]]，学校见 [[ecole]]
- **faux ami**：英语 **diploma** ≈ 法语 diplôme（对齐）；但英语 **diplomat**（外交官）对应法语 **diplomate**——别与 diplôme（文凭）混
