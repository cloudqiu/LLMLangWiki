# aide-moi

> 收录说明：inbox 形式 `aide-moi`——按多词单位（v1.5）独立建页（**动词 + 附着代词**的黏合形）；库内尚无独立 `aider` 页。

**释义**：帮帮我、救救我（对 **tu** 的**肯定命令式**） ｜ impératif présent d'*aider* à la 2ᵉ personne du singulier, avec pronom complément enclitique

**例句**
- _Aide-moi, s'il te plaît !_ 请帮帮我！
- _Aide-moi à porter cette valise._ 帮我提一下这个箱子。（aider qn **à** faire qch）
- _Ne m'aide pas, je peux le faire seul._ 别帮我，我自己能做。（**否定式：代词前置**）

**形态要点（本页重点）**
- **构成**：**aide**（`aider` 的 **tu 命令式**）＋ **moi**（重读人称代词，肯定命令式中**后置**、以**连字符**相连）
- **命令式代词规则（核心考点）**：
  - **肯定命令式**（impératif affirmatif）：代词**后置**，用**连字符**——aide-**moi**、donne-**le**-**lui**、parle-**lui**、va-**t'**-en；代词取**重读形** moi / toi（\*aide-je、\*aide-te 不成立）
  - **否定命令式**（impératif négatif）：代词**前置**，按常规语序——**ne m'aide pas**、ne lui parle pas、ne le lui donne pas
  - **例外（为谐音保留 -s）**：`aides-y`、`vas-y`、`penses-y`——-er 动词 tu 命令式本**去 -s**，但**后接 y 时保留 s**（谐音联诵 /ɛd.(z)i/）；后接 **en** 则**不**保留——`donne`-en ✓（\*donnes-en ✗）
  - **叠用顺序**（与 [[la-pron]]、[[en-pron]]、[[y]] 一致）：me / te / nous / vous / se 在前 → le / la / les 居中 → lui / leur 在后 → 再接 y / en。例：**donne-le-moi**、**donne-m'en**（me + en → **m'en**）、**emmène-nous-y**
- **-er 动词 tu 命令式通则**：形 ＝ 直陈式 présent 的 tu 形**去 -s**（tu aides → **aide !**）——故 aide 与 je / tu 形同形（无 -s）
- **语域 / 人称**：对 **tu** 的命令（亲疏）；尊称 / 复数用 **aidez-moi**（vous 形，**同规则**：代词后置连字符）；第一人称复数 **aidons-le**
- **音**：连字符处**联诵**——aide-moi /ɛd‿mwa/；va-t'en 的 **t** 为谐音插入
- **对照（非 -er 动词保留 -s）**：**fais-moi**（[[faire]]，3e groupe，fais 保留 s）、**va**（[[aller]]：va-t'en / vas-y）、**sois**（[[etre]]）——即「-er 去 -s，其余多保留」的分野

**词源 / 构词**
- **拆解（aider）**：← 拉丁 **adjutare**「帮助」——本身是 **adjuvare**（＝ **ad**「向」+ **juvare**「帮助、给力、支持」）的**反复态（fréquentatif）**；词干 **juvare** 的 PIE 来源**不确定**——etymonline 记「possibly connected」于 **iuvenis**「年轻人」（经 young 联想），**并列不折中**
- **演变**：拉丁 adjutare → 古法语 **aidier**；语音两步——**-u- 脱落**（aiutare → aitare）+ **元音间 t 浊化为 d**（aitare → aidare → aider）；古法异体 aidier / aïdier / haider / haydier。名词 **aide**（n.f. 帮助；助手）← 晚期拉丁 **adiuta**（adiutus 的阴性，adiuvare 的过去分词）
  - **关键记录**：拉丁 **adjuvare 本身在罗曼语中消失**（仅意语 *giovare* 存 juvare 简单式），**唯反复态 adjutare 全面胜出**——西语 ayudar、意语 aiutare、葡 / 加泰 ajudar、法语 aider 皆 adjutare 一线；另有古法异体 *aïawe / aiwe* 见 **adjuvare** 的词形影响
- **拆解（toi / moi）**：**moi** ← 拉丁 **me**（第一人称单数宾格 / 夺格），受格**直接继承**、取**重读形**；与非重读附着形 me 分工（命令式后置时必用 moi / toi）
- **同族 / 派生（法语）**：aide（n.f.）、aide-soignant、aide-mémoire、**à l'aide !**（求救！）、entraide、entraider；英语一侧见下节
- **记忆钩**：aider 的祖先是 **adjutare = 反复态**——「**反复去帮**」→ 帮忙；aide-moi 的**连字符**正是「动词 + 被推到身后的代词」的黏合标记（否定时代词又被拉回动词**前面**，连字符随之消失：ne **m'**aide pas）

**英法交叉核对（受影响的英语词）**
- **借入英语（同源借入：同一拉丁源、同一路径经古法）**：英 **`aid`**（n. **early 15c.** 形 *aide*，初为「战时税」及「援助」← 古法 **aide** ← 晚期拉丁 **adiuta**）；英 **`aid`**（v. **c.1400** *aiden* ← 古法 **aidier** ← 拉丁 **adiutare**）——与法语 `aider` **同一拉丁源、同一经古法路径**；相关：英 **`aide`**（n. 助手；← **aide-de-camp** 1660s，短形 **1777**）、`aide-de-camp`、`Band-Aid`、`Medicaid`、`unaided`
- **共祖（拉丁直借，非经法语）**：英 **`adjutant`**（n. 副官）← 拉丁 adjutare 的现在分词 *adjutans*（adjutare 一线）；**`adjuvant`**（n./adj. 佐剂）← 拉丁 adjuvare / adjutare 一线——**同源共祖**，与法语 aider **平行**（勿与「经古法借入」的 aid 混）；`adjutancy`、`adjutator` 同族。**（年代待验证：adjutant 一作 1590s、adjuvant 一作 1570s，未逐条直读 etymonline 原条）**
- **共祖链（不确定项，如实并列）**：juvare「帮助」的疑似亲缘 **iuvenis**「年轻」——英语 `young`（← 古英语 geong ← 原始日耳曼 ← PIE \*h₂yuh₁en-）**是否与 juvare 同根尚无定论**（etymonline 记「possibly connected」）——**并列不折中**
- 核对：aid n. early 15c. / v. c.1400 / aide-de-camp 1660s / 短形 1777 据 **etymonline 直读**（2026-10-04）；adjutant / adjuvant 的年代与形态**待验证**。法语侧：adjutare ＝ adjuvare 的反复态、adjuvare 在罗曼语中消失而反复态胜出、-u- 脱落与 t→d 浊化、古法异体 aidier / haider、名词 aide ← 晚期拉丁 adiuta，据检索转引词源 / 语法文献（grammaire des langues romanes、Brachtel / Sainéan 等；**未得 TLFi 原文**）。

**同义 / 搭配 / 易混**
- 搭配：`aider qn`（直接宾语，无介词）；`aider qn à faire qch`（帮某人做某事——**à + 不定式**）；`aider à qch`；`s'aider de qch`（借助某物）；`à l'aide !`（求救）
- 同义命令：`secours !` / `au secours !`（救命！）；`tu peux m'aider ?`（口语请求）；`donne-moi un coup de main`（口语「搭把手」）
- **易混（代词位置 —— 本短语第一考点）**：**Aide-moi !**（肯定：代词**后置** + 连字符）vs **Ne m'aide pas !**（否定：代词**前置**，连字符消失）
- **易混（-s 谐音）**：`aides-y`（保留 s）vs `donne-en`（不保留 s）——1 组动词命令式 + **y 保留 s** / + **en 去 s**
- 相关：[[la-pron]]、[[en-pron]]、[[y]]（宾语代词与叠用顺序）；[[faire]]、[[aller]]、[[etre]]（命令式保留 -s 的对照）
