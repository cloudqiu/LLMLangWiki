# tout le temps

**释义**：loc. adv. **不停地、总是、一直** ｜ sans cesse, toujours

**例句**
- _Il est tout le temps en retard._ 他总是迟到。
- _Elle parle tout le temps._ 她讲个不停。
- _Je pense à toi tout le temps._ 我一直想着你。

**形态要点**
- 副词短语（locution adverbiale），**不变**
- 由 **tout** + **le** + **temps** 组合的**自由短语**；fr.wiktionary 明示该条**词源缺失**（无世纪、无出处）
- 位置：可与动词搭配放句末，或置于句首作时间状语（*Tout le temps, il…*）

**词源 / 构词**
- 拆解（分字溯源）：**tout** ← 拉丁 **totus**「全部」；**le** ← 拉丁 **ille**「那个」；**temps** ← 拉丁 **tempus**「时间」
- 首证：**待验证**——**无权威词典给出该短语整体的首证年代**（各词典只做词组分解）。本年表按「副词短语，首证待验证」处理
- 同族 / 派生：**temps** 词族——**temps**（时间 / 天气）、**temporaire**、**temporairement**、**printemps**（春天——*primum tempus*「最初之时」）、**contretemps**（意外、不合时宜）
- 记忆钩：**tout（全部）+ le temps（时间）**——「把全部的时间都…」＝**一直**

**英法交叉核对（受影响的英语词）**
- **借入**：**无**——英语 *all the time* 为本土组合（all ← 古英语 *eall*），与法语无词源关系
- **共祖（非经法语）**：英语 **tense**（n.「时态」）← 拉丁 *tempus*，**经古法语 *tens* 为部分中介**——与法语 *temps* **共祖**（*tempus*）。拉丁 *tempus* 亦生 **temporal / temporary / tempo**（*tempo* 经意大利语）
- **核对要点**：法语 *temps*「时间 / 天气」两义同形（都出 *tempus*），英语则分成 time / weather 两词——**法语一词兼两职**，是母语者易忽略的点

**同义 / 搭配 / 易混**
- 同义：**toujours**、sans arrêt、constamment、en permanence、continuellement
- 搭配：tout le temps（句末 / 句首皆可）；**comme tout le temps**（像往常一样）
- **易混（重点）**：**tout le temps** vs **toujours**——*toujours* 兼「**仍然**」义（*Il est toujours là* 他还在 / 他总是在），而 *tout le temps* **只表「一直、总是」（频度）**，**不表「仍然」**——母语者高频错点
