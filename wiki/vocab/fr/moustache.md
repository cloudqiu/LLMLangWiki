# moustache

**释义**：（1）**髭、小胡子**（**上唇**的胡须——与下巴的 *barbe* 相区别）；（2）**（复数）moustaches** ＝ 髭；（3）**（动物）触须**（chat à moustaches）；（4）**vieille moustache** ＝ 老兵（旧称，因骑兵留髭） ｜ poils qui poussent au-dessus de la lèvre supérieure

**例句**
- _Il s'est laissé pousser la moustache._ 他留起了小胡子。
- _Le chat retrouve son chemin grâce à ses moustaches._ 猫靠触须找回路径。
- _Il a une moustache en croc._ 他留着一撮上翘的髭。

**形态要点**
- 名词：`la moustache`（**f.**）；**通常用复数 moustaches**（一根根称 *un poil de moustache*）
- **⚠️ 英法分区（重点）**：法语区分 **moustache**（上唇的髭）｜ **[[barbe]]**（下巴 / 两颊的胡须）——英语 **mustache / beard** 亦分，但别把 la barbe 说成 mustache
- 派生：**moustachu**（留髭的）、**s'emmoustacher**（留起髭）、**moustache en croc / en guidon / à l'américaine**（各种髭型）、**vieille moustache**（老兵）

**词源 / 构词**
- **拆解**：**借自意大利语 mostaccio**（Académie 记**那不勒斯语 mustaccio**）← **中世纪 / 晚期希腊语 moustakion**（← 古希腊 **mystax** γ. *mystakos*「**上唇**」的**指小**）; 与希腊 **mastax**「颌 / 嘴」相关（或 ← PIE ***\*mendh-***「咀嚼」；Beekes：整组或系**前希腊语（Pre-Greek）**）
- **演变 / 首见多说不一**：TLFi **1511**（Usito 引）；另 **1549**；Académie 9e「**xvie s.**」；Le Parisien「**fin xve s.**」（查理八世意大利战役）——**多说并列**（fr.wiktionary 记「date à préciser」）
- **同族 / 派生（法语）**：moustachu、emmoustacher、moustache en croc、`se friser les moustaches`、vieille moustache
- **记忆钩**：moustache 是**意大利语给的法语词**——文艺复兴时经意大利战役与时尚涌入；再经法语，变成英语的 **mustache**（第三条手）

**英法交叉核对（受影响的英语词）**
- **借入英语**：**mustache / moustache**（**1580s**）← **法语 moustache**（15c）← 意大利 mostaccio ← 中世纪希腊 moustakion；更早英语 **mostacchi**（**1550s**）← 意大利 / 西班牙 **mostacho**（另一条路）
- **拼写史**：原英语拼作 **moustache**（法式），美式 **mustache** 至 20c 中期才占主流——**英美拼写分歧的标本**
- **同义异源**：无（英语必须借词，本族无对应）
- 核对：英语侧（mustache 1580s ← 法语 moustache；mostacchi 1550s ← 意 / 西）经检索转引 etymonline（2026-10-11）；法语侧 1511 / 1549 / fin xve 与 mystax 链据 TLFi / Académie 9e / Le Parisien 转引（**待验证**）
- **命名提示**：本页占 basename `moustache`——英语侧日后收 **moustache**（英式拼法）**须记 `moustache-en.md`**（已登 [[french-vocabulary]] 命名消歧表），两页互标

**同义 / 搭配 / 易混**
- 搭配：`se laisser pousser la moustache`（留髭）｜ `une moustache en croc`（上翘的髭）｜ `se friser les moustaches`（捋髭，得意状）｜ `vieille moustache`（老兵）
- **易混**：**moustache**（上唇的髭）vs **[[barbe]]**（下巴 / 两颊的胡须，整体）vs **favoris**（络腮 / 鬓须）vs **bouc**（山羊胡）
