# morceau

**释义**：（1）一块、一片、一段（un morceau de pain 一块面包）；（2）片段、乐段（un morceau de piano 钢琴曲片段）；（3）碎块、残片 ｜ une partie d'un tout ; un extrait ; un fragment

**例句**
- _Je voudrais un morceau de gâteau._ 我想要一块蛋糕。（见 [[gateau]]）
- _Il a mangé un morceau de pain._ 他吃了一块面包。
- _Elle joue un morceau de Chopin._ 她弹奏了一首肖邦的乐曲（片段）。

**形态要点**
- 名词：`le morceau`（m.）；复数 `les morceaux`——**-eau → -eaux** 复数不规则（gâteau → gâteaux 同理）
- 核心搭配：`un morceau de + 不可数/整体`（一块……：un morceau de fromage / de bois / de sucre）
- 音乐义：`un morceau`（一段乐曲、一支曲子）——常用 `un morceau de musique / de piano`，也可指「乐章、选段」

**词源 / 构词**
- **拆解**：拉丁 **morsum**「被咬下的一口」（**mordere**「咬」的过去分词中性名词）→ 通俗拉丁指小 **\*morsellum**「小小一口」→ 古法语 **morsel** → morceau（-eau 由 -el 元音化而来）
- **演变**：PIE ***mer-**「磨、损伤」→ 拉丁 mordere「咬」→ morsum「被咬的一口」→ 通俗拉丁 \*morsellum（指小 -ellum）→ 古法语 morsel → 法语 morceau（「一小块」→「片段、乐段」的引申）
- **同族 / 派生（法语）**：mordre（咬）、morsure（咬伤、咬痕）、mordiller（轻轻咬）、remords（懊悔——re- 反 + mordre「反咬」，即「良心反噬」）；英语一侧见下节
- **记忆钩**：morceau 的祖先是一「口」——「被咬下的一小块」；同根的 remords（懊悔）就是「被良心反咬一口」

**英法交叉核对（受影响的英语词）**
- **借入英语**：**morsel**（n.「一口、小块食物」late 13c. ← 古法语 **morsel**〔现代法语 morceau〕，是 mors「一口」的指小 ← 拉丁 morsum ← mordere「咬」〔etymonline，2026-10-01 经检索转引〕）——注意：英语借入的是**更早的古法语形态 morsel**，法语自身已演变为 morceau，属「同一词、英语保留古形」的样本；**mordant**（adj.「尖刻的」← 法语 mordant「咬人的」，mordre 的现在分词）
- **共祖未借入**：**remorse**（← 古法语 remors / 拉丁 remordere——经法语线）；**mordacious / mordacity**（← 拉丁 mordax「爱咬的」，直承拉丁）
- 核对：已核实（etymonline，2026-10-01 经检索转引）——morsel late 13c.，注明「← 古法语 morsel（现代法语 morceau），mors『一口』的指小，← 拉丁 morsum ← mordere，或出自 PIE \*mer-『磨、损伤』的扩展形」

**同义 / 搭配 / 易混**
- 搭配：`un morceau de pain / de fromage / de gâteau`（一块面包 / 奶酪 / 蛋糕）；`manger un morceau`（口语「随便吃点东西」）；`un morceau de musique`（一支曲子）；`casser en morceaux`（打碎成块——见 [[casser]]）
- **易混（「块 / 片」家族）**：**morceau**（一块——不规则的碎块、切割出的一块）vs **pièce**（件、块——零件、房间、硬币、剧本，义域更广）vs **tranche**（薄片——切下的一片，tranche de pain 面包片）vs **part**（一份——分配意义上的部分）；音乐义 **morceau**（乐曲片段）vs **pièce**（乐曲——整首）
- **faux ami**：morceau ≈ piece / bit / morsel（英语 morsel 专指「一口食物」，比 morceau 义域窄）
