# quelque chose

> 收录说明：inbox 形式 `quelque chose`（多词单位）→ 文件名 `quelque-chose.md`，word 保留空格原形。本页办**中性不定代词**页，核心语法点是「主语单数 + 形容词借 de 引入且用阳性」。

**释义**：某物、某件事、某个东西——**中性不定代词**，指未确定的物或事 ｜ une chose indéterminée ; pronom indéfini neutre

**例句**
- _J'ai quelque chose à te dire._ 我有件事要告诉你。
- _Quelque chose de grave s'est passé._ 发生了严重的事情。（**de + 阳性形容词**）
- _Il y a quelque chose comme six mois._ 大约有六个月了。（quelque chose comme ＝ 大约）
- _C'est déjà quelque chose !_ 这已经很了不起了！（fig. 表「不简单」）

**用法要点**
- **作主语时动词用单数（本页最核心）**：**Quelque chose est arrivé**（不是 \*sont arrivés）；因「物」而不辨性，回指用中性代词 **il** 或关系代词 **qui**——Quelque chose **qui** me plaît；Il s'est passé quelque chose, **il** me semble…
- **形容词必须借 de 引入、且用阳性单数**：quelque chose **de** + adj **m. sg.**——quelque chose **de beau / de grave / de nouveau / de bizarre**（**不是** \*quelque chose belle，也不能直连形容词）；个别文学用法直连（Roubaud《Quelque chose noir》）属例外。
- **变体与形近**：**quelqu'un**（人）｜ **quelques-uns / quelques-unes**（「一些」人 / 物，复数代词）｜ **quelque chose**（物 / 事——本页）——三者勿混；另 **quelque + 名词**（quelques livres 几本书）是**限定词**用法，非本页代词。
- **古代 / 方言的阴性**：少数作家让「chose」恢复阴性（回指或形容用阴性——Claudel 1894、Bernanos 1926、Ponge 1952），属文学例外。
- **口语与搭配**：快读 /kɛk.ʃoz/；`quelque chose comme` ＝「大约」（＝ environ）；疑问时用 **quoi**（Tu veux **quoi** ? 见 [[quoi]]）。
- **分写 vs 合写**：**quelque chose**（合写两词，代词「某事」）≠ **quel que**（分写，让步 quel…que + subj.，见 [[quel]]）。

**词源 / 构词**
- **拆解**：**quelque**（← **quel**「何种」+ **que**）+ **chose**「东西、事情」——字面「**某个东西**」
  - **quel** ← 拉丁 **qualis**「什么样的」（疑问 / 关系形容词，与 talis 相对——见 [[quel]]）
  - **chose** ← 拉丁 **causa**「原因、诉讼、事情」——**古罗马俗拉丁里 causa 顶替了古典的 res「物」**，义由「原因 / 事由 / 案件」滑向泛指的「东西」
- **演变（CNRTL/TLFi、DHLF，2026-10-05 转引）**：
  - **chose**：**842** *cosa*「具体的或抽象的事」（《斯特拉斯堡誓词》——**最早的法语书面文献**之一）→ **ca 880** *niule cose*「没什么」（《圣欧拉莉传》）→ 12c 初 *chioses / chose / cose*；TLFi：「Du lat. *causa* … qui, à partir du sens de "affaire", a pris en b. lat. le sens de "chose"」——**chose 与 cause 是同一拉丁 causa 的「通俗形 / 学府形」双式词**（chose 民间音变，cause 后借书卷形）
  - **quelque**：古法 **quel + que**，**12 世纪**（fr.wiktionary 记 12c；其前身 quel ← 拉丁 qualis，首证 10c 下半叶——见 [[quel]]）
- **同族 / 派生（法语）**：**chose**（东西）、**quelque chose**（某事）、**quelqu'un**（某人）、**quelques**（几个——限定词）、**cause**（原因——**学府形双式**）、**chose publique**（＝ res publica 的仿译）；**quel / quelle**（见 [[quel]]）、**qui / que / quoi**（同出 \*kʷo-，见 [[qui]]、[[quoi]]）
- **记忆钩**：一句话记两半——**「quelque（某个）+ chose（东西）」**；而 chose 本身来自 causa「原因 / 事由」——**「事由」泛化成「东西」**，与英语 cause（原因）是同一拉丁词的两副面孔

**英法交叉核对（受影响的英语词）**
- **借入英语（chose / causa 一线）**：
  - **`cause`**（n. **c. 1200**「理由、动机」← 古法语 **cause**〔12c.〕← 拉丁 **causa**「原因、诉讼」；亦直接借拉丁；c. 1300「争议中的一方」、mid-14c「效果之因」）——英语 **cause 与法语 chose 同出拉丁 causa**：一个借了**学府形**（cause）、一个留了**通俗形**（chose），**同源异形**
  - **`chose`**（英语罕见 / 法律用语「物、标的」，如 *chose in action / chose in possession*）——**疑直借法语 chose**，但 etymonline 的 *chose* 词条只收 choose 的过去式，该名物义**未获 etymonline 覆盖**——标 **待验证**（另核 OED）
  - **`cause célèbre`**（**1763** ← 法语「著名案件」）——经法语借入
- **共祖未借入（quel 一线）**：英语 **`which`**（← 古英语 hwilc ＝ hwi- + -lic ← PIE \*kʷo-）与法语 quel / quelque **共祖非借入**；英语借入的 **`quality` / `qualify`** ← 拉丁 qualis（见 [[quel]]）——**qualis 一线英法或借入或共祖**
- **对照（无亲缘）**：英语 **`something`**（＝ some + thing，日耳曼构词）与法语 quelque chose（＝ qualis + causa，拉丁构词）**只是功能对等，两线无关**
- 核对：英语侧（cause c. 1200 ← 古法 cause ← 拉丁 causa；cause célèbre 1763；which ← OE hwilc ← \*kʷo-）2026-10-05 经 **etymonline 直读**；法语侧（chose ← 拉丁 causa、842 cosa / ca 880 niule cose、causa 顶替 res、chose/cause 双式；quelque ＝ quel + que 12c）2026-10-05 经 **WebSearch 转引 CNRTL/TLFi、DMF（ATILF）与 fr.wiktionary**。**待验证**：①英语名物义 `chose` 的借入年代（etymonline 未覆盖）；②quelque chose 短语的词典级首证定年；③「形容词借 de 引入、限阳性单数」的规范来源（Le Bon Usage §764 / Académie 8e）已见引，未直读

**同义 / 搭配 / 易混**
- 搭配：`quelque chose de + adj.`（de beau / de grave）｜ `quelque chose comme`（大约）｜ `quelque chose à + inf.`（quelque chose à manger 吃点东西）｜ `être / devenir quelque chose`（有出息）｜ `c'est quelque chose`（真不简单）｜ `il y a quelque chose entre eux`（他们之间有点什么）
- **易混（核心）**：**quelque chose**（物 / 事，中性代词——本页）｜ **quelqu'un**（人，代词）｜ **quelques-uns / quelques-unes**（「一些人 / 一些东西」，复数代词）｜ **quelques**（「几个」+ 名词，**限定词**）｜ **quoi**（疑问「什么」——见 [[quoi]]）
- **分写 / 合写陷阱**：**quelque chose**（合写，代词）｜ **quel que soit**（分写，quel + être + que + subj. 让步——见 [[quel]]）
- 相关：[[quel]]、[[quoi]]、[[tout]]（泛指「一切」）、`personne`（否定代词「没有人」——本库待建，与 quelque chose 同属不定代词一族）
