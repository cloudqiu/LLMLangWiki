# main

**释义**：（1）**手**——人体上肢末端（la main droite 右手；se laver les mains 洗手）；（2）**（引申）人手、帮助**（donner un coup de main 帮一把；prêter main forte 助一臂之力）；（3）**（引申）支配、掌握**（avoir qqch en main 掌握某物；de première main 第一手）；（4）**一手宽**（旧长度单位，约 12 厘米，量马用） ｜ extrémité du membre supérieur de l'homme, formée de la paume et des doigts ; (fig.) aide, autorité, possession

**例句**
- _Elle m'a tendu la main._ 她向我伸出了手。
- _Donne-moi un coup de main._ 帮我一把。
- _Il a la main verte._ 他很会养花。（直译「绿手」，指园艺能手）
- _L'affaire est en de bonnes mains._ 这事托付给了可靠的人。

**形态要点**
- 名词（n.f.）：`la main`（阴性）；复数 **les mains**
- 发音 /mɛ̃/——**鼻化元音 ɛ̃**；拼写 -ain 是法语鼻化元音的常见图形（同 pain /pɛ̃/、faim /fɛ̃/）；**注意 main 与 mien 同音** /mjɛ̃/ 不同，勿混
- 固定用 **la / sa**：*se laver les mains*（洗手，用定冠词不用主有）；*avoir mal à la main*（手疼，同上）
- 常见搭配：`poignée de main`（握手）／`sac à main`（手提包）／`main-d'œuvre`（劳动力）／`main-forte`（援手）／`main courante`（扶手；流水登记簿）／`haut la main`（轻而易举地）／`de main de maître`（大师手笔）／`à main levée`（举手；徒手）／`la main dans le sac`（当场捉住，抓现行）

**词源 / 构词**
- **拆解**：拉丁 **manus**（第四变格，阴性）「手」← 原始意大利语 **\*manus** ← PIE **\*man-**「手」——**裸词根**，无前缀无后缀；法语 main 三个字母直承拉丁词干
- **演变（CNRTL/TLFi，2026-10-05 经 WebSearch 转引）**：
  - **Fin xe s. man**「人体末端部分」——首证原文：« A. Fin xᵉ s. *man* « partie du corps humain, situé à l'extrémité du bras » (*Passion*, éd. D'Arco Silvio Avalle, 237 : « Pilaz sas mans dunques laved ») »
  - 古法语 *man*（980，Wiktionnaire 亦作 **man (980)**）→ *main / mein* → 现代法语 **main**（-ai- 图形标志鼻化）
  - **义项链**：ca 1170 **main a main**「并肩」（Chrétien de Troyes, *Erec*）→ 1225-30 *a main senetre*「在左侧」→ ca 1375 作**量长单位** → 1377 **以部分代全体**（指做事的人，如「一只手」＝一个劳动力）→ 1558 *par soubs main*「暗中」→ 1910 **petite main**「（缝纫）小工、学徒」→ 大量比喻义（触觉、拿取之器官；权威、占有、交换的象征）
- **同族 / 派生（法语）**：**manier**（操作、摆弄）；**manuel**（手工的；手册）；**manucure**（美甲）；**manuscrit**（手稿）；**manutention**（搬运）；**manivelle**（曲柄）；**quadrumane**（四足猿）；**manœuvre / manœuvrer**（操作；计谋）；**manier / maniement**；**manipuler / manipulation**；**manifeste**（← manifestus，另源，勿混）；复合词 main-d'œuvre / main-forte / main courante / main tendue / main invisible
- **记忆钩**：manus ＝「手」，英语与法语共享的**拉丁零件**：法 main ↔ 英 man-（manual, manuscript, manicure）——同一个 manus，法语留作整词，英语只留在派生词里，是「拉丁词根在两语中的不同命运」标本

**英法交叉核对（受影响的英语词）**
- **同形异源（最大陷阱）**：英语 **`main`**（adj.「主要的」／n.「总管道、干线」）**与法语 main 毫无关系**——它 ← 古英语 **mægen**（Mercian *megen*）「力量、体力」，← 原始日耳曼语 **\*maginam**「力量」，← PIE **\*magh-**「有能力、有力量」；「主要的」义（c. 1400 / c. 1600）由此而来；adj. 另受古诺斯语 *megen*「强壮的」影响。「输水总管」义（main drain）1727。**英语 main ≠ 法语 main**——切勿把「主要的」当成「手的」。法语「主要的」用 *principal* / *essentiel*
- **借入英语（法语输出，唯一保留 main＝手 的英语词）**：**`legerdemain`**（n.「戏法、障眼法」，15c.）← 古法语 **léger de main**「手轻巧」——etymonline 明记：「Main "hand" is from Latin manus」正指此词。除此以外英语**没有**从法语借入日常的 main＝手（英语「手」是日耳曼语 **hand**）（词库未收 `legerdemain`）
- **共祖 / 借入（拉丁 manus 一线，英语的派生词群）**：
  - **`manual`**（adj. c. 1400 ← 拉丁 *manualis*「属于手的」；n. early 15c. ← 古法语 **manuel**「手册」）——**经法语**的词义（手册）与**直承拉丁**的形容词义并存
  - **`manuscript`**、**`manicure`**、**`manacle`**、**`maneuver / manœuvre`**、**`emancipate`**、**`amanuensis`**、**`manubrium`**——均出拉丁 *manus*；其中 **`manage`** 经**意大利语** *maneggiare* ← *mano* ← 拉丁 *manus*（非经法语）
  - **`manus`**（拉丁原词，英语学位论文术语 *manus*）——直引
  - 共祖对照：拉丁 *manus* 这条线在**英语**只活于派生词（manual, manuscript），在**法语**则活于整词 **main**；两语共享拉丁零件，却各自演化出不同语域
- **英法同义异源对照**：英语「手」**`hand`** ← 古英语 *hand* ← 原始日耳曼语 **\*handuz**（与德语 Hand 同族）——与拉丁 *manus* **无亲缘**；故 **法 main ↔ 英 hand 是同义异源**（同 [[vie]] ↔ life、[[lait]] ↔ milk 型），而**法 main ↔ 英 main 是同形异源**——一词两名，两重陷阱
- 核对：英语侧（main ← OE mægen ← PGM \*maginam ← PIE \*magh-；legerdemain ← 古法 léger de main；manual ← 古法 manuel／拉丁 manualis；manage ← 意语 maneggiare）2026-10-05 **etymonline 直读**；法语侧（fin xe s. *man* 首证、《Passion》引文、main a main ca 1170、petite main 1910 等义项链）2026-10-05 经 **WebSearch 转引 CNRTL/TLFi**（cnrtl.fr 直连 sinkhole）

**同义 / 搭配 / 易混**
- 搭配：`donner un coup de main`（帮一把）｜ `poignée de main`（握手）｜ `se serrer la main`（互相握手）｜ `prêter main forte`（助一臂之力）｜ `avoir la main verte`（会养花）｜ `sac à main`（手提包）｜ `main-d'œuvre`（劳动力）｜ `haut la main`（轻而易举）｜ `à main levée`（举手／徒手）｜ `en un tour de main`（一转手、眨眼间）｜ `avoir qqch en main`（掌握）｜ `de la main à la main`（直接交手）
- 辨析：**main**（手）｜ **`bras`**（臂——从肩到腕）｜ **`doigt`**（指）｜ **`paume`**（掌）｜ **`poignet`**（腕）｜ **`membre`**（肢；成员，见 [[membre]]）
- **faux ami 双陷阱**：①英 **main**（主要的）≠ 法 **main**（手）——同形异源；②法 **main**（手）≠ 英 **hand** 的词源——同义异源。「手」的英法对译只能靠 hand ↔ main，切勿用 main ↔ main
- 相关：[[membre]]（肢体）；[[objet]]（à main levée 类搭配）；[[lait]]、[[vie]]（同为「同义异源」样本，可对照）
