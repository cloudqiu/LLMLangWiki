# pratique

**收录说明**：inbox 原形写作 **`plus partique`**（第 208 行）——`partique` 系 `pratique` 的**拼写变体／手误**，`plus` 为副词「更」，合为短语 **plus pratique**「更实用」（比较级）。本页按**形容词 pratique** 编译（兼收 n.f.「实践／做法」义）。**判定待用户确认**（其他读法未完全排除）。参见 hub「命名消歧登记表」中 couverture、énerver 等同类「inbox 拼写判定」条目。

**释义**：**adj.**（1）**实践的、实际的**——不停留于思辨、导向行动（des travaux pratiques 实践课／实验课；l'intelligence pratique 实践智力）；（2）**实用的、方便的**（un outil pratique 好用的工具；c'est plus pratique 这样更方便）；（3）**（人）务实的、有实干感的**（un homme pratique）｜ **n.f.**（4）**实践**——与 théorie 相对（la théorie et la pratique；mettre en pratique 付诸实践）；（5）**做法、惯例**（les bonnes pratiques 良好做法；en pratique 实际上）；（6）**（医生／律师／商贩的）顾客、主顾**（avoir de la pratique） ｜ qui tend à l'action, commode, aisé ; (n.f.) application, usage ; clientèle

**例句**
- _C'est plus pratique d'y aller en train._ 坐火车去更方便。（**对应 inbox 短语 plus pratique**）
- _Il faut mettre ces conseils en pratique._ 必须把这些建议付诸实践。（n.f.）
- _Ce logiciel est vraiment pratique._ 这个软件真方便。

**形态要点**
- 形容词（adj.）：**阴阳同形**——阳性 **pratique** ｜ 阴性 **pratique** ｜ 复数 **pratiques**
- 位置：**后置**（un outil pratique、une méthode pratique）；比较级 `plus pratique`、最高级 `le plus pratique`
- 名物化：**la pratique**（n.f. 实践、做法）——**阴性**名词

**词源 / 构词**
- **拆解**：拉丁 **practicus**「实践的、行动的」（← 希腊 **praktikos**「宜于行动的、务实的」← **praktos**「已做的、待做的」← **prassein / prattein**「做、行动、完成」）+ 名词 **practice**；希腊 **praktikos** 的阴性 **praktikē** 即「实践」名词一线的上源
- **演变（CNRTL/TLFi，2026-10-05 经 fr.wiktionary 转引）**：首证 **1256**——（形容词）← 拉丁 **practicus**，（名词）← 拉丁 **practice**；fr.wiktionary 此处**未**展开希腊语层与更多演变细节
- **同族 / 派生（法语）**：**pratiquer**（v. 实行、从事）；**pratiquant / pratiquante**（adj./n. 常去教堂的／实践者）；**pratiquement**（adv. 实际上、几乎）；**praticable**（可实行的、可通行的）；**praticien / praticienne**（n. 开业医生／从业者）；**impraticable**；**travaux pratiques**（TP 实验课）；**sens pratique**（务实感）
- **记忆钩**：prat-（做、行动）——同一希腊 **prassein / prattein** 根也出英语 **practical**、**practice**、**pragmatic**（← pragma「行为、事实」）、**praxis**

**英法交叉核对（受影响的英语词）**
- **共祖希腊（praktikos ← prassein「做」）**：英语 **`practical`**（adj. **early 15c.** *practicale*）系 **practic + -al**（或直接 ← 古法 **practique** 形容词、或 ← 中古拉丁 **practicalis** ← 晚期拉丁 **practicus** ← 希腊 **praktikos** ← **prassein**）；法语 **pratique** ← 拉丁 **practicus** ← 希腊 **praktikos** ← **prassein**——**两语同出希腊 praktikos / prassein，属共祖**（同源非借入）
  - 英语名词线：**`practic`**（n. late 14c.「method, practice」← 古法 **practique**「practice, usage」13c. ＋ 中古拉丁 **practica** ← 希腊 **praktikē**）；**`practice`**（n. early 15c. *practise* ← 古法 **pratiser** ← 中古拉丁 **practicare**）——**这里英语确有经古法语借入的成分**（practique / pratiser），须与「形容词共祖」分开看
  - **义项链（英）**：practical 本义「实践的」→ **1660s** 用于人「凭经验而非理论的」→ **practical joke 1771**（「付诸行动的笑话」）
- **共祖未借入**：英语 `practice`、`practical`、`praxis`、`pragmatic`、`practicable`、`practically` 与法语 pratique（adj.）/ pratique（n.f.）皆 ← 希腊 **praktikos / prassein** 一线，**同源**；中古拉丁中介形 **practicus / practica / practicalis** 为两语共用
- **核对（易混提示）**：英语 `practical` ≠ 法语 pratique 的**借入**——两词是**平行继承**希腊—拉丁线（加英侧部分经古法语 practique / pratiser 之名物化借入）；法语 pratique 既作 adj. 又作 n.f.，英语则分化为 `practical`（adj.）与 `practice`（n.）
- 核对：英语侧（practical early 15c. *practicale* ← practic + -al / 古法 practique 13c. / 中古拉丁 practicalis ← 晚期拉丁 practicus ← 希腊 praktikos ← prassein；practice early 15c. ← 古法 pratiser ← 中古拉丁 practicare；practic n. late 14c. ← 古法 practique ＋ 中古拉丁 practica ← 希腊 praktikē；practical joke 1771）2026-10-05 经 **etymonline 直读**；法语侧（pratique 1256 ← 拉丁 practicus／practice；fr.wiktionary 未展开希腊层）2026-10-05 经 **fr.wiktionary 转引 CNRTL/TLFi**

**同义 / 搭配 / 易混**
- 搭配：`mettre en pratique`（付诸实践）｜`en pratique`（实际上）｜`les bonnes pratiques`（良好做法）｜`travaux pratiques`（TP 实验课）｜`un outil pratique`｜`c'est plus pratique`｜`avoir de la pratique`（（医生等）有主顾）
- 辨析：**pratique**（实践的；实用的；n.f. 实践）｜ **`théorique`**（理论的——对义词）｜ **`concret`**（具体的）｜ **`utile`**（有用的，见 [[utile]]）｜ **`fonctionnel`**（功能的／实用的，见 [[fonctionnel]]）｜ **`commode`**（方便的）｜ **`aisé`**（容易的）
- **faux ami**：英语 **`practical`** 常用义「实用的」对应法语 **pratique**；但英语 **`practice`**（练习、惯例）**不可**直接当作法语 pratique 的 n.f. 全部义域（法语「练习」多用 exercice / entraînement；pratique 的 n.f. 侧重「实践／做法／（主顾）」）
- 相关：[[utile]]、[[fonctionnel]]（同表「实用／有用」——三者义域依次为：utile 有用 ／ fonctionnel 技术性实用 ／ pratique 日常方便）；[[savoir]]（théorie / pratique 的对立在「知识」话题下的展开）
