# stable

**释义**：（1）**稳定的、稳固的**——安稳不移动、不变动（une situation stable 稳定的局面；des fondations stables 稳固的地基）；（2）**（人）可靠的、沉稳的**——行为有常、靠得住（un homme stable、une humeur stable）；（3）专业义：物理「（平衡）稳定的」、化学／核物理「（同位素）稳定的」、经济「（货币）稳定的」；（4）数学／图论 n.m.「稳定子图」——**注意：法语名词 stable 不表「马厩」**（那是英语 stable 的义；法语「马厩」是 écurie / étable）——同形异义，见下 ｜ qui reste en place, ferme, durable ; (personne) sûr, constant ; (sc.) qui revient à sa position / ne se décompose pas

**例句**
- _La situation politique est restée stable pendant dix ans._ 政局十年来一直稳定。
- _On peut compter sur lui, c'est un homme stable._ 可以指望他，他是个沉稳可靠的人。
- _Cet isotope est stable._ 这种同位素是稳定的。

**形态要点**
- 形容词（adj.）：**阴阳同形**——阳性 **stable** ｜ 阴性 **stable** ｜ 阳性复 **stables** ｜ 阴性复 **stables**
- 位置：**后置**（une situation stable、un équilibre stable）——与多数 `-able / -ible` 结尾的形容词同组
- 无 beau / nouveau / vieux 型特殊变化

**词源 / 构词**
- **拆解**：拉丁 **stabilis**「稳固的、站得牢的」＝ **stare**「站立、立定」+ **-bilis**（形容词后缀「能……的」）——字面「**能站得住的**」；法语 stable 系**借入**（emprunt au latin），非通俗拉丁的自然演变（故几乎照抄拉丁形）
- **演变（CNRTL/TLFi，2026-10-05 经 WebSearch 转引）**：
  - **1re moitié du xiie s.** 首证 **estable**「ferme, constant（指精神、心志）」——*Psautier de Cambridge*, 50, 11（TLFi）
  - **1238-39** *estaule*；**1240** *estauble*（法律义「durable, permanent」）
  - **fin xiiie - début xive s.** 出现拼写 **stable**（「ferme, consistant」，指土地）
  - 现代 **stable**（词首 e- 脱落）；Académie 9e 亦记「xiie siècle，emprunté du latin stabilis，lui-même dérivé de stare」
- **同族 / 派生（法语）**：**stabilité**（n.f. 稳定）；**instable / instabilité**（不稳定）；**stabiliser / stabilisateur**（使稳定／稳定器）；**astable / bistable / monostable**（电子学）；**stablement**（adv.）
- **记忆钩**：拉丁 **stare**「站」是共同根——法语 [[rester]]（← restare「留下站住」）、**station**、**statut**、**état** 都在这一线；stable ＝「**站得住的**」

**英法交叉核对（受影响的英语词）**
- **借入英语（古法语 → 英语）——同一词形、两条词源，须分清**：
  - **形容词 `stable`**（英 **mid-12c.** 最早义「trustworthy, reliable（可靠）」；mid-13c.「constant, steadfast」；c. 1300「firm, fixed, permanent in its place」；late 14c. 物义「secure against falling」）← 古法语 **estable / stable**「constant, steadfast, unchanging」← 拉丁 **stabilis**——**借入**（etymonline 直读）
  - **名词 `stable`**（英 **early 13c.**「马厩、马房」）← 古法语 **estable / stable**（亦指牛栏猪圈；该词在法语本土作 **étable**）← 拉丁 **stabulum**「站位、栏圈」← PIE **\*ste-dhlo-**（根 **\*sta-**「站」）——**借入**。注意：形容词来自 **stabilis**、名词来自 **stabulum**，**词根同（stare）而拉丁词形异**
- **共祖未借入（拉丁 stabilitas / stabilire 一线）**：英语 **`stability`**、**`instability`**、**`stabilize`**、**`stabilizer`** 均 ← 拉丁 stabilitas / stabilire，与法语 stabilité / stabiliser **同源**；英语 **`establish`** 亦 ← 古法语 **establir** ← 拉丁 stabilire（**经法语借入**）
- **⚠️ 更正 / 待验证（记录本次 ingest 提示与权威源的分歧）**：本次 ingest 提示曾称「stable 在法语兼名词『马厩』——同形两义」。**经查 Larousse（该条仅列 adjectif，无名词义）、fr.wiktionary（明标 faux ami：英语 stable「écurie」之义在法语须用 écurie，并从法语侧反向标注）与 TLFi 均不支持该说法**——现代法语名词 **stable** 只作数学「稳定子图」；「马厩」是英语 stable（n.）的义项，法语作 **écurie**（← 古法 escuerie ← 法兰克语）／**étable**（← 古法 estable ← 拉丁 stabulum，今义「牛栏」）。**结论：法 stable ≠ 英 stable（名词义）**，实为 **faux ami**，非「同形两义」——**已按权威源更正；若用户另有依据（方言／旧语），待用户确认**
- 核对：英语侧（stable adj. mid-12c.／noun early 13c.，皆 ← 古法 estable ← 拉丁 stabilis／stabulum；stability、establish）2026-10-05 经 **etymonline 直读**；法语侧（TLFi 首证 1re moitié xiie s. estable「指精神」*Psautier de Cambridge* 50, 11；1238-39 estaule；1240 estauble；fin xiiie-début xive stable；Académie 9e 作 xiie s. 借自 stabilis）2026-10-05 经 **WebSearch 转引 CNRTL/TLFi**；**法语名词义**2026-10-05 经 **Larousse + fr.wiktionary 直读**核实（无「马厩」义）

**同义 / 搭配 / 易混**
- 搭配：`une situation stable`｜`un équilibre stable`｜`un emploi stable`（稳定工作）｜`un couple stable`｜`un isotope stable`｜`une monnaie stable`｜`des fondations stables`
- 辨析：**stable**（稳定的；沉稳可靠的）｜ **`instable`**（不稳定的——对义词）｜ **`ferme`**（坚定的、结实的——侧重不松动、不动摇）｜ **`durable`**（持久的）｜ **`constant`**（恒定的、持续的）｜ **`permanent`**（永久的）
- **faux ami**：法语 **stable** ↔ 英语 **`stable`**——法语的「马厩」须用 **écurie / étable**；英语名词 stable 不译作法语 stable
- 相关：[[rester]]（同出拉丁 stare「站」一线）；[[etre]]（拉丁 esse / stare 两条「存在」线，可对照）
