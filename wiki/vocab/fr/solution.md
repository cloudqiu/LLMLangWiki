# solution

**释义**：（1）解决办法、对策（trouver une solution à un problème 为问题找到办法）；（2）〔化学〕溶液（solution aqueuse 水溶液）；（3）〔数学〕解 ｜ réponse à un problème ; mélange liquide homogène ; (math.) valeur qui vérifie une équation

**例句**
- _Il faut trouver une solution à ce problème._ 得给这个问题找个解决办法。（见 [[trouver]]）
- _C'est la seule solution possible._ 这是唯一可行的办法。
- _Le sucre se dissout dans l'eau et forme une solution._ 糖溶于水，形成溶液。

**形态要点**
- 名词：`la solution`（f.）；复数 `les solutions`
- 介词：**solution à**（+ 问题 / 方程：solution **à** un problème / **à** une équation）——「……的解法」用 **à** 而非 de；固定语 `solution de continuité`（断裂、中断——医学 / 转义，首证 1314）
- 化学搭配：`solution aqueuse`（水溶液）、`solution concentrée / diluée`（浓 / 稀溶液）、`solution saline`（盐溶液）

**词源 / 构词**
- **拆解**：拉丁 **solutio**「解开、松开」＝ **solvere**「松开、解开、解决」的动作名词 ← **se-**（分开）+ **luere**「松开、洗去」（PIE **\*se-lu-** ← 反身词根 **\*s(w)e-** + 词根 **\*leu-**「松开、分开」）
- **演变**：拉丁 solutio → 法语 **soluciun**「解释」首证 **1119**（Philippe de Thaon, *Comput*）→ 13 世纪初「解开难题」义 → 化学「溶解」义 **1676**（Le Robert 记）/ **1690**（Furetière 记）→ 「均相溶液」**1811**（Le Robert 记）/ **1821**（Kapeler, Caventou）（据 CNRTL / TLF，2026-10-03 经检索转引）
- **同族 / 派生（法语）**：résoudre（解决、决定）、résolution（决心、决议）、dissoudre（溶解、解散）、dissolution、absoudre（赦免）、absolution；soluble / insoluble（可溶的 / 不可溶的）
- **记忆钩**：solution 的根是「松」——「把死结松开」→ 解决问题；「把糖松解进水里」→ 溶液；同一 solvere 串起 résoudre（松开 → 解决）、dissoudre（散开 → 溶解、解散）、absoudre（放走 → 赦免）

**英法交叉核对（受影响的英语词）**
- **借入英语**：**solution**（n. late 14c. *solucioun*「解释、答案；溶解」）← 古法语 **solucion**（旧义「分解、溶解；解释；付款」）+ 直接来自拉丁 **solutionem**（英←古法 + 拉丁双线——虽经法语，英语亦直取拉丁）（etymonline，2026-10-03 经检索转引）；「溶液」义英语 **1590s**——早于法语记录的 1676/1690，借入后各自独立发展
- **共祖未借入**：**solve / dissolve / resolve / absolute / solvent** 等 ← 拉丁 solvere 及其复合词，经拉丁 / 法语线分别进入英语——与 solution 同根，但**并非由法语 solution 传入**
- 核对：法语首证 1119 solucium「解释」据 TLF / CNRTL（经检索转引）；英 late 14c ← 古法语 solucion + 拉丁 solutionem、英「溶液」义 1590s 据 etymonline（同上）；solvere ＝ se- + luere 据 Littré / Académie（经检索转引）；PIE \*se-lu- 构拟据 etymonline

**同义 / 搭配 / 易混**
- 搭配：`trouver une solution à qch`（为……找到办法）、`apporter une solution`（拿出解决办法）、`solution de rechange`（备用方案）、`solution miracle`（万灵药式的办法）
- **辨析（本组重点）**：**solution**（对**问题**的「解法」——需思考，通常唯一或少数几种：solution à un problème）vs **réponse**（对**提问**的回答：réponse à une question）——问「怎么办」求 solution，问「是什么 / 谁 / 何时」求 réponse
- **faux ami**：solution 的「溶液」义与英语一致；古法语 solucion 曾含「付款」义（早期英语亦沿用），现代法、英均已废——遇旧文献别按今义读
