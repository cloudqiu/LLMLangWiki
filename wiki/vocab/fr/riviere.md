# rivière

**释义**：（1）**河、江**（尤其指**汇入另一条河**的中小河流——与 [[fleuve]] 相区别）；（2）**（一地的）河段；（钓鱼、航运的）河**（rivière navigable 通航河道）；（3）**（首饰）项链**（une rivière de diamants 一串钻石） ｜ cours d'eau naturel qui se jette dans un autre cours d'eau ou dans la mer ｜ (bijouterie) collier de pierres précieuses

**例句**
- _La rivière traverse le village._ 这条河穿过村子。
- _Ils se baignent dans la rivière._ 他们在河里游泳。
- _Elle porte une rivière de diamants._ 她戴着一串钻石项链。

**形态要点**
- 名词：`la rivière`（**f.**）；复数 **rivières**
- **⚠️ 关键区分（英法必考）**：**rivière** ＝ 一般中小河流（通常**流入另一条河**或较小的水体）｜ **[[fleuve]]** ＝ **流入大海**的大河——**法语严格区分两者，英语 river 一概不分**（faux ami 的经典处）
- 派生 / 同族：**rive**（岸）、**rivage**（滨、岸）、**riverain**（沿岸的、沿岸居民）

**词源 / 构词**
- **拆解**：**ripa**「岸」→ 通俗拉丁 ***riparia**（古典形容词 **riparius**「河岸的」的**阴性名词化**，原义「近水之地」）→ 古法语 **riviere** → 现代 rivière
- **演变**：拉丁 ripa「岸」→ 俗拉丁 \*riparia「近水之地」（8 世纪见于地名，951 年有「沿海」义）→ 古法 riviere；**首见 fin XIe s.**（形 **riviere**，*Gloses de Raschi*，据 Robert 史典；TLFi「11 世纪末」）——**转引待验证**；义项分期：「小溪」义最早 **1105**，「中小河流」义 **~1138**
- **词源竞争说**：部分旧源把 rivière 归入拉丁 **rivus**「溪流」——**主流权威**（Larousse、Académie 9e、Robert 史典、TLFi / FEW X *riparia）主 **\*riparia**；**rivus 一路**则给 **ru、ruisseau、ruisselet**——**两说并列**
- **同族 / 派生（法语）**：ripa / \*riparia 一路——**rive、rivage、riverain**；rivus 一路——**ru、ruisseau、ruisselet、dériver、rival / rivalité**
- **记忆钩**：rivière 字面是「**近岸之地**」（ripa「岸」）——从「河岸地带」转指「河」本身

**英法交叉核对（受影响的英语词）**
- **借入英语**：**river**（early 13c 成词，12c 末已见作姓氏）← 盎格鲁-法语 **rivere** / 古法语 riviere；**rivage**（archaic「岸、滨」）亦借自古法语（< rive < ripa）
- **共祖未借入**：**riparian**（← 拉丁 riparius）、**riviera**（← 意大利语 riviera，同享 ripa / \*riparia）、西 **ribera**——皆直接 / 经他语，非经法语
- **同义异源**：古英语本族「河」为 **ea**（今仅存于 river 名如 *Eden* 等）——与 rivière **无亲缘**
- 核对：英语侧（river early 13c ← 盎格鲁-法语 rivere）经检索转引 etymonline（2026-10-11）；法语侧 fin XIe s. 与 \*riparia 链据 Robert 史典 / TLFi / FEW 转引（**待验证**）
- **faux ami 提示**：英语 **river** 对应法语 **rivière 与 [[fleuve]] 两个词**——英语不分，法语必分

**同义 / 搭配 / 易混**
- 搭配：`au bord de la rivière`（在河边）｜ `rivière navigable`（通航河）｜ `rivière de diamants`（钻石项链）｜ `remonter / descendre la rivière`（沿河上 / 下行）
- **易混（重点）**：**rivière**（中小河流，汇入他河）vs **[[fleuve]]**（流入大海的大河）——**法语最经典的区分**；**rivière** vs **ruisseau**（小溪，< rivus 一路）；**rivière** vs **rive**（岸）
- 相关：[[fleuve]]（区分对，待收）；[[sauce]] / [[source]]（待收，同「水」域）
