# quel

**释义**：（1）（**疑问形容词 / 限定词**）什么样的、哪个——Quel film préfères-tu ? 你喜欢哪部电影？（2）（**感叹**）多么、何等——Quel beau jour ! 多美的一天！（3）**间接疑问**——Je ne sais pas quel chemin prendre 我不知走哪条路；（4）**quel que**（分写，+ subjonctif，让步）无论……什么样的；（5）**介词 + quel** 缩合成复合关系代词 **lequel / auquel / duquel** 家族 ｜ dét./adj. interr. « de quelle nature, lequel ? » ; adj. exclam. « combien grand, combien beau ! » ; loc. conj. quel que + subj. « quelle que soit la chose qui »

**例句**
- _Quel film préfères-tu ?_ 你更喜欢哪部电影？（疑问形容词，阳性单数）
- _Quelle robe as-tu choisie ?_ 你选了哪条裙子？（阴性 quelle，注意过去分词配合 choisie）
- _Je ne sais pas quel chemin prendre._ 我不知道该走哪条路。（间接疑问）
- _Quel beau jour !_ 多美的一天啊！（感叹）
- _Quels livres avez-vous lus ?_ 你们读了哪些书？（阳性复数）
- _Quelles que soient les circonstances, elle reste calme._ 无论情况如何，她都保持冷静。（**quel que 分写** + subjonctif，性数随主语）
- 对照：问「几点」用 **à quelle heure**（见 [[heure]]）；问「哪个人」用 [[qui]]。

**形态要点**
- **déterminant / adj. interrogatif-exclamatif**：四形 **quel / quelle / quels / quelles**——**四形同音** /kɛl/，仅靠书写与所修饰名词的性数区分（听力无法分辨，书写高频失分点）
- **与名词性数配合**：quel + n.m.sg ｜ quelle + n.f.sg ｜ quels + n.m.pl ｜ quelles + n.f.pl（与形容词同型：bon/bonne/bons/bonnes）
- **位置**：置于名词**前**，与冠词互斥（Quel livre ?；`le quel livre` 不成立）；作**表语**时用 **Quel est… / Quelle est…**（Quelle est ta couleur préférée ? 你最喜欢什么颜色？），此时 quel 与 être 后的主语性数配合
- **quel que（分写）vs quelque（合写）**：分写 **quel(le)(s) … que** 引让步从句、动词用 **subjonctif**（Quel que soit ton avis… 无论你的意见是什么）；合写 **quelque** + 名词＝「某个」（quelque chose 某物、quelques livres 几本书）；合写 **quelque + 形容词 + que** ＝ 副词「无论多么」（Quelque habile qu'il soit 无论他多熟练）——**合写/分写是语法分水岭**
- **lequel 家族（缩合）**：介词 + quel → **lequel / laquelle / lesquels / lesquelles**；**à + lequel → auquel / auxquels / auxquelles**；**de + lequel → duquel / desquels / desquelles**——复合关系代词
- 感叹句式：**Quel + (形容词) + 名词**（Quelle belle histoire !）——与英语 What a… ! 同构

**词源 / 构词**
- **拆解**：拉丁 **qualis**「什么样的、何种性质的」（疑问兼关系形容词，本与 **talis**「这样的」构成相关对 qualis…talis…）＝ 疑问/关系词干 **\*kʷo-**（见 [[qui]]）+ 形容词后缀 **-alis**（同 -al 家族）——字面「属于哪种的」
- **演变（TLFi，2026-10-04 转引）**：拉丁 **qualis** → 通俗拉丁／古法语 **qual → quel**（词首 qua- 元音前移）；**TLFi「Étymol. et Hist.」首证**：**10 世纪下半叶** 阴性 **qual** 作 épithète（《圣 Léger 传》St Léger, éd. Linskill, 149）；**10 世纪末** 代词 régime 与间接疑问 épithète（《Passion》458 / 332）；**ca 1100** 在《罗兰之歌》中大量铺开——**de quel que**（Roland 593）、**quel + 名词 + que** 让步（Roland 2034 *Quel part qu'il alt*）、作**表语**（Roland 191 *je ne sai quels en est sis curages*）、épithète 的 quel / quele（Roland 146 / 395）、阳性复数 **quels**（1849）、间接疑问（2553 / 2567）；其后 1135（Wace《圣玛格丽特》*Quel loi que ses peres tenist*）、ca 1170（Chrétien de Troyes《Erec》1929）
- **晚期拉丁的语义漂移**：TLFi 注——俗拉丁晚期 **qualis** 渐与关系代词 **qui** 混用（义项扩大）
- **同族 / 派生（法语）**：**quelque**（quel + que）、**quelqu'un**（quel + que + un）、**lequel / auquel / duquel** 家族、**tel**（← 拉丁 **talis**，qualis 的相关对）；上位疑问词族 **qui · que · quoi · quel · quand · comment · pourquoi**——同出 **\*kʷo-**（见 [[qui]]）
- **记忆钩**：qualis ↔ talis 是一对——「**Quel** jour sommes-nous ? — Nous sommes **tel** jour.」（今天什么日子？——今天某日）；疑问的 \*kʷo- 与指示的 \*to- 两干相对

**英法交叉核对（受影响的英语词）**
- **借入英语（经古法语／拉丁，均含 qualis 词干）**：
  - **`quality`**（n. **c. 1300**「性情、品性」← 古法语 **calite / qualite**（12c.，今 qualité）← 拉丁 **qualitatem / qualitas**「性质、属性」）——etymonline 引 Tucker 等：**qualitas 系西塞罗（Cicéron，前 1c.）为翻译希腊 **poiotēs**「性质」而造**（← qualis）；义项：c. 1300 品性 · late 14c. 固有属性／优劣程度 · c. 1400 社会地位 · 1580s 卓越特性
  - **`qualify`**（v. **mid-15c** ← 中世纪拉丁 **qualificare** ← qualis + facere）、**`qualitative`**（adj. **early 15c** ← 中世纪拉丁 qualitativus）
  - **`quale / qualia`**（哲学「感受质」，直接借拉丁 **qualis** 的中性单数／复数形；20 世纪由 C. I. Lewis 引入）——**待验证**（1929 引入系常见说法，未直读 Lewis 原书）
- **共祖未借入（本页核心）**：英语 **`which`** ← 古英语 **hwilc / hwælc / hwalc**（＝ **hwi-**「who」+ **-lic**「form/body」← 日耳曼 **\*likan**）← 日耳曼 **\*hwa-lik-** ← PIE **\*kʷo-**——与法语 quel（← 拉丁 qualis ＝ \*kʷo- + -alis）**结构惊人平行**：两个词都是「\*kʷo- 词干 + 表示『形态、性质』的形容词性后缀」，字面皆「of what form/kind」；**同源远亲、双向均非借入**（同型：[[quand]]↔when、[[qui]]↔who）。同族 `what`、`who`、`when`、`where`、`why`、`how` 亦同出 \*kʷo-
- **非亲缘（辨误，须明确否定）**：英语 **`such`** **不**出 \*kʷo-——such ← 古英语 **swylc / swilc** ← 日耳曼 **\*swalikaz**（＝ **\*swa**「so」+ **\*likan**「form」）← PIE **\*swo-**「自身、如此」（同族德语 solch、哥特 swaleiks）——与法语 quel 只有**语义平行**（Quel beau jour ! ＝ Such a beautiful day! ／ What a beautiful day!），**无词源亲缘**（「quel ← such 同源」之说不成立）
- 核对：英语侧（quality c. 1300 / qualitas 西塞罗造字 / qualify mid-15c / qualitative early 15c / which hwilc ← \*hwa-lik- / such swylc ← \*swalikaz ← \*swo- / quale）2026-10-04 经 **etymonline 直读**；法语侧（qualis → 古法 qual → quel；TLFi 首证 10c 下半叶 圣 Léger 149、10c 末 Passion、ca 1100 罗兰之歌各例、1135 Wace、ca 1170 Erec）2026-10-04 经 **WebSearch 转引 CNRTL/TLFi**（cnrtl.fr/etymologie/quel 被检索引出，直连仍 sinkhole）。**待验证**：①`quale/qualia` 由 C. I. Lewis 1929 引入之说未直读原始文献；②古法语 qual → quel 的拼写过渡年代未逐核；③TLFi「quel」原条首证定年（现为转引 10c 下半叶）

**同义 / 搭配 / 易混**
- 搭配：`Quel + n. + !`（感叹）｜ `Quel(le) est… ?`（表语疑问）｜ `quel(le)(s) … que + subj.`（无论，**分写**）｜ `n'importe quel`（任何一个）｜ `quel genre de…`（什么样的）｜ `de quelle couleur`（什么颜色）｜ `à quelle heure`（几点——见 [[heure]]）｜ `Quel bon vent !`（什么风把你吹来了）
- **易混（核心，同音）**：**quelle**（quel 的阴性）/kɛl/ ＝ **qu'elle**（＝ que + elle）/kɛl/——同音异形；**quels** /kɛl/ ＝ **qu'il(s)** 近音；写作高频失分点
- **quelque / quel que**：合写 quelque（+ 名词「某个／几个」；+ 形容词＝副词「无论多么」）｜ 分写 quel … que（让步，+ subjonctif）——**合写/分写决定句法**
- 辨析：**quel**（限定词，须跟名词）｜ **lequel**（复合关系代词，独用：Le livre **duquel** je parle 我谈的那本书）｜ **qui**（问「谁／哪个人」——见 [[qui]]）｜ **que**（问「什么／哪个东西」——见 [[que-penses-tu-de]]）
