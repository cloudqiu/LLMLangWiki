# classeur

**释义**：文件夹、档案夹（收纳并分类文件的夹子）；亦指「分类者」（少见） ｜ chemise ou reliure servant à classer des documents

**例句**
- _Range les feuilles dans le classeur._ 把这些纸收进文件夹。
- _J'ai acheté un classeur pour mes cours._ 我买了一个文件夹放我的课程资料。
- _Ce classeur contient tous mes documents importants._ 这个文件夹装着我所有重要文件。

**形态要点**
- 名词：`le classeur`（m.）；复数 `classeurs`（规则加 -s）
- 构词：**classer**（分类）+ 后缀 **-eur**（表「工具/器物」）——法语 -eur 既可表「做某事的人」（classeur 也指「分类者」，少用）也可表「器具」（本义项）
- 同族：classe（班级、类别）、classer（分类）、classement（分类、排名）、classé（分类的、保密的）

**词源 / 构词**
- 拆解：**classer**（分类）+ **-eur**（工具/施事者后缀）＝「用来分类的东西」→「文件夹」
- 演变：拉丁 **classis**（原义「被召集起来的一群人」——古罗马按财产召集公民所成的「等级/军团」，classis navalis「舰队」）→ 法语 **classe**（类别、班级）→ 动词 **classer** → 名词 **classeur**——classis 本义「召集（Aufgebot）」据 Krebs《Antibarbarus》转引（2026-10-01 经检索转引）；classeur「文件夹」的具体定年待验证
- 同族 / 派生：classe、classer、classement、classifier（拉丁化借词）；英语一侧见下节
- 记忆钩：class-（类别）+ -eur（工具）＝「把文件分门别类的东西」；classe 的「班级」义就是「把学生分成的一类」

**英法交叉核对（受影响的英语词）**
- 借入英语：**class**（← 法语 classe ← 拉丁 classis，16c 借入「等级/类别」义，后扩展「班级」「社会阶层」——「学校班级」义 17c）；**classify / classification**（← 法语 classifier / classification，拉丁化构词）
- 共祖未借入：（无——英语侧直接经法语借入）
- 核对：class ← classe ← classis（拉丁 classis 原义「召集的群体/军团」）；据 etymonline 与 Académie 转引（2026-10-01 经检索转引）

**同义 / 搭配 / 易混**
- 搭配：`un classeur à anneaux`（活页夹）；`ranger dans un classeur`（收进文件夹）
- 易混：**classeur**（文件夹）｜ **classe**（班级/类别）｜ **classement**（排名/分类）；「文件夹」义与 **dossier**（档案、卷宗）相近——classeur 偏「收纳夹」，dossier 偏「一份档案」
- 注意：法语「教室」是 **salle de classe**，不是 classeur
