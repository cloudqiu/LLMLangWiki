# étagère

**释义**：搁板、置物板；（多层）架子、书架 ｜ planche fixe ou meuble à tablettes pour poser des objets ou ranger des livres

**例句**
- _Les livres sont rangés sur l'étagère._ 书摆在架子上。
- _Il a fixé une étagère au-dessus du bureau._ 他在书桌上方装了一块搁板。
- _Cette étagère est pleine de bibelots._ 这个架子上摆满了小摆设。

**形态要点**
- 名词：`une étagère`（f.）；复数 `des étagères`
- **拼写**：é 与 è 两处重音（étagère）——由 étage 加后缀派生
- 用法：une étagère 可指一块搁板，也指整件架子；des étagères 复数常指多层书架的层板；étagère murale（壁架）、étagère à épices（香料架）

**词源 / 构词**
- **拆解**：**étage**（古法语 **estage**「逗留、住所」← 拉丁俗语 **\*staticum**「站立之处、居所」← 拉丁 **stare**「站立」，PIE \*stā-）+ 后缀 **-ier / -ière**（处所 / 器具）
- **演变**：普罗旺斯语 **estagiera**（**1379** 首证，Pansier——CNRTL）→ 法语 **estagiere 1488**（Comptes du roi René，「钉在墙上的木板」——CNRTL 记法语形式系借自普罗旺斯语）；16c. 及 1800（Boiste）再见记载
- **关于另一说（日耳曼 \*stad-「处所」）**：本次多轮检索所见来源（CNRTL / FEW XII 239a : stare；TLF VIII 205a；Pfeifer / DWDS；SAOB；lex.dk）一致指向拉丁 **\*staticum ← stare**；日耳曼说未获明证——标「**待验证**」，暂列备考（不折中、不采）
- **同族 / 派生（法语）**：étage（楼层——同根）、étager（分层摆放）、étagement（层次分布）
- **记忆钩**：stare（站）→ 站立之处 → 一层 → 一层层的架子；法语 étage ＝ 楼层，étagère ＝「层」的架子

**英法交叉核对（受影响的英语词）**
- **借入英语**：**etagere**（n. **1858** ← 法语 **étagère**——etymonline；其他词典记 mid-19c.（1850-55），两说并列）；英语中为装饰家具借词，常保持 étagère 拼写
- **共祖未借入（同根、另支借入）**：**stage**（n. **mid-13c.**「楼层、层」← 古法语 **estage**（12c.）← 拉丁俗语 \*staticum ← stare——与 étage / étagère 同根，系英语从古法语借入的另一支，**非法语 étagère 传入**；现代法语 étage 即其同源词——etymonline）
- 核对：已核实（CNRTL / etymonline，2026-10-03 经检索转引）——étagère 经普罗旺斯语 estagiera（1379）、法 1488 首见；étage ← estage ← \*staticum ← stare（FEW / TLF 线）；英 etagere 1858 ← 法语（他典 1850-55 并列）；英 stage mid-13c. ← 古法语 estage

**同义 / 搭配 / 易混**
- 搭配：`ranger / poser sur une étagère`（在架子上收纳 / 放置）；`étagère murale`（壁架）；`une étagère de bibliothèque`（书架层板）；`étagère à épices`（香料架）
- **易混**：**étagère**（搁板 / 架子——板或架子）vs **bibliothèque**（书柜；图书馆——整体家具）vs **rayonnage**（货架组——多层钢架，仓库 / 超市用）
- 收纳 / 阅读簇：[[classeur]]（文件盒）、[[librairie]]（书店）、[[marque-page]]（书签）、[[roman]]（小说）
