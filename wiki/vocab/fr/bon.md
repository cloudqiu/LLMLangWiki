# bon

**释义**：（1）好的、良好的（un bon repas 一顿好饭；une bonne idée 好主意）；（2）（人）善良的、和蔼的（Il est très bon. 他很善良）；（3）合适的、正确的（le bon moment 恰当的时机；la bonne réponse 正确答案）；（4）感叹 / 话语标记：好、行（Bon, on y va. 好吧，我们走）；（5）n.m. `le bon` 凭单、券（un bon de commande 订购单）；n.f. `la bonne` 女佣 ｜ qui a les qualités voulues ; agréable au goût ; convenable ; (n.m.) titre, coupon ; (n.f.) domestique

**例句**
- _C'est un bon restaurant, on y mange très bien._ 这是一家好餐馆，我们在那儿吃得很好。
- _Elle a eu une bonne idée._ 她有了个好主意。
- _Bon, il est temps de partir._ 好，该出发了。

**形态要点**
- 形容词：阳性单数 `bon` ／ 阴性 `bonne` ／ 阳性复数 `bons` ／ 阴性复数 `bonnes`——注意发音：bon 鼻化 /bɔ̃/，bonne 不鼻化 /bɔn/
- 比较级 / 最高级**不规则**：meilleur（更好）、le meilleur（最好）——与 bon 义同而根异（← 拉丁 melior / optimus）
- 兼类：n.m. `le bon`（凭单、券——le bon de commande 订购单、le bon d'achat 购物券）；**n.f. `la bonne`（女佣、女仆——阴性名词，与形容词阴性同形，别漏）**；`Bon.` 亦作话语标记（转换话题 / 勉强同意）
- 常见短语：`bon appétit`（好胃口）；`bonjour` / `bonsoir` / `bonne nuit`（问候词族 ← bon + jour / soir / nuit）；`bon marché`（便宜——固定短语，作定语时 bon 一般不变：des chaussures bon marché）；`à quoi bon`（何必）；`pour de bon`（当真、彻底）；`bon courage`（加油）；`bonne chance`（祝好运）
- **收录说明**：inbox 收录形式为阴性 `bonne`，按 lemma 规则归并到阳性单数 **bon**（本页同收形容词 bon / bonne 与名词 le bon / la bonne 的用法）。

**词源 / 构词**
- **拆解**：拉丁 **bonus**「好」（形容词）；比较级 **melior**「更好」、最高级 **optimus**「最好」为**异干补充**（同一个「好」的 paradigm 由不同词根拼合）；bonus 本义或为「有用、能干、称职」，出自原始意大利语 **\*dw-eno-**「好」，可溯至 PIE 词根 **\*deu- (2)**「做、履行、施惠」〔etymonline，2026-10-03 经检索转引〕
- **演变**：拉丁 bonus → 通俗 / 晚期拉丁 bonu- → 古法语 **bon**（Académie 9e 记 10 世纪已见，形式 **buon**，du latin bonus〔2026-10-03 经检索转引〕）→ 现代法语 bon / bonne（阴性 ← 拉丁 bona）
- **同族 / 派生（法语）**：bonté（善良 ← 拉丁 bonitatem）、bonheur（幸福——bon + heur 构词）、bonhomme（老好人）、bonbon（糖果——bon 的儿语重叠）、meilleur（更好）、améliorer（改善 ← melior 线）；问候词族 bonjour / bonsoir / bienvenue
- **记忆钩**：bonus / melior / optimus 三个不同根共用一个「好」——像英语 good / better / best 一样不规则；etymonline 指出「'好』的词普遍如此」（是语义共性，不是共同来源）

**英法交叉核对（受影响的英语词）**
- **借入英语**：
  - **bonus**（n. 1773「额外给予的钱物」，语出「Stock Exchange Latin」——取自拉丁 **bonus**「好」；「红利」义 1808；bonus army 1932〔etymonline，2026-10-03 经检索转引〕——**拉丁直借，非经法语**）
  - **短语整体借入**：**bon appétit**（1860）、**bon voyage**（1670s）、**bon mot**（「妙语」，1735）、**bon vivant**（1690s）、**bonhomie**（1803 ← bonhomme）、**bonbon**（17c——法语儿语重叠词）、**bon-ton**（1744）、**bon jour**（1570s，今拼 **bonjour**）〔etymonline，2026-10-03 经检索转引〕
  - **boon**（early 14c「愉快的、友善的」← 古法语 **bon**「好」，残留于 boon companion「酒友」；此 boon 与「恩惠 / 请求」义的 boon（← 古诺斯 bón）在英语中形义合流——**待验证**〔etymonline，2026-10-03 经检索转引〕）；**bounty**（← 古法语 bonte / 拉丁 bonitatem）
- **共祖未借入**：**good / better / best** 与 bonus / melior / optimus **不是共祖**——good ← 古英语 **gōd**（长音）← 原始日耳曼 \*gōda-（更深或 ← PIE \*ghedh-「合、适合」）；拉丁 bonus ← PIE \*deu-「做、施惠」——两条线各自演化（etymonline 并提 Latin bonus, melior, optimus 只为说明「'好』词普遍不规则」）〔2026-10-03 经检索转引〕
- 核对：已核实（etymonline；Académie 9e〔CNRTL〕，2026-10-03 经检索转引）——法语 bon 10c 已见（buon）← 拉丁 bonus；bonus ← 原始意大利 \*dw-eno- ← PIE \*deu- (2)，本义或「有用、称职」；英 bonus 1773 ← 拉丁直借（1808 红利义）；bon appétit 1860 / bon voyage 1670s / bon mot 1735 / bon vivant 1690s / bonhomie 1803 / bonbon 17c / bon-ton 1744 / bon jour 1570s（etymonline）；good ← 古英语 gōd（长音）← 原始日耳曼 \*gōda-，与 bonus 无关。**待验证**：boon 两义合流细节；la bonne（女佣）的 TLFi 首证年代未直连核对

**同义 / 搭配 / 易混**
- **经典易混：bon（形容词「好的」）vs `bien`（副词「好地」）**——对应英语 good（形）/ well（副）的分工：
  - 修饰**名词**用 bon（un bon film 一部好电影；une bonne idée 好主意）；修饰**动词**用 bien（Il travaille bien. 他工作得好；Il parle bien français. 他法语说得好）
  - _C'est bon._ ＝「（吃的）不错／好了、行了」——评价事物的状态（味道、是否完成）；_C'est bien._ ＝「（这）不错／挺好」——评价事情本身或表示认可（常带轻微保留：「还行」）。一句话记：bon 评**物**，bien 评**事**
  - 主语是人时：_Il est bon._ 他心地好（品质）；_Il est bien._ 他（过得／表现）不错——同主语两义，靠 bon / bien 切换
  - 第二组同类：**meilleur**（bon 的比较级：形容词，更好）vs **mieux**（bien 的比较级：副词，更好地）——_Il est meilleur que moi._ 他比我强 ｜ _Il travaille mieux que moi._ 他工作得比我好
- 搭配：`un bon repas`（一顿好饭）；`bonne chance`（祝好运）；`bon courage`（加油）；`bon appétit`；`bon marché`（便宜）；`à quoi bon`（何必）；`pour de bon`（当真）
- **faux ami**：英语 **bonus**（奖金）在法语日常对应 **prime**（奖金、津贴）；法语近年也直接借用英语 bonus 说「额外奖励」（如 le bonus écologique 环保奖励）——**英→法反向借入**（年代**待验证**）；名词 `le bon`（券）与英语 bonus（奖金）不是一回事
