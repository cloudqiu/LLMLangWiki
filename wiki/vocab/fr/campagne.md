# campagne

**释义**：（1）**乡村、农村**（habiter à la campagne 住在乡下——对立于城市 *la ville*）；（2）**田野、原野**（en rase campagne 在空旷的原野上）；（3）**战役**（la campagne de Russie 俄国战役）；（4）**运动、造势**（campagne électorale 竞选活动；faire campagne 造势）；（5）**（一段）作业期、生产季**（campagne betteravière 甜菜榨季） ｜ région rurale, hors des villes ; étendue de pays plat ; opérations militaires ; ensemble d'actions organisées

**例句**
- _Ils passent l'été à la campagne._ 他们在乡下过夏天。
- _La campagne électorale commence demain._ 竞选活动明天开始。
- _L'armée s'est avancée en rase campagne._ 军队在空旷的原野上推进。

**形态要点**
- 名词：`la campagne`（**f.**）；复数 **campagnes**
- 用法搭配：`à la campagne`（在乡下）｜ `en rase campagne`（在旷野 / 毫无掩护地）｜ `faire campagne`（竞选 / 造势）｜ `campagne électorale / publicitaire`（竞选 / 广告活动）｜ `se mettre en campagne`（出动、开始行动）
- 注意：**campagne**（乡村 / 战役 / 运动）与 **[[champ]]**（田、田地）同族但不同词

**词源 / 构词**
- **拆解**：拉丁 **campus**「田野、平地」→ 晚期拉丁 **campania**「平原地带」→ 古法语 **champagne / champaigne**「开阔原野」→ **诺曼-皮卡第形 campaigne** → 现代 campagne
- **演变**：拉丁 campus → campania → 古法 champagne（原野；今 **Champagne / champagne** 香槟地区的同源词）→ 北方形 campaigne → campagne；**首见两说**：**1535**（Ouest-France）vs **1536**（TLFi，C. A. Mayer 校《Épître 45》v.69，义「大片平坦开阔之地」）——**两说并列**；Académie 9e 只记 xvie s.（campaigne）。义项分期：军事义 **1587**（artillerie de campagne）、「军事远征」与「乡村（对立于城市）」**1671**
- **词源竞争说**：①**借自意大利语 campagna**（REW 1557）——TLFi 认为「原野」义**不必**借意大利语（古法已有诺曼-皮卡第形 campaigne，Tobler-Lommatzsch）；②16 世纪意大利语影响法语军事词汇，故**军事义**或受意大利语推动——**二者并存，未静默择一**
- **同族 / 派生（法语）**：**champ**（田）、**Champagne / champagne**（地区名 / 香槟）、**campagnard**（乡下的 / 乡下人）、**campagne**（政治宣传义）
- **记忆钩**：campagne 的核心是「**平野**」——从「原野」→「（打仗的）野地」→「战役」→「（造势的）活动」

**英法交叉核对（受影响的英语词）**
- **借入英语**：**campaign**（n. 1640s「军中野外作战」← 法语 **campagne**；1790 泛化、1809 起用于美国政治活动——etymonline 转引）；**champagne**（1660s ← 法语 *vin de Champagne*，与 campagne **同出拉丁 campus**，经地区名）——**两词皆借自法语**
- **共祖未借入**：拉丁 campus 直接给了英语 **camp**（← 拉丁 campus / 意大利 campo，**非经法语**）、campus（现代义「校园」）
- **同义异源**：英语「乡村」用 **countryside**（← 本族 / 日耳曼语成分）+ country——与 campagne 无亲缘
- 核对：英语侧（campaign 1640s、champagne 1660s）经检索转引 etymonline（2026-10-11）；法语侧首见 1535 / 1536 与 campania 链据 TLFi / Ouest-France / Académie 9e 转引（**待验证**）
- **faux ami 提示**：法语 campagne **兼「乡村」义**，英语 campaign **只有「战役 / 运动」义**——英语的「乡村」是 countryside / country

**同义 / 搭配 / 易混**
- 搭配：`à la campagne`（在乡下）｜ `la campagne` 对立 `la ville`（城市）｜ `en rase campagne`｜ `campagne électorale`｜ `faire campagne pour / contre`（为…造势 / 反对）｜ `campagne de presse`（舆论战）
- **易混**：**campagne**（乡村 / 战役 / 运动）vs **[[champ]]**（田）vs **pays**（地方 / 国家）vs **campagnard**（乡下人，可带贬义「土气」）
- 相关：[[champ]]（同族，待收）；香槟线 **champagne**
