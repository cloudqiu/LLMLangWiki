# salaire

**释义**：工资、薪水（按固定周期支付的报酬） ｜ rémunération versée régulièrement en contrepartie d'un travail

**例句**
- _Il touche un bon salaire._ 他拿一份不错的薪水。
- _Elle demande une augmentation de salaire._ 她要求加薪。
- _Le salaire minimum a été relevé._ 最低工资上调了。

**形态要点**
- 名词：`le salaire`（m.）；复数 `salaires`（规则加 -s）
- 常见搭配：`un salaire mensuel / annuel`（月薪/年薪）、`augmentation de salaire`（加薪）、`salaire minimum`（最低工资，即 SMIC 所涉）、`toucher / percevoir un salaire`（领薪水）

**词源 / 构词**
- **拆解**：拉丁 **salarium**「买盐的钱」＝ **sal**「盐」+ 后缀 -arium（「与…相关之物」）——原义「士兵的**盐饷**」，因古罗马一度以盐作士兵津贴之一部分（据 Lewis & Short「salt-money, soldier's allowance for the purchase of salt」——etymonline 转引，2026-10-01 经检索转引）
- **演变**：拉丁 sal「盐」→ salarium「盐饷 → 津贴 → 薪水」→ 古法语 **salaire** → 现代法语 salaire；同根法语词 **sel**（盐）、**saler**（加盐、腌）、**salé**（咸的）；PIE 词根 ***sal-**「盐」（etymonline 明言出自此根）
- **同族 / 派生**：sel（盐）、saler（加盐）、salé（咸的）、salière（盐瓶）、salaison（腌制）；英语一侧见下节
- **记忆钩**：salaire ＝ sal（**盐**）+ -aire＝「买盐的钱」——「值得你那份盐」的报酬；「盐」在古罗马贵如硬通货，拿薪＝拿盐

**英法交叉核对（受影响的英语词）**
- **借入英语**：**salary**（late 13c. ← 盎格鲁-法语 salarie / 古法语 salaire「工资、报酬」← 拉丁 salarium「盐饷」——etymonline，2026-10-01 经检索转引；19c. 起 salary 专指「按周期支付的固定报酬」）；**saline / salinity**（「盐的、咸的」——出拉丁 sal，同根但非经法语借入的「盐」词族）
- **共祖未借入**：**salt**（英语本族词，PIE ***sal-**「盐」——与拉丁 sal 同出 PIE 根，**同源非借入**）；**salad**（「凉拌菜」出拉丁 sal「盐」——因古时以盐调味，经古法语 salade 借入，同出 sal 根）；**sauce / sausage / salami / salsa**（均出 sal「盐」这条线，多为经拉丁/罗曼语的借入）
- 核对：已核实（etymonline，2026-10-01 经检索转引）——salary late 13c. ← 古法语 salaire ← 拉丁 salarium；PIE *sal-「盐」词族含 salt（本族共祖）/ salad / sauce / sausage / salami / salsa / saline；古罗马 Via Salaria「盐路」即因萨宾人走此路运海盐而得名

**同义 / 搭配 / 易混**
- 搭配：`augmentation de salaire`（加薪）、`salaire minimum`（最低工资）、`salaire brut / net`（毛/净工资）、`toucher son salaire`（领工资）
- **核心易混——「工资」辨析**：**salaire**（工资、薪水——按周期固定支付，雇员）vs **paie / paye**（工钱、工资单——偏「体力/手工劳动者的按日周计发」）vs **traitement**（俸给——偏「公务员、教师等公职/白领的待遇」）vs **solde**（军饷——偏「士兵」）；etymonline 亦记此法国「工资」词群按阶层细分（salaire 工人、traitement 教授、paye、solde 士兵、gages 佣仆）
- **faux amis 警示**：salaire ≠ 英语 salary 完全等值——法语口语常以 paie 泛指「到手的工钱」，salaire 偏正式；「盐」与「薪」的词源勾连是两语共享的经典故事
- 注意读音 /sa.lɛʁ/：-aire 读 /ɛʁ/，勿读成英语 -ary 的 /eəri/
