# épouser

**释义**：（1）**娶、嫁**——与某人结婚（épouser qqn 娶／嫁给某人；il a épousé une infirmière 他娶了一位护士）；（2）**（宗教／仪式）缔结婚姻**（se faire épouser；les épousés 新婚夫妇）；（3）引申：**拥护、赞同（某项事业、主张）**（épouser une cause 拥护一项事业；épouser les idées de qqn 赞同某人的想法）；（4）引申：**（事物）紧密贴合**（la robe épouse les formes du corps 裙子贴合身形） ｜ se marier avec, prendre pour époux/épouse ; (fig.) adopter, embrasser

**例句**
- _Elle a épousé un médecin l'an dernier._ 她去年嫁给了一位医生。
- _Ils se sont épousés à la mairie du village._ 他们在村政府结的婚。
- _Ce député a épousé la cause des sans-abri._ 这位议员站在了无家可归者一边。
- _Cette robe épouse parfaitement sa silhouette._ 这条裙子完美贴合她的身形。

**形态要点**
- 动词（v.）：不定式 **épouser** ｜ 组别：**1er groupe** ｜ 助动词：**avoir**（复合时态：j'ai épousé） ｜ 过去分词：**épousé**
  现在时：j'épouse ｜ tu épouses ｜ il·elle épouse ｜ nous épousons ｜ vous épousez ｜ ils·elles épousent
- 完全规则，**无拼写变化**（非 -ger / -cer / -ayer）；**代词式 se épouser → 缩合 s'épouser**（Ils se sont épousés，此处复合时态**用 être**：代词式动词一律 être）
- 关键拼写：**开头是 é-**（不是 e-），须带闭音符（← 古法 **es-** 的 -s- 于 15 世纪后脱落，es- 缩为 é-）；同型：**étudier**（← estudier）、**écouter**（← escouter）、**écrire**（← escrire）、**étrange**（← estrange）
- 名词化亲属：**l'époux / l'épouse**（配偶；新郎／新娘）、**les épousailles**（旧：婚礼）、**l'épousée**（新娘，古）

**词源 / 构词**
- **拆解**：俗拉丁 **sponsare**「许诺结婚、订婚」——是拉丁 **spondere**「**郑重承诺、起誓、缔结**」的**第一组反复／派生形**，建立在 **supin 词干 sponsum** 之上（fr.wiktionary 原文：「Du latin spondere qui devient, en bas latin sponsare」；「une forme itérative du premier groupe formée sur le radical du supin sponsum」）
- **e- 的来源（重要）**：拉丁 **sp- / sc- / st- 开头的词**在后期拉丁使用者口中被视作拗口，遂**冠以元音 e-**（etymonline 明述此现象），经古法语带入罗曼语；法语 **15 世纪后**「s」脱落，改以**闭音符（accent aigu）**标记，兼或按拉丁重塑拼写 → **es- → é-**
- **演变（CNRTL/TLFi，2026-10-05 经 WebSearch 转引；CNRTL 直连失败）**：
  - 古法语 **espouser / espuser**（DMF 记 **ESPOUSER** 词条，引 **T-L : esposer ; GDC : espouser ; AND : espuser**）
  - **首证：xie siècle**（Dictionnaire de l'Académie française 9e éd.：「**xie siècle**. Issu du bas latin sponsare »；etymonline 亦记古法 espouser「11c.」）
  - DMF 引 **FEW XII, 210 : sponsare** 与 **TLF VIII, 34b : épouser**
  - 古义：「se marier avec qqn, s'unir avec qqn par mariage selon les formes requises」（按既定仪式与某人结婚）
- **同族 / 派生（法语）**：**l'époux / l'épouse**（← 拉丁 **sponsus / sponsa**「新郎／新娘」，经古法 espus / espuse）；**les épousailles**（← sponsalia「婚约」）；**l'épousée**
  - **旁支（同根异义）**：**répondre**（回答 ← respondere）、**promettre**（承诺 ← promittere；同出「许诺」语义场）、**spontané**（← spontaneus，与 spondere 同出 \*spond-）
- **记忆钩**：épouser 的根是 **spondere**「起誓」——婚礼即**誓言**；同根词 **répondre（回应）、sponsor（保证人）** 都在「承诺—担保」这一语义圈里

**英法交叉核对（受影响的英语词）**——**本节是重点**
- **借入英语（古法语 → 英语）**：
  - **`espouse`**（v.「娶／嫁；拥护」）——**mid-15c.** 首证「to take as spouse, marry」← 古法语 **espouser**（**11c.**，现代法语 **épouser**）← 拉丁 **sponsare**（spondere 的过去分词／supin 词干）。**1620s** 起语义拓宽为「拥护（某项事业、党派）」（to espouse a cause）——**此比喻义英语先成，法语 épouser une cause 与之同型**
  - **`spouse`**（n.「配偶」）——**c. 1200** ← 古法语 **spus / spuse** ← 拉丁 **sponsus / sponsa**（「新郎／新娘」，spondere 的分词名词化）——与法语 **époux / épouse** **同源对借**
  - **`espousal` / `espousals`**（n.「婚礼；拥护」）——← 古法语 **espousailles** ← 拉丁 **sponsalia**；与法语 **les épousailles** 同源
- **共祖未借入（拉丁 spondere 线）**：**`sponsor`**（n. ← 拉丁 **sponsor**「保证人」，与 sponsare 同出 spondere）、**`spontaneous`**（← 拉丁 **spontaneus**，\*spond- 家族）、**`despond` / `despondent`**（← 拉丁 **despondere**「放弃、失去」）、**`respond`**（← 拉丁 **respondere**）——皆含拉丁 **spondere** 根，属**共祖**（多经拉丁／法语旁支，非由 épouser 传入）
- **同源对照**：法语 **époux / épouse** ↔ 英语 **spouse**——**同一拉丁 sponsus/sponsa，经古法语 espus/espusa 分别进入两语**；法语后来丢掉 -s-（é-），英语保留 sp-（spouse）
- 核对：英语侧（espouse mid-15c ← Old French espouser 11c ← Latin sponsare；比喻义 1620s；spouse c.1200 ← OF spus/spuse ← Latin sponsus/sponsa；e- 前缀现象、15c 后法语丢 -s- 改闭音符）2026-10-05 **etymonline 直读**；法语侧（spondere → 俗拉丁 sponsare、supin 词干 sponsum 的反复形；古法 espouser/espuser；首证 **xie siècle** Académie 9e；FEW XII 210、TLF VIII 34b；DMF 词条 ESPOUSER）2026-10-05 经 **WebSearch 转引 CNRTL/TLFi、Académie 9e、DMF 与 etymonline**。
- 命名提示：英语 `espouse` / `spouse` / `sponsor` 页尚未建；日后建页因词形不同，无须 `-en` 后缀，两页互标「同源对借」

**同义 / 搭配 / 易混**
- 搭配：`épouser qqn`（娶／嫁给某人）｜ `se faire épouser`（被娶／被嫁；让人娶／嫁自己）｜ `épouser une cause / un parti`（拥护事业／政党）｜ `épouser les idées / les vues de qqn`（赞同某人的想法）｜ `épouser la forme de qch`（贴合某物形状）｜ `être bien / mal épousé` 类口语（嫁得好／不好）
- **介词要点**：**épouser qqn**（直接及物，**不用 avec**）——与 **se marier avec qqn** 相对照：法语「和某人结婚」是 **se marier avec**，但「娶／嫁给某人」是及物的 **épouser qqn**；**épouser** 表「拥护」时亦直接及物
- 辨析：**épouser**（娶／嫁——及物；亦「拥护」）｜ **se marier (avec qqn)**（结婚——代词式，须 avec）｜ **marier**（把……嫁出／使成婚：marier sa fille）｜ **se fiancer (avec)**（订婚）｜ **s'unir à**（结合，书面）
- 易混名词：**l'époux / l'épouse**（配偶；新郎／新娘）↔ **l'épou**（**无此词**，注意拼写）↔ **la poux**（**勿混**，无意义）；**les époux**＝夫妻
