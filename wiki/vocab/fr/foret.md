# forêt

**释义**：（1）**森林**（vaste étendue de terrain peuplée d'arbres）；（2）**（引申）林立的东西**（forêt de mâts 桅杆林立）｜ grande étendue boisée

**例句**
- _Nous nous promenons dans la forêt._ 我们在森林里散步。
- _Cette forêt est protégée depuis 1990._ 这片森林自 1990 年起受保护。
- _Une forêt de grues domine le port._ 港口上塔吊林立。（隐喻）

**形态要点**
- `la forêt`（f.）；复数 **forêts**（**加 circumflex，对应词源中脱落之 s**）
- 派生：**forestier**（林业的 / 林业工人）、**foresterie**、**déforestation**、**forestage**、**forêt-galerie、forêt-jardin、microforêt**
- 介词：`dans la forêt`｜ `en forêt`
- **易混 / 辨析**：`forêt`（森林）vs `bois`（树林，较小）vs `sylve`（诗 / 学术）vs `jungle`（热带雨林）

**词源 / 构词**
- **拆解**：← 中古法语 **forest** ← 古法语 **forest** ← **晚期拉丁 [silva] forestis**（省略 silva）← 拉丁 **forum**「法庭」（**主流说**）
- **首证**：**1121–1134**，形 *forest*，义「大片林地」（Ph. de Thaon，*Bestiaire*, 401，ds T.-L.）
- **语义演变（本词要点）**：拉丁 *forestis* 先指「**归王之司法管辖的林地**」→「从公共用途划出、国王保留使用的领土」（**648** 已在拉丁文书，ds Nierm.）→ 因禁令多施于猎物栖息的林地，*forestare* 遂得「造林」义、树亦随之生长 → 法语 **forêt**「森林」
- **词源诸说并存（须显式记录，不折中）**：
  - ① **forum**（Diez 反对；Kaufmann 主张「ban / 禁令」义）——**主流**
  - ② **foris / foras**「外面」（Frisch 提，forestis silva「外面的林子」，对 parcus 园囿）——etymonline / EWA 亦重
  - ③ 高地德语 **foraha**（松树）——Diez 反驳：失 h 难解释
  - ④ 凯尔特 **\*dvorestu-**（威 *fforest*）——EWA 列可能
- **记忆钩**：forêt 的底是「**王家的禁林**」——先是一片**归王法管的林地**，才长成「森林」

**英法交叉核对（受影响的英语词）**
- **借入**：英语 **forest** ← 古法语 **forest**（**late 13c.**）——**借入**；取代古英语 *wudu*（wood）。可能与古高地德语 *forst* 相关
- **共祖（若取 foris 说）**：英语 **foreign / foris** 与 forêt 若从 foris「外面」说则**共祖**；但英语 **forest** 本身是**借入**
- **注意方向**：德语 **Forst** 今日词源学界认为系**从罗曼语传入德语**（**非反向**）
- 核对：英语侧经检索转引 etymonline（2026-10-13）

**同义 / 搭配 / 易混**
- 搭配：`forêt domaniale / privée`（国有 / 私有林）｜ `coupe à blanc`（皆伐）｜ `forêt vierge`（原始林）
- 相关：[[campagne]]、[[riviere]]（同「自然 / 乡野」域）
