# voir

> 收录说明：inbox 里的遇到形式是 **vu**（过去分词）——按 lemma 规则归并至不定式 **voir**。

**释义**：（1）看见、看到；（2）明白、看出；（3）voir qn（见某人） ｜ percevoir par les yeux ; comprendre

**例句**
- _Je vois la tour Eiffel._ 我看见埃菲尔铁塔。
- _Tu vois ce que je veux dire ?_ 你明白我的意思吗？
- _On se voit demain._ 我们明天见。

**形态要点**
- 动词：不定式 **voir** ｜ **3e groupe** ｜ 助动词 **avoir** ｜ 过去分词 **vu**
- 现在时六形：je **vois** ｜ tu **vois** ｜ il·elle **voit** ｜ nous **voyons** ｜ vous **voyez** ｜ ils·elles **voient**（注意 nous/vous 词干 voy-）
- 代词式：se voir（相见）；固定结构 voir + 不定式（voir venir 料到）

**词源 / 构词**
- **拆解**：单语素——拉丁 **videre**「看」（PIE \*weid-「看、知」）
- **演变**：PIE \*weid-「看」→ 拉丁 videre → 古法语 veoir → 法语 voir（-e- 与 -oi- 的更替是古法语音变；**年代待验证**）；同 PIE 根分出的「看」与「知」两线：拉丁 videre（看）与英语 wit（知）
- **同族 / 派生**：voyant（预言者、明眼人）、prévoir（预见）、revoir（再见、复习）、visible（可见的）、vision、vu（过去分词/「鉴于」au vu de）；英语一侧见下节
- **记忆钩**：voir 与英语 view / video / vision 同出「看」根；法语 voir「看」与英语 wit「知」是 PIE \*weid- 的一体两面——「看见」即「知道」

**英法交叉核对（受影响的英语词）**
- **借入英语**：**view**（← 盎格鲁-法语 veue ← 古法语 veoir「看」——法语本词的后裔，14c.）；**preview / review / interview**（← view 派生或再借）；**voyeur**（「偷窥者」，← 法语 voir + -eur，1910s 借入）
- **共祖未借入**：**wit / witness / wise / wisdom / guide**（同出 PIE \*weid-「看/知」，日耳曼/希腊支——共祖非借入）；**video / vision / visible / visit**（← 拉丁 videre 家族，经拉丁直接入英——共祖）
- **词源陷阱（勿混）**：英美法律术语 **voir dire** 里的 voir 是古法语「真」（← 拉丁 verum），与「看」**无关**；英语 **voyage** 也非 voir（← 拉丁 viaticum「路费」）——两个拼写相近的假亲戚
- 核对：view / voyeur 借入年代标**待验证**，待联网核实

**同义 / 搭配 / 易混**
- 搭配：`voir qn / qch`（看见，直接宾语）；`voir clair`（看清楚）；`voyons voir`（口语「看看再说」）；`au vu de`（鉴于）
- **核心易混——voir vs regarder**：**voir** 看见（被动感知，无意志）｜ **regarder** 看（主动注视，有意图）——regarder un film（看电影），Je vois un oiseau（我看见一只鸟）；别把「看电影」说成 voir un film（不地道，应用 regarder）
- 再易混：**voir vs entendre**（看见 vs 听见）；**se voir**（相见）vs **se regarder**（互相注视）
- **faux ami**：voir ≈ see（基本对齐）；但英语 "I see"（我明白）与法语 je vois 的「明白」义同样存在
