# proche

**释义**：（adj.）近的、接近的；亲近的、亲密的；（n.）亲人、亲近的人 ｜ voisin, qui est à peu de distance ; intime ; (nom) parent, ami intime

**例句**
- _C'est un ami très proche._ 这是一位很亲近的朋友。
- _La gare est proche d'ici._ 车站离这儿很近。
- _Elle a perdu un proche._ 她失去了一位亲人。

**形态要点**
- 形容词：**proche**（阴阳**同形**）；复数 **proches**；比较级 **plus proche** / 最高级 **le plus proche**（注意：不是 prochain——prochain 是「下一个」，见下）
- 名词：`un proche`（m.）/ `une proche`（f.）——亲人、亲近的人；复数 `les proches`（亲属、亲友）
- **核心辨析**：**proche**（形容词「近的」）vs **près de**（介词短语「在……附近」）vs **prochain**（形容词「下一个的」）；proche 作形容词接 de：`proche de qch/qn`（接近……）

**词源 / 构词**
- **拆解**：拉丁 **prope**「近」（副词/介词）→ 俗拉丁派生形（含比较级 **propius / propior** 之形）→ 古法语 **proche**；PIE ***per-**（1）「向前」——\*propro「一再向前」引申「向前即临近」
- **演变**：PIE \*per-「向前」→ 拉丁 prope「近」→ 比较级 propior/propius → 派生 → 古法语 proche → 法语 proche；同一根上长出 **proximus**「最近的」（→ 法语 proximité「邻近」、英语 proximity）与 **prochain**（← 俗拉丁 \*propeanus「附近的」）
- **同族 / 派生（法语）**：approcher（接近）、rapprocher（拉近）、rapprochement（接近、和解）、prochain（下一个的）、proximité（邻近）、proche de（接近……）；英语一侧见下节
- **记忆钩**：proche / près / prochain 三个「近亲」别混——proche 是形容词「近」，près de 是介词「附近」，prochain 是「下一个」（「最近的将来」→「下一次」）

**英法交叉核对（受影响的英语词）**
- **借入英语**：**approach**（v. c. 1300 ← 古法语 **aprochier**〔12c.，现代法语 approcher〕← 晚期拉丁 **appropiare / adpropiare**「走向」← ad- + 晚期拉丁 propiare「靠近」——propiare 即 prope「近」的比较级派生动词〔etymonline，2026-10-01 经检索转引〕）；**rapprochement**（原样借入，外交「和解、接近」）
- **共祖未借入**：**propinquity**（← 拉丁 propinquitas ← propinquus「近的」← prope，直承拉丁）；**proximity / proximate**（← 拉丁 proximitas / proximus「最近的」← prope，直承拉丁）；**approachable**（由 approach 派生）
- 核对：已核实（etymonline，2026-10-01 经检索转引）——approach c. 1300 ← 古法语 aprochier ← 晚期拉丁 appropiare ← ad + propiare ← 拉丁 prope「近」；propinquity late 14c. ← 拉丁 propinquitas ← propinquus ← prope（注：\*propro「一再向前」，PIE \*per-「向前」）

**同义 / 搭配 / 易混**
- 搭配：`proche de qch/qn`（接近某物 / 某人）；`un ami proche`（亲近的朋友）；`un proche parent`（近亲）；`dans un proche avenir`（在不远的将来——注意此处用 proche 修饰 avenir）
- **核心易混（法语「近」三兄弟）**：**proche**（adj. 近的、亲近的——un ami proche）vs **près de**（prép. 在……附近——près de la gare 在车站附近，介词短语不作定语）vs **prochain**（adj. 下一个的——le prochain arrêt 下一站；prochaine fois 下次）
- 再易混：**proche**（n. 亲人）vs **parent**（n. 亲属、父母——les parents 父母）vs **ami**（朋友）；les proches ≈ 亲友（比 parents 更泛，含密友）
- **faux ami**：proche ≈ near / close（对齐）；英语 near 是介词 / 形容词 / 副词三位一体，法语须按词性换词（près de / proche / près）
