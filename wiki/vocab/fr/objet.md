# objet

**释义**：（1）物品、东西（un objet d'art 艺术品）；（2）对象、目标、主题（l'objet de la discussion 讨论的主题；l'objet d'une étude 研究的对象）；（3）（语法）宾语（complément d'objet 宾语）；（4）sans objet：不成立、无标的（行政/法务语） ｜ chose matérielle ; ce à quoi tend la pensée, l'action

**例句**
- _Elle a posé l'objet sur la table._ 她把物品放在桌上。
- _C'est l'objet de la discussion._ 这就是讨论的主题。
- _Cette demande est sans objet._ 这个请求没有意义（不成立）。

**形态要点**
- 名词：`l'objet`（m.——元音开头，冠词省音 le → l'）；复数 `les objets`
- 固定短语：`objet d'art`（艺术品）、`objets trouvés`（失物 / 拾得物）、`sans objet`（无标的）、`l'objet de`（……的对象 / 主题）、`complément d'objet direct / indirect`（直接 / 间接宾语）
- 构词提示：与英语 object 同形近义——objet 系法语承中世纪拉丁 objectum 的自然演变（不是英语借词）

**词源 / 构词**
- **拆解**：拉丁 **objectum**「被置于前之物」（fr.wiktionary：ce qui est placé devant）——**objectus**（**obicere** 的过去分词）的中性名词化；obicere「投置于前、反驳」＝ **ob-**（对着、朝向）+ **iacere**「投、掷」（PIE **\*ye-**「投、推」）——「摆在眼前的东西 → 物品；摆在心智前的东西 → 对象」
- **演变**：拉丁 obicere → 过去分词 obiectus → 中世纪拉丁 **obiectum**（名词化；经院哲学中作「心智的对象」——哲学义之源）→ 古法语 **object**（**1346** 首证，fr.wiktionary 转引）→ 现代法语 objet
- **同族 / 派生**：objectif（目标的；客观的；镜头——n.m.）、objectivement、objectivité、objecter（提出异议）、objection（异议）、objet d'art；英语一侧 object / objection / objective 同源
- **记忆钩**：**ob-（对着）+ jacere（投）**——objet 就是「被扔到你面前的那个东西」；同一个「投」字（iacere）还投出英语 jet / project / eject / subject（法语 jeter「投掷」亦此根——古法语 geter ← 俗拉丁 iectare/iactare 的链条**待验证**）

**英法交叉核对（受影响的英语词）**
- **借入英语**：**object**（n. **late 14c.**「可感知之物」← 古法语 **object** + 直接 ← 中世纪拉丁 **obiectum**「thing put before」；「目的、被瞄准之物」义 early 15c. ← 拉丁 obiectus；语法义 1729；no object 1782）；**object**（v. **c. 1400** ← 古法语 objecter ← 拉丁 obiectare，obicere 的反复态）；**objection**（**late 14c.**）；同族借入：**objective**、**objectivity**、**objectify**（1838）
- **共祖未借入**：**jet / project / eject / subject**（同出拉丁 **iacere**「投」（PIE \*ye-）——与 obicere 共享词根，但各经自己的路径入英，非 objet 一词所派生）
- 核对：已核实（etymonline + fr.wiktionary，2026-10-03）——object(n.) late 14c. ← 古法语 object / 中世纪拉丁 obiectum（obiectus 中性名词化 ← obicere ＝ ob + iacere，PIE \*ye-）；object(v.) c. 1400 ← 古法语 objecter；objection late 14c.；法语 objet 首证 **1346**（形 object，fr.wiktionary 转引；CNRTL 未直连——**待验证**）

**同义 / 搭配 / 易混**
- 搭配：`un objet d'art`（艺术品）；`des objets trouvés`（失物招领处；艺术「拾得物」）；`l'objet de la discussion`（讨论主题）；`sans objet`（不成立）；`complément d'objet`（宾语）
- **易混**：**objet**（物品；对象 / 主题——正式、可数）vs **chose**（东西——最泛、口语）vs **truc / machin**（口语「玩意儿」）；objet vs **objectif**（目标、目的——努力的方向；也指镜头）：**objet** 是「（思维 / 讨论的）对象」，**objectif** 是「瞄准的目标」——英语 objective 对应 objectif，勿用 objet 表达「目标」
- faux ami：法语 objet ≈ 英语 object（义基本对齐）；但英语 **objective**（n. 目标）＝法语 **objectif**；英语 **object**（v. 反对）＝法语 **objecter / s'opposer à**
