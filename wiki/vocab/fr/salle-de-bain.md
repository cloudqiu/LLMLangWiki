# salle de bain

**释义**：n.f. **浴室、卫生间**——家中有浴缸 / 淋浴 + 洗手池的房间 ｜ pièce d'une habitation équipée d'une baignoire ou d'une douche

**例句**
- _La salle de bain est au fond du couloir._ 浴室在走廊尽头。
- _Je nettoie la salle de bain._ 我在打扫浴室。
- _Une salle de bain avec baignoire._ 带浴缸的浴室。

**形态要点**
- 名词：`la salle de bain`（**f.**）；复数 **salles de bain**——fr.wiktionary 标 **salles de bains** 为更常见的拼写变体（复数加 -s）
- 构词提示：名词 + de + 名词，**de 不变**（*salle de bain*、*salle de classe*、*salle à manger*——注意 **à manger** 用 à，表用途）
- 同类房名：*cuisine*（厨房）、*chambre*（卧室）、*salon*（客厅）、*WC / toilettes*（厕所）

**词源 / 构词**
- 拆解（两部分分述）：
  - **salle** ← **古法兰克语 sal**「只有一间的住所」，与德语 *Saal*、瑞典语 *sal* 同源，**8 世纪拉丁化为阴性 *sala***
  - **bain** ← 通俗拉丁 **\*baneum** ← 古典拉丁 **balneum / balineum** ← 希腊 **βαλανεῖον (*balaneîon*)**「浴池」
- 首证：
  - **salle**：**ca 1100**（《罗兰之歌》，作 *sale*）
  - **bain**：**并列冲突**——Académie 9e 记 **xie siècle**；Usito 记 **vers 1100 (in TLFi)**；fr.wiktionary 记 **xvie siècle**（**疑为「现代拼写 / 某义项」而非首现**，该页未给证明）；DMF 见 13 世纪书证（Aldebrandin de Sienne, **1256**）→ **首现待验证**
  - **salle de bain 整个复合词**：fr.wiktionary 作 **xxe siècle（20 世纪）**
- 同族 / 派生：**salle à manger**（餐厅）、**salle de classe**（教室）、**salle d'attente**（候诊室）；**bain**（洗澡 / 浴缸）、**baignoire**（浴缸）、**baigner**（浸洗）、**se baigner**（游泳 / 泡澡）
- 记忆钩：**salle（厅）+ de bain（洗浴的）**——法兰克语给「厅」、希腊语给「浴」，**一屋两名源**

**英法交叉核对（受影响的英语词）**
- **借入 / 同源（英 ← 法，两条不同路径）**：
  - **salon**（**1690s** ← 法语 *salon*「接待厅」17c ← 意大利 *salone* ← *sala* ← 日耳曼 **\*salaz**）
  - **saloon**（**1728**，*salon* 的**英语化变体**；「马车 / 船大厅」1747；「酒馆」美 **1841**）
  - 二者与法语 *salle* **同源**（日耳曼 \*salaz），**但并非直接借自 *salle***
  - **bain-marie**：英 **1733**（cookery）← 法语 *bain-marie* ← 中古拉丁 *balneum Mariae*「**玛利亚之浴**」；法语 *baing marie* **1516**（炼金文本，CNRTL），中古拉丁 *balneum Mariae* 14c 初（Arnaud de Villeneuve）——「**玛丽**」或指**女炼金术士 Mary the Jewess / Marie la Juive**，或喻加热之温和（**二说并列**）
- **⚠️ 反例（务必记，同义异源）**：英语 **bath**（OE *bæþ* ← 原始日耳曼 **\*bathaz**）是**日耳曼词**，与法语 *bain*（希腊-拉丁 *balneum*）**不同源、非共祖**——「洗澡」在英法两语走**两条完全不同的祖线**
- **核对要点**：*salle* 的日耳曼深层（法兰克 \*sal）与英语 *hall* / *salon* / *saloon* 同为日耳曼源，可作「**日耳曼语在法语里的地层**」样本

**同义 / 搭配 / 易混**
- 同义：**toilettes / WC**（厕所——但义域不同）、**cabinet de toilette**（盥洗室，较小）
- 搭配：**prendre un bain**（洗澡）、**robe de bain**（浴衣）、**salle de bain avec baignoire / douche**、**nettoyer la salle de bain**
- **faux ami**：英语 **saloon**（**酒吧**）↔ 法语 *salon*（**客厅 / 沙龙**）；法语 **salle de bain** ≠ 英语 **bathroom** 的全部义项（英语 *bathroom* 常兼指**厕所**，法语 *salle de bain* 不指厕所）
