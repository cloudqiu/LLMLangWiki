# cuisine

**释义**：（1）烹饪、烹调、烹饪法（faire la cuisine 做饭；la cuisine française 法国菜）；（2）厨房（la pièce où l'on prépare les repas）；（3）〈引〉（某地的）菜肴、饮食风格 ｜ art de préparer les aliments ; pièce où l'on fait la cuisine

**例句**
- _Ma mère fait très bien la cuisine._ 我妈妈做菜做得很好。（faire la cuisine 做饭——搭配见 [[faire]]）
- _On mange dans la cuisine._ 我们在厨房里吃饭。
- _Il adore la cuisine italienne._ 他特别喜欢意大利菜。

**形态要点**
- 名词：`la cuisine`（f.）；复数 `les cuisines`
- **一词两义**：「烹饪」（抽象活动 / 技艺）与「厨房」（房间）——靠语境与搭配分辨：faire la cuisine（做饭）vs manger dans la cuisine（在厨房吃）
- 常见搭配：`faire la cuisine`（做饭）、`la cuisine équipée`（整体厨房——配齐橱柜电器的厨房）、`un livre de cuisine`（菜谱书）、`la cuisine française / chinoise`（法餐 / 中餐）
- 派生家族：**cuisinier / cuisinière**（n. 厨师——人）；**cuisiner**（v. 做菜；〈引〉盘问）；**cuisinière** 另义「炉灶」

**词源 / 构词**
- **拆解**：拉丁 **coquina**「厨房、烹调术」（源自 **coquus**「厨师」／**coquere**「煮、烹调」）→ 通俗 / 晚期拉丁 **cocina**（qu → c 的俗变）→ 古法语 **cuisine**；词根 coquere 上溯 PIE ***pekw-**「煮、成熟」
- **演变**（首证链，CNRTL/TLFi，2026-10-03 经检索转引）：**1155**「食物的准备、烹饪术」（Wace, *Brut*）；**约 1170**「做饭的房间」义（Chrétien de Troyes, *Erec et Enide*）；约 1170「做好的菜肴」义；**1740**（转喻）「厨房工作人员」；**1778 前**（Voltaire）引申「（文学、政治中）处理素材的手法」
- **同族 / 派生（法语）**：cuisinier / cuisinière（厨师）、cuisiner（做菜）、cuisinière（炉灶）；英语一侧见下节（**双重借入**样本）
- **记忆钩**：cuisine 与英语 kitchen 是**同一个拉丁词的两次旅行**——一次随日耳曼人北上（kitchen），一次经法语渡海（cuisine）——见下节

**英法交叉核对（受影响的英语词）**
- **借入英语**：**cuisine**（n.「烹饪风格、菜肴」**1786** 年自法语借入——OED 首证为 Hannah More 1786 年文字；法语 cuisine 本义「厨房；烹饪、做好的菜」〔12c.〕，英语只取「烹饪风格」义——**词义窄化**）；**cuisinier**（厨房 / 菜单行话里的「厨师」借词，罕用）；`cuisinière`（炉灶——家电借词）
- **共祖未借入（同一拉丁源的另一条路）**：**kitchen**（n.「厨房」——**双重借入**的另一支：古英语 **cycene** ← 原始日耳曼语 ***kokina**，后者借自通俗拉丁 ***cocina**（＝coquina 的俗变）；中古英语形式 kitchen c. 1200；同族德语 Küche、荷兰语 keuken）——日耳曼诸语在通俗拉丁时期早期借入，与法语 cuisine 是「共祖异途」而非借入关系；意大利语 cucina、西班牙语 cocina 亦同源平行
- 核对：已核实（etymonline / OED，2026-10-03 经检索转引）——英 cuisine 首证 **1786**（借自法语）；英 kitchen ← 古英语 cycene ← 原始日耳曼 \*kokina ← 通俗拉丁 \*cocina ← 拉丁 coquina ← coquere（PIE \*pekw-）——与法语 cuisine 同一拉丁源。**双重借入**：同一拉丁词经日耳曼语（kitchen）与经法语（cuisine）分别进英语——教科书样本。**待验证**：日耳曼语借入 \*kokina 的具体年代（检索未得明证，仅知属通俗 / 晚期拉丁时期的早期借入）

**同义 / 搭配 / 易混**
- 搭配：`faire la cuisine`（做饭）；`la cuisine équipée`（整体厨房）；`un livre / une recette de cuisine`（菜谱书 / 菜谱）；`faire la cuisine pour qn`（给某人做饭）
- **易混**：**cuisine**（烹饪 / 厨房）vs **cuisinier / cuisinière**（厨师——**人**）——« Il est cuisinier. »（他是厨师）不能说 « Il est cuisine. »；**cuisiner**（做菜——动词）vs **cuisinier**（厨师——名词，同音近形）；**cuisine équipée**（整体厨房）≠「装备精良的烹饪」
- **职业对照**：cuisinier（厨师）／[[patissier]]（糕点师）／boulanger（面包师）——法语后厨职业词族
- **faux ami**：法语 cuisine 的「厨房」义英语不借（kitchen 已占位）——借入时各取一义：英语 cuisine＝烹饪风格，英语 kitchen＝厨房；别把 « dans la cuisine » 直译成 "in the cuisine"
