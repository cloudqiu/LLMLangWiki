# cochon

**释义**：（1）**猪**（le cochon 猪）；（2）**猪肉**（du cochon 猪肉——肉铺用语）；（3）**（俗）邋遢鬼、下流胚**（espèce de cochon ! 你这脏鬼！）；（4）**（adj.）不正经的、下流的**（une histoire cochonne 下流故事）；（5）**cochon d'Inde** ＝ 豚鼠（天竺鼠——**不是**「印度猪」） ｜ porc ; (familier) personne malpropre ou obscène

**例句**
- _À la ferme, il y a des cochons._ 农场里有猪。
- _Ne raconte pas d'histoires cochonnes devant les enfants._ 别在孩子面前讲下流故事。
- _Les enfants ont un cochon d'Inde comme animal de compagnie._ 孩子们把豚鼠当宠物养。

**形态要点**
- 名词：`le cochon`（**m.**）；复数 **cochons**；**阴性 cochonne**（母猪 / 邋遢女人，俗）
- 形容词（**同形**）：`cochon`（阳）/ `cochonne`（阴）——「不正经的、下流的」
- 派生：**coche**（母猪）、**cochonner**（弄脏 / 干得马虎）、**cochonnerie**（脏东西 / 下流事 / 劣质品）、**cochonnet**（小猪 / 法式滚球用的小球）、**cochonnaille**（猪肉制品）、**tirelire**（小猪扑满）
- **注意**：`cochon d'Inde` ＝ **豚鼠**（guinea pig），与印度无关

**词源 / 构词**
- **拆解**：古法语 **coche**「母猪 / 小猪」的**阳性** → cochon
- **词源不明（obscure）**：**很可能拟声**——**koš-koš**（唤猪声 / 猪的哼声）+ 后缀 **-on**（TLFi）；TLFi 另提低拉丁 *cutio*「鼠妇（潮虫）」，因**音义困难而不取**。各家一致承认**来源不明**
- **演变 / 首见**：**1091**（Cartulaire de Redon——但作**人名**，非普通名词）；**1268–71**「小猪」（TLFi）；**1611**「成年猪」；**1850** 起作 adj.「不正经的」
- **同族 / 派生（法语）**：coche、cochonner、cochonnerie、cochonnet、cochonnaille、cochonne；`tirelire`、`cochon d'Inde`
- **记忆钩**：cochon 本是「**（唤）猪猪**」的拟声——像中文「啰啰」唤猪；字面不体面，正是「俗」字的来源

**英法交叉核对（受影响的英语词）**
- **同义异源**：英语「猪」用 **pig**（中古英语 pigge，中 13c，orig.「小猪」，终极来源不明）、**swine**（← 日耳曼 \*swein ← PIE \*sū-）、**hog**——**皆日耳曼，非借自 cochon**
- **借入（兄弟词非同词）**：英语 **pork**（n. c.1300「猪肉」← 古法语 **porc**）——**porc 与 cochon 是「兄弟词」**（同出拉丁 **porcus** / PIE \*porko-），但英语借的是 **porc**，**不是 cochon**；**porcine / porcupine / porpoise** 亦出拉丁 porcus
- **英语无借自 cochon 的词**。（英语 **cochineal**「胭脂虫红」**无关**——← 西班牙 cochinilla。）
- 核对：英语侧（pig mid-13c；pork c.1300 ← 古法 porc）经检索转引 etymonline（2026-10-11）；法语侧 1091 / 1268–71 与「来源不明 + 拟声说」据 TLFi / Quem. 转引（**待验证**）
- **教学点**：**cochon（俗 / 日常）↔ porc（正式 / 烹饪）**——英语只借了 porc（作 **pork**），没借 cochon

**同义 / 搭配 / 易混**
- 搭配：`cochon de lait`（烤乳猪）｜ `cochon d'Inde`（豚鼠）｜ `tête de cochon`（猪头；俗：固执的人）｜ `sale comme un cochon`（脏得像猪）｜ `manger comme un cochon`（吃相难看 / 狼吞虎咽）
- **易混（猪家族）**：**cochon**（猪，日常 / 俗）vs **porc**（猪，正式 / 烹饪；亦「猪肉」）vs **sanglier**（**野猪**）vs **truie**（母猪）vs **verrat**（公猪）
- 相关：[[vache]]（农场动物，同批）；[[ferme]] / [[campagne]]（农场 / 乡村域）；[[sale]]（« cochon » 的俗义与 sale 同域）
