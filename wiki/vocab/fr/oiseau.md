# oiseau

**释义**：n.m. ①**鸟、禽** ②（引申）**家伙**（*un drôle d'oiseau* 一个怪人） ｜ animal vertébré ovipare, à plumes et à ailes

**例句**
- _Un oiseau chante sur la branche._ 一只鸟在枝头鸣唱。
- _Les oiseaux migrent en automne._ 鸟在秋天迁徙。
- _C'est un drôle d'oiseau._ 这真是个怪人。

**形态要点**
- 名词：`l'oiseau`（**m.**）；复数 **oiseaux**（**-eau → -eaux**，规则）；阴性 **oiselle**（罕用）
- 搭配：**oiseau de proie**（猛禽）、**oiseau-mouche**（蜂鸟，复数 *oiseaux-mouches*）、**à vol d'oiseau**（直线距离 / 鸟瞰）、**oiseau de mauvais augure**（不祥之人）
- 易混（近形）：**oisif**（闲散的——拼写近似，义无关）

**词源 / 构词**
- 拆解：中古法语 *oiseau, oyseau* ← 古法语 **oisel** ← 晚期拉丁 **aucellus**「小鸟」← ***\*avicellus*** 的**缩合形** ← 拉丁 **avis**「鸟」的**指小词**。（俗拉丁音变：*avi-* + 辅音发生 **-i- 脱落** → 新的 *au* 双元音：*auicellus > avicellus > aucellus*）
- 首证：**c. 1100**（fr.wiktionary 引 DMF 2010 / TLFi）
- 同族罗曼语：意大利 *uccello*、加泰罗尼亚 *ocell*、奥克 *aucèl*、弗留利 *ucel*
- 同族 / 派生：**oisillon**（雏鸟）、**oisellerie**（鸟舍 / 鸟店）、**oiseleur**（捕鸟人）
- 记忆钩：**avis（鸟）→ 指小 → 俗拉丁音变掉 -i- → aucellus**——「小鸟」的指小词在法语里**吃掉了「鸟」**，成了「鸟」本身

**英法交叉核对（受影响的英语词）**
- **关键前提**：英语**从未借入 oiseau 本词**——以下诸词与 *oiseau* 只是**拉丁祖词层面的亲缘**
- **共祖（同出拉丁 avis / PIE \*awi-）**：英语 **aviary**（**1570s** ← 拉丁 *aviarium*，**直取拉丁**）；**avian / aviculture / avifauna**（近现代拉丁造词）
- **借入 + 共祖混合**：英语 **osprey**（**mid-15c.** *osprai* ← 盎格鲁-法语 *ospriet* ← 中古拉丁 *avis prede*「猛禽」＝ *avis* + *praeda*，后在古法语中与拉丁 *ossifraga* 相混）——*avis* 成分**经法语 / 中古拉丁**
- **借入**：英语 **auspice** ← 法语 *auspice* ← 拉丁 *auspicium*（*auspex* ← **\*awi-spek-**「观鸟者」= *avis* + *specere*「看」）——但英语**亦直取拉丁**，属「**法 / 拉丁双途**」
- **核对要点**：**oiseau 的法语形与英语诸词完全对不上**，因为法语经历了 **avicellus → aucellus → oisel** 这一串俗拉丁音变；英语走的是 *avis* 原形（aviary）或经 *avis prede*（osprey）

**同义 / 搭配 / 易混**
- 同义：**oisillon**（雏鸟，非并义）
- 搭配：**oiseau de proie**（猛禽）、**oiseau-mouche**（蜂鸟）、**à vol d'oiseau**（鸟瞰 / 直线距离）、**oiseau de mauvais augure**（不祥之人）、**petit oiseau**（俗：消息灵通者）
- 易混：**oiseau**（鸟）vs **oisif**（闲散的）——**拼写近似而义无关**；**oiseau** vs **volaille**（家禽，供食用）
