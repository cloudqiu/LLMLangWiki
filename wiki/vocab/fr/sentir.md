# sentir

> 收录说明：inbox 里的遇到形式是 **`sentais`**（直陈式未完成过去时 je / tu 形）——按 lemma 规则归并至不定式 **sentir**。

**释义**：（1）**（以感官）感知**；（2）**闻、嗅**（sentir une fleur）；**闻到**（Je sens une odeur de café）；（3）**se sentir 感觉、感到（自己）**（se sentir bien / mal / fatigué）；（4）**直觉地辨知 / 预感**（sentir venir qqch）；（5）**sentir bon / mauvais / fort ＝（主语为物）闻起来香 / 臭 / 浓**；（6）**带有…的味道 / 气息**（Ça sent le brûlé 有股焦味）；**（口语否定）ne pas pouvoir sentir qqn ＝ 受不了某人**｜ percevoir par les sens ; flairer ; se sentir = éprouver (un état)

**例句**
- _Je sens une odeur de café._ 我闻到咖啡的香味。
- _Ces fleurs sentent bon._ 这些花很香。
- _Je ne me sens pas bien aujourd'hui._ 我今天不太舒服。

**形态要点**
- 动词（变位要点）：不定式 **sentir** ｜ 组别：**3e groupe**（-tir 型，同 partir / sortir / mentir）｜ 助动词：**avoir** ｜ 过去分词：**senti**
  现在时：je **sen**s ｜ tu **sen**s ｜ il·elle **sen**t ｜ nous **sent**ons ｜ vous **sent**ez ｜ ils·elles **sent**ent
  变位提示：**单数丢 t（sen-）、复数保留 t（sent-）**——词干末尾辅音交替，**非** -s 型变化
- 代动词：**se sentir**（感觉自身）——及物 vs 代动词之别：*je sens*（我闻到）vs *je me sens*（我感觉）
- **易混**：**sentir**（主动「闻到」）vs **sentir bon / mauvais**（被动「闻起来」——**主语是物**）；sentir vs **ressentir**（后者强调内心深处的感受）

**词源 / 构词**
- **拆解**：拉丁 **sentire**「percevoir par les sens（以感官感知）」，引申「être d'un certain avis, penser（持某种意见、想）」，法律 / 政治用法「décider（裁定）」；法语直接继承，无前缀 / 后缀
- **首证**：**fin XIe siècle（11 世纪末）**（fr.wiktionary 明文）——**继承**（非借入），法语本土演化的拉丁词
- **演变**：拉丁 sentire「感知」→ 法语「感官感知 / 闻 / 感觉 / 觉得」多线发展。**sentir bon / mauvais（闻起来）义**＝从「用嗅觉感知某物」转到「（主体）带有某种气味」，**主语从感知者变为被感知物**（*Ces fleurs sentent bon.*）
- **同族 / 派生（法语）**：**sens**（n.m.）、**sensation**、**sentiment**（n.m.）、**sentimental**、**ressentir**、**consentir / assentiment**、**pressentir**
- **记忆钩**：「闻起来香」用法其实是**主语翻转**——原本「我闻花」变成「花生香」（*les fleurs sentent bon*）

**英法交叉核对（受影响的英语词）**
- **借入（英 ← 法）**：英语 **sense**（中古英语 ← 古法 **sens / sen / san**「sense, reason, direction」＋ 直接 ← 拉丁 **sensus**，sentire 的过去分词）
- **借入（英 ← 法）**：**sentiment**（英语 *sentement* **late 14c.** ← 古法 *santement / sentement*（12c.）；现代拼写 *sentiment* 系 **17c 自法语再借入**）
- **借入**：**scent**（英语 *sent*「嗅出」← 古法 **sentir** ← 拉丁 sentire）；同族 **resent / assent / consent / dissent / sentient / sensual**
- 核对：英语侧经检索转引 etymonline（2026-10-13）；法语侧 fin XIe s. 据 fr.wiktionary 直取

**同义 / 搭配 / 易混**
- 搭配：`sentir bon / mauvais / le brûlé`｜ `se sentir bien / mal / fatigué / seul`｜ `sentir venir qqch`（预感到）｜ `ne pas pouvoir sentir qqn`（受不了某人）
- 同义：ressentir、éprouver、flairer、humer（嗅）、percevoir
- **易混**：**sentir**（嗅到 / 闻到）vs **sentir bon / mauvais**（闻起来——主语为物）；sentir vs se sentir；sentir vs ressentir
- 相关：[[peur]]、[[fatigue]]（同「身心感受」域）
