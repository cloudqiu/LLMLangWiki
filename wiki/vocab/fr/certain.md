# certain

**释义**：（1）肯定的、确信的（je suis certain）；（2）某个、某些（不定：un certain monsieur 某位先生）；（3）(pron.) certains ＝ 某些人 ｜ sûr ; (indéfini) quelque, un… donné

**例句**
- _Je suis certain de sa réponse._ 我对他的答复很有把握。
- _Un certain monsieur Dupont vous demande._ 有位叫杜邦的先生找您。
- _Certains pensent que c'est faux._ 有些人认为这是错的。

**形态要点**
- 形容词：certain（m.）／ certaine（f.）／ certains／ certaines
- 不定限定词：置名词前（certain + 名词 ＝ 某些、某种：certaines personnes）；注意冠词配合 `un certain + 名词`（某个）
- 代词：只用复数 certains / certaines（某些人）

**词源 / 构词**
- **拆解**：单语素——拉丁 **certus**「确定的、可靠的」（**cernere**「筛选、区分、决断」的过去分词）＝「已被筛定的」→「确定的」
- **演变**：拉丁 cernere「筛选」→ certus「确定的」→ 通俗拉丁 *certanus（certus 扩展形）→ 古法语 certain（12 世纪，约 1160 见载；Académie 9e 标 13 世纪作形容词）→ 法语 certain（据 etymonline／Wiktionnaire／Académie 9e，2026-10-01 经检索转引）；「确定」→「某个」（确定但不明说）的义项由「笃定的」弱化而来
- **同族 / 派生**：certitude（确信）、certifier（证明）、certainement（肯定地）、incertain（不确定的）；英语一侧见下节
- **记忆钩**：certain ＝ 「筛（cernere）定下来的」；同根的 discern（辨别）与 secret（秘密＝被「筛」开的）都在「筛」这条线上

**英法交叉核对（受影响的英语词）**
- **借入英语**：**certain**（← 古法语 certain ← 拉丁 certus，13c.——英语 certain 兼「确定的」与「某个」两义，与法语高度对齐）；**certitude / certainty**（← 法语 certitude ← 拉丁）；**certify / certificate / certification**（← 古法语 certifier ← 中世纪拉丁 certificare）
- **共祖未借入**：**discern**（← 拉丁 discernere）、**secret / discreet**（← 拉丁 secretus / discretus，同出 cernere 家族）——经拉丁直接入英，与法语 certain 同根非借入；**concert** 与 cernere **无关**（← 拉丁 concertare「争斗」，勿因拼写相近而误连）
- 核对（2026-10-01 经检索转引）：英语 certain c. 1300 借自古法语 certain（12c.）；certify 英语 14c. 中期 ← 古法语 certifier（12c.）← 中世纪拉丁 certificare；certificate／certification 英语 15c. 初（certificat 家族）；certitude 英语 15c. 初 ← 古法语 certitude／晚期拉丁 certitudinem；certainty c. 1300 ← 盎格鲁-法语 certeinté（13c. 晚）← 古法语 certainete（以上据 etymonline）

**同义 / 搭配 / 易混**
- 搭配：`être certain de qch / de faire qch`（确信）；`un certain + 名词`（某个）；`certain + 名词`（某些）；`certains / certaines`（某些人，代词）
- 易混：**certain**（有把握的，偏主观确信）vs **sûr**（确定的——更口语、更通用：je suis sûr）；「某个」义 certain 与 **quelque**（某个/一些）近义；代词 certains vs **quelques-uns**（某些人）
- 语法点：certain 作「某个」时置名词前（un certain temps 某段时间），作「肯定」时作表语/后置（une chose certaine 确定之事）
