# chaque

**释义**：每个、各个——指一个集合中被逐一取出的每一个个体，**限定词（déterminant）**，必须跟名词 ｜ déterminant indéfini distributif « chacun des éléments d'un ensemble, pris un à un »

**例句**
- _Chaque jour, je vais au travail à vélo._ 每天我都骑车去上班。
- _Chaque élève a reçu un livre._ 每个学生都收到了一本书。（**动词单数**：a，不是 ont）
- _Chaque fois que je le vois, il sourit._ 我每次见到他，他都微笑。
- _Nous partons en vacances chaque année._ 我们每年都去度假。
- _Chaque personne a son avis._ 每个人都有自己的看法。
- _À chaque problème, sa solution._ 每个问题都有它的解决办法。（谚语式搭配）

**形态要点**
- **déterminant indéfini（不定限定词）**：**词形不变、无阴阳、无复数**——chaque + 名词**单数**（chaque jour；`chaques jours` 不成立）
- **动词用单数**：chaque + n. sg. 作主语 → 谓语**单数**（Chaque élève **a** un livre；`Chaque élève ont` 错）
- **与冠词互斥**：置于名词前，不带冠词（`le chaque jour` 不成立）
- **与代词 chacun(e) 区分（本页必记）**：**chaque 是限定词，必须直接跟名词**（chaque homme 每个男人）；**chacun / chacune 是代词，可独立使用**（Chacun a son tour 各人轮流；Chacun pour soi 人各为己）——**chacun 有阴性 chacune，chaque 无**；「缺名词就补 -un 变 chacun」
- 高频搭配：`chaque fois (que)`（每次／每当——引导从句）、`chaque jour`（每天）、`chaque année / semaine / mois`（每年／每周／每月）、`de chaque côté`（每一边）、`à chaque instant`（每时每刻）、`à chaque fois`（每次）

**词源 / 构词**
- **拆解**：拉丁 **quisque**「每一个（各自）」→ 通俗拉丁 **\*cascu**（← **\*cascunum**）——由 **quisque unus**「每一个」与 **(unum) cata unum**「一个一个」（**cata** ← 借自希腊 **kata**「按、逐」的分配介词）**交叉**而成，**该交叉早于 3 世纪初** → 古法语 **chascun / cascun / chasque** → 现代 **chaque**（限定词形）与 **chacun**（代词形）
- **音变**：\*cascunu 中 **i → a**、**qua → ca**（故有 casc- 形）；加泰语 **quiscu** 被视为**最忠实的形态**，普罗旺斯 córrer **quecs / cascus**
- **演变（诸说，如实并列，2026-10-04 转引）**：
  - **chacun / chascun 线（代词）**：古法变体繁多——cascun / cachun / chescun / chascon / cadhun / cheün（皮卡第、诺曼、勃艮第、洛林各方言）；首证 **842**（cadhun, cheün——最早）；**cascune**（阴性形容词）**1050**；**chascun** 记**末 11 世纪**（一记 **1100** cascuns）
  - **chaque 线（限定词／形容词）**：**chasque / chaque 12 世纪已有，但直到 16 世纪才通行**（Littré 未引 16 世纪前的例子）；系由 **chascun 截去尾音**而成（一说仿 quelque / quelqu'un 类推），**非相反方向**——即「chacun 先于 chaque」——**待验证**（该说据 Romania 1873 与历史语法转引，未直读 TLFi 原条）
- **同族 / 派生（法语）**：**chacun / chacune**（代词）、**chaque fois que**（每当）；同场的不定限定词 **quelque / quelques**（某个／几个）、**plusieurs**（几个）、**aucun**（任何一个／没有一个）；上位疑问/不定词干 **\*kʷo-**（见 [[qui]]）
- **记忆钩**：chaque（限定词，后必跟**单数**名词）／chacun（代词，独用）——chaque 的名词一消失，就得补个 -un 变成 chacun

**英法交叉核对（受影响的英语词）**
- **共祖未借入**：英语 **`each`** ← 古英语 **ælc** ← **a-gelic**（＝ **a-**「ever」+ **gelic**「alike」）← 西日耳曼 **\*aina-galīk**（同族：荷兰 elk、古弗里斯 ellik、古高地德语 iogilih、德语 jeglich）——日耳曼自有构词，**与法语 chaque 无语源关系**（each 的 a- 出 PIE **\*aiw-**「生命、永恒」，与 \*kʷo- 无涉）
  - **但有一条语义纽带（本页有趣处）**：etymonline 明记英语 each 今义「每一个（各别）」是**「受拉丁 quisque 影响」**而成（"the present-day use is credited to the influence of Latin quisque"）——即**同一个拉丁 quisque 既给了罗曼语的 chaque，又充当了英语 each 的语义模型**（**语义影响，非借词**）
  - 相关：**`every`**（early 13c ← 古英语 æfre ælc「ever each」）——**every 本即 each 的复合**；古英语中 each 曾兼「every / all」之职
- **借入英语**：**无**——chaque / chacun 未整体借入英语
- **拉丁 quisque（共祖，横向对照）**：`quisque` 为拉丁原词（「每一个」），英语几乎不用；罗曼语对照——西语 **cada**、意语 **ciascuno / cadauno**、加泰 **quiscu**、普罗旺斯 **quecs**——均同出 \*cascunu
- 核对：英语侧（each ← OE ælc ← a-gelic ← \*aina-galīk；"influence of Latin quisque"；every early 13c ← æfre ælc）2026-10-04 经 **etymonline 直读**；法语侧（quisque → \*cascu / \*cascunum（quisque unus × cata unum，早于 3 世纪）；842 cadhun/cheün；1050 cascune；末 11c chascun（或 1100 cascuns）；chasque 12c 已有、16c 通行；chascun 截尾说；加泰 quiscu 最忠实）2026-10-04 经 **WebSearch 转引**（Romania 1873、历史法语语法、Littré、Cairn《Précis d'ancien français》、Wiktionnaire）。**待验证**：①chaque 由 chascun 截尾而来的说法及其年代（系二次文献转引，TLFi 原条未直连）；②TLFi「chaque」原条首证定年未得；③「842 首证」所据具体文本（cadhun / cheün）未逐核

**同义 / 搭配 / 易混**
- 辨析：**chaque**（限定词 + **单数**名词：chaque jour）｜ **chacun(e)**（代词，独用：chacun son tour）｜ **tout(e)(s)**（[[tout]]：整体的「全部」——chaque 是逐一的「每个」，tout 是汇总的「全部」）｜ **tous les / toutes les**（+ **复数**＝「每」：tous les jours 每天）｜ **quelque / quelques**（某个／几个）｜ **aucun(e)**（任何一个／没有一个，多与 ne 连用）
- 比较：`chaque jour`（每天——强调**逐日**）≈ `tous les jours`（每天——更日常）；`chaque fois que`（每当）≈ `toutes les fois que`（较正式）
- 相关：[[tout]]、[[meme-si]]、[[parfois]]、[[souvent]]、[[qui]]
