# rester

**释义**：（1）停留、留下；（2）保持、仍然是（rester calme 保持冷静）；（3）剩下 ｜ demeurer ; continuer d'être ; subsister

**例句**
- _Elle ne peut jamais y rester longtemps._ 她从不能在那里久留。（inbox 例句）
- _Je reste à la maison._ 我待在家里。
- _Il reste du pain._ 还剩下一些面包。

**形态要点**
- 动词：不定式 **rester** ｜ **1er groupe** 但**助动词用 être**（je **suis** resté——过去分词 resté 随主语性数变化：elle est restée）
- 现在时六形：je **reste** ｜ tu **restes** ｜ il·elle **reste** ｜ nous **restons** ｜ vous **restez** ｜ ils·elles **restent**

**词源 / 构词**
- **拆解**：拉丁 **restare**「停下、留在后面」＝ re-（向后）+ **stare**「站」——「站住不走」→「停留」
- **演变**：PIE \*sta-「站」→ 拉丁 stare「站」→ restare「停留」→ 古法语 rester → 法语 rester（TLFi 定年：古法语首证 1174-76，义「停下」——2026-10-01 经检索转引）；同根 stare 也是法语 être 与英语 stand 的远亲
- **同族 / 派生**：reste（剩余、其余——le reste）、restant（剩余的）、arrêter（停下——同 stare 家族经 arestare）；英语一侧见下节
- **记忆钩**：rester ＝ re（向后）+ stare（站）＝「站住不走」；同根的 stand（站）与 rest（休息）都是「站/停」这条线

**英法交叉核对（受影响的英语词）**
- **借入英语**：**rest**（「剩余」义 the rest，← 古法语 reste ← rester ← 拉丁 restare——「the rest 其余」就是「剩下的」；「休息」义 rest 系日耳曼本族词，与 rester 无词源关系）；**arrest**（← 古法语 arester「使停下」← 俗拉丁 \*arrestare ← ad- + restare）；**restaurant**（← 法语 restaurant ← restaurer「恢复体力」——原指「恢复体力的浓汤」；出拉丁 restaurare「修复、恢复」，与 rester 的 restare 系两个不同拉丁动词（仅共享 re- 前缀），非同出——2026-10-01 经检索转引）
- **共祖未借入**：**stand / steady / station / state / stay**（← 拉丁 stare / PIE \*sta-「站」——共祖非借入）
- 核对：已核实（据 etymonline，2026-10-01 经检索转引）——the rest「剩余」early 15c（← 古法语 reste）；rest「留下」义动词 mid-15c；arrest 动词 late 14c（← 古法语 arester ← 俗拉丁 \*arrestare）；「休息」义 rest 系日耳曼本族词，非借入

**同义 / 搭配 / 易混**
- 搭配：`rester à la maison`（待在家）；`rester + adj.`（保持：rester calme 保持冷静）；`il reste + 名词`（剩下：il reste du pain）；`y rester`（留在那里——[[y]] 代「那里」；口语「丧命」）
- **核心易混——rester vs demeurer**：**rester** 停留/保持（常用）｜ **demeurer** 居住/保持（更书面）；两者都可用 être 助动词
- 再易混：**rester**（保持状态）vs **être**（是）；**il reste**（剩下）vs **il manque**（缺少）
- **语法陷阱**：rester 用 **être** 助动词（je suis resté），不是 avoir——这是高频错误点
