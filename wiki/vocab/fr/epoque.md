# époque

**释义**：（1）**时代、时期**（période de temps, ère）；（2）**（地质）世**；（3）**（艺术 / 文学）时期、风格**（meuble d'époque 古董家具）｜ période de temps ; ère ; période artistique

**例句**
- _À cette époque, je vivais encore à Paris._ 那时候我还住在巴黎。
- _Nous vivons une époque difficile._ 我们正处在一个艰难的时代。
- _C'est un meuble d'époque._ 这是一件古董家具。

**形态要点**
- `l'époque`（元音前省音）；`une époque` → `des époques`；词尾 `-que` 的 *e* 不发音（/e.pɔk/）
- 搭配：`à l'époque`（当时）｜ `à l'époque de`（在…时代）｜ `de l'époque`（当时的）｜ `d'époque`（古董的）｜ `Belle Époque`（美好年代）｜ `faire époque`（划时代）｜ `époque moderne / géologique`
- **易混**：`époqué`（法律术语形容词）、`épochê`（现象学术语，保留希腊形）

**词源 / 构词**
- **拆解**：← 古希腊 **ἐποχή / epokhê**「停顿、（天体的）停点、时期、纪元」← **epéchein**「持有、停住」（**epi-** + **echein**「持」）。注意：fr.wiktionary 称**直接借自希腊语**（**非**经拉丁）
- **首证**：**1637**，形 *epoche*（无重音符号）；**1680** 法语化作 *époque*（fr.wiktionary：「(1637) epoche … francisé en 1680 en époque」）；Académie 9e 笼统作「xviie siècle」
- **存疑**：有资料把首现锁定在 **1680**（HAL 文摘片段）——**1637 与 1680 并存，须核 TLFi**；「直接借自希腊 vs 经（新）拉丁 *epocha*」亦两说
- **记忆钩**：époque 的本义是「**天体停下的那一点**」——希腊天文学的「关键时刻」演化成泛指的「时代」

**英法交叉核对（受影响的英语词）**
- **借入**：英语 **epoch** ← 法语 *époque* / 新拉丁 *epocha* ← 希腊 *epokhē*——**借入**（经法语 / 新拉丁，17c）；二者**同源**，但英语词是**借入**，非独立共祖
- 核对：英语侧经检索转引 etymonline（2026-10-13）

**同义 / 搭配 / 易混**
- 同义：**ère、période、temps、âge**；（艺术）**période**
- **易混**：英语 **epoch**（纪元 / 时代）与法语 époque 词形近义；英语 **period** 与法语 *période* 需另辨
- 相关：[[temps]]（待收）、[[epoque]] 所属「时代 / 时间」域
