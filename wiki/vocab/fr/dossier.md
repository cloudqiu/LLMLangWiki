# dossier

**释义**：n.m. ①**座椅靠背** ②**卷宗、档案**——为特定目的汇集的一套文件 ③（特）诉讼或档案文件 ④（特）**关于某人的一套材料、个人档案** ⑤（信息）**文件夹、目录** ⑥（新义）关于某人的**秘藏把柄 / 黑材料** ⑦有篷货车上联结两侧的窄部件 ｜ ensemble de documents réunis sur une question ; (informatique) répertoire

**例句**
- _Range ces documents dans le dossier « Travail »._ 把这些文件放进「工作」文件夹里。
- _La police a un dossier complet sur lui._ 警方有关于他的完整卷宗。
- _Le dossier de la chaise est cassé._ 椅子靠背坏了。

**形态要点**
- 名词：`le dossier`（**m.**）；复数 **dossiers**（规则）
- 注意：可指**具体物件**（椅背）也可指**抽象集合**（卷宗 / 档案）——由语境定

**词源 / 构词**
- 拆解：**dos** + 后缀 **-ier**。文件义是**转喻**——**捆扎物或纸盒的标签通常贴在「背面」（dos）**，故以 *dossier* 指这捆文件。*dos* ← 古法语 *dos*（XIIe s.）← 通俗拉丁 **\*dossum**，是拉丁 **dorsum**「背」的**变体**（Littré 追溯到低拉丁 *dorsarium / dorserium*）
- 首证（TLFi / CNRTL）：**1352**「dossier de lit（床头靠板）」；**1386**「deux rolles dorsiens」；**1586** **文件义**「les dossiers de ladicte imposicion」(Arch. municipales de Bayonne)；**1611**「dos de certains sièges」(Cotgrave)。fr.wiktionary 仅注源出 *dos*，**未给年代**
  - **⚠️ 更正记录**：子代理初拟的文件义年代「1580」**无据**，正确文件义首证为 **1586**——本页按 1586 记录
- 同族 / 派生：**dos**（背）、**dossard**（号码布）、**dossier médical / scolaire / fiscal**、**sous-dossier**（子文件夹）、**endosser**（穿上；背书——**同出 dos**）
- 记忆钩：**dos（背）+ -ier**——「**贴在背面的标签**」框住了整捆文件，于是「椅背」与「卷宗」共用一词

**英法交叉核对（受影响的英语词）**
- **借入（英 ← 法）**：英语 **dossier**（n.，**1880**）「bundle of documents referring to some matter」（**1868 起**作法语词出现于英语）← 法语 *dossier*「一捆文件」← *dos*「背」← 通俗拉丁 *\*dossum* / 拉丁 *dorsum*——etymonline 解释：**或因标签贴在捆扎物背面，或因纸捆隆起似背**
- **共祖 / 同根**：英语 **endorse**（← 盎格鲁-法语 *endosser* ← *en-* + *dos*）、**dorsal**（← 拉丁 *dorsum*）、*reredos*、*addorsed*——均与 *dossier* 同出 dos / dorsum
- **反向借入**：无（法语是英语 dossier 的源）
- **核对要点**：法语 *dossier* 是「**法 → 英**」借入，且英语**只取走『一宗文件』一个义**

**同义 / 搭配 / 易混**
- 同义：(文件) chemise、liasse、carton、fichier；(信息) répertoire、(anglicisme) folder；(靠背) appui、dosseret
- 搭配：**ouvrir / constituer / consulter un dossier**（开卷 / 立案 / 查卷）；**monter un dossier**（备齐申请材料）；**dossier médical / scolaire / fiscal**；**classer dans un dossier**；**(信息) créer un dossier**（新建文件夹）；**sous-dossier**（子文件夹）
- 易混：**dossier** vs **chemise**（卷宗夹）vs **carton**（档案盒）vs **fichier**（文件 / 数据文件）vs **[[classeur]]**（活页夹）
- **faux ami（重点）**：法语 *dossier* 的义域**远宽**于英语 *dossier*——法语的「（电脑）文件夹」「椅背」「黑材料」三义，**英语 dossier 都没有**；英语 *dossier* 只指「（关于某人 / 某事的）一宗文件」，**多带调查 / 间谍 / 政治色彩**
