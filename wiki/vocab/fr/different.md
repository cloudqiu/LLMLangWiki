# différent

> 收录说明：inbox 形式 `differente`（阴性单数）——按 lemma 规则归并至阳性单数 **différent**。

**释义**：（1）不同的、有差异的（deux avis différents）；（2）复数前置：**différents** ＝「各种、若干」（les différents pays d'Europe 欧洲各国） ｜ qui n'est pas pareil ; au pluriel antéposé : plusieurs, divers

**例句**
- _Cette situation est très différente de la mienne._ 这情况与我的很不同。（介词固定用 **de**）
- _Les différents pays d'Europe collaborent sur ce projet._ 欧洲各国在这个项目上合作。
- _Nos goûts sont complètement différents._ 我们的口味完全不同。

**形态要点**
- 形容词：阳性 **différent** ｜ 阴性 **différente** ｜ 阳性复数 **différents** ｜ 阴性复数 **différentes**
- **介词固定为 de**：différent **de** qn / qch（与……不同）——**不与英语 different from 对译**：法语只有 **de**，别写 \*différent à / \*différent que；接从句用 **différent de ce que + 直陈式**（C'est différent de ce que je pensais）
- **复数位置两义（必记）**：名词**前** différents ＝「各种、若干」（les **différents** pays ＝各国——枚举、罗列）｜ 名词**后** différents ＝「不同的」（des pays différents ＝各不相同的国家——强调差异）
- 副词：**différemment**（不同地）；动词 **différer**（相异：différer de qch；**推迟**：différer une décision）
- 同族名词：**différence**（差异）；反义族：identique、pareil、semblable

**词源 / 构词**
- **拆解**：拉丁 **differre**「分开、相异、推迟」＝ **dis-**（分开、离）+ **ferre**「拿、搬、带」（PIE **\*bher-**「搬运」）——「分开拿」→「拿开 → 不一样」；形容词 **differens / differentem** 即其**现在分词**（「正相异着的」→「不同的」）
- **演变**：拉丁 differens → 法语 **XIVe siècle** 首见（Wiktionnaire 记其「apparaît comme substantif masculin, au sens de « différence »」——**先作名词「差异」，后定型为形容词**）〔Wiktionnaire，2026-10-03 经页面转引〕→ 现代 différent / différente / différents；同根名词 **différence**（← 拉丁 differentia）
- **同族 / 派生（法语）**：différence（差异）、différemment（不同地）、différer（相异；推迟）、différencier（区分）、différenciation；**indifférent / indifférence**（无差别的 → 漠不关心的）；**ferre「搬运」一条线**（同根细节**待验证**）：préférer（拿到前面 → 偏爱）、conférer（授予；商谈）、transférer（转移）、offrir（← offerre「拿到面前」）、souffrir（← sufferre「在下面扛」）；英语一侧见下节
- **记忆钩**：dis-（分开）+ ferre（拿）——把两样东西「分开拿」，就看出「不同」了；ferre 线一词三态：**拿**（ferre 本体）→ **搬**（transférer / transfer）→ **忍**（souffrir / suffer「扛着」）

**英法交叉核对（受影响的英语词）**
- **借入英语**：**different**（late 14c.「not the same, unlike, dissimilar」← 古法语 **different**〔14c.〕← 拉丁 **differentem / differens**＝differre 的现在分词）〔etymonline，2026-10-03 经检索直读〕；**differ**（late 14c.「be unlike」← 古法语 **differer**〔14c.〕＋直借拉丁 **differre**——双线；「持异议」义 1560s）；**difference**（mid-14c. ← 古法语 **difference** ＋直借拉丁 **differentia**；「争执」义 late 14c.）
- **共祖未借入**：**ferre 拉丁直传一支**——transfer（← transferre）、prefer（← praeferre）、confer（← conferre）、suffer（← sufferre）、offer（← offerre）等与 differre 同根（PIE \*bher-）——**待验证**（各词入英路径未逐条核）
- 核对：已核实（etymonline 直读，2026-10-03）——different late 14c. ← 古法语 different（14c.）← 拉丁 differentem ← differre（dis- 分开 + ferre 拿 ← PIE \*bher-）；differ late 14c.；difference mid-14c.。法语侧据 Wiktionnaire 转引：XIVe siècle 首见（**先作阳性名词「差异」义**）← 拉丁 differens ← differre（dis- + ferre）。**介词对照**：法语 **différent de**（唯一介词）vs 英语 different from / to / than——学习者别把英语介词照搬进法语（\*différent from），也别自造 \*différent à——法语只有 **de**

**同义 / 搭配 / 易混**
- 搭配：`différent de qn / qch`（与……不同）；`différent de ce que + 从句`（与……（所想的）不同）；`complètement différent`（完全不同）；`à différents niveaux`（在不同层面、多个层面）；`les différents + n.`（各种……）
- **辨析——différent / divers / varié**：**différent** 强调「不一样、有差异」（两两对比：leurs avis sont différents）｜ **divers**（复数、常前置）「种种、若干」——罗列列举（diverses raisons 种种原因；近 plusieurs）｜ **varié**「多样化的、不单调」——整体变化丰富（un menu varié 菜色丰富）；三词都译「不同 / 各样」，语感各守一摊：对比差异用 différent，列举多种用 divers，强调不单调用 varié
- 再易混：**différent ≠ indifférent**（漠不关心的——「无差别」转「无所谓」）；**différent（adj.）vs différence（n.）vs différer（v.）**——词族三件套别混词性；**autre**（另一个——中性的「别的」）
- 介词口诀：différent **de**——「不同」永远跟 **de**（不是 à，不是 from）
