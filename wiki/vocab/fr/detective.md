# détective

**释义**：侦探（多为私家侦探或侦探小说形象；法国警务体系内对应职位叫 inspecteur / enquêteur） ｜ enquêteur, souvent privé ; personnage d'enquêteur

**例句**
- _Il a engagé un détective privé._ 他雇了一名私家侦探。
- _Le détective suit une piste._ 侦探在追踪一条线索。
- _Elle lit des romans de détective._ 她在读侦探小说。

**形态要点**
- 名词：`un détective`（m.；指女性时 `une détective` 亦通用）；复数 `les détectives`
- 拼读：词形与英语 detective 只差重音 é，但按法语音系读——重音在末音节 /tiv/（英语重音在中间）；-ec- 读 /ɛk/

**词源 / 构词**
- **拆解**：**整体借自英语**（**反向回借**——法语词条里少见的「法 ← 英」）：英语 **detective** = **detect**（拉丁 **detegere**「揭开、揭发」= de-「去」+ tegere「覆盖」）+ **-ive**
- **演变**：拉丁 detegere「揭开」→ 英语 detect（15c.）→ detective（19c. 中期，侦探小说年代）→ **法语 détective**（约 1907 借入，**待验证**）；法语同族 détecter / détection / détecteur（19c.）亦经英语或拉丁入法（**待验证**）
- **同族 / 派生**：détecter、détection、détecteur；法语本土替代词：enquêteur（调查员）、inspecteur（警探/警官）、limier（「猎犬」→侦探，文学语）；英语一侧见下节
- **记忆钩**：detective = 「揭盖子的人」（de- 去 + tegere 盖）——侦探的工作就是揭盖子；同源的 protect（pro- 在前 + tegere 盖）是「在前面盖住」——一个揭、一个盖，同根反义

**英法交叉核对（受影响的英语词）**
- **反向回借（法 ← 英）**——本例正主：**détective** 借自英语 **detective**（约 1907——**待验证**）；注意方向与大多数法语词条相反
- **英语侧词族**（本词的来源与亲戚）：**detective** ← **detect**（← 拉丁 detegere「揭开」）+ -ive；**detection**、**detector**；**protect**（pro- + tegere「在前面盖住」——与 detect 同根反义）；**tegument / integument**（「覆盖物」——同根本义，罕见词）
- **核对**：wiktionary / etymonline / CNRTL 待联网核实；「1907」等年代标「待验证」；英语词库尚未收录 detective / detect / protect

**同义 / 搭配 / 易混**
- 搭配：`un détective privé`（私家侦探，最高频搭配）；`engager un détective`（雇侦探）；`jouer au détective`（玩侦探游戏）
- 易混（法国警制对照）：**l'inspecteur**（警官/警探——法国没有 detective 这一职级，警务用词）；**l'enquêteur**（调查员——警务、记者、民调通用）；**le limier**（文学语「猎犬」→侦探）；文学体裁：`le roman policier`（侦探小说——比 roman de détective 更常用）
- 语用提示：détective 在法语里带点「英语世界 / 私家」色彩（福尔摩斯式）；日常街面警察不会自称 détective
