# champ

**释义**：（1）**农田、田地、田野**（terrain cultivé）；（2）**（引申）领域**（champ d'étude 研究领域；champ magnétique 磁场）；（3）**范围、场所**（champ de bataille 战场）；（4）**（pl.）乡村**（les champs，对 ville / ville 而言）｜ terrain cultivé ; domaine, étendue

**例句**
- _Les paysans travaillent dans les champs._ 农民在田里劳作。
- _Ce sujet sort de mon champ de compétences._ 这个题目超出我的能力范围。
- _Il habite à la campagne, en plein champ._ 他住在乡下，四野之中。

**形态要点**
- `le champ`（m.）；复数 **champs**（**p 不发音**）
- **同形 / 近形提醒**：某些词典另列 **champ n.m.2**（与 *chant*「歌唱」混列）；**champ n.m.3** 是 *champagne* 的缩略（读 [ʃɑ̃p]，**p 发音**）——**本页取「田地」义**
- 搭配：`champ de bataille / tir / visuel / lexical`｜ `à travers champs`（穿过田野）｜ `champ libre`（自由放任）｜ `laisser le champ libre à qqn`｜ `sur-le-champ`（立即）｜ `hors champ / hors-champ`（电影术语）

**词源 / 构词**
- **拆解**：← 拉丁 **campus**「平原、平地」（对 mons 山）→ 古法语借入后作「耕地」「田地」；**champ 是 camp 的同源双式词（doublet étymologique）**（fr.wiktionary）
- **首证**：**约 1100**（TLFi，经 Usito 转引）；DMF 确认 *campus*（FEW II-1, 156a-160b）
- **演变**：拉丁「平原 / 练兵场（campus Martius）」→ 因耕作在平原 → 加图（Caton）起「田地」（campus frumentarius）——据 Ernout-Meillet
- **同族 / 派生（法语）**：**champêtre、Champagne / champagne、champion、contrechamp、sur-le-champ、plein champ**
- **记忆钩**：champ 与 **camp**（营地）、**champion** 同出拉丁 campus「平原」——**练兵的平地 → 田地**

**英法交叉核对（受影响的英语词）**
- **借入**：英语 **camp** ← 法语 / 意大利语 *campo* ← 拉丁 campus（16c）；**champion** ← 古法 *champion* ← 晚期拉丁 *campio* ← campus；**campaign** ← 法语 *campagne*（← campus 的又一支）
- **同义异源**：英语 **field** ← 古英语 *feld*——**日耳曼语**，与 **champ 无同源关系**；英语**无直接借入**法语 champ 的常用词
- 核对：英语侧经检索转引 etymonline（2026-10-13）

**同义 / 搭配 / 易混**
- **辨析**：`champ`（田地 / 领域）vs [[campagne]]（乡村 / 战役）vs *camp*（营地，借自意 / 法）
- 介词：`dans / sur le champ`；`hors champ / hors-champ`
- 相关：[[campagne]]（同族）、[[ferme]]（农场）
