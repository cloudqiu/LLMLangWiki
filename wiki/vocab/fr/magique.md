# magique

**释义**：（1）有魔力的、魔法的（une baguette magique 魔杖；une formule magique 咒语）；（2）神奇的、奇妙的（C'est magique ! 太神奇了！；une ambiance magique 神奇的气氛） ｜ qui a rapport à la magie ; merveilleux, qui semble surnaturel

**例句**
- _La fée agite sa baguette magique._ 仙女挥动魔杖。
- _« Sésame, ouvre-toi ! » est une formule magique._ 「芝麻开门」是一句咒语。（见 [[ouvrir]]）
- _Ce lieu a une ambiance magique._ 这个地方有一种神奇的气氛。（见 [[ambiance]]）

**形态要点**
- 形容词：**阴阳同形 magique**（un sourire magique / une histoire magique）；复数 **magiques**；副词 **magiquement**
- 位置：通常后置（baguette magique、pouvoir magique、formule magique）；文学修辞可前置（une magique soirée——较罕）
- 相关名词 **magie**（n.f. 魔法；魔术；魔力）：faire de la magie（变魔术）、un tour de magie（一个戏法）、comme par magie（奇迹般地）、la magie de Noël（圣诞魔力）
- 相关名词 **magicien / magicienne**（魔术师；巫师）

**词源 / 构词**
- **拆解**：拉丁 **magicus**「魔法的」← 希腊 **magikos**（μαγικός）← **magos**（μάγος）「术士——波斯祭司阶层成员」← 古波斯 **magush**（或 ← PIE \***magh-**「能够、有力量」）；名词 **magie** ← 拉丁 **magia** ← 希腊 **mageia**〔magos → magush 链据 etymonline「magic」条，2026-10-03 直连〕
- **演变**：法语 **magie 首证 1535**（← 拉丁 magia——fr.wiktionary 引 TLFi / Littré〔经检索转引〕）；**magicien 14 世纪**（magique + 后缀 -ien——fr.wiktionary〔经检索转引〕）；形容词 **magique 的法语首证年代未得**——fr.wiktionary 仅记「← 拉丁 magicus」（**待验证**）
- **同族 / 派生（法语）**：magie、magicien / magicienne、magiquement、magicité；**mage**（〈史〉术士、东方三博士之一——同出 magos）；英语一侧见下节
- **记忆钩**：magos 本是波斯祭司——史书与《马太福音》里的「mages（东方三博士）」即此；「巫师」义由此下凡，magie / magique / magicien / mage 一条线串起

**英法交叉核对（受影响的英语词）**
- **借入英语**：**magic**（n. 与 adj. 均 **late 14c**）← 古法语 **magique** / 晚期拉丁 **magice** ← 希腊 **magikē**（tekhnē）「（术士的）技艺」← **magikos** ← **magos** ← 古波斯 **magush**（或 ← PIE \*magh-「有力量」）；它取代了古英语 **wiccecræft**（witchcraft 一族）与 **drycræft**；「戏法、魔术」义 **1811**〔etymonline，2026-10-03 直连〕
- **借入英语（派生）**：**magician**（**late 14c** ← 古法语 **magiciien** ← magique；「变戏法者」义 **1590s**）〔etymonline，直连〕；**mage**（c. 1400）与 **magi**（c. 1200）**直承拉丁-希腊线**，非经法语
- 共祖未借入：mage / magi（见上）；英语 witch（← 古英语 wicce——被 magic 挤出的本土词，非借入）
- 核对：2026-10-03——英 magic late 14c、magician late 14c、magos → magush 链、戏法义 1811、取代 wiccecræft / drycræft 据 etymonline（直连）；法语 magie 1535、magicien 14c 据 fr.wiktionary（引 TLFi / Littré，经检索转引）

**同义 / 搭配 / 易混**
- 搭配：`baguette magique`（魔杖）；`formule magique`（咒语）；`mot magique`（神奇字眼/口令）；`C'est magique !`（太神奇了！）；`comme par magie`（奇迹般地）；`la magie de Noël`（圣诞魔力）
- **易混**：**magique**（adj. 有魔力的）vs **magie**（n.f. 法术、魔术）vs **magicien**（n. 魔术师/巫师）vs **merveilleux**（美妙的、奇迹般的）vs **féerique**（仙境般的）
- **faux ami**：英语 **magic** 兼名词与形容词；法语 **magique 只作形容词**——名词必须用 **magie**（勿造 \*la magique）
- 童话语境：les contes de fées（童话——见 [[histoire]]）里，baguette magique 与 formule magique 是标配道具
