# probablement

**释义**：很可能、大概、多半（概率很高） ｜ selon toute probabilité, vraisemblablement

**例句**
- _Il est probablement déjà parti._ 他很可能已经走了。
- _Probablement pas._ 大概不会。（独词应答用法）
- _Ce livre est probablement le meilleur de l'année._ 这本书很可能是年度最佳。

**形态要点**
- 副词，**无变化**（不随性、数变化）
- 构成：**probable** + **-ment**（形容词以元音 -e 结尾时直接加 -ment，拼写无重音变化：probable → probablement——对比 complètement 的 è）
- 位置：紧跟动词（il est probablement parti）、句首（Probablement, il a oublié 大概他忘了）、独词应答（— Tu viendras demain. — Probablement.）

**词源 / 构词**
- **拆解**：**probable**（← 拉丁 **probabilis**「可信的、可证明的、值得赞许的」← **probare**「检验、证明」← **probus**「好的、正直的」）+ **-ment**（拉丁 **mente**「以……方式」语法化的副词后缀）
- **演变**：拉丁 probabilis → 古法语 probable（14c.）→ 法语 probable（CNRTL：fin 14e–début 15e [ms.] 首证，Catholicon「有真实之貌的」；1656 名词用法见 Pascal）→ 副词 **probablement**（**Académie 9e：「xive siècle. Dérivé de probable.」**；《Journal of French Language Studies》亦记「vers le XIVe siècle」——2026-10-03 经检索转引）
- **同族 / 派生（法语）**：probable（adj. 很可能的）、probabilité（概率）、probablement（adv.）、probabilisme（或然论）；同根 probare 线：prouver（证明）、probant（有说服力的）
- **记忆钩**：prob- ＝「检验、证明」（与英语 prove 同根）——经得起检验 → 可信 → 很可能；法语词族与英语 probable / prove 全线同源

**英法交叉核对（受影响的英语词）**
- **借入英语**：**probable**（adj. **late 14c.** «likely, reasonable, plausible» ← 古法语 **probable**（14c.）← 拉丁 **probabilis**）；**probability**（n. **mid-15c.** ← 古法语 **probabilite**（14c.）/ 拉丁 **probabilitatem**）；**prove**（← 拉丁 **probare**，经古法语入英——etymonline 于 probable 条交叉引证）
- **共祖未借入**：**probably**（adv. **mid-15c.**，拼写 probabli，«plausibly, in all likelihood» ＝ **probable + -ly**——**英语自构**；与法语 probablement 是「同模型平行构词」，**互不借贷**——etymonline；Dictionary.com 另记 1525-35——两说并列）
- 核对：已核实（CNRTL / Académie 9e / etymonline，2026-10-03 经检索转引）——法 probable fin 14e–début 15e [ms.]（CNRTL）；probablement 14e s.（Académie 9e「xive siècle. Dérivé de probable.」）；英 probable late 14c.、probability mid-15c.、probably mid-15c.（probable + -ly 自构）

**同义 / 搭配 / 易混**
- **辨析（「可能性」阶梯）**：**probablement**（很可能——概率高，可独词应答）vs **sans doute**（大概、也许——**现代法语表「不确定」**）vs **peut-être**（也许——不确定性最强，常句首或 peut-être que + 从句；见 [[peut-etre]]）；表达**确定**用 **sans aucun doute** / **certainement** / **sûrement**
- **faux ami（重点）**：法语 **sans doute** ＝ 英语 perhaps / probably（不确定），**≠「无疑」**；英语 no doubt / without doubt ＝ 法语 **sans aucun doute**（确定）——直译必翻错。史证：Académie 1764 版 sans doute 释「assurément」，1798 版补「selon toutes les apparences」，1932 版已注明确定义「on dit plus souvent sans aucun doute」（2026-10-03 经检索转引）
- 搭配：`très probablement`（极有可能）；`probablement pas`（大概不）；`probablement que` + 从句（口语）；`selon toute probabilité`（同类正式表达）
- **faux ami**：probablement ≈ probably（基本对齐）；probablement / probable 两词拼写与英语 probable / probably 同形度高，勿混词性（-ment 是副词、-ble 是形容词）
