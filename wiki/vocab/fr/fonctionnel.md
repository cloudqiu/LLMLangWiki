# fonctionnel

**释义**：（1）**功能的、职能的**——关于功能或职能的（le modèle fonctionnel 功能模型；une analyse fonctionnelle 功能分析）；（2）**实用的、好用的**——设计上便于使用（un mobilier fonctionnel 实用的家具；une cuisine fonctionnelle）；（3）**能运行的、处于工作状态的**（un ascenseur fonctionnel 能用的电梯）；（4）**（生理）功能性的**——非器质性的（des troubles fonctionnels 功能性疾病） ｜ relatif à la fonction ; bien adapté à sa fonction ; en état de marche

**例句**
- _Ce modèle fonctionnel décrit les actions du système._ 这个功能模型描述系统的各项动作。
- _Ils ont choisi un mobilier simple et fonctionnel._ 他们选了简单实用的家具。
- _L'ascenseur n'est pas fonctionnel depuis hier._ 电梯从昨天起就不能用了。

**形态要点**
- 形容词（adj.）：阳性 **fonctionnel** ｜ 阴性 **fonctionnelle** ｜ 阳性复 **fonctionnels** ｜ 阴性复 **fonctionnelles**（-el → -elle / -els / -elles，**规则型**）
- 位置：**后置**（un modèle fonctionnel、une approche fonctionnelle）——与多数长后缀形容词同组
- 无 beau / nouveau / vieux 型特殊变化

**词源 / 构词**
- **拆解**：**fonction**（n.f. 功能、职能） + **-el**（形容词后缀，← 拉丁 **-alis**）→ **fonctionnel**；fonction ← 拉丁 **functio**「履行、执行」← **fungi**「履行、执行、尽责」
- **演变（CNRTL/TLFi，2026-10-05 经 WebSearch 转引）**：TLFi「**Dér. de fonction** ; suff. **-el**」；首证 **ca 1830**（据 Bl.-W.），**1845**（Besch.）；Académie 9e 记「xixe siècle，dérivé de fonction」
- **同族 / 派生（法语）**：**fonction**（n.f.）；**fonctionner**（v. 运转）；**fonctionnement**（n.m. 运行）；**fonctionnalité**（n.f. 功能、特性）；**fonctionnellement**（adv.）；**dysfonctionnel / dysfonctionnement**（功能失常）；**multifonctionnel / bifonctionnel / monofonctionnel**（多／双／单功能的）
- **记忆钩**：fonction（功能）+ -el；**fungi**「履行」这一根也出英语 **function**、**defunct**（已故＝「不再履职的」）、**perfunctory**（敷衍的）

**英法交叉核对（受影响的英语词）**
- **两语平行构词（非借入）——须辨方向，本词的关键**：
  - 英语 **`functional`**（adj.）首证 **1630s**「pertaining to function or office」（etymonline 给两条可能路径：**英语 function + -al**，**或**借中古拉丁 **functionalis**），**未**提任何法语来源；「utilitarian（实用）」义 **by 1864**；建筑学「功能主义」义 **1928**
  - 法语 **fonctionnel** 首证仅 **ca 1830**（TLFi 据 Bl.-W.；1845 Besch.）
  - **⚠️ 更正（记录 ingest 提示与权威源的分歧）**：本次 ingest 提示曾称「英 functional 系 **19c. 仿法语**」。**经查 etymonline（直读）与 TLFi/CNRTL（转引）：英语 functional 首证 1630s，远早于法语 fonctionnel（ca 1830）**——**方向相反或平行**，**不存在「英 19c. 仿法」**。正确表述：两语各自从拉丁 **functio / function** 一线造形容词，属**平行构词**；法语 fonctionnel 的现代「实用／功能主义」义（19c.）与英语 functional 的 utilitarian 义（1864）**大致同代呼应**，二者是否有互借影响，**待验证**
  - 名词线：英语 **`function`**（**1530s**）← 法语 **fonction**（16c.）**＋** 直接拉丁 **functionem** ← fungi——**双路径**；法语 fonction（16c.）与英语 function（1530s）大体同代，**谁先谁后难断**
- **共祖未借入（拉丁 functio / fungi 一线）**：英语 `function`、`functional`、`defunct`、`perfunctory` 与法语 fonction、fonctionnel、défunt 皆 ← 拉丁 functio / fungi，**同源**
- 核对：英语侧（functional 1630s；utilitarian 义 by 1864；architectural 1928；function 1530s ← 法 fonction 16c. + 拉丁 functionem ← fungi；functionalis 路径并列）2026-10-05 经 **etymonline 直读**；法语侧（fonctionnel ca 1830 d'apr. Bl.-W. / 1845 Besch.；Académie 9e xixe s.，dérivé de fonction + -el）2026-10-05 经 **WebSearch 转引 CNRTL/TLFi**

**同义 / 搭配 / 易混**
- 搭配：`un modèle fonctionnel`（功能模型）｜`un mobilier fonctionnel`｜`la programmation fonctionnelle`（函数式编程）｜`des troubles fonctionnels`（功能性疾病）｜`un groupe fonctionnel`（官能团，化学）｜`une analyse fonctionnelle`（功能分析）
- 辨析：**fonctionnel**（功能的；实用的；能用的）｜ **`pratique`**（实用的——更日常，见 [[pratique]]）｜ **`opérationnel`**（可操作的、已投入使用的）｜ **`utilitaire`**（功利／实用的）｜ **`efficace`**（有效的）
- 相关：[[pratique]]（同表「实用」——**义域有别**：pratique 更日常通用，fonctionnel 偏技术／设计语境）
