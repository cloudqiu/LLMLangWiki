# regarder

**释义**：（1）看、注视、盯着看（regarder la télé 看电视；regarder qn dans les yeux 直视某人）；（2）观看（regarder un film 看一部电影）；（3）看待、认为（regarder qn comme un ami 把某人看作朋友）；（4）涉及、与……有关（Ça ne te regarde pas 这不关你的事）；（5）**regarder à**：顾及、计较（regarder à la dépense 计较花费） ｜ diriger ses yeux vers, considérer ; concerner ; (regarder à) prendre en considération

**例句**
- _Regarde ce que j'ai trouvé !_ 看我找到了什么！
- _Elle regarde les enfants jouer dans le jardin._ 她看着孩子们在花园里玩耍。（regarder qn faire qch）
- _Je regarde un film avec des amis._ 我和朋友们看一部电影。
- _Ça ne te regarde pas._ 这不关你的事。

**形态要点**
- 动词：不定式 **regarder** ｜ **1er groupe** ｜ 助动词 **avoir** ｜ 过去分词 **regardé**
- 现在时六形：je **regarde** ｜ tu **regardes** ｜ il·elle **regarde** ｜ nous **regardons** ｜ vous **regardez** ｜ ils·elles **regardent**
- 变位提示：**-ger 型拼写**——词干以 -g- 结尾，在 a / o 前保留 **e** 以保 /ʒ/ 软音：**nous regardons**（非 \*regardons 无 e）、未完成 **je regardais**（-ge- 已含 e，**不**写成 ç——注意与 -cer 型 `je commençais` 的 ç 相反）。命令式 regarde / regardons / regardez
- 搭配：regarder qch / qn（**直接及物——不接介词**）；regarder qn faire qch（看某人做某事——不定式）；regarder qn comme…（把某人看作……）；regarder **à** qch（顾及、计较）；Ça (ne) me regarde pas（不关我的事）；se regarder dans le miroir（照镜子）

**词源 / 构词**
- **拆解**：**re-**（回、加强）+ 古法语 **garder**「看守、守卫、注视」← **法兰克语 \*wardōn**（**日耳曼语，非拉丁！**）← 原始日耳曼 **\*wardon**「守卫」← **PIE \*wer-**「察觉、当心」。**关键**：regarder 的根不在拉丁，而在**日耳曼底层**——法兰克人（日耳曼部族）入主高卢后把 \*wardōn 借入罗曼语，日耳曼的 **w-** 在罗曼语中写作 **gu- / g-**（这是日耳曼借词的「烙印」，同意大利语 guardare、西语 guardar）
- **演变（CNRTL/TLFi、DMF、Dictionnaire Historique，2026-10-04 经检索转引）**：古法语 garder（守、护、看）＋ re- → **regarder**；「**diriger sa vue sur**（把目光投过去）」义首证 **1080**（Dictionnaire Historique / Le Robert；TLF XIV, 640a；DMF 记 FEW XVII 510a 源自 **\*wardôn**）；代词式 **se regarder** **1118**；间接构造 **regarder à** 约 **1120**；及物「加以考虑」**1188**；「涉及（concerner）」义 12 世纪；**1250**「以某种心态看待」。同族的 garder 在古法语中兼「看守／注视」，esgarder（已废，今存 égard、à l'égard de、par mégarde）
- **同族 / 派生（法语）**：**regard**（n.m. 目光、注视）、**regardant**（adj. 爱惜钱财的）、**garder**（看守、保存）、**égard**（考虑、尊重——à l'égard de, par mégarde）、**garde**（守卫、保管）、**gardien / garderie / garde-manger**；如今 **garder**「守着、保存」与 **regarder**「看」分工
- **记忆钩**：日耳曼底层词的见证——法语 **regarder / garder / garde** 与英语 **ward / guard** 是**同一批日耳曼词**在两岸的分布；「看」与「守」在这族词里始终纠缠

**英法交叉核对（受影响的英语词）**
- **核心——日耳曼词源把法英两侧串成一族**：
  - **`ward`**（英 n.「看守、病房、选区」← 古英语 **weard**；v. ← 古英语 **weardian** ← 原始日耳曼 **\*wardon**）——与法语 garder / regarder **同源（共祖）**：英语**直接继承**原始日耳曼词，法语**经商借入**——**非借入，是共祖**
  - **`guard`**（英 n. **early 15c.**、v. **mid-15c.** ← 法语 **garde** ← 古法语 **garder** ← 法兰克 \*wardon）——**借入**（英 ← 法）；guard 与 ward 是**双式词（doublets）**，靠 **w- / gu- 的拼写分化**（法语把日耳曼 w- 写作 gu-）
  - **`regard`**（英 n. / v. **mid-14c.** ← 古法语 **regarder**「注视、留意」＝ re- + garder）——**借入**（英 ← 法），与法语 regarder 同源同形
  - **`reward`**（英 ← 古北法语 **rewarder**「考虑、奖赏」← warder ← \*wardon）——同族借入（etymonline 明记 reward 为 regard 的双式词）
  - **义域分工（英法皆然）**：法语 **regarder**（把目光投过去·主动注视）vs **garder**（守着、保存）；英语 **guard**（守卫）vs **ward**（看守／病房）
- **共祖未借入**：\*wer- 的远亲另见英语 `ware`（当心）、`wary`、`warn`、`beware`、`steward`、`wardrobe`——同出 PIE **\*wer-**「察觉、守望」，与 regarder 共祖
- **核对**：英语侧（ward ← OE weard / weardian ← PGmc \*wardon ← PIE \*wer-；guard early / mid-15c. ← 法 garde / garder；regard mid-14c. ← OF regarder；reward ← OF north rewarder）2026-10-04 经 **etymonline 直读**；法语侧（法兰克 \*wardōn、OF garder / regarder、\*wer-、1080 义首证、1118 se regarder、1120 regarder à、TLF XIV 640a、FEW XVII 510a）2026-10-04 经 **检索转引 CNRTL/TLFi、DMF 与 Dictionnaire Historique（Le Robert）**（CNRTL 直连仍失败）。**待验证**：①TLFi「regarder」原条首证定年（现为转引 1080，出自 Le Robert 历史词典）；②regard 名词「980 年首证」之说（France Bleu 播客**单一来源、无旁证**，存疑不采）；③法兰克语 \*wardōn 借入罗曼语的具体年代未逐核

**同义 / 搭配 / 易混**
- **义域分工（本页核心）**：**regarder**（**主动把目光投向**——看／注视／观看：regarder un film, regarder qn）｜ [[voir]]（**看见**——被动感知结果：Je vois un oiseau 我看见一只鸟；voir 亦作「会见、明白」）｜ **assister à**（**出席观看**——接 à，强调到场：assister à un match 现场看一场比赛）｜ **observer**（观察）｜ **contempler**（凝视、端详）｜ **fixer**（盯住）
  - 口诀：**regarder 是动作，voir 是结果**——Regarde ! 你看！／ Je ne vois rien. 我什么也看不见
- 搭配：`regarder qch / qn`（直接及物）；`regarder qn faire qch`（看某人做某事）；`regarder qn comme…`（把某人看作……）；`regarder à qch`（顾及、计较）；`Ça (ne) me regarde pas`（不关我的事）；`regarder autour de soi`（环顾四周）；`se regarder dans le miroir`（照镜子）
- 易混：**regarder**（看）vs [[voir]]（看见）；**regarder à**（计较——如 regarder à la dépense）与直接及物 regarder 的区别；**garder**（看守／保存）——同根近形，勿混（garder la porte 守门 vs regarder la porte 看门）
- 相关：[[voir]]（看见）、[[chercher]]（寻找）、[[connaitre]]（认识）、[[recevoir]]（接收）——链 [[voir]]、[[chercher]]、[[connaitre]]
