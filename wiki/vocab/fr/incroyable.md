# incroyable

**释义**：难以置信的、不可思议的；惊人的 ｜ qu'on ne peut pas croire ; extraordinaire

**例句**
- _C'est une histoire incroyable._ 这是个难以置信的故事。
- _Elle a un talent incroyable._ 她有惊人的才华。
- _Incroyable ! Tu as gagné ?_ 难以置信！你赢了？

**形态要点**
- 形容词：incroyable（阴阳**同形**，只加复数 -s：incroyables）；常作感叹语（Incroyable !）；无特殊比较级变化

**词源 / 构词**
- **拆解**：**in-**（否定）+ **croyable**「可信的」（← **croire**「相信」）——「不可信的」→「难以置信的、惊人的」
- **演变**：拉丁 **credere**「相信」→ 古法语 creire → croire；词干 croy-（如 croyable、croyons）源自 cred- 的古法语演化 → incroyable（**年代待验证**）
- **同族 / 派生**：croire（相信）、croyable（可信的）、croyance（信仰）、croyant（信徒）、incroyant（不信教者）；英语一侧见下节
- **记忆钩**：incroyable ＝ in（不）+ croire（相信）+ -able（可……的）＝「没法信的」；法语 croire 与英语 creed（信条）同出拉丁 credere

**英法交叉核对（受影响的英语词）**
- **借入英语**：**credit**（← 法语 crédit ← 拉丁 creditum「贷出的、信任之物」——「信用/信贷」义经法语入英）；**credible / incredible**（← 拉丁 credibilis / incredibilis——**拉丁直借或经法语，路径待验证**）；**creed / credo / credentials**（← 拉丁 credo「我信」）
- **平行构词（非借入）**：英语 **incredible** 与法语 incroyable 是**同义同构但非同源借入**——incredible 走拉丁 incredibilis 路线，incroyable 是法语自家 croire 的否定构词，两者各自独立、恰好对齐
- 核对：credit / incredible 借入路径标**待验证**，待联网核实

**同义 / 搭配 / 易混**
- 搭配：`une histoire incroyable`（难以置信的故事）；`un talent / un succès incroyable`（惊人的才华/成功）；感叹语 `Incroyable !`
- 易混：**incroyable**（难以置信——偏「超乎想象的好/大」，日常惊叹）vs **incrédule**（不信的、怀疑的——指人，宗教语境多）vs **croyable**（可信的）；感叹语系列：Incroyable ! / Pas possible ! / C'est fou !
- **faux ami**：incroyable / incredible 基本对齐，但法语 incroyable 日常使用频率更高（＝英语 unbelievable 的常用度），而英语 incredible 稍偏书面
