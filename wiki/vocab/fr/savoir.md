# savoir

> 收录说明：inbox 形式 `sais` 是现在时 1 单变位（je sais），按词形归并到不定式 lemma **savoir**。

**释义**：（1）知道（savoir qch ／ savoir que + 从句 ／ savoir si… 知道是否）；（2）会、懂得（savoir + inf.：savoir nager 会游泳）；savoir 名词化 = 知识、学问（le savoir） ｜ être informé de ; avoir la connaissance de ; être capable de

**例句**
- _Je sais qu'il habite à Paris._ 我知道他住在巴黎。
- _Elle sait nager depuis l'âge de cinq ans._ 她五岁起就会游泳。
- _Personne ne sait ce qui s'est passé._ 没人知道发生了什么。

**形态要点**
- 动词：不定式 **savoir** ｜ **3e groupe**（极不规则）｜ 助动词 **avoir** ｜ 过去分词 **su**（j'ai **su**）
- 现在时六形：je **sais** ｜ tu **sais** ｜ il·elle **sait** ｜ nous **savons** ｜ vous **savez** ｜ ils·elles **savent**（单数词干 sai-，复数 sav-）
- 将来 je **saurai** ｜ 未完成 je **savais** ｜ 虚拟式 que je **sache** ｜ 命令式 **sache / sachons / sachez** ｜ 现在分词 **sachant**（sachant que「已知……」）
- 句法：`savoir + 从句`（savoir que / si / où / comment…）；`savoir + inf.`（会做——习得的能力）；`savoir qch`（知道某事）；`je ne sais pas si…`（不知道是否……）

**词源 / 构词**
- **拆解**：拉丁 **sapere**「有滋味、有辨别力 → 明智」（民间拉丁 **\*sapēre**，PIE **\*sap-**「尝」）——「尝出味道」→「辨出真伪」→「知道」
- **演变**：古典拉丁 sapere 本义「有味道；明智」；民间拉丁以 \*sapēre **取代 scire**（知道）成为罗曼语「知道」动词（意大利语 sapere、普罗旺斯语 sabèr 同出一辙）；法语 **842 年**已见名词化不定式「savoir（知识）」（《斯特拉斯堡誓言》），**10 世纪**起见动词用例（圣莱热传「知情」义；受难曲「有能力」义），约 1050-1100 起兼作 pouvoir 的弱化替身——据 CNRTL/TLFi（2026-10-03 经检索转引）
- **同族 / 派生（法语）**：savant（学者、博学的——savoir 的旧现在分词）、sachant（现代分词）、savoir-faire（本领——savoir + [[faire]]）、savoir-vivre（处世礼貌）、sapience（书面「智慧」）；英语一侧见下节
- **记忆钩**：savoir 的祖义是「尝」——先尝出味道，再尝出真假，最后就「知道」了；英语 sapient（明智）与 savour（滋味）同出 sapere——一个走「智」侧、一个走「味」侧

**英法交叉核对（受影响的英语词）**
- **借入英语**：**savoir-faire**（英文首见 1788〔OED，Robert Bage〕／etymonline 记 1815〔Scott〕——**两说并存**）；**savoir-vivre**（英语作家偶用，常带斜体）；**savant**（1719「博学者」← 法语 savant——savoir 的旧现在分词）；**savvy**（1785 俚语「懂行、见识」← 西印度洋皮钦语：一说 ← 法语 **savez(-vous)**「您知道吗」，一说 ← 西班牙语 **sabe (usted)**〔← saber ← sapere〕，一说葡萄牙语 sabe——**诸说并列，无定论**）；**sage**（adj. c. 1300 ← 古法语 sage ← 高卢罗曼 \*sabius ← 民间拉丁 \*sapius ← sapere）；**savor / savour**（n. c. 1200 ← 古法语 savor ← 拉丁 sapor「味道」← sapere——「味」侧）
- **共祖未借入**：**sapient / sapience / insipid**（← 拉丁 sapiens / sapientia / insipidus——拉丁直传，非经法语）
- 核对：已核实（etymonline，2026-10-03 经检索转引）——savant 1719、savvy 1785（皮钦语来源诸说不一）、sage c. 1300 ← 古法语、savor c. 1200 ← 古法语；savoir-faire 首见两说（OED 1788 ／ etymonline 1815，如实并列）。法语侧据 CNRTL/TLFi：民间拉丁 \*sapēre、842 名词化首见、10 世纪动词用例（经检索转引）

**同义 / 搭配 / 易混**
- 搭配：`savoir que / si / où / comment…`（知道……）；`savoir faire qch`（会做）；`savoir par cœur`（背下来）；`à savoir`（即、也就是）；`un savoir-faire`（技艺、诀窍）；`Dieu sait`（天晓得）
- **易混（本组核心）**：**savoir**（知道「信息、事实、怎么做」——savoir que… ／ savoir + inf. ／ savoir qch）vs [[connaitre]]（熟悉「人、物、地方、作品」——connaître qn ／ connaître Paris ／ connaître un auteur）；「我认识他」＝ je **le connais**（不能用 savoir）；「我知道他到了」＝ je **sais** qu'il est arrivé；详见综合页 [[connaitre-vs-savoir]]
- **faux ami**：英语 know 一词兼两义，法语必须二分——这是法语学习者最高频的混淆点之一（错用 *je sais cette ville 会立刻被察觉）
