# liseuse

**释义**：（1）电子阅读器、电纸书（lire sur une liseuse——当代主义）；（2）阅读灯（夹书小灯，1918 义）；（3）书封套（保护在读之书的活套，1930 义）；（4）女读者（liseur 的阴性） ｜ appareil de lecture numérique ; lampe de lecture ; couvre-livre ; celle qui lit

**例句**
- _Elle lit ses romans sur une liseuse._ 她用电子阅读器读小说。（见 [[roman]]）
- _La liseuse protège le livre en cours de lecture._ 书封套保护正在读的书。
- _C'est une grande liseuse de romans policiers._ 她是个侦探小说读得很多的女读者。（见 [[roman-policier]]）

**形态要点**
- 名词：`la liseuse`（f.）；复数 `les liseuses`；阳性对 **liseur**（读者——人）；-euse 读 /øz/
- 构词同款：lire 现在时干 **lis-**（je lis, nous lisons）+ -eur / -euse（同 chanteur / chanteuse）
- **一词多义**（同一词根长出的「阅读用具」群）：电子阅读器（当代）｜ 阅读灯（1918）｜ 书封套（1930——见 [[couverture]] 一族）｜ 女读者（人义，最古）
- 常见搭配：`lire sur une liseuse`（用阅读器读）；`une liseuse en cuir`（皮书套——1930 义）；`une liseuse de livres numériques`（电子书阅读器——当代）

**词源 / 构词**
- **拆解**：**lire**（拉丁 **legere**「拾取、收拢」——引申「读」，见下）＋ 阴性后缀 **-euse**（-eur 的阴性）；**liseur / liseuse** ＝「读的人」→ 由人及物：「帮人读的东西」
- **lire 的底**：拉丁 legere 义为「收集、拾取」，**legere oculis**「用眼睛拾取（字母）」式用法引申出「读」；古法语首证 **ca 1050**（《圣阿莱克西斯传》Vie de saint Alexis），早期形式 **leire**，13 世纪初缩为 **lire**；现在时 -s-（je lis, nous lisons）系拉丁 g 的换位（同 faire、dire）〔CNRTL / DHLF，2026-10-03 经检索转引〕
- **liseuse 的义项编年（CNRTL）**：**1867**「裁书刀兼书签」（Littré）；**1889**「放书小桌」；**1909**「寝读披肩（mantelet）」；**1918**「阅读灯」（Bourget）；**1930**「书封套 couvre-livre」；当代「电子阅读器」（术语 2008–09 在法国通行——见「待验证」）〔2026-10-03 经检索转引〕
- **同族 / 派生（法语）**：lire、lecture（阅读）、lecteur / lectrice（读者；阅读器 / 播放器）、lisible（可读的）、leçon（课——← 拉丁 lectio，legere 同根）、élire / élection（← eligere「选出」——**legere 的「选」与「读」一体两面**）
- **记忆钩**：legere 的本义是「**拾取**」——把字母一个个拾起来看＝读；把候选人一个个挑出来＝**élire**（选）；liseuse 则是替你做这件「拾取」之事的工具

**英法交叉核对（受影响的英语词）**
- **借入英语**：**liseuse**（英 n. ← 法）——英语词典所载义为（a）**读写用折叠小桌**（en.wiktionary 释义，对应法 1889「小桌」义）与（b）**bed jacket** 义（Collins / vocabulary.com 以 liseuse 对译「寝读披肩」，对应法 1909 义）；近年电子阅读圈（MobileRead 论坛等）亦借 liseuse 指电纸书〔2026-10-03 经检索转引〕。**注：提示称「英语借的正是书封套（1930）义」——检索未获词典明证，如实按词典义（小桌 / 披肩）记录**
- **借入 / 共祖（legere 家族进英语）**：**legible**（late 14c ← 晚期拉丁 legibilis）；**legend**（early 14c ← 古法语 legende / 中世纪拉丁 legenda「（弥撒中）应读的（圣徒传）」）；**lesson**（c. 1200 ← 古法语 leçon ← 拉丁 lectionem——与英语 lection 互为双胞）；**lecture**（late 14c ← 古法语 lecture / 中世纪拉丁 lectura）；**lection / lectern / lector**（同根）；**elect / select / collect / intellect / elegant**（leg- 变体）——全出 PIE **\*leg-「收集」**〔etymonline，2026-10-03 经检索转引〕
- **反例（勿混）**：英 **read** 与 legere **无词源关系**（← 古英语 rædan「建议、诵读」，日耳曼本族词）
- 核对：已核实（CNRTL / etymonline，2026-10-03 经检索转引）——liseuse = liseur 的阴性（CNRTL，首证 1867）；lire ← 拉丁 legere「拾取」，ca 1050 首证；英 legible / legend / lesson / lecture 路径（etymonline）；英语 liseuse 词典义（Wiktionary / Collins / vocabulary.com）

**同义 / 搭配 / 易混**
- 同义：`une tablette de lecture` / `un lecteur de livres numériques`（电子阅读器——描述性说法）；书目语：`un couvre-livre`（书套——1930 义的通用说法）
- **易混（都含「读」）**：**liseuse**（设备 / 阅读工具——本页）｜ **lecteur / lectrice**（读者；也指阅读软件 / 播放器）｜ **liseur / liseuse**（女读者——人义）｜ **lisible**（可读的）
- **易混（书封套 vs 封面）**：**la liseuse**（可换用的活套，1930 义）｜ **la jaquette**（护封——一本专用的、带宣传的封套）｜ **la [[couverture]]**（封面 / 封皮——书本身的外皮；也指被子）——OQLF 建议 liseuse 与 jaquette 分清〔转引〕
- 相关链接：[[roman]]、[[librairie]]、[[marque-page]]（书签——与 1867 义「兼书签的裁书刀」同属阅读配件）
