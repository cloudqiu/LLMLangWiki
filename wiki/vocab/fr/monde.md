# monde

**释义**：n.m. ①**世界、宇宙** ②**地球** ③**人们、人群、大家**（*tout le monde* 所有人）④**社交界、上流社会**（*le beau monde*）⑤（生物的）**界**（*le monde animal*）⑥**大量**（*un monde fou* 人山人海） ｜ ensemble de ce qui existe ; les gens ; société

**例句**
- _Tout le monde est là._ 大家都在。
- _Il y a beaucoup de monde dans la rue._ 街上人很多。
- _Le monde entier regarde._ 全世界都在看。

**形态要点**
- 名词：`le monde`（**m.**）；复数 **mondes**（规则）
- 另作**形容词** *monde*（**阳阴同形**，pl. *mondes*）——「**纯净的、无杂质的**」，属旧 / 技术义（如 *blé monde* 净麦）
- 关键搭配：**tout le monde**（大家 / 所有人）、**beaucoup de monde**（很多人）、**gens du monde**（上流人士）、**le monde entier**（全世界）、**mettre au monde**（分娩）

**词源 / 构词**
- 拆解：← 拉丁 **mundus**，本义「（整理好的）**物件、妆饰**（尤指**新娘嫁妆箱**）」，后**选以对译希腊 κόσμος (*kósmos*)** 之「有序＝宇宙」义。拉丁 *mundus* 另有形容词义「**洁净、整齐**」——法语形容词 *monde* 由此而来
- **⚠️ 同形异源之谜（照录）**：fr.wiktionary 并注：拉丁 ***mundus***「世界」与 ***mundus***「洁净」**同形而词源关系不明**；etymonline 亦云 *"the exact connection is uncertain"*
- 首证（并列）：fr.wiktionary 记 **xiiᵉ siècle（12c）**；Usito 记 **Vers 1131 (in GRLF)；10ᵉ s., *mont* (in TLFi)** → 「*monde*」形约 **12c（1131）**首现、「*mont*」形可**上溯 10c**；**二源并列，不折中**
- 同族 / 派生：**mondial**（全球的）、**mondialisation**（全球化）、**mondain**（世俗的 / 社交界的）、**immonde**（污秽的——**同出 mundus「洁净」那一义**）
- 记忆钩：**mundus 本是「妆饰整齐」**——「**整整齐齐的一整套**」先成了「世界」（仿希腊 *kosmos* 的「有序＝宇宙」），又留下「洁净」一义给形容词

**英法交叉核对（受影响的英语词）**
- **借入（英 ← 法）**：
  - **mundane**（**mid-15c.** *mondeine*）← 古法语 *mondain*（12c.）← 晚期拉丁 *mundanus* ← 拉丁 *mundus*「世界」；义「**世俗的、平淡乏味的**」**1850** 起 → **经古法语中介，属借入**
  - **beau monde**（**1714**）、**demi-monde / demimonde**（**1855** ← 法语 *demi-monde*「半个世界」）——近代**直接借入的法语短语**
  - 中古英语 **mounde**「世界」← 古法语 *monde*（**后废**）
- **共祖（直取拉丁）**：拉丁 *mundus* 直取英语者——*anima mundi*（**1670s**）、*supermundane*（**1670s**）——与 *monde / mundane* 同源
- **核对要点**：*mundane* 在英语里已漂移为「**平庸的、乏味的**」，而法语 *monde* 是「**世界**」——**同源而义分**

**同义 / 搭配 / 易混**
- 同义：**univers**（宇宙）、**terre**（地球）、**gens**（人们）、**société**（社会）
- 搭配：**tout le monde**、**beaucoup de monde**、**gens du monde**、**le monde entier**、**mettre au monde**（分娩）、**se faire du monde**（俗：发愁）
- **faux ami**：英语 *mundane*（**平庸的**）与法语 *monde*（**世界**）**义已漂移**——英语 *mundane* 的「世俗」义来自 *mundanus*，与法语 *mondain*（社交界的 / 世俗的）才更对齐
- **易混**：**monde**（世界 / 人们）vs **gens**（人们——**复数概念，本身已是复数**）
