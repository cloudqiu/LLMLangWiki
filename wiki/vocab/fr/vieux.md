# vieux

**收录说明**：inbox 收词为 **`vieille`**（阴性形）——按 lemma 归并到阳性单数 **vieux**，未另建页。

**释义**：（1）**老的、年老的**（un vieux monsieur 一位老先生）；（2）**旧的、陈的**（de vieux habits 旧衣服；du vieux pain 陈面包）；（3）**多年的、长久的**（un vieil ami 老朋友；une vieille habitude 老习惯）；（4）**n. 老人**（les vieux 老一辈 / 老年人）；（5）**（前置）老一套的、陈旧的、熟悉的**（une vieille histoire 老掉牙的事） ｜ qui a vécu longtemps ; qui existe depuis longtemps ; usé, ancien

**例句**
- _Mon voisin est un vieux monsieur très gentil._ 我邻居是位很和善的老先生。
- _Je porte mes vieux habits pour bricoler._ 我做活儿时穿旧衣服。
- _C'est un vieil ami d'enfance._ 这是个从小结识的老朋友。
- _Encore cette vieille histoire !_ 又是那套陈年旧事！

**形态要点**
- **阳性单数两形**：**vieux**（辅音前：un vieux livre）／**vieil**（**元音或哑音 h 前**：un vieil homme、un vieil arbre）；**阴性 vieille**；阳复 **vieux**；阴复 **vieilles**
- 属 **beau / nouveau / vieux** 型特殊形容词（**双阳形 + 前置**）——与 [[beau]] / [[nouveau]] 同类变化
- 名词用法：`les vieux`（老人们——口语 / 略俗）；`un vieux`（老家伙）
- 比较级：`plus vieux`（更老 / 更旧；指人「年长」常用 **aîné**、礼貌说法 **âgé**）
- 派生：**vieillir**（变老）、**vieillesse**（老年）、**vieillard**（老人）、**vieillot**（显老的 / 过时的）、**vieillissement**（老化）、**suranné**（过时的）

**词源 / 构词**
- **拆解**：拉丁 **vetulus**（**vetus**「老」的**指小**）→ 俗拉丁 **\*vetlus / \*veclus** → 古法语 **viel** → 现代 **vieux / vieil / vieille**
- **演变**：拉丁 vetulus → 俗拉丁 \*veclus → 古法 viel；**首见约 1050**，形 ***velz***（《圣阿莱克西传》；CNRTL / TLFi / Usito）；**vieil** 形 **1480**（Guillaume Coquillart）
- **词源假说**：阳性两形之分工有一说（Mildred K. Pope《From Latin to Modern French》§509, 808）：**vieux ← 主格 vetulus**、**vieil ← 宾格 vetulum**——**假说**
- **同族 / 派生（法语）**：vieillir、vieillesse、vieillard、vieillot、vieillissement
- **记忆钩**：「老」的拉丁词 *vetus* 已带指小 *vetulus*（「有点老的」）——法语 vieux / vieille 承的正是这个指小形

**英法交叉核对（受影响的英语词）**
- **同义异源**：英语「老的」用 **old**（← 古英语 *eald* ← 日耳曼）——与 vieux **无亲缘**；英语**无**借自 vieux 的词
- **共祖未借入**：罗曼语同源词（意大利 **vecchio**、西班牙 **viejo**、奥克 **vielh**）系拉丁 **vetulus** 的**共祖**后代，**非法语输入英语**
- 核对：英语侧（old ← OE eald）经检索转引 etymonline（2026-10-11）；法语侧首见约 1050 *velz* 与 vetulus 链据 CNRTL / TLFi / Usito 转引（**待验证**）

**同义 / 搭配 / 易混**
- 搭配：`vieux / vieil ami`（老朋友）｜ `vieille ville`（老城）｜ `vieux jeu`（老一套）｜ `à la vieille mode`（老派的）｜ `les vieux jours`（晚年）
- **易混**：**vieux**（老的 / 旧的）vs **ancien**（古老的 / 前任的——前置＝前任，后置＝古老）vs **âgé**（年长的——**礼貌说法**，避免 vieux 的冒犯感）vs **vieillot**（显老 / 过时）
- 反义：**[[jeune-adj]]**（年轻的）；**[[]]** ／ **[[nouveau]]**（新的——vieux ↔ nouveau 是「旧 / 新」对）
- 相关：[[jeune-adj]]（反义）；[[nouveau]]（新 / 旧对）；[[propre]] / [[sale]]（同批形容词）
