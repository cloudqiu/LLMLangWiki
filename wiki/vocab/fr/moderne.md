# moderne

**释义**：现代的、近代的；（艺术）现代的、新派的 ｜ de notre époque ; récent

**例句**
- _C'est un appartement moderne._ 这是一套现代公寓。
- _J'aime l'art moderne._ 我喜欢现代艺术。
- _La vie moderne est rapide._ 现代生活节奏很快。

**形态要点**
- 形容词：moderne（阴阳**同形**，复数 modernes）；位置多在名词后（une ville moderne）；亦作名词 les Modernes（现代派，与 les Anciens 相对）

**词源 / 构词**
- **拆解**：晚期拉丁 **modernus**「现在的、当代的」＝ **modo**「刚刚、现在」（**modus**「方式、尺度」的夺格）＋ -nus（形容词尾）——字面「以当下方式（的）」
- **演变**：拉丁 modus「方式、尺度」→ 夺格 modo「现在」→ 晚期拉丁 modernus「当今的」→ 法语 moderne（最早为 14 世纪形式 moders，借自晚期拉丁 modernus，据 Académie 9e 版经 CNRTL 转引，2026-10-01 经检索转引；TLF 载 moderne 早于 1455 年）；modernus 是拉丁自身较晚的构词（非古典拉丁）
- **同族 / 派生**：moderniser（现代化）、modernité（现代性）、mode（方式、时尚）、modèle（模型、模范）；英语一侧见下节
- **记忆钩**：moderne ＝ modo「现在」的形容词——「按当下的方式」；同根 mode（时尚）就是「当下的方式」

**英法交叉核对（受影响的英语词）**
- **借入英语**：**modern**（← 法语 moderne / 晚期拉丁 modernus，16c.）；**modernity / modernize / modernism / modernist**（← modern 派生，部分再借法语 modernité）
- **共祖未借入**：**mode / model / modify / modal / module / mood**（← 拉丁 modus「方式、尺度」家族，经拉丁/法语入英——modernus 内含 modus，故 mode / model 是 moderne 的同族共祖，非本词借入）
- 核对：英 modern 约 1500 年（16 世纪之交，义「现存、当下」），← 法语 moderne（15c.）并直承晚期拉丁 modernus（据 etymonline，2026-10-01 经检索转引）——2026-10-01 清账核实

**同义 / 搭配 / 易混**
- 搭配：`un appartement / une ville moderne`；`l'art moderne`（现代艺术）；`les langues modernes`（现代语言）
- 易混：**moderne**（现代的——时期/风格，指近现代）vs **contemporain**（当代的、同时代的——指当下/同时期）vs **actuel**（当前的、现行的）；文学史 **les Modernes**（现代派）vs **les Anciens**（古典派）
- **faux ami**：moderne / modern 基本对齐，非典型 faux ami；但注意英语 modern 也可指「现代主义」艺术，法语对应表达多用 l'art moderne
