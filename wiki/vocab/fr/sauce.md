# sauce

**释义**：（1）调味汁、酱、沙司（sauce tomate 番茄酱）；（2）（转义）附属物、陪衬（la sauce 与主菜相对）；`à toutes les sauces`（各式各样地、到处——贬义） ｜ préparation liquide servant d'assaisonnement ; (fig.) ce qui accompagne ou déguise

**例句**
- _J'aime les pâtes à la sauce tomate._ 我喜欢番茄酱拌意面。
- _Cette sauce au poivre est délicieuse._ 这个黑胡椒酱汁很好吃。
- _On le cite à toutes les sauces._ 人们到处援引他。（百搭引用）

**形态要点**
- 名词：`la sauce`（f.）；复数 `les sauces`
- 常见：`sauce tomate`（番茄酱）、`sauce au poivre`（黑胡椒酱）、`sauce blanche`（白汁）、`sauce piquante`（辣酱——见 [[piment]]）；法餐「母酱」体系：`béchamel / velouté / espagnole / hollandaise / tomate` 等；`monter une sauce`（把酱汁打稠乳化）
- 惯用：`à toutes les sauces`（到处套用——贬）；`mijoter dans sa sauce`（闷在自己的小天地里）；`napper / verser la sauce`（浇汁）
- 派生：`saucer`（用面包蘸净盘底酱汁；给菜浇酱）、`saucière`（酱汁壶）、`saucier`（酱汁师；酱汁锅）

**词源 / 构词**
- **拆解**：拉丁 **salsa**「盐渍物、咸食」——**salsus**「盐腌的」（sallere「腌、加盐」的过去分词）的**阴性名词化**；sallere ← **sal**「盐」（PIE 根 **\*sal-**「盐」）
- **演变**：拉丁 salsa → 古法语 **sause / sausse**（英语 mid-14c. 借入即自此形）→ 中古法语 **saulce / saulse / sause**（fr.wiktionary 引 TLFi，2026-10-03 经检索转引；该页另提一个推测形 \*salce——**待验证**）→ 现代法语 sauce；**法语侧首证年代未得**（**待验证**；Académie 1re éd. 1694 收录拼形「sausse」）
- **同族 / 派生（法语）**：**saler**（加盐、腌）、**sel**（盐）、**salé**（咸的；腌肉）、**salière**（盐瓶）、**saumure**（盐水、卤水）、**saucisse**（香肠 ← 通俗拉丁 salsicia「盐腌物」）；**[[salaire]]**（工资 ← salarium「买盐的钱」）——**「盐」词族大集合**：sauce / salaire / saucisse / saler / saumure 全是 sal 的子孙
- **记忆钩**：sauce 的祖先是「**盐**」——古罗马人用盐腌渍调味，salsa 就是「咸东西」；法语里 sal 一旗下：sel（盐）、saler（腌）、salaire（盐饷 → 工资）、saucisse（腌肉肠）、sauce（咸食 → 酱汁）——一勺盐调出半个词库

**英法交叉核对（受影响的英语词）**
- **借入英语**：**sauce**（英 mid-14c.「调味汁；腌渍液、盐水」← 古法语 **sauce / sausse** ← 拉丁 **salsa**「things salted」；16c.–17c. 拼写 sawce / salse 频见——英语反复借法语烹饪词使旧拼写得以保留；转义「俏皮话的佐料」c. 1500、**saucy**「冒失的」1520s、**sassy / sass** 1835 一线相承——etymonline，2026-10-03 经检索转引）；**sausage**（英 mid-15c. sawsyge ← 古北法语 **saussiche** ← 通俗拉丁 \*salsica / salsicus「盐调味」← salsus「盐腌的」← sallere ← sal；法语对应 **saucisse**——etymonline，同上）——sauce 与 sausage 是 sal 线在英语的两大门面
- **共祖未借入**：**salt**（英语本族词 ← 古英语 sealt ← 原始日耳曼，PIE **\*sal-**「盐」——与拉丁 sal **共祖**，非借入；etymonline 列同根：希腊 hals、古爱尔兰 salann、德语 Salz 等）；**salsa**（西班牙语 salsa ← 同一拉丁 salsa——经西语入英的「同源异借」，音乐 / 舞曲义 20 世纪）
- 核对：已核实（etymonline / fr.wiktionary 引 TLFi，2026-10-03 经检索转引）——英 sauce mid-14c. ← 古法语 sauce / sausse ← 拉丁 salsa ← salsus ← sallere ← sal（PIE \*sal-）；英 sausage mid-15c. ← 古北法语 saussiche ← 通俗拉丁 \*salsica；拉丁 salsa → 西 salsa 同源异借。**待验证**：法语 sauce 首证年代（TLFi 原条未及）；fr.wiktionary 的「\*salce」推测形；saucy 诸义年代未逐一核

**同义 / 搭配 / 易混**
- 搭配：`sauce tomate`（番茄酱）、`sauce au poivre`（胡椒酱）、`sauce blanche`（白汁——见 [[cuisine]]、[[piment]]）；`à toutes les sauces`（百搭地、到处套用——贬义）；`une sauce piquante`（辣酱——见 [[piment]]）
- **易混**：**sauce**（酱汁——浇在菜上的具体汁）vs **assaisonnement**（调味——统称）vs **condiment**（调味品——芥末、醋等）；同族对照 **[[salaire]]**（工资——同出 sal 根，见其页 sal 词族）与 **saucisse**（香肠）
- **faux ami**：法语 sauce 的转义 `à toutes les sauces` 是「到处套用」的贬语；英语 saucy「冒失无礼」义**不在**法语 sauce 上（法语「冒失」用 impertinent / insolent）——saucy 是英语内部引申，别回译成法语 sauce；法语 `sauce` 大写无特殊联邦机构义（对照 trésor → le Trésor）
