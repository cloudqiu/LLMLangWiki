# émouvant

**收录说明**：inbox 收词 `emouvant`（缺音符）——按**形容词 lemma émouvant** 建页；其底词动词 **émouvoir** 的变位要点见本页「形态要点」。

**释义**：（1）**感人的、动人的**（une histoire émouvante 感人的故事；un adieu émouvant 令人动容的告别）；（2）**扣人心弦的、令人激动的** ｜ qui émeut, qui suscite une émotion ; touchant

**例句**
- _C'est un film très émouvant._ 这是一部非常感人的电影。
- _Elle a prononcé un discours émouvant._ 她发表了感人的讲话。
- _Le spectacle était émouvant jusqu'aux larmes._ 演出感人至深、催人泪下。

**形态要点**
- 形容词：阳性 **émouvant** ｜ 阴性 **émouvante** ｜ 阳复 **émouvants** ｜ 阴复 **émouvantes**
- 底词动词 **émouvoir**：不定式 **émouvoir** ｜ **3e groupe**（-oir 不规则）｜ 助动词 **avoir**（亦代词式 **s'émouvoir** 受感动）｜ 过去分词 **ému**（阴 **émue**）
- 现在时六形：**j'émeus ｜ tu émeus ｜ il·elle émeut ｜ nous émouvons ｜ vous émouvez ｜ ils·elles émeuvent**
- 用法：`être émouvant`（感人）｜ `émouvoir qn`（打动某人）｜ `s'émouvoir de qch`（因某事动容）

**词源 / 构词**
- **拆解**：通俗拉丁 ***\*exmovere**（古典拉丁 **emovere**「移出、搅动」的**重构**；**ex-**「出」+ **movere**「移动」）→ 古法语 **esmouvoir** → 现代 **émouvoir** → 现在分词 **émouvant** 用作形容词
- **演变**：拉丁 emovere → 古法 esmouvoir（约 **1100**「使动」，《罗兰之歌》；约 **1170**「搅动感情」）→ émouvoir；**形容词首见 1834**（Sainte-Beuve《Volupté》t.1 p.122；CNRTL）
- **同族 / 派生（法语）**：**émotion**（情感）、**émoi**（激动、不安）、**s'émouvoir**（动容）、**ému**（受感动的，过去分词）
- **记忆钩**：émouvoir ＝「把（感情）**移出来**」（e-/ex- + mouvoir）——把心里的东西「搅动出来」＝打动；émouvant 就是「能搅动你的」

**英法交叉核对（受影响的英语词）**
- **借入英语**：**emotion**（n. **1570s**「（社会的）动、搅动」← 法语 **émotion**（16c）← 古法 emouvoir ← 拉丁 emovere）；**emotive**（1735，← 拉丁 emot-）
- **借入（同根另支）**：**move**（v.）← 盎格鲁-法语 ***mover*** / 古法 moveir ← 拉丁 **movere**——与 émouvoir **同出拉丁 movere**，但英语 move 借的是 mover，**非** émouvoir 本词
- **同义异源**：英语「感人的」用 **moving / touching**（本族成分）——与 émouvant 义平行而构词不同
- 核对：英语侧（emotion 1570s ← 法语 émotion；move ← 盎格鲁-法语 mover）经检索转引 etymonline（2026-10-11）；法语侧 1100 / 1170 / 1834 与 exmovere 链据 CNRTL / Académie 9e 转引（**待验证**）

**同义 / 搭配 / 易混**
- 搭配：`un moment émouvant`（动人的一刻）｜ `un récit émouvant`（感人的叙述）｜ `émouvant jusqu'aux larmes`（催人泪下）
- **易混（重点）**：**émouvant**（**令人**感动的）vs **ému**（**自己**受感动的）——现在分词 vs 过去分词，**受英语 moving / moved 干扰最易错**（*je suis émouvant* ≠ *je suis ému*）
- 再易混：**émouvant**（感人的）vs **touchant**（动人的）vs **[[passionnant]]**（引人入胜的 / 精彩的）vs **impressionnant**（令人印象深刻的）
- 相关：[[passionnant]]（近义 / 易混）；[[triste]]（情感域）
