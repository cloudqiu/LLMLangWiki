# rêve

**释义**：（1）**梦**（faire un rêve 做梦；en rêve 在梦中；un mauvais rêve 一场噩梦）；（2）**梦想、理想**（un rêve de jeunesse 年少时的梦想；le rêve américain 美国梦）；（3）**（俗）梦寐以求的东西**（Cette voiture, c'est mon rêve 这车是我梦寐以求的）；（4）**`de rêve`** ＝ 梦一般的、理想的（des vacances de rêve 梦幻假期） ｜ images pendant le sommeil ; désir, idéal

**例句**
- _J'ai fait un drôle de rêve cette nuit._ 我昨晚做了个怪梦。
- _Son rêve est de devenir médecin._ 她的梦想是当医生。
- _Ils ont passé des vacances de rêve._ 他们度过了梦幻般的假期。

**形态要点**
- 名词：`le rêve`（**m.**）；复数 **rêves**
- 底词动词 **rêver**：**1er groupe**，助动词 **avoir**，过去分词 **rêvé**；现在时 **je rêve / tu rêves / il·elle rêve / nous rêvons / vous rêvez / ils·elles rêvent**
- 派生：**rêver**（做梦 / 梦想）、**rêverie**（遐想、白日梦）、**rêveur**（做梦的 / 出神的）、**rêvasser / rêvasserie**（做白日梦）
- 短语：`rêve éveillé`（白日梦）｜ `vendre du rêve`（兜售美梦 / 画大饼）｜ `de rêve`（梦幻的）｜ `un rêve de gosse`（儿时的梦想）

**词源 / 构词**
- **拆解**：名词 **rêve** 系动词 **rêver** 的**逆构（déverbal）**——**首见 1674**（fr.wiktionary）；名词长期罕用（Furetière 1690、Académie 1694 仍标「旧 / 俗」），**19c 才普及**。动词 **rêver** ← 古法 **resver**（约 **1130**「因病谵妄」；古法诸形 *rever / raver*）
- **词源学界未定（诸说并列，勿择一）**——古法 resver 的源头有 ≥6 说：
  - ***\*esver***「游荡」（< 高卢罗曼 \*esvo「流浪者」< 俗拉丁 **\*exvagus** = ex- + **vagus**「漫游」）——fr.wiktionary 采此链
  - ***\*reexvadare***（← 拉丁 **evadere**「逃脱」）——TLFi 另一说
  - ***\*reexvagus***——FEW 说
  - ***\*reex-vare***——因古法 resve 拼写与 \*raba 相抵
  - **revehi**（中世纪拉丁「被梦带走」）——Lidforss-Nordin
  - ***\*refragu***「倔强」→ \*revu——Gamillscheg（**音变有严重困难**）
  - 拉丁 **rabies**「狂犬病 / 狂怒」——Diez 旧说，**已被否定**（rabies 已给 *rage*；且古法 rever 义为「游荡」）
- **反向注记**：Littré 主张英语 **rave** 系**出自**法语 resver（**非**反向）
- **同族 / 派生（法语）**：rêver、rêverie、rêveur、rêvasser、rêvogène；`cauchemar`（噩梦——另一词）、`onirique`（梦的，希腊线）
- **记忆钩**：法语「梦」的字面起点是「**游荡、胡言乱语**」——做梦就像神志「飘出去逛了一圈」；19c 才把 *songer* 挤出「睡梦」义

**英法交叉核对（受影响的英语词）**
- **借入英语**：**rave**（v. early 14c *raven*「在言语中发狂 / 谵妄」← 古法语 **raver**，*resver* 的变体）；**reverie**（n. mid-14c *reuerye*「狂放行为」← 古法 **reverie**；**1650s 再借**，得「白日梦 / 遐想」义）
- **同义异源**：英语「梦」用 **dream**（← 日耳曼）——与 rêve **无亲缘**
- **⚠️ 已校验的假关系**：英语 **reverberate 与 rêve 无关**（← 拉丁 *re-* + *verber*「鞭」）——**勿连**
- 核对：英语侧（rave early 14c ← 古法 raver；reverie mid-14c / 1650s）经检索转引 etymonline（2026-10-11）；法语侧 1674（名词）/ 约 1130（动词）与六说据 fr.wiktionary / TLFi / FEW / Gamillscheg / Diez 转引（**待验证**）

**同义 / 搭配 / 易混**
- 搭配：`faire un rêve`（做梦）｜ `un rêve éveillé`（白日梦）｜ `de rêve`（梦幻的）｜ `vendre du rêve`（画大饼）｜ `le rêve américain`（美国梦）｜ `un rêve brisé`（破碎的梦）
- **易混**：**rêve**（梦 / 梦想）vs **cauchemar**（噩梦）vs **songe**（书面「梦」——19c 后被 rêve 取代）vs **rêverie**（白日梦 / 遐想，与英语 reverie 同源）
- 相关：[[rêveur]]（待收）；[[triste]]（情感域）
