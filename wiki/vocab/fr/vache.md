# vache

**释义**：（1）**母牛、奶牛**（une vache 一头母牛；vache laitière 奶牛）；（2）**（俗，adj.）狠的、缺德的**（un coup vache 阴招；être vache avec qn 对某人刻薄）；（3）**vache à lait** ＝ 奶牛 / **摇钱树**（喻）；（4）**感叹 `La vache !`** ＝ 哇！好家伙！（表惊讶）；（5）**（旧）警察**（俗） ｜ femelle du taureau, bovine adulte ; (familier) méchant, dur

**例句**
- _Le fermier trait ses vaches._ 农夫给母牛挤奶。
- _La vache ! Je ne m'y attendais pas !_ 哇！我真没想到！
- _Ce client est une vraie vache à lait._ 这个客户真是棵摇钱树。

**形态要点**
- 名词：`la vache`（**f.**）；复数 **vaches**
- 形容词（**同形**）：`vache`（俗，阴阳同形）——un type vache（刻薄的家伙）
- **感叹用法**：`La vache !`（≈ 哇 / 天哪）——日常高频，**不是**「母牛」义
- 副词派生：**vachement**（俗，「非常」——*vachement bien* 非常棒）
- 同族 / 派生：**vacher / vachère**（牧牛人）、**vachette**（小母牛 / 牛皮）、**vacherie**（卑劣行径 / 苦差事）、**vachard**（难办的 / 坏心眼的）、**vacherin**（一种奶酪）、**vache à lait**

**词源 / 构词**
- **拆解**：拉丁 **vacca**「母牛」→ 古法语 **vache** → 现代 vache；与 **bœuf**（牛 / 牛肉）同出 **PIE \*gʷōus**（牛）——**无竞争假说**
- **演变 / 首见两说**：**fr.wiktionary** 记「**IXe s.**，du latin vacca」vs **TLFi / CNRTL** 记 **约 1130**（《Lois de Guillaume le Conquérant》，「bovine 的繁殖雌性」——Usito 引 TLFi）——**两说并列**（TLFi 更精确，本页取 1130 为主）
- **同族 / 派生（法语）**：vacher / vachère、vachette、vacherie、vachard、vachement、vacherin、picard / normand **vaque**
- **记忆钩**：vache 的拉丁 vacca 也是**牛痘疫苗 vaccine** 的远祖——Jenner 用 **牛痘**（vaccine ← vaccinus ← vacca「牛」）防天花，「疫苗」一词里藏着「母牛」

**英法交叉核对（受影响的英语词）**
- **借入英语（同词根）：** **vaccine**（adj. **1798**「牛的、牛痘的」← 拉丁 **vaccinus** / 法语 **vaccin**；n. **1846** ← 法语 *vaccin*——Jenner 1796 用牛痘 *vaccinia*）；**vaccination**（**1800**）；**vaccinate**（**1803**）；**vaccary**（牧牛场 ← 中世纪拉丁 vaccaria）——**皆出拉丁 vacca**（经拉丁或法语）
- **同义异源**：英语「牛」用 **cow**（← 日耳曼 **\*kū**）——与 vache **无亲缘**；**vache 本身未入英**
- **共祖未借入**：vaccine 与法语 vache **同出拉丁 vacca**，但英语 vaccine 走拉丁（vaccinus）/ 法语 vaccin，非直接借 vache
- 核对：英语侧（vaccine 1798 / vaccination 1800 / vaccinate 1803）经检索转引 etymonline（2026-10-11）；法语侧约 1130 与 vacca 链据 TLFi / CNRTL / Usito 转引（**待验证**）
- **教学点**：**英 vaccine ↔ 法 vache 同根（拉丁 vacca）**——「疫苗」的字面是「母牛的」

**同义 / 搭配 / 易混**
- 搭配：`vache laitière`（奶牛）｜ `vache à lait`（奶牛 / **摇钱树**）｜ `traire une vache`（挤牛奶）｜ `La vache !`（哇！）｜ `vachement bien`（非常棒）｜ `peau de vache`（狠心的人）
- **易混（牛家族）**：**vache**（母牛）vs **bœuf**（公牛 / 阉牛；亦指**牛肉**）vs **taureau**（**种公牛**）vs **veau**（小牛 / 小牛肉）vs **génisse**（小母牛）
- 相关：[[cochon]]（农场动物，同批）；[[ferme]] / [[campagne]]（农场 / 乡村域）
