# mystérieux

**释义**：（1）神秘的、谜一般的（un air mystérieux 神秘的神色；un personnage mystérieux 神秘人物）；（2）难以解释的、费解的（une disparition mystérieuse 神秘失踪） ｜ qui a un caractère secret, difficile à expliquer ; énigmatique

**例句**
- _Le roman commence par une disparition mystérieuse._ 小说以一桩神秘的失踪开场。（见 [[roman]]）
- _Elle a un air mystérieux._ 她神色神秘。
- _Il est resté mystérieux sur ses projets._ 他对自己的计划讳莫如深。（见 [[rester]]）

**形态要点**
- 形容词：阳性单数 **mystérieux** ｜ 阴性 **mystérieuse** ｜ 阳性复数 **mystérieux**（与单数同形）｜ 阴性复数 **mystérieuses**——即 -eux / -euse 型（同类：heureux、curieux、délicieux）；副词 mystérieusement
- 位置：一般后置（un air mystérieux、un lieu mystérieux）；文学修辞可前置（une mystérieuse inconnue 一位神秘女子）
- 搭配介词：être mystérieux **sur** qch（对……讳莫如深——Il reste mystérieux sur ce point）
- 名词化：**le mystérieux**（神秘之处、神秘感——1803 起〔CNRTL，2026-10-03 经检索转引〕）

**词源 / 构词**
- **拆解**：**mystère**（n.m. 秘密、秘仪）+ 形容词后缀 **-eux**；mystère ← 拉丁 **mysterium**「秘密祭仪、秘密」← 希腊 **mystērion**（μυστήριον）← **mystēs**（μύστης）「（厄琉西斯密仪的）入教者」← **myein**（μύειν）「闭上（眼、口）」——密仪以闭眼封口得名〔2026-10-03 经检索转引〕
- **演变**：拉丁 mysterium → 古法语 mistere → 法语 mystère；形容词 mystérieux **首证约 1475 之前**（Chastellain——「神秘、隐晦的一面」义）；1552 Rabelais「难以解释」义、1657–62 Pascal「小题大做之人」义、1675 Bossuet「宗教秘仪」义、1680 名词化、1803「神秘性」名词义〔CNRTL，经检索转引〕；Académie 9e 记 15 世纪
- **同族 / 派生（法语）**：mystère（秘密；中世纪「神秘剧」）、mystérieusement、**mystique / mysticisme**（神秘主义——经拉丁 mysticus ← 希腊 mystikos，同出 mystēs 一族）、mystification；英语一侧见下节
- **记忆钩**：mystēs「入教者」——密仪要闭眼（myein）封口，只有入教者才配知道；「神秘」＝「进了密仪的人才知道的事」

**英法交叉核对（受影响的英语词）**
- **借入英语**：**mysterious**——**两说并列，不折中**：① Oxford（OALD）记 **16 世纪后期 ← 法语 mystérieux**（Webster's / Wiktionary 亦记 partly Middle French mystérieux，另与拉丁线合流）；② **etymonline 记 1610s ← 拉丁 mysterium + -ous**（不经法语）
- **借入英语（名词线）**：**mystery**（n.1）**early 14c** ← 盎格鲁-法语 \***misterie** / 古法语 **mistere** ← 拉丁 **mysterium** ← 希腊 mystērion（首义为神学「藉启示而知的真理」；世俗「谜、秘密」义 late 14c；**「侦探小说」义 1908**）〔etymonline，2026-10-03 直连〕
- **共祖未借入**：**mystic / mystical**（← 拉丁 **mysticus** ← 希腊 **mystikos** ← mystēs——直承古典线，非经法语；年代未逐核）；另英语 mystery「手艺、行会」义**同形异源**——中世纪拉丁 misterium ← 拉丁 **ministerium**（ministry 一族），与 mystery 1 在中世纪拼写混同（都铎戏剧常见双关）〔etymonline，经检索转引〕
- 核对：2026-10-03——法语侧 mystérieux 首证 before 1475（Chastellain）与诸义项年代（1552 / 1657-62 / 1675 / 1680 / 1803）据 CNRTL（经检索转引）；英语侧 mystery early 14c、mysterious 1610s 据 etymonline（直连）；「mysterious ← mystérieux」说据 OALD / Webster's / Wiktionary（经检索转引）。**提示原记「17c 借入」经检索修正**：法语 mystérieux 是 15c 词，17c 只对应 Pascal / Bossuet 的具体义项

**同义 / 搭配 / 易混**
- 搭配：`un air mystérieux`（神秘的神色）；`un personnage mystérieux`（神秘人物——见 [[personnage]]）；`une affaire / une disparition mystérieuse`（神秘事件/失踪）；`être mystérieux sur qch`；`le mystérieux de l'affaire`（事件的神秘之处）
- 近义：mystérieux（神秘）｜ **énigmatique**（谜一般的——更书面）｜ secret（秘密的）｜ étrange（奇怪的）｜ obscur（晦涩的）
- **易混**：**mystérieux**（形容词）vs **mystère**（名词——le mystère reste entier 谜团未解）vs **mystique**（神秘主义的——宗教体验色彩）；**faux ami**：英 **mystic** 对应法语 **mystique**，不对 mystérieux——英语 mysterious 才是 mystérieux 的对应面
- 叙事语境：侦探小说与悬疑故事（[[roman-policier]]、[[detective]]、[[histoire]]）里，un personnage mystérieux 与 une disparition mystérieuse 是常见开场零件
