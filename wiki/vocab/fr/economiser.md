# économiser

**释义**：（1）**节省、节约**——不浪费地使用（économiser l'eau / l'électricité 省水／省电；économiser son argent 省钱）；（2）**积攒、储蓄**（économiser pour acheter une maison 攒钱买房）；（3）**（抽象地）节省、保留**（économiser ses forces 保存体力；économiser ses paroles 少说话）；（4）古义：「**勤俭持家、管理得当**」（1718 年初义） ｜ épargner, faire des économies, ménager ; (vieilli) administrer avec économie

**例句**
- _Il faut économiser l'eau en été._ 夏天要节约用水。
- _Elle économise depuis deux ans pour voyager._ 她为旅行攒了两年钱。
- _Économise tes forces, la course est longue._ 省点力气，路还长。
- _Nous économisons sur tout sauf sur la nourriture._ 除了吃饭，我们什么都省。

**形态要点**
- 动词（v.）：不定式 **économiser** ｜ 组别：**1er groupe** ｜ 助动词：**avoir** ｜ 过去分词：**économisé**
  现在时：j'économise ｜ tu économises ｜ il·elle économise ｜ nous économisons ｜ vous économisez ｜ ils·elles économisent
- 完全规则，**无拼写变化**（-iser 型；非 -ger / -cer / -ayer）；**代词式 s'économiser**（爱惜自己、省着点用力）
- 拼写注意：开头 **é-**（闭音符）＋ **-iser**（不是 -izer——法语一律 **-iser**，英语多作 **-ize**）；同型：**réaliser, organiser, moderniser, utiliser**（皆 -iser）
- 名词化亲属：**l'économie**（经济；节省）、**les économies**（积蓄）、**l'économiseur**（节省装置）、**économique**（经济的）、**économe**（节约的；管家）

**词源 / 构词**
- **拆解**：**économie**（名词）+ 后缀 **-iser**（fr.wiktionary 原文：「Dérivé de économie, avec le suffixe -iser」；TLFi：「Dér. du rad. de économie ; dés. -er」）
- **économie 之词源**：拉丁 **oeconomia** ← 希腊 **οἰκονομία** oikonomia「持家之道、家务管理」＝ **oikos**「家、住所」+ **nomos**「管理、法则、分配」（同出英语 **economy / ecology / astronomy** 的 **-nomy**）
- **演变（CNRTL/TLFi，2026-10-05 经 WebSearch 转引；CNRTL 直连失败）**：
  - **1718** 首证——形式 **œconomiser**，义「administrer, gérer avec économie」（Académie française, s.v. *œconomiser*，为 TLFi 所引的最早书证）
  - **1747**：义「faire des épargnes sur la dépense, la consommation」（Graffigny, *Lettres péruviennes*，据 Littré 转引）——**「省钱」义自此确立**
  - **1759**：*au propre* 用法（Rich.）
  - **正字**：Académie 1718 作 **œconomiser**；1740 至 1932 各版改作 **économiser**（fr.wiktionary 记此演变）
  - Académie 9e 定年「**xviiie siècle**」，形式 œconomiser「administrer avec économie」；Usito 亦记 **1718**（économie + -iser）
- **同族 / 派生（法语）**：**économie**（经济；节约）、**les économies**（积蓄）、**économique**（经济的）、**économe / économe**（节约的；n. 管家）、**l'économat**（总务处）、**l'économiste**（经济学家）、**l'économétrie**
- **记忆钩**：économie 的底义是「**持家**」（oikos 家 + nomos 法则）——「经济」原本就是「把家管好」；économiser 即「按持家之道来用」

**英法交叉核对（受影响的英语词）**
- **共祖／平行造词（希腊 oikonomia 线）**：**`economy`**（n.，**1530s**「持家管理」← 拉丁 **oeconomia** ← 希腊 **oikonomia**；「节俭」义 **1660s**）、**`economic` / `economical`**、**`economist`**、**`ecology`**（oikos + logos）——皆与法语 **économie** **同出希腊 oikonomia**
- **`economize`（关键辨析——非借自法语）**：英语 **`economize`**（v.）**1640s** 首证，义「to govern a household」（持家），**由 economy + -ize 自行构成**；「省钱、节约」义 **1790**。etymonline **未**列法语 économiser 为其来源，也**未**给出「英 ← 法」的借入路径；后缀 **-ize** 系中古英语经**古法语 -iser/-izer** 与晚期拉丁 **-izare** 借自希腊 **-izein**——**即：后缀本身经法语入英，但动词整体是英语自造**
- **方向核实（本条为 prompt 焦点）**：
  - **法语 économiser** ＝ **économie + -iser** 的**法语内部派生**（1718，œconomiser）——诸源（fr.wiktionary、TLFi、Académie 9e、Usito）**一致**如此，**无**「借自英语」之说
  - **英语 economize** ＝ **economy + -ize** 的**英语内部派生**（1640s）——etymonline **无**「借自法语」之说
  - **时间序**：英语 economize（**1640s**）**早于**法语 économiser（**1718**）约七十年——**若言影响，方向只能是 英 → 法**，且**未见文献如此主张**；再者，法语「省钱」义（**1747**）反**早于**英语对应义（**1790**）
  - **结论**：prompt 提出的「19c. 英 → 法回流」**未见任何来源支持**（且年代不符）——**两语为平行自造的同源对**（同出希腊 oikonomia），**不构成借入关系**；本条**待验证**，若另见「英 → 法」之文献，须与本条并列记录（依「矛盾显式记录」硬规）
- **同源动词对照（罗曼／日耳曼）**：义语 **economizzare**、西语 **economizar** —— 与法语 économiser 同型（皆「économie/economia + -iser/-izar」），可作「平行自造」的横向佐证
- 核对：英语侧（economy 1530s ← Latin oeconomia ← Greek oikonomia＝oikos + nomos；economize 1640s ← economy + -ize，financial sense 1790；-ize ← Greek -izein via Latin -izare / Old French -iser）2026-10-05 **etymonline 直读**；法语侧（1718 œconomiser 义「administrer avec économie」、1747 义「faire des épargnes」、1759 propre、1740-1932 正字 économiser、Académie 9e「xviiie siècle」、Usito 1718）2026-10-05 经 **WebSearch 转引 CNRTL/TLFi、Académie 9e 与 Usito**。
- 命名提示：英语 `economize` / `economy` 页尚未建；日后建页因词形不同，无须 `-en` 后缀

**同义 / 搭配 / 易混**
- 搭配：`économiser qch`（节约某物：économiser l'eau / l'énergie / son argent）｜ `économiser sur qch`（在某项上省钱：économiser sur le chauffage）｜ `économiser pour + inf.`（攒钱为了……）｜ `économiser ses forces`（保存体力）｜ `faire des économies`（攒钱、省下）｜ `une économie de`（省下的一笔）
- **介词要点**：**économiser qch**（直接及物，省某物）；**économiser sur qch**（在……上节省；**sur** 引出节约的领域）；**faire des économies sur / de**（在……上省钱）
- 辨析：**économiser**（节省、积攒——**动词**）｜ **épargner**（省下、储蓄；亦「宽恕、饶过」——épargner qqn）｜ **ménager**（爱惜、慎用：ménager ses forces）｜ **faire des économies**（名词式，口语最常）｜ **se priver**（克扣自己）｜ 反义 **dépenser**（花）、**gaspiller**（浪费）
- 易混：**économe**（节约的 adj.；n. 管家／总务）↔ **économie**（经济；节约，n.f.）↔ **économique**（经济的 adj.）——**三词形近，词性各异**
