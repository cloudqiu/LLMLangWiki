# connaître

> 收录说明：inbox 里的遇到形式是 **connais**（je / tu 的现在时）——按 lemma 规则归并至不定式 **connaître**。

**释义**：认识、了解（人、地、事物——凭经验熟悉）；体验、经历（connaître le succès 尝到成功）；se connaître 认识自己 / 彼此 ｜ avoir une connaissance de ; être en relation avec

**例句**
- _Je connais bien cette ville._ 我很熟悉这座城市。
- _Tu connais Paul ?_ 你认识保罗吗？
- _Elle a connu de grandes difficultés._ 她经历过很大的困难。

**形态要点**
- 动词：不定式 **connaître** ｜ **3e groupe** ｜ 助动词 **avoir** ｜ 过去分词 **connu**
- 现在时六形：je **connais** ｜ tu **connais** ｜ il·elle **connaît** ｜ nous **connaissons** ｜ vous **connaissez** ｜ ils·elles **connaissent**
- 变位提示：词干 connai-（单数 / 第三人称）与 connaiss-（nous / vous / 第三人称复数）；**il connaît 的 î 源自历史 -s-**（古法语 conoist，同类 maître / naître / paraître）；1990 拼写改革允许 **connaitre**（无 accent），教材多仍用 connaître；同类 -aître 动词：paraître（出现）、apparaître、disparaître、reconnaître

**词源 / 构词**
- **拆解**：拉丁 **cognoscere** ＝ con-「共同」+ **gnoscere / noscere**「知道」（PIE \*gneh₃-「认识」）——「共同地知道」→「认识、识别」
- **演变**：PIE \*gneh₃-「知道」→ 拉丁 noscere / gnoscere → cognoscere → 古法语 conoistre → 现代 connaître（长音符 î 记录消失的 -s-，同 maître / naître；已核：古法语 conoistre 最早见 ca 1050〔Vie de Saint Alexis〕、「经历」义 ca 1175〔Chrétien de Troyes〕——据 CNRTL/TLFi，2026-10-01 经检索转引）
- **同族 / 派生**：reconnaître（认出、承认）、méconnaître（不认识、低估）、connaissance（知识、认识）、connaisseur（行家、鉴赏家）、connu（著名——过去分词作形容词）、inconnu（未知的、陌生人）；英语一侧见下节
- **记忆钩**：connaître ＝ con + gnoscere「一起知道」——认识一个人就是「共同知道」；英语 **know** 与其同源（PIE \*gneh₃-），k-n 与 g-n 是同一条「知道」根

**英法交叉核对（受影响的英语词）**
- **借入英语**：**connoisseur**（1714，← 法语 connaisseur「行家、鉴赏家」← connaître；拼写 connois- 保留古法语 oi，是借入年代的古音遗迹）；**reconnoiter / reconnoitre**（18c.，← 法语 reconnoître 的旧形，＝ 现代 reconnaître；美式拼写 reconnoiter）；**cognizance**（← 盎格鲁-法语 conissance ← 拉丁 cognoscere——经法语中介）
- **共祖未借入**：**know / ken / can / cunning**（英语本族日耳曼词，同出 PIE \*gneh₃-——与 connaître 是「印欧共祖」而非借入，又一最佳对比例）；**recognize / cognition / notice / notion / noble / ignore**（均来自拉丁 cognoscere / noscere 家族——已核〔etymonline，2026-10-01 经检索转引〕：recognize ← 古法语 recognoistre；cognition ← 拉丁直借（mid-15c.）；notice ← 古法语 notece / 拉丁 notitia（早 15c.）；notion ← 拉丁直借（晚 14c.，Cicero 造译）；noble ← 意大利语 nobile / 古法语 noble；ignore 入英路径未见明确数据，**仍标待验证**）
- 核对：已核实（2026-10-01 经检索转引）——connoisseur 1714（etymonline，首见于 Mandeville）；cognizance mid-14c，← 盎格鲁-法语 conysance（etymonline）；recognize / notice / notion / noble 诸路径见上；reconnoiter 借入年代（页内作 18c.）与 ignore 入英路径未获明确数据，**仍标待验证**。

**同义 / 搭配 / 易混**
- 搭配：`connaître qn / qch`（认识——直接宾语，**不用介词**）；`connaître le succès / des difficultés`（经历）；`faire la connaissance de qn`（结识）；`se connaître`（互相认识）
- **核心易混——connaître vs savoir**：**connaître** 认识（人 / 地 / 事物，凭经验熟悉，+ 名词）｜ **savoir** 知道（事实、做法，+ 从句 / 不定式：je sais qu'il vient、je sais nager）；「会不会说某语言」用 **savoir**（savoir parler français），「了解某文化/某地」用 **connaître**（connaître la France）
- 再易混：**reconnaître**（认出 / 承认）、**méconnaître**（不认、低估）；**connaissance**（知识 / 认识）vs **connaissances**（人脉——les connaissances）
