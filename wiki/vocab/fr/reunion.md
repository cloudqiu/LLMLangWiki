# réunion

**释义**：n.f. ①**重聚、合并**——分开之物重新聚合 ②（喻）**和解、和好** ③（封地等）归并 ④**聚集、汇集**（及结果）⑤**集会**——人群的聚集 ⑥**会议**——为议事而聚集（审议或协商）⑦（数学）**并集** ⑧（赛马）一日同场赛马会 ⑨（田径）一日同场多项赛事 ｜ fait de réunir, de se réunir ; assemblée de personnes pour délibérer

**例句**
- _Je suis en réunion, je te rappelle plus tard._ 我在开会，待会儿给你回电话。
- _La réunion de travail a duré deux heures._ 工作会议开了两个小时。
- _La réunion de famille aura lieu dimanche._ 家庭聚会定在周日。

**形态要点**
- 名词：`la réunion`（**f.**）；复数 **réunions**（规则）
- 构词提示：由 **réunir** 派生或 **re- + union**；搭配介词视义而定——**réunion de** travail / famille（内容）、**en réunion**（开会中，＝ in a meeting）、participer **à** une réunion

**词源 / 构词**
- 拆解：**re-**（拉丁前缀「再、重新」）+ **union**（← 拉丁 **unio, unionis**「一、结合」← **unus**「一」）。或直接视为 **réunir** 的派生名词
- 演变：拉丁 *unus* → *unio* → 中古法语 *reunion*（XVe s.）→ 现代 *réunion*
- 首证（**并列**）：**CNRTL 记 1468**「entente, réconciliation（和解）」，**1611**「ligne, association」(Cotgrave)；fr.wiktionary 记 **XVe siècle**（中古法语）；Académie 9e 记 **15 世纪**，本义「réconciliation, entente」——三源一致指向 **15 世纪**，具体年 1468（CNRTL）
- 同族 / 派生：**réunir**、**réunionite**（贬：开会成瘾）、**réunionnais**（留尼汪的——专名 *La Réunion* 同形）
- 记忆钩：**re-（再）+ union（成一）**——把人「再凑成一堆」就是开会；Note 专名 **La Réunion**（留尼汪岛）即「（多物）汇合之岛」

**英法交叉核对（受影响的英语词）**
- **借入（英 ← 法，但两说并列）**：英语 **reunion**（n.，**c. 1600**）「act of coming together again」——etymonline 称**或来自英语自身构词 re- + union**，**或来自法语 réunion（1540s）**——**两说并列不折中**；「旧友重聚」义 **1820**；Collins 给 **1600–10**
- **共祖**：英语 **union** ← 古法语 *union* ← 拉丁 *unio*（**union 本身就是法语借入英语**）；unity / unique / unite 同源
- **专名**：**La Réunion**（留尼汪岛）亦入英语作 *Réunion*
- **核对要点**：法语 *réunion* 早于英语 *reunion*——若英语系自造，则是**两语平行构词**；若系借入，则方向为法 → 英——**未定论**

**同义 / 搭配 / 易混**
- 同义：assemblée、rencontre、rassemblement、séance、conclave；(anglicisme) **meeting**
- 搭配：**réunion de travail**（工作会议）/ **de famille**（家庭聚会）/ **de crise**（紧急会议）/ **parents-professeurs**（家长会）；**tenir / assister à / organiser une réunion**；**en réunion**（开会中）
- 易混：**réunion**（会议）vs **rencontre**（会面）vs **rendez-vous**（约见）vs **manifestation**（游行）
- **faux ami（重点）**：法语 *réunion* = **任何会议**（含工作例会）；英语 *reunion* 特指「**旧人重逢**」——故英语 **"a work reunion" 是误用**，应说 *meeting*
