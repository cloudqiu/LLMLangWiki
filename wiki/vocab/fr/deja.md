# déjà

**释义**：已经；（疑问句）曾经、已经（as-tu déjà vu…?）；(惊叹/催促) 都……了（déjà !） ｜ avant le moment présent ; (interrogatif) jamais auparavant

**例句**
- _J'ai déjà mangé._ 我已经吃过了。
- _Tu es déjà allé à Paris ?_ 你已经去过巴黎吗？
- _Il est déjà midi._ 已经中午了。

**形态要点**
- 副词：**无变化**；位置在变位动词后、复合时态的助动词后（j'ai **déjà** mangé）；疑问中表「曾经」（as-tu déjà…?）

**词源 / 构词**
- **拆解**：古法语 des ja ＝ **des**（dès「从……起」）＋ **ja**「已经」（← 拉丁 **jam**「已经」）——「从（那时）就已经」
- **演变**：拉丁 jam「已经」→ 古法语 ja（11 世纪已见）→ des ja（ca 1275 首见，J. de Meun《玫瑰传奇》「自现在起」；1465 见 desja，Commynes）→ 凝固为 **déjà**（据 CNRTL，2026-10-01 经检索转引）；同根的 **jamais**（jam + mais「更多的已经」→ 本义「任何时候、永不」）与 déjà 一正一反
- **同族 / 派生**：jamais（永不——同根反义！）、déjà-vu（似曾相识）；英语一侧见下节
- **记忆钩**：déjà 与 jamais 同出一家（拉丁 jam「已经」）——一个「已经」、一个「（从）不」，看似反义实为同根

**英法交叉核对（受影响的英语词）**
- **借入英语**：**déjà vu**（「似曾相识」，1903，← 法语 déjà vu「已经见过」——心理学名词 + 日常语，本词的正主借入，拼写原样保留重音）；**déjà entendu / déjà lu**（少见，同理「已经听过/读过」）
- **共祖未借入**：无显著——拉丁 jam「已经」无英语后代；英语 already / yet 为日耳曼词，与 déjà 无同源关系
- 核对（2026-10-01 经检索转引）：英语 déjà vu 1903 见载（etymonline；OED 亦引 1903 之说）——已核实；法语侧术语更早用例（Boirac 1876 等）仅见转述，**待验证**

**同义 / 搭配 / 易混**
- 搭配：`déjà + 过去分词`（j'ai déjà vu）；`as-tu déjà…?`（你曾……吗）；`c'est déjà ça`（总算有点收获，习语）；`déjà vu`（似曾相识）
- **核心易混——déjà vs encore**：**déjà** 已经（肯定）｜ **encore** 还、仍然——否定用 **pas encore**（还没有：je n'ai pas **encore** mangé 我还没吃）；déjà 与 encore 在「时间位置」上互为参照
- 再易混：**jamais**（永不——déjà 同根反义）；**ne…jamais**（从不）
- **faux ami**：déjà vu 英语保留法语原形（保留重音拼写 déjà vu），但 déjà 本身不单独借入英语
