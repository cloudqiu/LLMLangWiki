# c'est pour ça que

> 收录说明：inbox 形式 `c'est pour ca que`——按 v1.5 多词单位约定独立建页（凝固的口语连接短语）；`ca` 补软音符为 **ça**（见 [[ca]]）；词条内 que 在元音前省作 **qu'**。与同批 [[vu-que]]（引原因）互为镜像：此短语引结果。

**释义**：所以、因此；这就是……的原因（引出结果或结论） ｜ c'est la raison pour laquelle ; voilà pourquoi

**例句**
- _Il pleut, c'est pour ça que je reste à la maison._ 下雨了，所以我就待在家里。
- _C'est pour ça que je t'appelle._ 这就是我给你打电话的原因。
- _Elle est malade, c'est pour ça qu'elle n'est pas venue._ 她病了，所以没来。（注意 qu' 省音）

**形态要点**
- **拆解**：c'est（「这是」＝ ce + est）+ pour（为了）+ ça（这个）+ que（从属连接词）——把前句的原因装进 ça，再引出结果
- **省音**：que 在元音开头词前一律省作 **qu'**——c'est pour ça **qu'**on…、**qu'**elle…（\*que on 不合语法）
- **后接从句用陈述式**：前句给原因、本短语引出结果（_Il pleut, c'est pour ça que…_）；方向与 [[vu-que]]（引原因）相反，二者成对
- **语域**：ça 是 cela 的口语形式——整个短语属**口语/日常**层；书面写作 c'est pour cela que 或 c'est pourquoi（见下节）
- 独立用法：— Pourquoi tu ne viens pas ? — C'est pour ça !（口语，指前文原因）

**词源 / 构词**
- **拆解**：成分词各有来源——c'est ＝ ce（← 拉丁 **ecce + hoc**）+ est（être ← 拉丁 **esse**，见 [[etre]]）；**pour** ← 拉丁 **pro**「为了、在……之前」；**ça** ← **cela**（← ce，见 [[ca]]）；**que** ← 拉丁 **quod / quam**（从属连接词）
- 演变：本短语无独立词源史——是现代法语口语中凝固起来的功能短语（ça 的代词用法 17 世纪起通行，见 [[ca]] 核对说明）；书面凝固形 c'est pourquoi 与之平行
- **同族 / 派生**：书面 **c'est pour cela que**；正式同义 **c'est pourquoi**、**voilà pourquoi**；展开式 **c'est la raison pour laquelle**、**c'est pour cette raison que**（soutenu）
- **记忆钩**：ça ＝「这个」——« c'est pour ça que » 字面「这是为了这个（才）……」，前句的原因就是「这个」

**英法交叉核对（受影响的英语词）**
- **借入英语**：无——整个结构未进入英语；英语对应手段 **that's why / this is why** 系本族要素自构（that + is + why），与本短语无形式关联
- **共祖未借入**：成分词 pour ← 拉丁 pro 与英语 for（本族 ← 古英语 for）、pro-（拉丁借层）三线并行，无借入关系；que ← 拉丁 quod 与英语 that（本族）义近而源异
- 核对：语域与同义式（c'est pour ça que 为口语最常用；c'est pourquoi / voilà pourquoi 偏正式书面；\*c'est pourquoi que 不合语法）据 WebSearch 转引的辨析讨论与词典（Hinative / Reverso，2026-10-03 经检索转引）；\*未借入英语 \*为否定性结论，无年代可核。

**同义 / 搭配 / 易混**
- 同义（语域递升）：`c'est pour ça que`（口语）→ `c'est pour cela que`（中性/书面）→ `c'est pourquoi`（正式/书面）→ `c'est la raison pour laquelle`（soutenu）；`voilà pourquoi`（正式，多用于收束总结）
- **易混（推理/因果簇，本批重点）**：**c'est pour ça que**（引**结果**——口语）｜ [[vu-que]]（引**原因**——「既然/由于」）｜ [[donc]]（连接副词「因此」——可插句中：je pense, donc je suis）
- **病句警示**：\*c'est pourquoi que 不合语法——c'est pourquoi 与 c'est pour ça que 两式选一，不叠加
- **拼写 faux ami**：ça ≠ sa（同音）——\*c'est pour sa que 不合语法（见 [[ca]]）
- 与 c'est / il y a 的分工（指认 vs 存在）见 [[il-y-a]]
