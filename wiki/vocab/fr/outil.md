# outil

**释义**：n.m. ①**工具、器具**——工匠、园丁等在工作中使用者 ②（引申）**（从事某行动的）手段、工具** ③（动物学）一种白鲑（*corégone oxyrhynque*）④（俗）**笨手笨脚的人** ｜ objet fabriqué qui sert à faire un travail ; (fig.) moyen d'action

**例句**
- _Range tes outils dans la boîte à outils._ 把你的工具收进工具箱。
- _L'ordinateur est un outil de travail indispensable._ 电脑是不可或缺的工作工具。
- _Il est devenu un outil entre les mains du pouvoir._ 他成了当权者手中的工具。

**形态要点**
- 名词：`l'outil`（**m.**）；复数 **outils**（规则）
- 复合：**boîte à outils**（工具箱）、**machine-outil**（机床，复数 *machines-outils*）、**outil numérique**（数字工具）

**词源 / 构词**
- 拆解：**ūt- / ūs-**（拉丁词根「使用」）+ **-il(ia)**。← 中古法语 *outil* ← 古法语 **ustilz**「装备、旅行所需之物」（début XIIe s.）← 低拉丁重建 **\*usitilia**，是拉丁 **utensilia**「必需之物、家具、用具」（← *ūtensilis* ← **ūti**「使用」）的变体，**受 ūsāre「使用」影响而产生 /s/**
- **注意（fr.wiktionary 照录）**：*« l'évolution phonétique du mot pose encore quelques problèmes »*——**outil 的语音演变仍有争议**
- 首证：fr.wiktionary 记 **début XIIe s.** 古法语 *ustilz*「装备」；**1174**「objet fabriqué qui sert à faire un travail」；**XIIIe s.**「membre viril」；**1272**「moyen d'action」。（CNRTL 存 *outil* 词源专页，但**正文未能取到**→ CNRTL 详版**待验证**）
- 同族 / 派生：**ustensile**（家用器具 / 餐具——**同出拉丁 utensilia 的现代法语形**）、**outillage**（成套工具、装备）、**outiller**（配备工具）、**outillé**（装备好的）
- 记忆钩：**outil 与英语 use 同根**（都来自拉丁 *ūti*「使用」）——「工具」就是「用来**使**的东西」

**英法交叉核对（受影响的英语词）**
- **借入（英 ← 法）**：英语 **utensil**（n.，**late 14c.**）「家用物品、器皿」← **古法语 utensile**（14c.）← 拉丁 *utensilia*——注意：**英语 utensil 借自古法语 *utensile***，而**现代法语形为 ustensile**；故英语 *utensil* 与法语 **ustensile** 才是直接借入对，法语 **outil** 是拉丁 \*usitilia 的**另一支**
- **共祖（非借入）**：英语 **use / useful / usury / utilize** 与法语 outil / user / ustensile 都回到拉丁 **ūti**「使用」→ **outil 与英语 use 是共祖**（同拉丁词根 ūt-），**非借入**
- **反向借入**：无
- **核对要点**：两个现代词 **outil** / **ustensile** 在法语里分工——outil 泛指**工具**（手工 / 抽象手段），ustensile 指**家用器具 / 餐具**；英语只借走了后者的词形，义域却仍是「器皿」

**同义 / 搭配 / 易混**
- 同义：instrument、ustensile、engin、appareil、dispositif；(fig.) moyen、instrument、levier
- 搭配：**outils de travail**（工具）；**boîte à outils**（工具箱）；**machine-outil**（机床）；**être un outil entre les mains de qqn**（成为他人手中的工具）；**outil numérique**（数字工具）
- 易混（Académie 有专文《Utile, outil, ustensile》辨析）：**outil**（工具——含抽象手段）vs **ustensile**（餐具 / 家用器具）vs **instrument**（精密仪器 / 乐器 / 手段）vs **engin**（机械装置）
