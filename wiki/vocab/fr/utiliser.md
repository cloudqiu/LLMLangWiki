# utiliser

**释义**：（1）**使用、利用（工具、方法）**（utiliser un outil 使用一件工具；utiliser un ordinateur 用电脑）；（2）**利用（某人 / 某事）**（utiliser qn 利用某人）；**s'utiliser**（被使用） ｜ employer, se servir de ; exploiter

**例句**
- _J'utilise souvent ce dictionnaire._ 我常用这本词典。
- _Il a utilisé tous les moyens possibles._ 他用尽了一切可能的手段。
- _Ce mot ne s'utilise plus._ 这个词已不再使用。

**形态要点**
- 动词：不定式 **utiliser** ｜ **1er groupe**（规则，**-iser 型**）｜ 助动词 **avoir** ｜ 过去分词 **utilisé**
- 现在时六形：**j'utilise** ｜ tu utilises ｜ il·elle utilise ｜ nous utilisons ｜ vous utilisez ｜ ils·elles utilisent
- 代动词：**s'utiliser**（被使用——*ce mot s'utilise*）
- 同族 / 派生：**utile**（有用的）、**utilisation**（使用）、**utilisable**（可用的）、**utilisateur / utilisatrice**（使用者 / 用户）；**outil**（工具——同出拉丁 *uti* 一族）
- 介词：**utiliser qch**（直接宾语）——区别于 **se servir **de** qch**、**user de qch**（**须 de**）

**词源 / 构词**
- **拆解**：拉丁 **utilis**「有用的」（← **uti**「使用」）→ 法语 **utile** + 后缀 **-iser**
- **演变 / 首见**：**1792**（TLFi：Necker，《Pouvoir exécutif》t.8 p.474，引 Brunot t.10 p.44——**citation indirecte / 转引**）；**1802 遭指摘 / 一度被禁**；义「employer」**1949**
- **词源两说（并列）**：①**TLFi**：法语**内部派生** utile + -iser；②**etymonline / AHD**：法语 **utiliser ← 意大利语 utilizzare ← utile ← 拉丁 utilis ← 拉丁 ūtī**（拉丁 ūtī 来源不明）——**两说并列**
- **同族 / 派生（法语）**：utile、utilisation、utilisable、utilisateur；同根异支：**outil**（工具，← 低拉丁 \*usitilia 一线，见 [[outil]]）
- **记忆钩**：utiliser ＝ **utile + -iser**（「使有用」→「拿来用」）——同一拉丁 uti「用」在法语里还长出 outil（工具）

**英法交叉核对（受影响的英语词）**
- **借入英语（法 → 英回流）**：**utilize**（v. **1794**，etymonline ← **法语 utiliser**）——**反向借入 fr → en**；另有 1800-10 / 1807 诸说——**年代两说**
- **借入（同根另支）**：**use**（v. c.1200 ← 古法 **user** ← 俗拉丁 \*usare ← 拉丁 **ūtī**）——与 utiliser **同出拉丁 ūtī**，但英语 use 借的是另一支 user
- **共祖未借入**：**utilize / use** 与法语 utiliser / usage **同出拉丁 ūtī**——祖源相同
- **同义异源**：英语「用」核心词 **use** 已如上述；无纯日耳曼对例
- 核对：英语侧（utilize 1794 ← 法语 utiliser；use c.1200 ← 古法 user）经检索转引 etymonline（2026-10-11）；法语侧 1792（引 Brunot）与 utile + -iser 链据 TLFi / Brunot 转引（**待验证**）
- **教学点**：**英语 utilize ← 法语 utiliser**——法语**造词**再输出英语（拉丁 ūtī 一族的现代一环）

**同义 / 搭配 / 易混**
- 搭配：`utiliser qch`（用某物）｜ `utiliser qn`（利用某人）｜ `s'utiliser`（被使用）｜ `bien / mal utiliser qch`（善用 / 误用）
- **易混**：**utiliser qch**（直接宾语）vs **se servir **de** qch**（用——**须 de**）vs **employer qch**（使用 / 雇用——较正式）vs **user de qch**（行使 / 使用——书面，须 de）；**utiliser** vs **[[user]]**（待收）
- faux ami：英语 **utilize** 偏「（加以）利用 / 使有用」（略正式、常含「本可用别的」意味），法语 utiliser 更**中性、日常**——语义温度不同
- 相关：[[outil]]（同根异支——工具）；[[usine]] / [[usage]]（ūti 族，待收）
