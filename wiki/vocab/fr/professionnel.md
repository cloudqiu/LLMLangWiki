# professionnel

**释义**：adj. ①**职业的、与职业 / 行业相关的**（*cursus professionnel*, *vie professionnelle*）②**职业培训的**（*enseignement professionnel*, *école professionnelle*）｜ n.m. **以某行业 / 技艺 / 运动为职业者**（*professionnel de santé* 医护专业人员） ｜ relatif à la profession ; personne qui exerce un métier, par opposition à l'amateur

**例句**
- _Elle est une professionnelle de la santé._ 她是一名医护专业人员。
- _Il souffre d'une maladie professionnelle._ 他得了职业病。
- _Ce joueur est passé professionnel à dix-huit ans._ 这名球员十八岁转为职业选手。

**形态要点**
- 形容词：阳性 **professionnel** ｜ 阴性 **professionnelle** ｜ 阳性复数 **professionnels** ｜ 阴性复数 **professionnelles**
- 名词：**n.m.** *un professionnel*，复数 *professionnels*；阴性用 *professionnelle*；非二元写法 *professionnel·le*
- 反义：**amateur**；同义（名）：**pro**（口语）

**词源 / 构词**
- 拆解：**profession** + 形容词后缀 **-el / -al**。**profession** ← 古法语 *profession*（12c.）← 拉丁 **professio, -onis**「公开声明」← **profiteri**「公开宣称」（过去分词 *professus*）= **pro-**「向前 / 公开」+ **fateri**「承认」
- 演变：拉丁 *professio* → 古法语 *profession* → *professionnel*。**关键（CNRTL）**：法语 *professionnel* **很可能是仿英语 professional 构成**（见下）
- 首证：**CNRTL 记 1842** 形容词「qui se rapporte à… la profession」(Reybaud, *J. Paturot*, p. 417)；**1872** 名词（体育，参照英国）(Pearson, *Dict. du Sport fr.*)；**1876** *les professionnels*；**1885** *beautés professionnelles*。fr.wiktionary 仅注「Dérivé de profession, avec le suffixe -el」，**无年代**
- 同族 / 派生：**profession**、**professionnalisme**（专业精神）、**professionnaliser**、**déprofessionnaliser**、**interprofessionnel**
- 记忆钩：**profession（公开宣称的行当）+ -el**——「把某一行当**公开声明**为生」的人，就是 professionnel

**英法交叉核对（受影响的英语词）**
- **反向借入（法 ← 英）候选（重点）**：**CNRTL 明言法语 professionnel 很可能是仿英语 professional 而造**——若成立，则方向为**英 → 法**（尽管词根 professio 是拉丁、profession 是法入英）。本库须与「英语回借簇」（[[french-vocabulary]] 候选）合观
- **借入（英 ← 法）**：英语 **profession**（n.，**c. 1200**）← 古法语 *profession*（12c.）← 拉丁 *professio*
- **回环**：德语 *professionell*（19c.）借自**法语** *professionnel*；英语 *Professional / Profi*（20c. 初）又借回德语——**英 → 法 → 德 → 英**的循环样本
- **共祖**：均回到拉丁 *professio / profiteri*
- **⚠️ 时间对照（重要）**：英语 professional（**形容词 mid-18c**、名词 **1848**）**早于**法语 professionnel（1842 / 1872）——这正支持「法 ← 英仿造」说；本页并列记录

**同义 / 搭配 / 易混**
- 同义：名——pro、spécialiste、expert；形——du métier；反义：**amateur**、bénévole
- 搭配：**professionnel de santé**（医护专业人员）；**maladie professionnelle**（职业病）；**lycée / bac professionnel**（职业高中 / 职业会考）；**secret professionnel**（职业保密）；**à titre professionnel**（以职业名义）
- 易混：**professionnel**（职业的）vs **personnel**（个人的）vs **professionnalisme**（专业精神）
- **faux ami（重点）**：法语 *professionnel* 偏「**与职业相关**」（＝英语 **occupational**）——故 *maladie professionnelle* = 英语 **occupational disease**，**不是** "professional disease"；英语 *professional* 义更宽（含「内行的、显得专业的」）
