# généralement

**释义**：通常、一般地；一般说来、大体上（多数情况下如此） ｜ d'une manière générale, ordinairement, dans la plupart des cas

**例句**
- _Généralement, je me lève à sept heures._ 我通常七点起床。
- _Les magasins sont généralement fermés le dimanche._ 商店周日一般关门。
- _Les gens sont généralement gentils ici._ 这里的人一般都很友善。

**形态要点**
- 副词，**无变化**（不随性、数变化）
- 构成：形容词 **général** 的阴性 **générale** + **-ment**（以元音结尾的形容词用阴性形式构成副词；同类：seule → seulement、complète → complètement——见 [[completement]]）
- **拼写要点**：两处重音符号——généralement（é … è）；别漏第一个 é
- 位置：常居句首（后加逗号：Généralement, …），或紧跟动词（il arrive généralement en retard 他一般到得晚）；修饰形容词时前置

**词源 / 构词**
- **拆解**：**général**（← 拉丁 **generalis**「属于整个种类的」← **genus, -eris**「种类、族、出身」，PIE \*gene-「生育」）+ **-ment**（拉丁 **mente**「以……方式」语法化而成的副词后缀——与英语 -ly 对应）
- **演变**：拉丁 generalis → 古法语 general（**1121-34** 首证，义「共同的、普遍的」——CNRTL）→ 副词 **généralement** **fin 12e s.**（形式 generalment，Sermons St Bernard；初义「sans exception」无例外地——CNRTL / Académie 9e，2026-10-03 经检索转引）→ 现代义「通常、一般地」；短语 **en général** 约 **1270** 年见诸记载（CNRTL）
- **同族 / 派生（法语）**：général（adj. 普遍的；n. 将军）、généraliser（推广）、généralité（一般性）、généraliste（全科医生；通才）；短语 en général（一般而言）、d'une manière générale（总体而言）
- **记忆钩**：général 的根是 genus「种类」——「属于整个种类」→ 普遍 → 通常；-ment 即英语 -ly 的法国表亲

**英法交叉核对（受影响的英语词）**
- **借入英语**：**general**（adj. **c. 1200**「广泛的、普遍的」← 古法语 **general**（12c.）/ 直承拉丁 **generalis**——etymonline，2026-10-03 经检索转引；名词「将军」1570s ← 短语 captain general ← 法语 capitaine général）；**in general**（late 14c.，「无例外地、一般地」）
- **共祖未借入**：**generally**（adv. **mid-14c.**«including everyone; in a general way, without reference to particulars»＝ **general + -ly**——**英语自构**；与法语 généralement 是「同模型平行构词」（拉丁系形容词 + 本族副词后缀），**互不借贷**——etymonline）
- 核对：已核实（CNRTL / Académie 9e / etymonline，2026-10-03 经检索转引）——法 général 1121-34 首证、généralement fin 12e s.（generalment）、en général ca 1270；英 general c. 1200 ← 古法语 general、generally mid-14c.（general + -ly 自构，非借自法语）

**同义 / 搭配 / 易混**
- 搭配：句首 `Généralement,` + 逗号；`très généralement`（极其一般地说，书面）；`d'une manière générale`（总体而言）；`parler généralement`（笼统地讲）
- **辨析（频率 / 惯例副词场）**：**généralement**（通常——叙述出现频率，偏客观统计：Les gens sont généralement gentils）vs **en général**（一般而言——总体判断，可句首可句尾：En général, il est ponctuel）vs **d'habitude**（习惯于——个人惯例：D'habitude je prends le bus 我平时坐公交）vs **normalement**（按理说——带预期色彩：Normalement, il devrait être là 按理他该到了）；频率阶梯另见 [[parfois]]（有时）
- **faux ami**：généralement ≈ generally（基本对齐）；注意法语另有同形短语 **en général**（＝英语 in general）；书写勿漏重音（généralement / generalement）
