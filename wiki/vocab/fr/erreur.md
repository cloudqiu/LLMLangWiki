# erreur

**释义**：（1）错误、差错——判断、计算、事实上的不确（une erreur de calcul 计算错误）；（2）弄错、误认的行为（faire une erreur 犯错；par erreur 误、错手）；（3）认识上的虚妄、谬见（être dans l'erreur 弄错了、错了） ｜ ce qui est faux, inexact ; action de se tromper ; opinion fausse

**例句**
- _Il y a une erreur dans ce calcul._ 这个计算里有个错误。
- _J'ai fait une erreur en choisissant ce livre._ 我挑这本书时犯了错。（见 [[choix]]）
- _Par erreur, il a pris mon manteau._ 他误拿了我的外套。
- _Cette erreur de jugement lui a coûté cher._ 这个判断上的失误让他付出很大代价。
- _Reconnaître son erreur, c'est déjà se corriger._ 承认错误，已是改正。（谚）

**形态要点**
- 名词（n.f.）：`l'erreur`——**元音开头，须省音**（\*la erreur 不成立）；复数 **les erreurs**
- 无阴阳或复数不规则；**阴性**（与英语 error 同性）
- 数量表达：「一个错误」直接用 **une erreur**；「犯了错」固定用 **faire une erreur**（不用 \*commettre 之外的高频搭配 faites attention）——commettre une erreur 亦通，偏书面
- 常见搭配里 erreur 常带 **de + 领域**：erreur de calcul / de jugement / de frappe / de goût / de jeunesse

**词源 / 构词**
- **拆解**：拉丁 **error, erroris**「错误、错觉、迷途」——由动词 **errare**「游荡、迷途、走岔」加名词后缀 **-or** 构成（-or 表状态／施事，如 amor「爱」、timor「怕」）；errare 上溯 **PIE \*ers-**「动、四处游荡」（同根：梵语 arsati、古英语 ierre）。字面意象是**「走岔了路」**——「错」在拉丁语中首先是**空间的偏离**，后转指认识与道德的偏离
- **演变（CNRTL/TLFi，2026-10-04 经 WebSearch 转引）**：拉丁 **error** → 古法语 **error**（**fin xe s.**，*Passion de Clermont* 365，义「tromperie, imposture」欺骗、冒名）→ 中古以后词尾 -or 变 -ur，得现代 **erreur**
- **义项链（TLFi 按义项列的首证）**：
  - **fin xe s.** *error*「欺骗、冒名」（*Passion de Clermont*）
  - **a) ca 1125**「弄错的行为」（*Grant mal fist Adam* 15 f）；**b) ca 1200**「令人遗憾的行为」（*Jourdain de Blaye* 3864）；**ca 1355** 复数用法（Bersuire）
  - **a) ca 1200**「错误的判断、意见、学说」（*Dialogue Grégoire*）；**b) 1549** 法律用法（Estienne）；**c) 1585**「过失、不确」（N. Du Fail）
  - 可见现代的核心义（判断错误）**ca 1200** 才定型；最早的「欺骗、冒名」义今已不存
- **同族 / 派生（法语）**：**errer**（v.「游荡；弄错」——与 erreur 同出 errare）；**errance**（n.f. 流浪）；**errant**（adj. 流浪的、游荡的）；**erroné**（adj. 错误的）；**aberrant**（adj. 反常的 ← 拉丁 aberrare = ab-「离」+ errare）；**aberration**（n.f. 偏差、反常）
- **记忆钩**：erreur 的词根意象是**「走岔路」**（errare 游荡）——迷途才有错；英语 err / error / aberrant 同出这一根，一眼串起

**英法交叉核对（受影响的英语词）**
- **借入英语（同源借入，本页核心）**：**`error`**（n. **c. 1300** ← 古法语 **error**「mistake, flaw, defect, heresy」← 拉丁 **errorem**/error ← errare）——英语**经古法语**借入拉丁词，与法语 erreur **同一个词**，同源同义（法 erreur ↔ 英 error 一一对应）
  - 义项年代（etymonline 直读）：**c. 1300**「因无知或疏忽而偏离真理」，并兼道德义「违逆道德／正义的行为、罪」；**early 14c**「持／行虚妄或异端」；**late 14c**「偏离常规、反常」；**1726**「观测值与真值之差」（科学义）
  - 拼写：英语 18 世纪前多作 **errour**，后定 error——正是古法语 error 的原形残留
- **共祖未借入（同出拉丁 errare，但与 erreur 分途入英）**：
  - **`err`**（v. **c. 1300** ← 古法语 **errer**「走岔、迷路、犯错」← 拉丁 errare）——**经古法语**传入，与 erreur 同根同期
  - **`aberrant`**（adj. **1798** ← 拉丁 **aberrantem**/aberrans ← aberrare = ab-「离」+ errare）——**直接借自拉丁**（非经法语），故与 erreur **共祖非借入**；同族 **aberrancy**（1660s）
  - **`errant`**（adj.「流浪的」← 古法语 errant，即 errer 的现在分词）——与 erreur 同根（**首证年代未逐核，待验证**）
  - **`erroneous`**（adj. ← 拉丁 erroneus ← error）——同根（**年代未逐核，待验证**）
- **罗曼语同源（共祖，横向对照）**：西语 **error**、意语 **errore**、葡语 **erro**、加泰语 **error**——皆出拉丁 error；法语 erreur 是这条线上的北支
- 核对：英语侧（error 义项年代 c. 1300 / early 14c / late 14c / 1726、err c. 1300、aberrant 1798、PIE \*ers-）2026-10-04 经 **etymonline 直读**；法语侧（étymon error, erroris、四层义项与逐条首证 fin xe s. *Passion de Clermont* / ca 1125 / ca 1200 / 1549 / 1585）2026-10-04 经 **WebSearch 转引 CNRTL/TLFi**（cnrtl.fr/etymologie/erreur 条目被检索引出，直连仍失败）

**同义 / 搭配 / 易混**
- 搭配：`faire une erreur`（犯错）｜ `par erreur`（误、错手）｜ `être dans l'erreur`（弄错了）｜ `une erreur de calcul / de jugement / de frappe / de goût`｜ `corriger / réparer une erreur`｜ `erreur de jeunesse`（年少轻狂之误，见 [[jeune-adj]]）｜ `erreur de compte`（账目错误，见 [[compte]]）｜ `tirer qqn d'erreur`（使某人醒悟）
- **易混（核心辨析）**：
  - **erreur**（**客观**：判断／事实上的错——erreur de calcul 计算错误）｜ **`faute`**（**主观**：含有**责任、过失**义；也指拼写／语法错误、行为失误——faute d'orthographe 拼写错误，faute grave 严重过失）｜ **`méprise`**（**看走眼、认错**——par méprise 误以为；偏「认错了对象」）｜ **`bévue`**（**失着、疏忽**，口语，多指办事上的疏漏）
  - 一句话：**erreur 是「算错了／想错了」，faute 是「做错了、有责任」，méprise 是「认错了」**
- 相关：[[raison]]（erreur 的反面是 raison「理」与 vérité「真」）；[[compte]]（erreur de compte 账目错误）；[[trouver]]（trouver l'erreur 找出错误）；[[simple]]（对比：erreur 指不确，simple 指不繁）
