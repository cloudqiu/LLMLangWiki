# mille

> 收录说明：inbox 作 **`mille`**——**同形双词**，本页两义并收：①**数词「千」**（不变）；②**n.m.「（英制 / 古法）里、英里、海里」**（复数 milles）。

**释义**：（1）**adj. num. 千、一千**（dix fois cent）；n.m. **成千上万**（des milliers）、**靶心**（le mille）；（2）**n.m. 距离单位——英里 / 里 / 海里**（mille marin ＝ 1852 m；英制 mille ＝ 1609.344 m）｜ dix fois cent ; (n.) unité de distance

**例句**
- _Il y a mille habitants dans ce village._ 这个村子有一千居民。
- _Merci mille fois !_ 万分感谢！（固定搭配）
- _Le bateau a parcouru vingt milles marins._ 船行驶了二十海里。

**形态要点**
- 数词：`le mille`（阳性）；**绝不加 s**（*deux mille*，**非** *deux milles*）；年份写法 **mil**（1001–1999 为变体，2000 年起只能用 mille）
- 名词：`le mille`（m.），复数 **milles**；符号 `mi`
- **易混**：`mil`（年份变体）、英语借入拼写 `mile`

**词源 / 构词**
- **拆解（数词）**：← 拉丁 **mille**（1000）（fr.wiktionary：「Du latin mille de même sens」）。**首证：约 1050**，形 *mil*（TLFi，经 Usito 转引）；**Académie 9e：「XIe siècle, emprunté du latin mille」**。更远的 IE 词源**有争议**（或与希腊 χίλιοι 相关，Pokorny 提 \*ĝhéslo，Meillet 认为 -ll- 仅标记 l exilis）——**标存疑**
- **拆解（名词「里」）**：← 拉丁 **milia**（mille 的复数），**省略 passuum「步」**——原义「一千步」（fr.wiktionary：「Du latin millia (sous-entendu passuum)」）。**首证：1213**（TLFi，经 Usito 转引）；英制 mile 义 1859（航海）/ 1868（陆上）自英语 **mile** 借入
- **同族 / 派生（法语）**：**millier、millénaire、millésime、millième、million、milliard、mille-feuille、mille-pattes、milliaire**
- **记忆钩**：数词「千」与「里」同出拉丁 mille——「里」原是「**一千步**」（milia passuum）

**英法交叉核对（受影响的英语词）**
- **共祖（非借自法语）**：英语 **mile** ← 古英语 *mīl* ← 拉丁 *milia (passuum)*——**共祖拉丁 milia**；拉丁中性复数 milia 被日耳曼语误作阴性单数。**方向：拉丁 → 日耳曼（英语）‖ 拉丁 → 法语，两条独立路径**
- **共祖**：英语 **milli- / million** ← 拉丁 mille
- **faux ami**：英语 **mill**（千分之一）≠ 法语 mille——mill 系拉丁 millesimum 缩略，**同名异义**
- 核对：英语侧经检索转引 etymonline（2026-10-13）

**同义 / 搭配 / 易混**
- 搭配：`mille marin`（＝ mille nautique 海里）｜ `mille terrestre` / `mile international`｜ `mille à l'heure`（mph）｜ `mille feuilles`
- 相关：[[million]]（同数词族）
