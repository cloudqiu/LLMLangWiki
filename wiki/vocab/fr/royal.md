# royal

**释义**：王室的、皇家的；国王的；威严的、盛大的 ｜ du roi, de la royauté ; magnifique, majestueux

**例句**
- _La famille royale habite ce palais._ 王室住在这座宫殿里。
- _C'est une résidence royale._ 这是一处王室（皇家）宅邸。
- _Ils ont reçu un accueil royal._ 他们受到了盛大的接待。

**形态要点**
- 形容词：阳性 **royal** ｜ 阴性 **royale** ｜ 阳复 **royaux** ｜ 阴复 **royales**——**-al → -aux** 阳性复数不规则（这是 -al 类形容词的共性，如 national → nationaux）
- 位置：一般在名词后（la famille royale）；`la voie royale`（康庄大道、最顺捷的路径）为固定搭配
- 派生名词：royauté（王权）、royaliste（保皇党人 / 保皇的）

**词源 / 构词**
- **拆解**：拉丁 **regalis**「国王的」＝ **rex / regis**「国王」＋ 形容词尾 **-alis**（表「属于……的」）；rex ← PIE ***reg-**「直线移动」→ 引申「引导、统治」（同根「直线 → 指挥 → 治理」）
- **演变**：拉丁 regalis → 古法语 **roial**（12c.，etymonline 转引）→ 现代法语 **royal**（-g- 元音化 → 半元音 /j/，拼作 -y-）；「王室」义最古，「盛大、威严」为引申义
- **同族 / 派生（法语）**：roi（国王）、reine（王后 ← 拉丁 regina）、royaume（王国）、royauté（王权）、royaliste（保皇的）、royalement（王式地、极好地）；英语一侧见下节
- **记忆钩**：royal 家族一条线「国王」——roi / reine / royaume / royal 全出拉丁 rex；「统治」根的 PIE \*reg- 也串起英语 regal / reign / rule 与 right

**英法交叉核对（受影响的英语词）**
- **借入英语**：**royal**（adj.「国王的」——「配当国王」义 mid-13c、「与国王相关」义 late 14c ← 古法语 **roial**〔12c.〕← 拉丁 regalis〔etymonline，2026-10-01 经检索转引〕）；**royalty**（c. 1400 ← 古法语 roialte / 仿 roialte ← 俗拉丁 \*regalitas）；**loyal**（← 古法语 loial/leal，虽出拉丁 legalem，但 royal/loyal 之对是英语拼写「-oyal」并行的样本）
- **共祖未借入**：**regal**（← 拉丁 regalis **直接**借入，与 royal 形成**双重借入**——royal 经法语、regal 直承拉丁）；**reign**（← 古法语 regner ← 拉丁 regnare）；**regalia**（← 拉丁 regalia，regalis 的中性复数）；**rex / regicide / regulate**（← 拉丁 rex / regula 一系，同 \*reg- 根，非经法语）
- 核对：已核实（etymonline，2026-10-01 经检索转引）——royal（adj.）mid-13c / late 14c ← 古法语 roial（12c.）；royalty c. 1400；royal / regal 双重借入对（loyal / legal 同理），与法语 roi / royaume 同出 rex

**同义 / 搭配 / 易混**
- 搭配：`la famille royale`（王室）；`un palais royal`（王宫）；`la voie royale`（康庄大道——引申「最顺的路 / 最佳捷径」）；`un accueil royal`（盛大接待）
- **易混（同一 rex 根，别串义）**：**royal**（王室的、国王的）vs **royaliste**（保皇的——政治立场）vs **régulier**（规则的——出拉丁 regula「尺、规则」，同 \*reg- 但义别）vs **régalien**（王权的——出 regalia）
- **faux ami**：royal / royal 基本对齐；但英语 royal 的「顶好、彻底」（美口语强调词，1940s）与「splendid, first-rate」（1853）是英语侧漂移义，法语 royal 无此强调用法；Battle royal「大混战」保留了「形容词后置」的法语语序
