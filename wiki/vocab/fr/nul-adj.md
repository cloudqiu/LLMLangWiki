# nul

> **收录说明（命名消歧）**：inbox 形式 `nul`。**`nul` 是 Windows 保留名**（CLAUDE.md §3.1：con / aux / nul / prn / com1-9 / lpt1-9），故本页文件名记为 **`nul-adj.md`**（加词性后缀 `-adj`，本页首要词性为形容词；代词 / 数词义并收于本页）——**须登记法语 hub「命名消歧登记表」**。原形 `nul` 以 `word` 字段保留。

**释义**：（1）adj.（分数、数量）**零的**——*zéro*（*une note nulle* 零分）；**nulle part** 无处、哪儿都不；（2）adj. **毫无价值的、无能的**、<口>**差劲的**（*un film nul* 一部烂片；*nul en maths* 数学很差）；（3）pron. indéf.（**书面 / 法律**）**无人**、没有任何人（*Nul n'est censé ignorer la loi.*）；（4）adj. num. **零**（多见于分数 / 比赛用语） ｜ adj. « qui n'a aucune valeur ; très mauvais ; zéro » ; pron. indéf. « personne » (littér. / jur.)

**例句**
- _Il a eu une note nulle en maths._ 他数学得了零分。（本义「零的」）
- _Ce film est nul._ 这部电影很差劲。（口语「差评」义）
- _Nul n'est censé ignorer la loi._ 任何人都不被允许不知法（＝不知法不能免责）。（代词义，书面 / 法律）
- _Il n'est nulle part._ 他哪儿都不在 / 到处都找不到他。（**nulle part** 须阴性）

**形态要点**
- **形容词（首要词性）**：阳性 **nul** /nyl/ ｜ 阴性 **nulle** ｜ 阳性复 **nuls** ｜ 阴性复 **nulles**（**规则变化**，无特殊形式；注意发音：nul /nyl/、nulle /nyl/ 同音，复数 nuls /nyl/ 与 nulle 亦近）
- **常用搭配（注意阴性，本页第一易错点）**：**nulle part**「无处、哪儿都不」（＝ nowhere，**必须阴性** nulle——\*nul part ✗）；**nul en qch**（在某方面很差）；**une note nulle**；**match nul**（平局，如 0–0）
- **代词（pron. indéf.）**：**nul** / **nulle**「无人」——**书面 / 法律**用语，多作**阳性单数主语**（*Nul n'est prophète en son pays.* 无人能在本乡当先知）；阴性 **nulle** 作代词**较少见**，通常带 **de** 补语（*nulle de vous*「你们中没有一个」）；现代口语已被 **personne** / **aucun**（见 [[aucune-idee]]）取代
- **数词（adj. num.）**：表「零」——多见于**分数 / 比赛**语境（*match nul*、*nul partout*「双方均得零分」）；现代标准表数「零」多用 **zéro**——**两词的分工与「nul 作基数词」的规范地位待验证**
- 性数一致：作形容词须与名词一致（note **nulle**、films **nuls**）；作代词无复数常规用法

**词源 / 构词**
- **拆解**：拉丁 **nullus**「没有、无」＝ **ne-**「不」（PIE **\*ne-**）+ **ullus**「任何一个」（← **unus**「一」的指小）——字面「**连一个也没有**」
- **演变**：拉丁 nullus → 古法语 **nul / nulle**（阴性 nulla → nulle）
- **首证（TLFi / CNRTL，2026-10-04 经检索转引）**：
  - **842**《斯特拉斯堡誓词》——**adj. indéf.**「aucun, pas un」（与法语语言史上第一件文献同批）
  - **10 世纪下半叶**（《圣莱热传》*St Léger*）——**pron. indéf.**「nul (de)」「（其中）没有一个人」
  - **ca 1170** *nul autre*；**1174** *nulle part*
- **义项演变**：「无一个」（adj.）→「毫无价值的」（价值义后起）→ 口语「差劲的」；代词义（「无人」）由形容词义凝固为书面 / 法律层
- **同族 / 派生（法语）**：nullement（adv. 一点也不）、nullité（n.f. 无价值；无能）、nullissime（口语强式「烂透了」）、annuler（v. 取消 ← a- + nul）、**nul autre**、**nulle part**
- **记忆钩**：nullus ＝ **ne + ullus**「**一个也不**」——与英语 naught / aught 同型构造（「否定 + 任一」＝「无一」）；记住 **nulle part** 的阴性——因为 **part** 是**阴性**名词（une part）

**英法交叉核对（受影响的英语词）**
- **借入英语（经法语中介 —— 本页核心）**：英 **`null`**（adj. **1560s**，「void of legal force, invalid」无法律效力、无效）← **法语 nul** ← 拉丁 **nullus**——**经法语（Anglo-French）中介**，**非**直接借自拉丁（etymonline 明记经 French *nul*；Merriam-Webster 记借自 Anglo-French *nul*「not any」）；该义原多用于**苏格兰法律**语境，今 legal / scientific 常用
  - 英语中 **`nul`** 这一**拼写**（法律 / 纹章学）与法语同形——**同形借词**；但**「nul 作纹章学术语」的用法未获核实（检索无据）——待验证**
- **共祖（拉丁直借 / 经古法 / 本族，均 \*ne- 家族）**：英 **`nullify`**（v. **1590s** ← 晚期拉丁 *nullificare*「使归于无」＝ nullus + facere「做」）；英 **`annul`**（v. **late 14c.** ← 古法 / 盎格鲁法 *anuler* 13c. 或直取晚期拉丁 *annullare* ＝ ad + nullum）；英 **`nullity`**（n. ← 晚期拉丁 nullitas）；英 **`nil`**（n. **1833** ← 拉丁 **nil**，*nihil* 的缩略 ＝ ne- + hilum「小东西」，hilum 来源不明）——**共祖 / 拉丁直借，非经本页法语 nul 传入**（annul 另有古法中介，注意与 null 的借入路径区分）
- **PIE \*ne-** 更广家族：`null` / `nullify` / `annul` / `nil` / `annihilate` / `negate` / `deny` / `renege` / `naught`——「not」词族（etymonline 明列）
- 核对：null 1560s（经 French nul ← 拉丁 nullus）据 **etymonline 直读** + Merriam-Webster 转引；nullify 1590s ← nullificare、annul late 14c. ← 古法 anuler / 晚期拉丁 annullare、nil 1833 ← 拉丁 nil/nihil（ne- + hilum），均据 **etymonline 直读**（2026-10-04）。**否定性结论**：英语 `nul` 的**纹章学义**未核实——待验证。

**同义 / 搭配 / 易混**
- 搭配：`nulle part`（无处）；`nul en maths`（数学很差）；`match nul`（平局）；`note nulle`（零分）；`nul autre`（无他人）；`nul n'est censé ignorer la loi`（法律格言）
- 同义（分层）：**zéro**（零——分数 / 数量的标准词）；**mauvais / médiocre**（坏 / 平庸——nul 口语**更贬、更直白**）；代词义 **personne**（无人——日常）、**aucun**（见 [[aucune-idee]]）
- **易混（口语分层）**：**nul**（口语「差劲」——很常用）；**mauvais**（中性「坏」）；**aucun / personne**（「没有任何 / 无人」——书面 / 中性）；作**代词**的 nul 属**书面 / 法律**层，日常口语用 personne
- **易错（本页第一考点）**：**nulle part** 必须**阴性**（part 为阴性名词）——\*nul part 不合语法；与 **quelque part**（某处）、**partout**（到处）对照：_On ne va nulle part._ / _On va quelque part._
- 拼写提醒：nul / nulle / nuls / nulles 四形——注意 une note **nulle**、des films **nuls**
