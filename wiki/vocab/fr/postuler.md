# postuler

**释义**：（1）求职、应聘、申请（postuler à / pour un poste 申请一个职位）；（2）〈书〉要求、谋求、争取（solliciter）；（3）〈逻 / 哲〉假定、把……当作公设（postuler que…） ｜ faire une demande pour obtenir un emploi, un poste ; solliciter qqch

**例句**
- _Elle postule pour un poste de traductrice._ 她在申请一个翻译职位。
- _Il a postulé à plusieurs entreprises avant de trouver ce travail._ 他找到这份工作前向好几家公司投了申请。
- _Pour postuler, envoyez votre CV et une lettre de motivation._ 申请时请发送简历和求职信。

**形态要点**
- 动词：不定式 **postuler** ｜ 组别：**1er groupe** ｜ 助动词：**avoir** ｜ 过去分词：**postulé**
- 现在时：je **postule** ｜ tu **postules** ｜ il·elle **postule** ｜ nous **postulons** ｜ vous **postulez** ｜ ils·elles **postulent**
- 变位提示：规则 -er 动词（词干 postul- 无变化、无拼写变化）；读音——不定式 /pɔs.ty.le/，现在时三单 **postule** /pɔs.tyl/（词尾 -e 不发音）
- 介词搭配：**postuler à / pour** un poste / un emploi（申请职位 / 工作）；postuler **dans** une entreprise / **auprès de** qn（向企业 / 某人求职）；书面直接宾语＝「谋求」：postuler une bourse（申请奖学金）

**词源 / 构词**
- **拆解**：拉丁 **postulare**「（向……）要求、请求、主张；诉请」——TLFi 记其为 **poscere**「迫切要求」的派生；上溯 PIE 词根 ***prek-**「求问、请求」（同根英语 pray / precarious，见下节）
- **演变**（CNRTL/TLFi，2026-10-03 经检索转引）：借自拉丁，**13 世纪**首证（不及物用法）；**约 1355** 及物义「solliciter——为获得某物多方奔走」；**1399** 宗教义「请求教会当局豁免教规障碍以行选举」；**1843**（编者注）逻辑义「作为公设提出」——TLFi 特别指出：逻辑义的 postuler 是名词 **postulat** 的**逆向派生**（dérivé régressif + -er），并与英语 to postulate（1646 记）对照
- **同族 / 派生（法语）**：postulat（n.m. 公设、假定；宗教「候选期」）、postulant / postulante（申请人；见习修士）、postulation（申请、谋求）
- **记忆钩**：postuler 的祖义是「要求」——求职＝向用人单位提出请求；同一拉丁词在英语里成了 postulate（假定）——**同祖异义**的活样本

**英法交叉核对（受影响的英语词）**
- **借入英语（经法语）**：**postulant**（n.「申请人；见习修士」**1759** 年英语首见，**经法语**借入 ← 拉丁 postulantem〔postulare 的现在分词〕）
- **共祖未借入（英语直接自拉丁 / 中世纪拉丁）**：**postulate**（v. **1530s** 首见、原义「提名某人任教会圣职」← 中世纪拉丁 **postulatus**〔postulare 的过去分词〕；逻辑义「设定公设」**1640s**；n. **1580s**「请求、要求」← 拉丁 **postulātum**「被要求之物」，逻辑义亦 **1640s**；另 **expostulate** 1530s ← 拉丁 expostulare）——英语借的是拉丁 / 中世纪拉丁，**不经过法语**（etymonline，2026-10-03 经检索转引）
- 核对：已核实（etymonline，2026-10-03 经检索转引；对照 CNRTL/TLFi）——**提示原记「英 postulate 1530s ← 拉丁 postulatum」；检索转引 etymonline 显示：动词义源为中世纪拉丁 postulatus（postulare 的过去分词），拉丁 postulatum 对应的是 1580s 的名词——按检索结果记录**；英 postulate 与法语 postuler 同出拉丁 postulare 家族，但词义分化（英：假定、公设；法：应聘、申请）——**faux ami**；TLFi 亦记法语逻辑义为 postulat 的逆向派生、非自英语借入

**同义 / 搭配 / 易混**
- 搭配：`postuler à / pour un poste`（申请职位）；`postuler dans une entreprise`（向企业求职）；`postuler une bourse`（申请奖学金——直接宾语，书面雅语）；同义表达：`poser sa candidature`、`candidater à`（新闻体更常见）
- **faux ami（本页重点）**：**postuler ≠ postulate**——法语 postuler＝应聘、申请（« Je postule pour ce poste. »＝我申请这个职位）；英语 postulate＝假定、把……当作公设（「假定一个理论」）——**同祖异义**，互译时不能对接
- **易混（求职家族）**：postuler（申请）vs candidater à（应聘）vs recruter（招聘——反方向）vs employer（雇用）；相关词：[[salaire]]（薪水）、[[carriere]]（职业生涯）——职场簇
- 句式注意：法语求职语境 **postuler à un poste / pour un poste** 均可（TLFi 列 à / pour / 直接宾语三式）；说「申请公司」用 postuler **dans / auprès de** + 机构
