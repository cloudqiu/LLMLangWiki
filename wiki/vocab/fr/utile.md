# utile

**释义**：（1）**有用的、有益的、管用的**（un conseil utile；une information utile；se rendre utile 帮上忙）；（2）**（法律／商业）可用的**——指优先债权人按抵押日期从债务人财产受偿；（3）**（地理）经济上活跃的**（la surface agricole utile 农用有效面积）｜ **n.m.（罕）**「有用之物」（joindre l'utile à l'agréable 既实用又惬意） ｜ qui sert à quelque chose, profitable, avantageux ｜ 对义：**inutile**

**例句**
- _Ce dictionnaire m'est très utile._ 这本词典对我很有用。
- _Il est utile de savoir nager._ 会游泳很有用。
- _Joignons l'utile à l'agréable._ 让我们把实用与惬意结合起来。（n.m. 义）

**形态要点**
- 形容词（adj.）：**阴阳同形**——阳性 **utile** ｜ 阴性 **utile** ｜ 复数 **utiles**
- 位置：**后置**（un conseil utile、une information utile）；少数固定短语中前置（**en temps utile**、**à toutes fins utiles**、**en bonne et due forme** 一类）
- 无 beau / nouveau / vieux 型特殊变化

**词源 / 构词**
- **拆解**：拉丁 **utilis**「有用的」＝ **uti**「使用、享用、利用」+ **-ilis**（形容词后缀「能……的」）——字面「**用得上的**」；动词 uti 的过去分词 **usus** 另出「使用」一线
- **演变（CNRTL/TLFi，2026-10-05 经 fr.wiktionary 转引）**：首证 **1260**，形式 **utile** ← 拉丁 **utilis**；属**借入**（法语保留拉丁形，无通俗演变痕迹）
- **同族 / 派生（法语）**：**utilité**（n.f. 用处；功利）；**utiliser**（v. 使用）；**utilisateur / utilisatrice**（n. 使用者）；**utilisable**；**utilitaire**（实用的；功利主义的）；**utilitarisme / utilitariste**（功利主义／者）；**inutile / inutilité / inutilement**（无用的／无用／徒然地）
- **记忆钩**：ut-（用）+ -ilis（能……的）＝「能用的」；同一 **ut-** 根见 `usage`（← usus）、`usité`、`usufruit`、`abus`、英语 **use**

**英法交叉核对（受影响的英语词）**
- **借入英语（法语 → 英语）**：英语 **`utile`**（adj.「useful, profitable, beneficial」）**late 15c.**（首见 Caxton）← 古法语 **utile**（**13c.**）← 拉丁 **utilis** ← **uti**——**借入**（etymonline 直读）
  - **关键（义域／频率落差）**：英语 `utile` 今**罕用／学究**，日常英语「有用的」用 **`useful`**（← use + -ful，**日耳曼式构词**，与拉丁 utilis 无词形关系）；英语 utile 主要活于**哲学／美学**文本（the **utile**「有用之物」与 the dulce「愉悦之物」相对）及 **utilitarian** 一族。**故：法 utile 高频，英 utile 低频**——勿以法语 utile 默认为常用英语词
- **共祖未借入（拉丁 uti / utilis 一线）**：英语 **`utility`**、**`utilize`**、**`utilization`**、**`utilitarian`**、**`utilitarianism`** 皆 ← 拉丁 utilis / utilitas 一线，与法语 utilité / utiliser / utilitaire **同源**；英语 **`use`**（n./v.）← 古法语 **user** ← 拉丁 **usus / uti**——**同源且经法语借入**（use 才是英语里 uti 一线的**日常承继词**）
- **核对（faux ami 提示）**：英 `utile` 与法 **utile** 同形同源，但**使用频率天差地别**（英 → 口语用 useful；法 → 只用 utile）
- 核对：英语侧（utile late 15c. ← 古法 utile 13c. ← 拉丁 utilis ← uti；use ← 古法 user ← usus / uti）2026-10-05 经 **etymonline 直读**；法语侧（utile 1260 ← 拉丁 utilis；派生 utiliser / utilité / utilitaire / inutile）2026-10-05 经 **fr.wiktionary 转引 CNRTL/TLFi**

**同义 / 搭配 / 易混**
- 搭配：`un conseil utile`｜`se rendre utile`（帮上忙）｜`en temps utile`（在适当时候）｜`à toutes fins utiles`（为备不时之需）｜`charge utile`（有效载荷）｜`surface agricole utile`（SAU 农用有效面积）｜`joindre l'utile à l'agréable`
- 辨析：**utile**（有用的）｜ **`inutile`**（无用的——对义词）｜ **`profitable`**（有利可图的）｜ **`avantageux`**（有利的）｜ **`serviable`**（乐于助人的——指人）｜ **`efficace`**（有效的——侧重效能）
- **faux ami**：法语 **utile**（高频常用）↔ 英语 **`utile`**（罕用学究）——英语日常须用 **`useful`**
- 相关（待建）：`usage`、`user`、`utilisateur` 同出拉丁 uti 一线（法语页尚未建，**待建**）
