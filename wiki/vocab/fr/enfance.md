# enfance

**释义**：（1）**童年、幼年**（dans mon enfance 在我童年；une enfance heureuse 幸福的童年）；（2）**（事物的）早期、初期**（l'enfance d'un art 一门技艺的初期）；（3）**孩子气、幼稚** ｜ période de la vie entre la naissance et l'adolescence ; début, premier stade

**例句**
- _Elle a passé son enfance à la campagne._ 她在乡下度过童年。
- _C'est l'enfance de l'art._ 这是最容易 / 最初级的部分。
- _Le vieil homme est retombé en enfance._ 这位老人返老还童（变得孩子气）了。

**形态要点**
- 名词：`l'enfance`（**f.**）；复数 **enfances**
- 固定短语：`l'enfance de l'art`（技艺的入门 / 最容易的部分——**不是**「艺术童年」）｜ `retomber / tomber en enfance`（返老还童 / 老糊涂）｜ `la petite enfance`（幼儿期 < 3 岁）｜ `la première / tendre enfance`（幼年）
- 同族 / 派生：**enfant**（孩子）、**enfantin**（孩子气的）、**enfantillage**（孩子气举动）、**enfantement**（分娩）
- 近义 / 对照：**jeunesse**（青春 / 青年）｜ **vieillesse**（老年，见 [[vieux]]）——人生三段

**词源 / 构词**
- **拆解**：拉丁 **infantia**「幼年、婴儿期」（**未缩合形**，属**书面借形**——俗形则演变为 **enfant**）← **infans**「**不会说话的**」＝ **in-**（否定）+ **fari**「**说**」（现在分词 *fans*）← PIE ***\*bha-***「说」
- **演变**：拉丁 infantia → 法语 enfance（书面 / 半学者词）；对应的俗形造成 **enfant**——**同一拉丁词根的两条命运**
- **首见**：Académie 9e 记 **xiie s.**；DMF（1330–1500）收 ENFANCE，引 FEW IV 663b *infantia* + TLF VII 1083a——**精确 TLFi 日期未取得（待验证）**；无竞争假说
- **同族 / 派生（法语）**：enfant、enfantin、enfantillage、enfantement
- **记忆钩**：enfance ＝「**不会说话**的时期」（in- + fari「说」）——婴儿「还不会说话」，故为 *infans*；法语「孩子」enfant 与「童年」enfance 同源

**英法交叉核对（受影响的英语词）**
- **借入英语**：**infancy**（late 14c ← **盎格鲁-法语 enfaunce**，并直取拉丁 infantia）；**infant**（late 14c ← 拉丁 infantem，受法语 **enfant 强化**——**借入 + 共祖**）；**infantile**（mid-15c ← 晚期拉丁 infantilis）；**infantry**（**1570s** ← 法语 **infanterie** ← 意 / 西 infanteria——「步兵」原义「（年轻的）仆从 / 新兵」）
- **同义异源**：英语「童年」用 **childhood**（← 本族 child + -hood，日耳曼）——与 enfance **无亲缘**；英语「孩子」用 **child**（← OE cild）
- **共祖未借入**：infant / infancy 与法语 enfant / enfance **同出拉丁 infans / infantia**
- 核对：英语侧（infancy late 14c ← 盎格鲁-法语 enfaunce；infantile；infantry 1570s）经检索转引 etymonline（2026-10-11）；法语侧 xiie s. 与 infantia 链据 Académie 9e / DMF / FEW 转引（**待验证**）

**同义 / 搭配 / 易混**
- 搭配：`dans mon enfance`（在我童年）｜ `une enfance difficile / heureuse`（艰难 / 幸福的童年）｜ `l'enfance de l'art`（最容易的部分）｜ `retomber en enfance`（变得孩子气）｜ `la petite enfance`（幼儿期）
- **易混**：**enfance**（童年，n.f.）vs **enfant**（孩子，n.）vs **enfantin**（孩子气的，adj.）——**同族近形，别混**；**enfance**（童年）vs **jeunesse**（青年时期）——人生分段不同
- 相关：[[vieux]] / [[jeune-adj]]（人生阶段域）；[[etre]]（「是」词族—infans 的 *fari* 与英语 fate / fame 同出 PIE \*bha-）
