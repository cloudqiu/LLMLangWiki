# toujours

**释义**：（1）**总是、一直**——无例外、时时（Il est toujours en retard. 他总是迟到）；（2）**仍然、还**——状态持续（Il travaille toujours. 他还在工作）；（3）**永远**（Je t'aimerai toujours. 我永远爱你）；（4）**无论如何、至少**（C'est toujours ça. 好歹算是） ｜ en tout temps, continuellement ; encore ; éternellement ; en tout cas, du moins

**例句**
- _Elle est toujours de bonne humeur._ 她总是心情很好。
- _Il habite toujours à Paris._ 他还住在巴黎。
- _Je me souviendrai toujours de ce jour._ 我永远记得这一天。
- _Viens toujours, on verra._ 你先来，回头再说。

**用法要点**
- 副词（adv.），不变；**核心是「时间全称」**：把「所有的日子」压缩进一个词。
- **位置**：多置于动词前（助动词与过去分词之间）：il a **toujours** su；或句首作话语标记。
- **与否定系统的对立（核心）**：**toujours**（总是）↔ **[[jamais]]**（从不）——「全称肯定 vs 全称否定」；**注意** `toujours` 与否定连用时的歧义：*pas toujours*（不总是）/ *toujours pas*（仍然没有）。*toujours* 还是 **[[ne-plus]]**（不再）的对立项（「还」↔「不再」）
- 常见短语：`pour toujours`（永远地）｜ `depuis toujours`（一向以来）｜ `comme toujours`（一如既往）｜ `toujours est-il que`（不管怎样，总之——让步话语标记）｜ `encore et toujours`（一再）｜ `toujours plus`（越来越多）
- 语域：通用；`toujours` 作「至少」义（C'est toujours ça de pris）偏口语

**词源 / 构词**
- **拆解**：**tous**（← 拉丁 **totus**「全部」的复数 tous）+ **jours**（← 拉丁 **diurnum**「白天」→ 古法 jor）——古法 **toz jorz / tous jours**，字面「**所有的日子**」→「总是」。副词性 -s（adverbial genitive）固化
- **演变（DEAF / TL / DMF，2026-10-05 经 WebSearch 转引）**：
  - **ca 1170** **toujours**（《Roman de Horn》, v. 692；DEAF J 565, Städtler 定年）——首证**较早**；**TL**（s.v. *jor*）则给「**1er tiers du xiie s.**」——两说并列，**待核**
  - 中法 **tousjours**（亦作 *touz jours*）；旧拼写 **toûjours**；皮卡德语 **toudi**
  - **取代**古法 **sempres**「总是」（← 拉丁 *semper*）——法语用「所有的日子」这一**分析式**说法，挤掉了拉丁 semper 的直承词
  - 旁证 BFM [1369/1400]
- **同族 / 派生（法语）**：**tout**（全部）、**jour**（日）；**toujours** 与 **`toutefois`**（然而）、**`tous les jours`**（每天——未完全词汇化，与 toujours 有别）、**`de toujours`**（素来的）
- **记忆钩**：toujours ＝ tous + jours——「**所有的日子**」＝ 总是；同一造词法见英语 **`always`**（all + way「所有的路」）——**两语都用「全 + 时间单位」拼「总是」**（平行构词，非借入）

**英法交叉核对（受影响的英语词）**
- **借入英语**：无（英语未借入 *toujours*；英语里偶见的 *toujours* 系近代表现法语风味的借形，非常用）
- **共祖未借入**：英语 **`day`**（← OE dæg ← PGmc \*dagaz）与法语 **jours**（← 拉丁 diurnus）**不同源**（日耳曼 \*dagaz vs 拉丁 dies / diurnus）——toujours 的「jours」在英语里**无同源对应**
- **同义异源 + 平行构词（核心对照）**：英语的「总是」是 **`always`**（mid-14c.，缩自 OE **ealne weg**「all the way，所有的路」）——**日耳曼语零件**（all + way），**非借入**；而 **`semper`** 线的英语词是 **`sempiternal`**（← 拉丁 sempiternus）。法语用「tous + jours」、英语用「all + way」——**同一「全 + 时间」模型平行构词**（与 vie↔life 的「同义异源」同类）。**结论：toujours ↔ always 同义异源、平行构词**
- 核对：英语侧（always mid-14c ← OE ealne weg；day ← OE dæg；sempiternal）2026-10-05 **etymonline 直读**；法语侧（ca 1170《Roman de Horn》／ TL「1er tiers du xiie s.」两说、取代 sempres、tousjours / toûjours / toudi 诸形）2026-10-05 经 **WebSearch 转引 DEAF / TL / DMF**（CNRTL 直连仍 sinkhole；TLFi 原条未直取）——**待验证**

**同义 / 搭配 / 易混**
- 搭配：`pour toujours`（永远）｜ `depuis toujours`（一向）｜ `comme toujours`｜ `toujours est-il que`（总之）｜ `toujours plus`（越来越多）｜ `pas toujours`（不总是）｜ `toujours pas`（仍然没有）
- 辨析：**toujours**（总是／还）｜ **[[jamais]]**（从不——toujours 的**全称否定对**）｜ **[[ne-plus]]**（不再——toujours「还」的对立）｜ **[[souvent]]**（经常——频率低于 toujours）｜ **[[parfois]]**（有时）｜ **`encore`**（还、再——与 toujours「还」义近，但 encore 强调「再来一次」）｜ **`sans cesse`**（不停）｜ **`perpétuellement`**（永久地，书面）
- 相关：[[tout]]（toujours 的构成件）；[[jamais]]（对立项，**建议双向互链**）；[[ne-plus]]（对立项）；[[souvent]] ／ [[parfois]]（频率场）；[[longtemps]]（时段）
- 反义链：toujours ↔ **jamais**；toujours（还）↔ **ne… plus**（不再）；toujours ↔ **parfois / rarement**

## 闪卡 #flashcards/fr

toujours
??
**adv.** 总是、一直（Il est toujours en retard）；仍然、还（Il travaille toujours）；永远（Je t'aimerai toujours）；至少（C'est toujours ça）
**用法**：置动词前（il a toujours su）；**对立项 [[jamais]]（从不）**；`pour / depuis toujours`、`toujours est-il que`；`pas toujours`（不总是）vs `toujours pas`（仍然没有）
**词源**：古法 **tous jours / toz jorz**「所有的日子」（tous ← 拉丁 totus + jours ← diurnus）→ **ca 1170**《Roman de Horn》首证；**取代**古法 sempres（← 拉丁 semper）
**英法交叉**：英 `always`（mid-14c. ← OE ealne weg「所有的路」）——**同义异源、平行构词**（全+时间），**无借入**
