# compter

**释义**：v. ①**数、计算**——以数数或计算确定数量 ②（绝对）**计算** ③（专门）**依次念自然数** ④在钱上**斤斤计较** ⑤觉得某金额**过大** ⑥**付给**某人一笔钱 ⑦把某物**记在**某人的账上 ⑧（喻，雅，与 *par* 连用）**表明、标志** ⑨把某人某物**列为** ⑩**计入** ⑪**包含** ⑫被计入 ⑬**与某人算账** ⑭（喻）**考虑、顾及**（*compter qqch*）⑮**打算、计划**（*compter* + 不定式）⑯（不及物）**重要、有分量** ｜ dénombrer, calculer ; tenir compte de ; (intr.) avoir de l'importance

**例句**
- _Il ne faut pas compter sur lui._ 别指望他。
- _Ils comptent leurs économies chaque mois._ 他们每月都数自己的积蓄。
- _Je compte partir en vacances en août._ 我打算八月去度假。

**形态要点**
- 动词（1er groupe，及物 / 不及物两用）｜ 助动词：**avoir** ｜ 过去分词：**compté**
- 现在时：je **compte** ｜ tu **comptes** ｜ il·elle **compte** ｜ nous **comptons** ｜ vous **comptez** ｜ **ils·elles comptent**（inbox 原形）
- 变位提示：规则 -er 动词；无词干变化；重读式与 *conter*（讲述）**完全同音**——是本组的核心拼写陷阱

**词源 / 构词**
- 拆解：← 古法语 **conter** ← 拉丁 **computare**「计算、估算、数」← **com-**「一起」+ **putare**「计算、修剪、认为」。**书面拼写 compter（带 -p-）13 世纪出现**，专化「计算」义——是 *conter* 的**「人为分化」（dédoublement artificiel）**；**compter / conter 的明确分工迟至 17 世纪才稳定**
- 首证（并列）：CNRTL / Académie 9e 记 **conter 12 世纪**（先作 *conter*）；fr.wiktionary 记 **compter 拼写「apparue au XIIIe siècle」**；另一说中古法语约 **1348**；又一说 **XVe**（**三种拼写日期并列**）；「计算」义 **1080**；**compte**（n.）约 **1080**
- 同族 / 派生：**compte**（n.m.，账、数——**本库已收 [[compte]]**）、**compteur**（计数器 / 计量表）、**comptable**（会计）、**comput**、**décompter**、**recompter**、**raconter / conter**（讲述——**拼写分化的另一支**）
- 记忆钩：**computare（一起算）** 分出两支拼写——**compter 算数**、**conter 讲述**；「讲」原是「把事一件件数给人听」

**英法交叉核对（受影响的英语词）**
- **借入（英 ← 法）**：英语 **count**（v.，**late 14c.**）← 古法语 *conter* ← 拉丁 *computare*；**count**（n.，late 15c.）← 盎格鲁-法语 *counte* / 古法语 *conte*；英语 **compute**（v.，**1630s**）← 法语 *computer*（16c.）← 拉丁 *computare*——etymonline 明确注 **compute 是 count 的 doublet（同源异体）**；英语 **account**（**c. 1300**）← 古法语 *aconter*（*a-* + *conter*）
- **共祖**：均回到拉丁 *computare*（*com-* + *putare*）
- **反向借入**：无
- **核对要点**：**count 与 compute 同源而异路**——count 走**古法语**中介，compute 走**16 世纪法语**中介，两度从同一拉丁词入英，是本库可复用的「双式词」样本（可与 [[gutter]] 的 gutta 两面、[lentil] 的 lens 两面并列）

**同义 / 搭配 / 易混**
- 同义：dénombrer、calculer、énumérer、recenser；(喻) tenir compte de、envisager、prévoir；(不及物) importer、avoir de l'importance
- 搭配：**compter sur qqn / qqch**（依靠、指望）；**compter avec**（考虑到）；**compter parmi**（属于……之列）；**à compter de**（自……起）；**sans compter**（不计其数）；compter les points（记分）
- **易混三同音词（重点）**：**compter**（数 / 算 / 打算）vs **conter**（讲述）vs **comte**（伯爵）——三词均读 /kɔ̃t/，是法语拼写的经典陷阱（Grevisse 有专文《COMTE / CONTE / COMPTE》）
- **faux ami**：法语 *compter* 有「**打算、意图**」义（*Je compte partir demain* 我打算明天走），英语 *count* 无此义
