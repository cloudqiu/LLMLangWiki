# chance

**释义**：n.f. ①（绝对用法）**影响行动成败的境遇组合**——幸或不幸的处境 ②（复数）某事发生的**量化概率** ③（主观估计的）**实现 / 成功的可能性** ④（*une chance*）**机会**——转瞬即逝的有利时机（= *occasion / opportunité*） ｜ hasard heureux ; occasion ; (pl.) probabilité

**例句**
- _Tu as beaucoup de chance !_ 你运气真好！
- _Il y a peu de chances qu'il pleuve._ 下雨的可能性很小。
- _Bonne chance pour ton examen !_ 祝你考试顺利！

**形态要点**
- 名词：`la chance`（**f.**）；复数 **chances**（规则）
- 搭配介词：**par chance**（幸好——用 **par**）；**avoir de la chance**（走运）、**bonne chance**（祝好运）
- 反义：**malchance**（倒霉）；派生：**chanceux / chanceuse**（走运的）

**词源 / 构词**
- 拆解：古法语 ***cheance***「落下的方式」——是 *cheoir*（← 拉丁 *cadere*「落下」）的**动词派生名词（déverbal）** ← 通俗拉丁 ***cadentia***（*cadens / cadere* 的中性复数现在分词）「落下之物」——**古典拉丁已用于掷骰 / 掷骨游戏**
- 语义链：**落下的方式 → 骰子如何落 → 偶然、机遇 → （单数）好运**
- 首证：**12 世纪**（形 *cheance*，据 TLFi / Académie 9e 经 CNRTL）。**⚠️ 并列**：fr.wiktionary 该条标「**Date à préciser**」，**未给年代** → 本页采「12 世纪（TLFi / Académie 9e，形 *cheance*）」，并注明 Wiktionary 未定年
- 同族 / 派生：**chanceux**、**malchance**、**bonne chance**；英语侧见下
- 记忆钩：**cadere（落下）**——「运气」原是**骰子落下来的样子**；*chance* 与 *cadence*（节奏）**同一个拉丁妈妈**

**英法交叉核对（受影响的英语词）**
- **借入（英 ← 法）**：英语 **chance**（**c.1300**）← 古法语 *cheance*（12c.）← 俗拉丁 *\*cadentia* ← 拉丁 *cadere*（PIE \*kad-「落」）。原义「**发生之事**」（多偏不幸），后由「机会」「随机性」两义渐渐取代。另有 **mischance**（c.1300，← 古法语 *mescheance*）、*chance-medley* 等
- **共祖（双式词 doublet）**：英语 **cadence** 与 *chance* **同为 *cadentia* 之后代**，但 *cadence* 是**经意大利语 *cadenza*（15 世纪末）**进入（法语亦同）——故与 *chance* 构成**同源双式词**；*cadence* 属**意大利路径，非直接法语借入**
- **核对要点**：**chance（法语路径）／ cadence（意大利路径）**——同一个俗拉丁 *\*cadentia* 两度入英，可作「双式词」样本（可比 *count / compute*）

**同义 / 搭配 / 易混**
- 同义：**hasard**、**fortune**、**opportunité**、**occasion**；反义 **malchance**
- 搭配：**avoir de la chance**（走运）、**bonne chance !**（祝好运）、**par chance**（幸好）、**chances de réussite**（成功几率）、**tenter sa chance**（碰碰运气）
- **介词**：**par chance**（用 *par*）
- **faux ami（重点）**：法语 *chance* 单数多含**褒义**（好运），英语 *chance* 中性偏「**机会 / 概率**」；法语 **chanceux**（走运的）≠ 英语 **chancy**（冒险的）
