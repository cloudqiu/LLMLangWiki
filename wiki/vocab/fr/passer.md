# passer

> 收录说明：inbox 里的遇到形式是 **`passe`**（直陈式现在时 je / il 形，亦可为命令式 / 虚拟式）——按 lemma 规则归并至不定式 **passer**。**注意**：名词「过去」是 **le passé**（**带重音**），**不可写作 *passe***——故 inbox 的 `passe` 无歧义为**动词形**。

**释义**：（1）**经过、通过**（Aller d'un lieu à un autre）；**流逝**（时间）；（2）**通过、及格**；（3）及物：**穿过、越过**；**超越**；**度过、花（时间）**（passer du temps）；**参加（考试）**（passer un examen ＝**参加**，**非**「通过」）；**传递**（passer le sel）；**过滤**；**穿（衣）**；（4）**se passer 发生**（Qu'est-ce qui se passe ?）；**se passer de 没有…也行**（Je peux me passer de voiture）｜ traverser, franchir ; s'écouler ; (se passer) avoir lieu

**例句**
- _Je passe te voir demain matin._ 我明天早上过去看你。
- _Il a passé deux heures à lire._ 他花了两个小时读书。
- _Qu'est-ce qui se passe ici ?_ 这里发生什么事了？

**形态要点**
- 动词（变位要点）：不定式 **passer** ｜ 组别：**1er groupe**（完全规则 -er）｜ 助动词：**avoir / être**（两制，见下）｜ 过去分词：**passé**
  现在时：je passe ｜ tu passes ｜ il·elle passe ｜ nous passons ｜ vous passez ｜ ils·elles passent
- **助动词两制（核心语法点）**：不及物时用 **être** 表「结果 / 已越过」；用 **avoir** 表「动作 / 移动」；带**直接宾语时一律 avoir**（*Il a passé deux heures…*）
- **faux ami（必记）**：**passer un examen ＝ 参加考试**，**不是通过**；「通过考试」＝ **réussir à / être reçu à un examen**
- 代动词：**se passer**（发生）；**se passer de**（不需要）；**se passer bien / mal**（进展顺利 / 不顺）
- 名词化：**le passé**（过去——过去分词名词化；还表过去时态 / 动词过去式）

**词源 / 构词**
- **拆解**：古法 **passer** ← 俗拉丁 **\*passare**「traverser」← 拉丁 **passus**「pas（步子）」的派生；无前缀 / 后缀（法语直接继承俗拉丁动词）
- **首证**：**1050**（11 世纪中期；fr.wiktionary 记 1050，另有「milieu du 11e s.」表述）——**TLFi 原句未直核**
- **演变**：原义「穿过某地」→ 时间上「流逝」→ 大量引申（超越、度过、传递、通过考试、代动词「发生」）
- **同族 / 派生（法语）**：**passage**（n.m.）、**passant**（n.）、**passe**（n.f. 通行证 / 传球）、**passé**（n.m./adj.）、**dépasser**、**repasser**、**surpasser**、**trépasser**
- **记忆钩**：passer 的底是「**步子**」（passus）——「经过」就是「一步步走过去」；英语 pass 借的正是它

**英法交叉核对（受影响的英语词）**
- **借入**：英语 **pass**（v. 中古英语 *passen*，**late 13c.**「to go by, cross over」）← 古法 **passer**；**pass**（n. 山口，c.1300）← 古法 *pas*「step, track」
- **借入**：**passé**（adj. **1775**「past one's prime」）← 法语 passé（过去分词）；**trespass** ← 古法 *trespasser*（tres- + passer）
- **共祖**：法语 **pas**（约 late 10c.）本身 ← 拉丁 *passus*，后演化出否定副词 *ne… pas*——与英语 pass 同出 passus
- 核对：英语侧经检索转引 etymonline（2026-10-13）；法语侧 1050 据 fr.wiktionary / 论文转引（**待验证**）

**同义 / 搭配 / 易混**
- 搭配：`passer à table`（入席）｜ `passer par`｜ `passer pour`（被当作）｜ `en passant`（顺便）｜ `passer son tour`｜ `passer un coup de fil`（打电话）｜ `se passer de`｜ `il se passe qqch`
- 同义：traverser、franchir、dépasser；（se passer）se produire / arriver
- **易混**：**passer un examen（参加）vs réussir / être reçu à un examen（通过）**；passer vs se passer；**le passé**（过去）vs le passif
- 相关：[[aller]]、[[venir]]（同「移动」域）
