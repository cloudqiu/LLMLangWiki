# désert

> 收录说明：inbox 作 `desert`（去重音 ASCII）→ 本页 lemma **désert**（名词／形容词）。**与 `dessert`（甜点）是两个词条，不得合并**——拼写只差一个 s、读音只差清浊，而**词源方向恰好相反**（见下）；`dessert` / `déserter` 拟另建页。

**释义**：**n.m.**（1）（地理）**沙漠、荒漠**——干旱少雨、植被稀少的广袤地带（le désert du Sahara；traverser le désert）；（2）荒无人烟之地、荒野；（3）引申**冷清、孤寂**（un désert humain 一片人际荒漠；crier dans le désert 无人理睬）；（4）**离群索居之处、隐居地**（尤指修道院僻静处；le désert spirituel 灵修静地）；（5）引申**缺失、匮乏**（un désert médical 缺医地区；un désert culturel 文化荒漠）
**adj.**（1）**荒芜的、无人居住的、冷清的**（une rue déserte 空无一人的街；une île déserte 荒岛）；（2）（古／文学）被荒弃的、荒凉的 ｜ **n.m.** étendue aride et inhabitée ; lieu désert, solitude ; (fig.) vide, manque. **adj.** qui est inhabité ou peu fréquenté ; inculte, désolé

**例句**
- _« Si purpernes les deserz e les tertres. »_ ——《罗兰之歌》（Chanson de Roland）ca 1100（ms. O 读法；TLFi 引作名词首证 *les deserz e les tertres*）：我们穿越了荒漠与丘陵。（**名词首证**）
- _Il a traversé le désert à dos de chameau._ 他骑着骆驼穿越了沙漠。
- _Une rue déserte à trois heures du matin._ 凌晨三点空无一人的街道。（形容词）
- _Ses paroles sont restées un cri dans le désert._ 他的话成了无人回应的空喊。（引申义「无人理睬」）
- _Ce village est un désert médical : plus un seul médecin._ 这个村子是「医疗荒漠」：连一个医生都没有了。（引申义「匮乏」）
- _Elle aime se retirer dans son désert._ 她喜欢躲进自己那片清静地。（引申义「隐居处」）

**形态要点**
- 名词（n.m.）：`le désert`；复数 **les déserts**
- 形容词：阳性 `désert` **/de.zɛʁ/**（词尾 t **不读**）；阴性 **déserte** **/de.zɛʁt/**（**t 读出来**）；复数 déserts / désertes
- **发音陷阱**：名词与阳性形容词同音 /de.zɛʁ/；一读成 /de.zɛʁt/ 就落到阴性或军俚义。军俚名词 `désert`（＝déserteur 逃兵，Wiktionnaire 记 nom commun 2）词尾 t 大概读 /de.zɛʁt/——**该义未见书证，待验证**
- **派生**：`déserter`（v. 离弃；开小差）→ `déserteur`（n.m. 逃兵；背弃者）、`désertion`（n.f. 逃亡、背弃）；`désertique`（adj. 沙漠的——用于气候／地带）、`désertification`（n.f. 沙漠化）、`déserticole`（adj. 沙漠生的）、`semi-désert`
- 固定表达：`crier / prêcher dans le désert`（白费唇舌、无人响应）｜`traverser le désert`（喻「熬过荒年／低谷期」）｜`le désert médical / culturel / vert`（缺医／文化／「绿色荒漠」＝单一种植区）｜`une île déserte`（荒岛）｜`les Pères du désert`（旷野教父）
- **易混（一字母之差，务必分辨）**：
  - **désert** /de.zɛʁ/（沙漠；荒芜的）↔ **dessert** /de.sɛʁ/（n.m. 甜点）——**注意清浊**：désert 的 s 是 /z/，dessert 的 s 是 /s/；且**词源方向相反**（见下）
  - **désert**（n./adj.）↔ **déserter**（v. 离开、弃守、开小差）↔ **déserteur**（n.m. 逃兵）

**词源 / 构词**
- **拆解**：拉丁 **deserere**「抛弃、离弃、玩忽」= **de-**「（彻底）离开、去除」+ **serere**「连接、排列」（PIE **\*ser-**(2)「排成行」，与 series、insert、exert、sermon 同根）→ 过去分词 **desertus**「被抛弃的」→ 中性 **desertum**「被遗弃之物／地」
  - **两个拉丁源，按词性分途（TLFi/CNRTL 词源条）**：**名词**借自**帝国拉丁 desertum**「荒漠、孤寂」；**形容词**借自**古典拉丁 desertus**「荒废的、未开垦的、野蛮的」——同根而**来源层次不同**
  - **教会拉丁 /《武加大》的关键作用**：哲罗姆的 Vulgate 用 **desertum** 译圣经里的「旷野」（旷野受试探、以色列人过旷野、Desert Fathers 旷野教父）；这一宗教语境把 desertum 从「被弃之地」**固化为「荒野、沙漠」**并推入欧洲诸语言（etymonline 明记 Vulgate 用法）——法语「沙漠」义是**经教会拉丁过滤**的产物
- **演变（各源并录）**：
  - **形容词（TLFi，2026-10-03 经检索转引）**：**ca 1100**「inculte 未开垦」（《罗兰之歌》Bédier 编，v. 3246）；**ca 1100**「vidé de ses habitants 居民尽失」（同书 v. 664，阴性 *deserte*）
  - **名词（TLFi）**：**ca 1100** *les deserz e les tertres*（《罗兰之歌》ms. O 读法，L. Foulet 主张保留；与 v. 3246 一线）→ **1135**「干旱无人区」（Wace, *Conception de Notre Dame*）→ **1269-78** 比喻用法（J. de Meun, *Roman de la Rose*）→ **1618**「人烟稀少处、隐居地」（Racan）→ **1788**「缺失、没有」（*Histoire naturelle*）
  - **矛盾显式记录（首证年代）**：fr.wiktionary 词源仅作「(1080) Du latin desertus」——**1080 与 TLFi 的 ca 1100 不合**，且 wiktionnaire 只给 *desertus* 一个拉丁源，**未分 desertum / desertus**。**两说并录，不折中**
  - **矛盾显式记录（《罗兰之歌》v. 3246 的词性）**：同一行诗的 *desert*，**TLFi 词源条**按**形容词**「inculte」引（Bédier 编），而**Gautier 编本词汇表**按**名词**处理（读作 *le desert*，溯源 *Desertum*）——**同一行，两种词性判读**；Gautier 版另把 v. 805 的 *deserz* 判作 *destrez* 之误（**待验证**）
- **同族 / 派生（法语）**：**déserter**（v. ← 古法语 **deserter** 12c. ← 晚期拉丁 **desertare**——deserere 的**反复态**「一再离弃」；英语 *desert* v. 即经此径入英）；**déserteur**、**désertion**；**désertique**、**désertification**、**déserticole**、**semi-désert**
- **记忆钩**：de-（去掉）+ serere（连起来）＝「拆散、脱队」——所以 **déserter 就是「脱队、弃阵」**；「沙漠」是「被弃之地」。而 **dessert** 走的是另一个 de-（「去除」）+ **servir**（上菜）＝「撤去餐具」——**同一个前缀，两条岔路**（见下节）

**英法交叉核对（受影响的英语词）**
- **借道法语入英语（英 ← 法）**：
  - **desert**（n.）**c. 1200**「荒地、荒野」← 古法语 **desert**（12c.）＋直接 ← 晚期拉丁 **desertum**（字面「被弃之物」，**Vulgate 用于「wilderness」**）；「干旱无树的沙地」义中古英语已存，后渐成主义；18c. 另有**非词源拼写 *desart***（etymonline 注：为与另两义避混）
  - **desert**（adj.）**mid-13c.**「荒废的、未开垦的、荒凉的」← 古法语 desert ＋ 拉丁 desertum；「属于沙漠的」义 **1630s**；**desert island**「无人岛」**c. 1600**；**deserter**（n.）**1630s**（尤指逃兵 **1660s**）
  - **desert**（v.）**c. 1600** 及物「离开、抛弃」；**1640s** 军义「擅自离队、开小差」；**1680s** 不及物——← 法语 **déserter** ＋ 晚期拉丁 **desertare**（deserere 的反复态）；**deserted**（pp./adj.）
  - **"just deserts"**（罪有应得）：属 **desert (n.2)**，**c. 1300**「（善／恶）应得的报偿」← 古法语 **deserte**「功过、报偿」← 拉丁 **deservire**「尽力服务」（de- + servire）——**这个 desert 与「沙漠」同形而词源不同**（走 servire 线）
- **共祖未借入（拉丁 serere → 英语，不经法语）**：**series**（← 拉丁 series ← serere「连接」）、**insert**（← in- + serere）、**exert**（← exserere）、**sermon**（← sermo）——与英 desert 是「同根不同路」（**共祖、非借入**）
- **英法同构的一字母陷阱（双向）**：
  - 英语 **desert**「荒漠」↔ **dessert**「甜点」——靠**拼写**（一个 s）、**读音**（/'dɛzərt/ 名词 vs /dɪ'zɜːrt/ 动词 vs /dɪ'zɜːrt/ dessert）区分
  - 法语 **désert** /de.zɛʁ/ ↔ **dessert** /de.sɛʁ/——靠**重音符**（é 与否）与**清浊**（/z/ vs /s/）区分
  - **词源方向恰好相反**：法语 **dessert** ← **desservir**「撤去餐具」= des-「去除」+ **servir**「上菜」← 拉丁 **servire**（「服务」线）；而 **désert** ← **serere**（「连接／拆散」线）。**两条线在拉丁语里毫无关系**，却因音变在法英两语同时撞成一个 s 之差——**这是本书里最典型的「跨语言同构陷阱」样本**
  - 英语 **dessert**（c. 1600「餐末的水果与甜食」）← 法语 **dessert**（16c. 中期「最后一道」）← **desservir**；法语侧 TLFi：**1393** *desserte*「餐末最后一道」（*Ménagier de Paris*）→ **1549** *dessert*（Est.）——**英法年代链可互证**
- 核对：英语侧（desert n. **c. 1200**、adj. **mid-13c.**、v. **c. 1600**、military **1640s**、intransitive **1680s**、deserter **1630s**、just deserts **c. 1300**、dessert **c. 1600**）2026-10-03 **etymonline 直读**；法语侧（形容词 desertus ca 1100、名词 desertum ca 1100《罗兰之歌》、1135 Wace、1269-78 Meun、1618 Racan、1788 *Hist. naturelle*；dessert 1393/1549）2026-10-03 经 **WebSearch 转引 TLFi/CNRTL**（CNRTL 直连仍 sinkhole）。**待验证**：fr.wiktionary 的 1080 说；《罗兰之歌》v. 3246 的词性（形容词 vs 名词）；古法语 deserter 的确切首证年代；dessert 1393→1549 间的形态演变细节；désert 军俚义（＝déserteur）无书证

**同义 / 搭配 / 易混**
- 搭配：`traverser le désert`｜`crier / prêcher dans le désert`（无人响应）｜`le désert avance / recule`（沙漠进退）｜`un désert médical / culturel / vert`｜`une île déserte`｜`une rue déserte`｜`le désert spirituel`｜`les Pères du désert`
- 辨析：**désert**（n.m. 沙漠；adj. 荒芜的）｜**dessert**（n.m. 甜点——差一 s，**词源相反**）｜**déserter**（v. 离开、弃守、开小差）｜**déserteur**（n.m. 逃兵）｜**désertique**（adj. 沙漠的——修饰气候／地带，不说 *une rue désertique*）｜**aride**（adj. 干旱贫瘠的——可指土地，也可指枯燥的文体／生活）｜**vide**（adj. 空的——désert 强调「人烟」，vide 强调「无内容」）
- **母语干扰点**：法语 **désert** 与英语 **desert** 同源同形，但两语**区分「荒漠／甜点」的手段不同**：英语靠**重音**（'dɛzərt vs dɪ'zɜːrt）＋拼写，法语靠**重音符**（é）＋清浊（/z/ vs /s/）。书写法语时的**第一道防线就是那个 é**
- 相关：[[seul]]（seul / solitude——désert 引申义「孤寂」的近邻）

**n.m.** 沙漠、荒漠；（引申）荒无人烟之地、孤寂、隐居处、匮乏（un désert médical）｜**adj.** 荒芜的、无人居的、冷清的（une rue déserte）
