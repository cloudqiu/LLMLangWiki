# être

**释义**：（1）是（系动词）；（2）存在、在；（3）在（某处）；（n.m.）存在、生命体 ｜ exister ; se trouver ; (copule) relier le sujet à son attribut

**例句**
- _Je suis étudiant._ 我是学生。
- _Elle est à Paris._ 她在巴黎。
- _Ils sont fatigués._ 他们累了。

**形态要点**
- 动词：不定式 **être** ｜ **3e groupe**（极不规则，法语的「王牌不规则」）｜ 助动词 **avoir**（复合过去 j'**ai** été——être 自身用 avoir，不用 être）｜ 过去分词 **été**（不变）
- 现在时六形：je **suis** ｜ tu **es** ｜ il·elle **est** ｜ nous **sommes** ｜ vous **êtes** ｜ ils·elles **sont**
- 其他时态提示：未完成时 j'**étais**、将来时 je **serai**、简单过去 je **fus**、虚拟现在 que je **sois**——变位源于两个拉丁动词的拼接，故各时态词干互不相通（见词源）
- **作助动词**：être 是复合过去（passé composé）的助动词之一——用于①所有**代词式动词**（je me **suis** levé 我起床了）、②一批**表示位移/状态变化的不及物动词**（aller、venir、arriver、partir、naître、mourir、rester、tomber、monter 等——即「être 动词」）；用 être 作助动词时，过去分词须随主语**性数配合**（elle est partie ／ ils sont venus）

**词源 / 构词**
- **拆解**：现代 être 是**两个拉丁动词拼合**的「异干互补」（supplétion）：不定式 **être** ← 通俗拉丁 **essere** ← 古典拉丁 **esse**「是、存在」；而过去分词 **été**、未完成时 étais 则 ← 拉丁 **stare**「站」（statum → esté → été；stare 也是 [[rester]] 与英语 stand 的根）
- **演变**：拉丁 esse「是」＋ stare「站」→ 通俗拉丁 essere → 古法语 estre → 现代 être；现在时六形 suis/es/est/sommes/êtes/sont 直接承拉丁 sum/es/est/sumus/estis/sunt（esse），未完成/过去分词承 stare（据 TLFi，2026-10-01 经检索转引）；「是」与「站」合流，是印欧语「存在」义动词常见的混合现象
- **同族 / 派生**：étant（现在分词）、été（过去分词兼 n.m.「夏天」——été「夏天」与 été「曾是」同形，出拉丁 aestas，系**异源同形**勿混）、essence（本质——经拉丁 essentia）、essentiel（本质的）、intérêt（兴趣——出拉丁 interesse，= inter- + esse）；英语一侧见下节
- **记忆钩**：être ＝ esse（是）＋ stare（站）两股线编成一条绳——「站得住」就是「在/是」；现在时记「suis, es, est, sommes, êtes, sont」这六兄弟

**英法交叉核对（受影响的英语词）**
- **借入英语**：**entity**（1590s「实体」← 晚期拉丁 entitas ← ens ← esse「是」——etymonline，2026-10-01 经检索转引）；**essence**（late 14c.「本质」← 拉丁 essentia ← esse）；**essential**（← essentialis ← essentia）；**interest**（「兴趣、利息」← 拉丁 interesse「在…之间、关乎」= inter- + esse）；**absent / present**（← ab- / prae- + esse 的现在分词）；**future**（← futurus，esse 的将来分词）
- **共祖未借入**：英语 **is / am / are**（← PIE ***es-**「是」——与拉丁 est / sum **同出 PIE 根**，系最古老的同源词之一，**非借入**；etymonline *es- 词条已核）；英语 **be**（← PIE ***bheu-**「生长、成为」——**另一条根**，与 être/esse **无词源关系**，勿误连）
- 核对：已核实（etymonline，2026-10-01 经检索转引）——entity 1590s、essence late 14c. 均出拉丁 esse；is 出 PIE *es-ti-（同源词 Sanskrit asti / 希腊 esti / 拉丁 est）；be 出 PIE *bheu-（与 *es- 分属两词根）

**同义 / 搭配 / 易混**
- 搭配：`être + 形容词`（系动词，il est grand 他高）；`être + 地点`（在…处，elle est à Paris）；`être en train de + inf.`（正在做）；`c'est / ce sont`（这是——ce + être）；`il y a`（有——见 [[il-y-a]]，本出 il + y + avoir，非 être）
- **核心易混——「是/在」三词**：**être**（是、在——存在/系动词）vs **avoir**（有——属有；两词是复合过去的双助动词，分工见形态）vs **il y a**（有、存在——「某处有某物」，与 être 的「某人在某处」不同构）
- **语法陷阱**：être 作助动词时过去分词要**性数配合**（elle est allée）；用 avoir 时不配合（elle a mangé）——这是法语复合过去最大的失分点；être 自身的复合过去用 **avoir**（j'ai été），是高频例外
- 再易混：**été**（曾是）vs **été**（夏天 n.m.）——异源同形；**être**（是）vs **rester**（保持、停留——见 [[rester]]，rester 助动词才用 être）
