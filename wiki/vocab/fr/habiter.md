# habiter

**释义**：（1）**居住（在某处）**（habiter à Paris / habiter Paris 住在巴黎；habiter une maison 住一座房子）；（2）**定居于、栖息于**；（3）**（喻）驻于、充满（某人）**（la peur habite son regard 恐惧驻于他眼中） ｜ occuper un lieu comme demeure ; résider

**例句**
- _J'habite à Lyon depuis dix ans._ 我在里昂住了十年。
- _Ils habitent une vieille ferme._ 他们住在一座旧农场里。
- _Ce quartier est agréable à habiter._ 这个街区住着很舒服。

**形态要点**
- 动词：不定式 **habiter** ｜ **1er groupe**（规则）｜ 助动词 **avoir** ｜ 过去分词 **habité**
- 现在时六形：**j'habite**（省音）｜ tu habites ｜ il·elle habite ｜ nous habitons ｜ vous habitez ｜ ils·elles habitent
- **介词搭配（重点）**：`habiter à + 城市 / 农村`（habiter à Paris）｜ **`habiter + 城市`（不加介词，更雅）**（habiter Paris）｜ `habiter chez qn`（住在某人家）｜ `habiter dans + 建筑`（habiter dans un immeuble）
- 同族 / 派生：**habitant**（居民）、**habitation**（住宅）、**habitable**（可居住的，**1155**）、**habitacle**（座舱 / 住所）、**habitat**（生境）、**habitude**（习惯——同出 habere 一族）

**词源 / 构词**
- **拆解**：拉丁 **habitare**（**habere**「持有、拥有」的**反复态 / fréquentatif**，「反复持有（一处地方）」→「居住」）→ 古法 **habiter / abiter** → 现代 habiter
- **演变**：拉丁 habitare → 古法 habiter；**首见 12 世纪上半叶**（Usito 引 TLFi；Académie 1935「déb. XIIe」）——**一致，无两说**
- **同族 / 派生（法语）**：habitant、habitation、habitable、habitacle、habitat、habitude——**一整族 habere（持有）后代**
- **记忆钩**：habiter 的底是 **habere「持有」**——「居住」＝「**（反复）持有**一处地方」；同族的 habitude（习惯）也是「持有（的状态）」

**英法交叉核对（受影响的英语词）**
- **借入英语**：**inhabit**（mid-14c ← 古法语）；**habitation**（late 14c ← 古法）；**inhabitant**（late 15c ← 古法）；**habit**（n. ← 拉丁 habitus / 古法）——**皆经法语 / 拉丁**
- **共祖未借入（技术构词）**：**habitat**（**1762**）= **拉丁技术构词**（拉丁 habitare 的直构），**非经法语**——英语 1762 **早于**法语 **1818**，即英语 habitat 系拉丁直造、法语反向受影响——**参见英语页 [[habitat]]**
- **同义异源**：英语核心「居住」用 **live / dwell**（← 本族 / 日耳曼）——与 habiter **无亲缘**；英语 **dwell** ← OE dwellan「使迷路 / 居住」
- 核对：英语侧（inhabit mid-14c 经古法；habitat 1762 拉丁直造）经检索转引 etymonline（2026-10-11）；法语侧 12e 上半叶与 habitare 链据 TLFi / Usito / Académie 转引（**待验证**）
- **⭐ 本库互链**：英语页 [[habitat]]（1762 拉丁技术构词）与法语 habiter / habitat（1818）**同出拉丁 habitare**——两页互见

**同义 / 搭配 / 易混**
- 搭配：`habiter à / Ø + 城市`（habiter à Paris / habiter Paris）｜ `habiter chez qn`（住某人家）｜ `habiter en ville / à la campagne`（住城里 / 乡下——见 [[campagne]]）｜ `habiter au premier étage`（住在二楼）
- **易混**：**habiter**（居住——中性 / 常用）vs **vivre**（生活 / 活着）vs **demeurer**（居住——较正式）vs **résider**（居住——官方 / 行政）/ **loger**（住宿 / 安置）；**habiter** vs **[[vivre]]**（待收）
- 相关：[[habitat]]（英语页，同族互链）；[[campagne]]（habiter à la campagne）；[[ferme]]（habiter une ferme）
