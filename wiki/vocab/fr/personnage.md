# personnage

**释义**：（1）（小说、戏剧、电影等）人物、角色（le personnage principal 主人公；un personnage de roman 小说人物）；（2）大人物、要人（un grand personnage；un personnage historique）；（3）家伙、人物（带色彩——un drôle de personnage 一个怪家伙） ｜ être fictif d'une œuvre ; personne importante ; individu (souvent avec une nuance)

**例句**
- _Le personnage principal de ce roman est une jeune détective._ 这部小说的主人公是一位年轻女侦探。（见 [[roman]]、[[roman-policier]]、[[detective]]）
- _Elle incarne un personnage historique au cinéma._ 她在电影里饰演一位历史人物。（见 [[histoire]]）
- _C'est un drôle de personnage._ 这家伙是个怪人。

**形态要点**
- 名词：`le personnage`（m.）；复数 `les personnages`；**指女性也用阳性**（un personnage——même pour une femme）；文学中偶见阴性用法（罕见〔fr.wiktionary 引 Racine 研究，经检索转引〕）
- 常配定语：personnage **principal**（主角）/ **secondaire**（配角）；personnage **de fiction / de roman / de film / de théâtre**；**grand** personnage（大人物）；personnage **historique**（历史人物）
- 相关词分工：**personne**（人——一般名词，阴性；又作不定代词「没有人」）；**rôle**（角色——功能视角：jouer / tenir le rôle de…）；**caractère**（性格；「人物」义已旧）
- 惯用语：`entrer dans la peau de son personnage`（进入角色——演员）；`se déguiser en personnage de…`（装扮成……角色）
- 性别彩蛋：personnage 阳性而 personne 阴性——同一个拉丁 persona 来源的两种性别

**词源 / 构词**
- **拆解**：**personne**（n.f. 人）+ 名词后缀 **-age**（← 拉丁 **-aticum**）；中世纪拉丁中间形 **personaticum**（11c.——etymonline 记）/ **personagium**（fr.wiktionary 记）——两记并存；personne ← 拉丁 **persona**「（戏剧）面具、角色」→「人」
- **演变**：拉丁 persona → 古法语 **persone**（→ personne）→ 派生古法语 **personage**（**13c.**——「身材、地位；要人」义，etymonline 记〔经检索转引〕）→ 现代法语 personnage；法语侧首证年代**未得**（fr.wiktionary 记「← 拉丁 personagium」、世纪待考〔经检索转引〕）
- **persona「面具」来源之争（两说并列，不折中）**：OED（1989）曾连拉丁 **personare**「声音穿透」（面具开口传声）——但长音 ō 对不上；Klein / Barnhart 主张借自伊特鲁里亚语 **phersu**「面具」；De Vaan 词源词典未收〔etymonline「person」条，经检索转引〕
- **同族 / 派生（法语）**：personne、personnel（个人的；人员）、personnalité（人格；名人）、personnifier（拟人化）、personnification（拟人）
- **记忆钩**：persona 本是演员面具——面具 → 角色 → 人物 → 人；personnage 就是把「角色/人物」义钉死在名词里——小说里活动的是一张张「面具」

**英法交叉核对（受影响的英语词）**
- **借入英语**：**personage**（**mid-15c**——兼「人的体貌」与「要人、显贵」义；← 古法语 **personage**〔13c.〕← 中世纪拉丁 **personaticum**〔11c.〕← persona；1550s 起又用作 person 的加长替代，常带「自视甚高」的揶揄；今罕用）〔etymonline，2026-10-03 直连〕
- **借入英语（双重路径）**：**person**（**c. 1200** ← 古法语 **persone**〔12c.〕**并**直接 ← 拉丁 **persona**——法、拉双料借入；persona 本义即「面具」）；**personnel**（n. **1837** ← 法语 **personnel**——原为军事用语，与 **matériel** 对举；法语 personnel ← 古法语 personel ← 晚期拉丁 personalis ← persona）〔etymonline，直连〕
- 共祖未借入：无其他关键项（同出 persona 的英语 personality 等未逐核年代）
- 核对：2026-10-03——personage mid-15c ← 古法 personage 13c ← 中世纪拉丁 personaticum 11c、person c. 1200、personnel 1837（← 法语 personnel，与 matériel 对举）据 etymonline（直连）；persona「面具」与 personare / phersu 两说据 etymonline「person」条（经检索转引）

**同义 / 搭配 / 易混**
- 搭配：`le personnage principal / secondaire`（主角/配角）；`un personnage de fiction / de roman`；`un grand personnage`（大人物）；`un personnage historique`（历史人物）；`entrer dans la peau de son personnage`（进入角色）
- **易混**：**personnage**（人物、角色——作品内或社会上有分量的人）vs **personne**（人——最一般名词；代词义「没有人」）vs **rôle**（角色——功能/作用视角）vs **héros / héroïne**（主人翁、英雄）
- **faux ami**：英语 **personage** 罕用且偏「要人」义；「（小说）人物」英语说 **character**——别拿 personage 顶 character
- 文学语境：侦探小说（[[roman-policier]]）的看点常在 un personnage mystérieux（神秘人物——见 [[mysterieux]]）
