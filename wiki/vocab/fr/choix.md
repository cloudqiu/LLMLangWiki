# choix

**释义**：选择、挑选；选择权、选择余地 ｜ action de choisir ; liberté de choisir ; ensemble des options

**例句**
- _J'ai fait le bon choix._ 我做了正确的选择。
- _Tu n'as pas le choix._ 你别无选择。
- _Le choix est difficile._ 这个选择很难做。

**形态要点**
- 名词：`le choix`（m.）；**复数 `choix`（单复数同形**——词尾已为 -x，不再变化，les choix）
- 相关动词：**choisir**（选择、挑选——**2e groupe**，助动词 avoir，过去分词 choisi；je choisis / tu choisis / il choisit / nous choisissons / vous choisissez / ils choisissent）
- 高频搭配：`faire un choix`（做选择）、`avoir le choix`（有选择的余地）、`un choix difficile`（艰难的选择）、`par choix`（出于自愿、自愿地）

**词源 / 构词**
- **拆解**：动词 **choisir**「选择」← 古法语 choisir「挑选、分辨、看出」← **法兰克语 \*kausjan** 或其他日耳曼来源「尝、试、挑选」← PIE ***geus-**「尝、选」（「尝一口 → 判定 → 选」的语义链）
- **演变**：法兰克语 *kausjan「尝、试」→ 古法语 choisir「选」→ 名词 **choix**「选择」（由动词反衍/并列而来）；PIE *geus-「尝」也是英语 choose / 拉丁 gustare「尝」（法语 goûter 品尝）的根（据 TLFi 与 etymonline，2026-10-01 经检索转引）
- **同族 / 派生**：choisir（选择）、choisi（选定的、精选的）、goûter（品尝——出拉丁 gustare，同出 PIE *geus-「尝」的拉丁支）；英语一侧见下节
- **记忆钩**：choix 的祖先是「**尝**」——先尝后选，选 = 精挑细「尝」；「选（choisir）」与「尝（goûter）」在古印欧语里是同一张嘴干的事

**英法交叉核对（受影响的英语词）**
- **借入英语**：**choice**（n. mid-14c.「选择」← 古法语 **chois**「选择」（12c.，现代法语 choix）← choisir「选」← 法兰克语/日耳曼源，与古英语 ceosan「选、尝、试」同出 PIE *geus-——etymonline，2026-10-01 经检索转引；adj.「精选的、上等的」mid-14c.）
- **共祖未借入**：**choose**（英语本族词，古英语 ceosan ← 原始日耳曼 *keus- ← PIE *geus-「尝、选」——与法语 choisir 的日耳曼源**同出 PIE 根，系同源非借入**）；**gustatory / disgust**（出拉丁 gustare「尝」，同根的另一拉丁支）
- 核对：已核实（etymonline，2026-10-01 经检索转引）——choice(n.) mid-14c. ← 古法语 chois（12c.）；choose 古英语 ceosan ← PIE *geus-；etymonline 明言 choisir 出自法兰克/日耳曼源、与古英语 ceosan 相关。**注意**：choice 是「名词经法语借入」，choose 是「本族动词共祖」——借入与共祖在本词族里并列出现，是绝佳对比例

**同义 / 搭配 / 易混**
- 搭配：`faire un choix`（做选择）、`avoir le choix`（有选择余地）、`le choix entre A et B`（在 A 与 B 之间选择）、`par choix`（自愿地）、`un choix judicieux`（明智的选择）
- **核心易混**：**choix**（选择——名词）vs **choisir**（选择——动词，2e groupe）vs **goûter**（品尝——出拉丁 gustare，同根但「尝」义）；别把名词 choix 当动词用（「我选」是 je choisis，不是 je choix）
- **faux amis 警示**：choix / choice 形近义同，是英法同源对的好样本——但英语 choice 的 adj. 义「上等的」法语用 **de choix**（精选的，des fruits de choix 上等水果）而非 choice 本身
- 注意读音 /ʃwa/：-oi 读 /wa/，词尾 -x 不发音；choisir 读 /ʃwa.ziʁ/
