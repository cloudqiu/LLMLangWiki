# cacher

> 收录说明：inbox 形式 `cache` 为**多形同音**——可能是 cacher 的现在时变位（il cache 他藏起来）、过去分词/形容词 **caché**（un trésor caché 藏起来的宝物），或名词 **le cache**（藏匿处；摄影遮片；计算机「缓存」）——按 lemma 规则编译为动词不定式 **cacher**，三形在下文各自说明（若原意偏名词/形容词，可在本页追加说明——**待用户确认**）。

**释义**：（1）藏、把……藏起来（cacher un cadeau 藏礼物）；（2）隐瞒、掩饰（cacher la vérité à qn 对某人隐瞒真相）；（3）遮住、挡住（cacher la vue 挡住视线） ｜ mettre à l'abri des regards ; dissimuler ; masquer

**例句**
- _Elle cache les cadeaux dans le placard._ 她把礼物藏在柜子里。
- _Il cache la vérité à ses parents._ 他对父母隐瞒真相。
- _Les enfants se cachent derrière le canapé._ 孩子们躲在沙发后面。（代词式动词——见 [[verbes-pronominaux]]）

**形态要点**
- 动词：不定式 **cacher** ｜ **1er groupe** ｜ 助动词 **avoir** ｜ 过去分词 **caché**
- 现在时：je **cache** ｜ tu **caches** ｜ il·elle **cache** ｜ nous **cachons** ｜ vous **cachez** ｜ ils·elles **cachent**——标准 -er 变位，**无拼写变化**（c 在 a/o/u 前保持 /k/，不必变 ç）
- **代词式动词 se cacher**（躲藏——见 [[verbes-pronominaux]]）：je me cache ｜ tu te caches ｜ il se cache…；命令式 **cache-toi !**（躲起来！）；复合过去 il s'est caché
- 介词搭配：cacher qch **à** qn（对某人隐瞒某事——间接宾语用 à）；se cacher **derrière / sous / dans** qch（躲在……后面/下面/里面）
- 同族形：**un cache**（n.m. 藏匿处；摄影/印刷遮片；计算机「缓存」）；**caché, -e**（adj. 隐藏的——un trésor caché 藏宝〔见 [[tresor]]〕、caméra cachée 隐藏摄像机）；**cachette**（n.f. 藏匿处——en cachette 偷偷地）；**cache-cache**（n.m. 捉迷藏——jouer à cache-cache）

**词源 / 构词**
- **拆解**：通俗拉丁 \***coacticare**「压紧、攒存」（**fréquentatif** 反复体）← 拉丁 **coactare**「强迫、压紧」← **coactus**（**cogere** 的过去分词）← **cogere**「赶到一起」＝ **com-**「一起」+ **agere**「驱赶、推动」（PIE \***ag-**）→ 古法语 **quachier / cachier**〔fr.wiktionary 引 TLFi，2026-10-03 经检索转引；etymonline「cache」条同链——直连〕
- **语义演变**：古法语 escachier「压碎」→ quachier / cachier「压、挤」；**「隐藏」义 16 世纪前不多见，16c 起才由「压、盖住」义占主导**〔fr.wiktionary，经检索转引〕；cacher「藏」逐步取代 escondre、musser 等旧词；法语 cacher 首证 **13c.**（古法语 cachier——etymonline 记〔直连〕；法语侧 TLFi 原条未直连——**待验证**）
- **词源另说（如实并列）**：提示提及「法兰克语来源说」——本次所核两源（fr.wiktionary 引 TLFi；etymonline）**均只记拉丁 coactare 一线，未见表法兰克说**——不作实据、如实登记（**待验证**）
- **同族 / 派生（法语）**：cache、caché、cachette、cache-cache、**cachet**（← 古法语方言 cacher「压、挤」——「印章」义从「压印」来）、cachot（牢房）、cachotterie（故弄玄虚）、décacher / recacher
- **记忆钩**：cacher「藏」与 cachet「印章」是同族远亲——一支走「藏起来」，一支走「压下去」；而英语 **cache** 正是把 cacher 一族借去后成了「藏匿处 + 计算机缓存」

**英法交叉核对（受影响的英语词）**
- **借入英语**：**cache**（n. **1797**「藏匿处」← 法属加拿大皮草猎人法语行话〔1660s〕——即 cacher 一族的**逆构 / 截取形**；1830s 扩为「藏起来的一切东西」）〔etymonline，2026-10-03 直连〕；**计算机「缓存」义**为 20 世纪由「藏匿处」再引申（etymonline 原条未展开——**待验证**）
- **借入英语（同族双胞）**：**cachet**（1630s「封印」← 法语 **cachet**〔16c.〕← 古法语方言 **cacher**「压、挤」← 拉丁 coactare——与 cacher 同族但走「压印」义；18c. 经 **lettre de cachet**（盖印密札）发展，1840 起引申为「威望、独门特质」）〔etymonline，直连〕
- 共祖未借入：无关键项——英语本土 hide / conceal 各有其源，与 cacher 无关
- 核对：2026-10-03——cacher ← 通俗拉丁 \*coacticare ← coactare ← cogere（com- + agere，PIE \*ag-）为两源一致链（fr.wiktionary 引 TLFi——经检索转引；etymonline——直连）；英 cache 1797 / 行话 1660s、cachet 1630s / 16c. 据 etymonline（直连）

**同义 / 搭配 / 易混**
- 搭配：`cacher qch à qn`（对某人隐瞒某事）；`cacher son jeu`（隐藏意图——牌桌隐喻）；`se cacher derrière / sous / dans`（躲在……）；`jouer à cache-cache`（捉迷藏）；`en cachette`（偷偷地）；谚语 `l'arbre qui cache la forêt`（见树不见林）
- **易混（近形对）**：**cacher**（藏）vs **[[chercher]]**（找）——拼写只差一字母、意义一藏一找（捉迷藏 jeu de cache-cache 里两词都现身）；**cacher** vs **dissimuler**（文雅）vs **masquer / couvrir**（遮蔽、盖住）
- **同形异源提示**：另有形容词 **cacher** ＝ **casher**（犹太洁食）的变体，读 /ka.ʃɛʁ/——与动词 cacher /ka.ʃe/ 同形异源〔fr.wiktionary，经检索转引〕
- **faux ami**：英语 **cache**（/kæʃ/）即借自法语 cacher 一族的「藏匿处」词，现代又指「缓存」——同名同源，不是巧合；注意别与 **cachet**（/kaʃɛ/，印章；引申「威望」）混
