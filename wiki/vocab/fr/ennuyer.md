# ennuyer

> 收录说明：inbox 里的遇到形式是 **`ennuyais`**（直陈式未完成过去时 je / tu 形）——按 lemma 规则归并至不定式 **ennuyer**。

**释义**：（1）**使厌烦、使感到无聊**（Ce film m'ennuie 这电影让我觉得无聊）；（2）**使烦恼、使不安 / 使为难**（Cette nouvelle m'ennuie）；（3）**s'ennuyer 感到无聊、烦闷**（Je m'ennuie）；亦表「担忧、操心」；（4）**s'ennuyer de qqn 因某人不在而惦记**（文学 / 旧用法）｜ causer de l'ennui ; contrarier, tourmenter ; s'ennuyer = éprouver de l'ennui

**例句**
- _Tu m'ennuies avec tes questions._ 你的问题让我很烦。
- _Il s'ennuie ferme pendant les vacances._ 放假期间他无聊极了。
- _Je me suis ennuyé à ce concert._ 这场音乐会让我觉得很乏味。

**形态要点**
- 动词（变位要点）：不定式 **ennuyer** ｜ 组别：**1er groupe**（-yer 型，同 broyer / essuyer）｜ 助动词：**avoir** ｜ 过去分词：**ennuyé**
  现在时：j'**ennuie** ｜ tu ennuies ｜ il·elle ennuie ｜ nous ennuy**ons** ｜ vous ennuy**ez** ｜ ils·elles ennuient
  变位提示：**y → i** 只出现在「哑音 e 前」（ennuie / ennuies / ennuient），**-yons / -yez 保留 y**；1990 年正字法（orthographe rectifiée）允许 j'ennuye / tu ennuyes / il ennuye / ils ennuyent——**本库取传统拼写**
- 代动词：**s'ennuyer**（感到无聊）——注意及物 vs 代动词之别：*il m'ennuie*（他使我烦）vs *il s'ennuie*（他自己无聊）
- 易混：**ennuyeux**（令人厌烦的——指物 / 事）vs **ennuyé**（感到烦的——指人）

**词源 / 构词**
- **拆解**：古法 **enuier / enoier / anoier** ← 晚期拉丁 **inodiare**「使可憎」← 拉丁短语 **in odio esse**「être un objet de haine（成为憎恨的对象）」；词根 **odium**「仇恨」
- **首证**：**约 1100**——初作**过去分词形容词**，义「recru de fatigue（疲惫不堪）」，例 *chevalz… las et ennuiez*（《罗兰之歌》2484）；**ca 1135** 出现无人称用法「造成折磨」；**ca 1175** 出现代动词用法「对…感到厌倦」；Académie 9e 亦记 **XIe siècle**
- **演变（语义漂移——本词要点）**：原义强（道德痛苦、折磨、憎恶 ← odium 恨）→ 弱化为「烦恼、操心」→ **17 世纪起**得今义「使无聊 / 厌倦」；据 Académie 版次：5e（1798）仍作「lassitude, fatigue d'action d'esprit」，6e（1832–35）定型为「fatigue d'esprit」；18 世纪中期（Encyclopédie 1755）*ennui* 转指「缺乏乐趣」——**annoy → bore 的漂移在法语由强（痛苦）到弱（无聊）完成**
- **同族 / 派生（法语）**：**ennui**（n.m. 无聊 / 烦恼）、**ennuyeux**（adj. 令人厌烦的）、**ennuyé**（adj. 感到烦的）、ennuyant（较少用）
- **记忆钩**：ennuyer 的老底是「**恨**」（odium）——「无聊」原是一种**道德上的折磨**

**英法交叉核对（受影响的英语词）**
- **借入**：英语 **annoy**（中古英语 *anoien / annuien*，**late 13c.**）← 盎格鲁-法 *anuier* / 古法 *enoiier, anuier* ← 晚期拉丁 *inodiare*——**英语 annoy 与法语 ennuyer 是同一古法词源的两个后代**（法语继承、英语借入）；英语最早义「to harm, hurt; vex」保留了古法较强的语义层
- **借入（第二次）**：英语 **ennui**（n. **1660s** 以法语原词入英「weariness / tedium」；**1758** 本土化）——**同一词根的再度借入**，语义取自法语弱化后的「无聊」；另有借形 *ennuyé(e)*
- 核对：英语侧经检索转引 etymonline（2026-10-13）；法语侧 1100 / 1135 / 1175 据 TLFi / Académie 9e 转引（**待验证**）

**同义 / 搭配 / 易混**
- 搭配：`s'ennuyer à mourir`（无聊死）｜ `s'ennuyer ferme`（口语，极无聊）｜ `ennuyer qqn`（烦某人 / 使为难）｜ `s'ennuyer de qqn`（惦记某人）
- 同义：barber（口语）、lasser、importuner、embêter、agacer；反义：**intéresser**
- **易混**：**ennuyer**（使…烦，及物）vs **s'ennuyer**（自己无聊，代动词）；**ennuyeux**（物）vs **ennuyé**（人）
- 相关：[[interesser]]（反义）、[[detester]]（同情感域）
