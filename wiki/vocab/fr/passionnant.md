# passionnant

**释义**：引人入胜的、扣人心弦的、精彩极了的（un livre passionnant 一本引人入胜的书） ｜ qui passionne, très intéressant

**例句**
- _C'est un livre passionnant._ 这是一本引人入胜的书。（[[roman]]）
- _La discussion était passionnante._ 讨论非常精彩。
- _J'ai vu un documentaire passionnant sur les océans._ 我看了一部关于海洋的精彩纪录片。

**形态要点**
- 形容词：阳性 **passionnant** ｜ 阴性 **passionnante** ｜ 复数 passionnants / passionnantes
- **现在分词形容词化**（← passionner 的现在分词）——语义**主动**：「使人激动、使人着迷的」；性数随所修饰名词变化（un film passionnant / une histoire passionnante）
- 相关动词 **passionner**（使激动、使着迷；se passionner pour 热衷于——1er groupe，助 avoir，pp passionné）；名词 **passion**（激情；受难）

**词源 / 构词**
- **拆解**：**passionnant** ＝ **passionner**（使激动、使着迷）的**现在分词形容词化**（fr.wiktionary：participe présent adjectivé de passionner，引 TLFi）；passionner ← **passion** ← 晚期拉丁 **passio**「受苦、忍受」← **pati**「忍受、经历」（词源不明）——「使人动情 → 引人入胜」
- **演变**：拉丁 pati → 晚期拉丁 passio（基督教语境首义为**耶稣受难**）→ 古法语 passion（**10c.**，etymonline 载）→ 法语 passionner → passionnant；法语首证年代检索未得——**待验证**
- **同族 / 派生**：passion（激情、酷爱；la Passion 受难）、passionné（热情的、着迷的——过去分词形容词化）、passionnément、se passionner pour（热衷于）；英语一侧见下
- **记忆钩**：passio 本义「受苦」——激情是「折磨人的强烈情感」；「耶稣受难」= la Passion——同一个词：引人入胜的书就是让你「为它受折磨」的书

**英法交叉核对（受影响的英语词）**
- **借入英语**：**passion**（n. **c. 1200** ← 古法语 **passion**（10c.）← 晚期拉丁 **passionem / passio**「受苦、忍受」← **pati** 的过去分词词干；首义「基督受难」c. 1200 → 「殉道受难、痛苦」early 13c → 「情感、欲望」mid-13c → 「强烈情感」late 14c（译希腊 pathos）→ 「酷爱、热情」**1630s**；其借入淘汰了古英语本族词 þolung）；同族：**passionate**（← 中世纪拉丁 passionatus）、**passive / patience**（同出 pati——passivus / patientia，借入路径与年代**待验证**）
- **共祖未借入**：**thole**（古英语 þolian「忍受」——与拉丁 pati 同为表「忍受」的词，非借入；已被 passion 淘汰出常用域）
- 核对：已核实（etymonline，2026-10-03 直连）——passion c. 1200 ← 古法语 passion（10c.）← 晚期拉丁 passio/passionem ← pati（词源不明）；首义基督受难；「强烈情感」late 14c、「酷爱」1630s。法语侧：passionnant ＝ passionner 现在分词形容词化（fr.wiktionary 转引 TLFi）；法语首证年代**待验证**

**同义 / 搭配 / 易混**
- 搭配：`un livre passionnant`；`un débat passionnant`；`une histoire passionnante`；`un métier passionnant`（一份迷人的职业）
- **三板斧辨析（本页重点）**：**passionnant**（**物**——令人着迷的、引人入胜的：un film passionnant）｜ **passionné**（**人**——热情的、着迷的：un lecteur passionné；亦修饰强烈情感：un amour passionné）｜ **[[interesser|intéressant]]**（有趣的——程度最轻、最中性：un livre intéressant）
- **规律（-ant / -é 对照组）**：现在分词 -ant ＝ 主动「令人……的」（passionnant / intéressant）；过去分词 -é ＝ 被动「感到……的」（passionné / intéressé）——同型：surprenant / surpris、fatigant / fatigué
- 近义：passionnant（引人入胜）｜ captivant（扣人心弦）｜ fascinant（令人着迷）｜ prenant（扣人心弦——fr.wiktionary 列 synonyms：envoûtant, prenant, fascinant）
- 链：[[roman]]（小说）· [[interesser]]（intéressant / intéressé 易混对）
