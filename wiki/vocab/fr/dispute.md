# dispute

**释义**：争吵、争执、口角 ｜ querelle ; échange de propos vifs, altercation

**例句**
- _Ils ont eu une dispute hier soir._ 他们昨晚吵了一架。
- _Une dispute a éclaté entre les deux frères._ 两兄弟之间爆发了一场争吵。
- _La dispute portait sur l'argent._ 这场争执是关于钱的。

**形态要点**
- 名词：`la dispute`（f.）；复数 `les disputes`
- 相关动词：**se disputer**（争吵——se disputer avec qn 跟某人吵架）；**disputer**（1er groupe：争论、争夺——disputer un match 打比赛、disputer la victoire 争夺胜利）；过去分词 disputé
- 注意：法语 **dispute** 是**名词**（口角），「争吵」这个动作常说 **se disputer**（代词式动词）；而英语 dispute 既是名词也是动词

**词源 / 构词**
- **拆解**：拉丁 **disputare**「衡量、讨论、争论」＝ **dis-**（分开）+ **putare**「计算、考虑」（本义「修剪、清理」，PIE ***pau-**（2）「切、打」）——「分开来算/理清」→「辩论、争论」
- **演变**：拉丁 disputare「讨论、争论」→ 古法语 **desputer**（12c.，etymonline 转引）→ disputer（争论、争夺）→ 名词 **dispute**（由动词派生，偏「口角、争执」）；拉丁 disputare 在《武加大译本》已用「争辩」义
- **同族 / 派生（法语）**：disputer（争论、争夺）、se disputer（争吵）、disputable（可争辩的）、indisputable（无可争辩的）；英语一侧见下节
- **记忆钩**：dispute 的「put-」不是「放」而是「算」——dis-（分开）+ putare（算）＝「各算各的账」→「争起来」；putare「修剪」本义也藏在英语 amputate（截肢）里

**英法交叉核对（受影响的英语词）**
- **借入英语**：**dispute**（v. c. 1300「争论、讨论」← 古法语 **desputer**〔12c.〕并直承拉丁 disputare〔etymonline，2026-10-01 经检索转引〕；n. c. 1300「争辩」——「contention, strife, quarrel」义 1610s）；**disputation**（late 14c. ← 古法语 desputasion / 拉丁 disputationem）；**disputable**（1540s ← 法语 disputable 或直承拉丁 disputabilis）
- **共祖未借入**：**disputant**（1610s ← 拉丁 disputantem，disputare 的现在分词——直承拉丁）；**indisputable**（由英语 dispute 派生，与法语 indisputable 平行构词）
- 核对：已核实（etymonline，2026-10-01 经检索转引）——dispute v. c. 1300（← 古法语 desputer 12c. + 直承拉丁 disputare ← dis- + putare「计算/修剪」）；n. c. 1300，quarrel 义 1610s；「put-」＝「算」的线索经 amputate / dispute 同族可证

**同义 / 搭配 / 易混**
- 搭配：`avoir une dispute (avec qn)`（与某人吵架）；`se disputer avec qn`（与某人争吵）；`provoquer une dispute`（挑起争执）；`une dispute familiale`（家庭争执）
- **核心辨析（冲突等级）**：**dispute**（口角、争吵——日常、情绪化的拌嘴）vs **querelle**（争执、纠纷——更持久、可涉及名分/利益，querelle de famille 家产纠纷）vs **conflit**（冲突——更严重，可指战争、利益冲突 conflit d'intérêts）vs **débat**（辩论——理性、有议题的讨论）
- **faux ami**：英语 dispute 偏中性（争议、争论，可正式：a legal dispute 法律纠纷）；法语 dispute 偏「口角、吵架」（更口语、情绪化）——**义域有漂移**：法语「法律纠纷」用 litige 不用 dispute
