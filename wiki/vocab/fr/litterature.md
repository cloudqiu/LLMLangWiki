# littérature

**释义**：（1）文学、文学作品；（2）（关于某主题的）文献（la littérature sur un sujet） ｜ ensemble des œuvres écrites ; les écrits sur un sujet

**例句**
- _Elle étudie la littérature française._ 她学习法国文学。
- _J'aime la littérature du XIXe siècle._ 我喜欢 19 世纪的文学。
- _Il y a beaucoup de littérature sur ce sujet._ 关于这个主题有很多文献。

**形态要点**
- 名词：`la littérature`（f.）；复数 `les littératures`；-ature 尾（同 nature、candidature、signature）

**词源 / 构词**
- **拆解**：拉丁 **littera**「字母」＋ **-tura**（表行为/结果的名词尾）→ **litteratura**「书写、文字之学」
- **演变**：拉丁 littera「字母」→ litteratura「文字、学识」→ 法语 littérature（「用字母写成的艺术」；最早见于 1121–1134 年 Philippe de Thaon《Bestiaire》，义为「所写之物、字面义」，据 CNRTL，2026-10-01 经检索转引）；法语「文学」义在中世纪后逐步定型为「美的书写」
- **同族 / 派生**：lettre（字母、书信）、littéraire（文学的）、littéral（字面的）、illettré（不识字的）、lettré（有学问的）；英语一侧见下节
- **记忆钩**：littérature ＝ littera「字母」的集合艺术——「文学」就是「字母的艺术」；同根 lettre（书信/字母）是它的日常近亲

**英法交叉核对（受影响的英语词）**
- **借入英语**：**literature**（← 法语 littérature ← 拉丁 litteratura；入英 early 15c.，原作 litterature；据 etymonline，2026-10-01 经检索转引）；**letter**（← 古法语 lettre ← 拉丁 littera「字母」——英语 letter 兼「字母」与「书信」两义，与法语 lettre 对齐）；**literal / literate / literacy / literary / alliteration**（← 拉丁 littera 家族——literal 14c. 末 ← 晚期拉丁 literalis；literate 15c. 初 ← 拉丁 literatus；literacy 系 1883 年英语自 literate 新造；literary ← 拉丁 litterarius（以上据 etymonline，2026-10-01 经检索转引）；alliteration 路径仍**待验证**）；**belles-lettres**（← 法语 belles lettres「美文学」，原样借入）
- **共祖未借入**：无显著（littera 家族几乎都经拉丁/法语入英，属借入线）
- 核对：literature 入英 early 15c.（原作 litterature，义「book-learning」，← 拉丁 literatura/litteratura；据 etymonline，2026-10-01 经检索转引）；-litter- → -liter- 拼写简并年代未核实，仍标**待验证**——2026-10-01 清账

**同义 / 搭配 / 易混**
- 搭配：`la littérature française / du XIXe siècle`；`étudier / enseigner la littérature`；`la littérature sur un sujet`（某主题文献）
- 易混：**la littérature**（文学）vs **la lecture**（阅读——lecture ← 拉丁 legere「读」，别混！）；**littéraire**（文学的——形容词）vs **littéral**（字面的）；**les lettres**（文学、文科——les lettres françaises 亦指「文学」）
- **faux ami**：literature / littérature 基本对齐（都兼「文学」与「文献」），非典型 faux ami
