# trésor

**释义**：（1）宝藏、宝物（un trésor caché 埋藏的宝藏）；（2）珍品、珍宝（les trésors d'un musée 博物馆的珍宝）；（3）财富、财宝；（4）大写 Trésor：国库、国家财政（le Trésor public）；（5）昵称：宝贝、亲爱的（mon trésor） ｜ ensemble de biens précieux ; (Trésor) finances de l'État ; terme d'affection

**例句**
- _Ils ont trouvé un trésor caché dans la grotte._ 他们在山洞里发现了埋藏的宝藏。
- _Ce musée conserve des trésors artistiques._ 这座博物馆收藏着艺术珍品。
- _Mon trésor, je t'aime._ 我的宝贝，我爱你。

**形态要点**
- 名词：`le trésor`（m.）；复数 `les trésors`
- 大写专指国家财政：`le Trésor`（国库、金库——法国国家财政机构）、`le Trésor public`（国库；文献中「thresor public」对译拉丁 fiscus 1671 已见——CNRTL，2026-10-03 经检索转引）
- 常见搭配：`un trésor de guerre`（战争基金、压箱底的本钱）、`la chasse au trésor`（寻宝游戏）、`un trésor de + 名词`（大量的、极宝贵的……——un trésor de patience 极大的耐心）、`mon (petit) trésor`（我的宝贝——昵称）

**词源 / 构词**
- **拆解**：拉丁 **thesaurus**「宝库、宝藏」← 希腊 **thēsauros**（θησαυρός）「宝库、贮藏、宝物」；thēsauros 与希腊 tithenai「放置」相关——一说 ← PIE 根 **\*dhe-**「放置」（Watkins 说）；Beekes 则判其「无词源，疑为前希腊语借词」——**两说并列，不折中**（etymonline，2026-10-03 经检索转引）
- **演变**：希腊 thēsauros → 拉丁 thesaurus → 高卢罗曼语 **\*tresaurus**（r 音**换位**——thesaurus → tresaurus）→ 古法语 **tresor**；法语 trésor **约 1050 首证**于《圣阿莱克西斯传》（Vie de saint Alexis：「De lur tresors prenent l'or e l'argent」他们从君王财库取出金银），义「君主可支配的财源」；此后 ca 1100《罗兰之歌》；12 世纪初「珍藏的宝物」义（Benedeit, St Brendan）；1135 一般义（Wace）——（CNRTL，2026-10-03 经检索转引）
- **同族 / 派生（法语）**：trésorerie（资金、现金状况；财政机构）、trésorier / trésorière（司库、财务主管）；**thésaurus**（词库、术语库——20 世纪学术借词，与 trésor 同出拉丁 thesaurus 而分途，见下节——「同源分途」活标本）
- **记忆钩**：三个兄弟——**trésor / treasure / thesaurus**：同一个希腊词 thēsauros「宝库」，一路经法语进英语成 treasure，一路由拉丁原封不动搬进英语成 thesaurus（词库——「词汇的宝库」）；法语自己守着 trésor。Roget 1852 年把新义「词汇集」装进 thesaurus 这只老瓶，让「宝库」义复活

**英法交叉核对（受影响的英语词）**
- **借入英语**：**treasure**（英 mid-12c. 形 tresor / tresour「积聚的钱财珍宝」← 古法语 **tresor**（11c.）← 高卢罗曼语 \*tresaurus ← 拉丁 thesaurus；家族另有 **treasury**（c. 1300）、**treasurer**（late 13c.）、**treasure trove**（late 14c. ← 盎格鲁法语 tresor trové，对译拉丁 thesaurus inventus「拾得之宝」，字面「找到的宝藏」）——etymonline，2026-10-03 经检索转引）；德语 **Tresor**（19c. 末回借自法语 trésor——**反方向借词**，可注意；DWDS，同上）
- **共祖未借入**：**thesaurus**（英 1823 年入英义「treasury, storehouse」，**直借拉丁 thesaurus**；1840 得「知识大全」义、1852 经 Roget 得「按义类编排的词汇集」义——与法语 trésor 同出希腊 thēsauros，但走「希腊 → 拉丁 → 英语」直借线，**非经法语**——「thesaurus / treasure / trésor 三兄弟」一目了然）
- 核对：已核实（etymonline / CNRTL 转引，2026-10-03）——trésor 约 1050 首证（Vie de saint Alexis）；英 treasure mid-12c. ← 古法语 tresor（11c.）← \*tresaurus ← thesaurus；thesaurus 1823 直借拉丁（1852 Roget 义）；treasure trove late 14c. ← tresor trové；德语 Tresor 反向借自法语。thēsauros 深层词源两说如实并列（\*dhe- 说 vs Beekes 前希腊语说）

**同义 / 搭配 / 易混**
- 搭配：`le Trésor (public)`（国库）；`un trésor de guerre`（战争基金）；`la chasse au trésor`（寻宝游戏）；`un trésor de patience`（极大的耐心）；`mon trésor`（我的宝贝）；`cacher / enfouir un trésor`（藏宝、埋宝）
- **辨析**：**trésor**（宝藏——实物或抽象的大量财宝）vs **trésorerie**（资金、现金状况——企业/行政财务用语）vs **richesse**（财富——总称）vs **[[precieux]]**（珍贵的——形容词，宝藏的定语好搭档：des objets précieux 正是 trésor 的组成）
- **faux ami**：大写 **le Trésor** 是法国的「国库」（对应英 the Treasury / US Treasury），行政语境高频；`mon trésor` 作昵称对应英语 my darling / sweetie——照搬 treasure 会怪
