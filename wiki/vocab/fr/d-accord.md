# d'accord

> 收录说明：inbox 形式 `d'accord`——按多词单位（v1.5）独立建页（**de + accord** 的黏合形，撇号转写为连字符 → `d-accord.md`）；核在 **cor「心」**，与 [[courageux]] 同根。

**释义**：（1）同意、赞成（être d'accord avec qn / sur qch）；（2）**D'accord !** 好的、行、成（表同意或认可） ｜ du même avis, en accord ; « D'accord ! » = formule d'acquiescement

**例句**
- _Je suis d'accord avec toi._ 我同意你（的看法）。
- _Nous sommes d'accord sur ce point._ 在这一点上我们看法一致。
- _— On se voit à midi ? — D'accord !_ ——我们中午见？——好的！

**形态要点**
- **构成**：**de**（在元音前省作 **d'**）＋ **accord**——d'accord /d‿akɔʁ/（联诵）
- **核心句法（介词搭配，必记）**：**être d'accord avec qn**（同意**某人**）/ **être d'accord sur qch**（在某**事**上同意）；**se mettre d'accord**（达成一致）、**tomber d'accord**（取得一致）、**mettre d'accord**（使一致，调和）
- **独立用法**：**D'accord !** ＝ OK、行、成（认可对方提议）；升调 **D'accord ?** ＝「行吗？/ 同意吗？」（求确认）；**Pas d'accord !** ＝「不同意！」
- **词性**：être d'accord 中 d'accord 为**形容词性短语**（表状态，主语随之变：je suis / nous sommes d'accord）；单独成句时为**感叹 / 应答词**（interjection）
- 语域：口语高频；正式场合同样通用（中性）——书面更正式可作 **être en accord avec**（与……一致：en accord avec la loi）

**词源 / 构词**
- **拆解（accord）**：← 通俗拉丁 **\*accordare**「使同心」＝ 拉丁 **ad**「向」+ **cor / cordis**「心」（← PIE **\*kerd-**「心」，兼喻「灵魂、心智」）；古法语 **acord / acorde**「同心、一致」
- **演变**：古法 **acorder**（v.，约 12 世纪初）→ 名词 **acord**（英语借入时作 late 13c. 形）；法语本线 acord → **accord**（**词源学拼写加 d**，回映拉丁 cord-）→ 现代法语 accord「一致、协定、和弦」
  - 义项链：本义「**同心**」→「意见一致」→「协定、条约」（les accords de Genève）→ 音乐「**和弦**」（数音「同心」和鸣）
- **同族 / 派生（法语）**：accorder（v. 使一致；调音；给予）、accordéon（手风琴）、désaccord（不和）、**cor / cord-** 一族：courage（← 古法 corage）、cordial、cœur（← 拉丁 cor）
- **记忆钩**：accord 的核是「**心**」（cord-）——d'accord 字面＝「（彼此）是同一条心」；与 [[courageux]]（勇气＝「心气」）共用同一个拉丁 **cor**——「一条心」即「同意」，「有心」即「有勇」

**英法交叉核对（受影响的英语词）**
- **借入英语（同源借入：经古法入英）**：英 **`accord`**（v. **early 12c.** *accorden*「达成一致」← 古法 **acorder** ← 通俗拉丁 **\*accordare**「使同心」，字面「be of one heart, bring heart to heart」）；英 **`accord`**（n. **late 13c.** *accourd / acord*「一致、和谐」← 古法 **acorde / acort**，由 acorder **逆构**）——与法语 accord **同一来源、经古法入英**；派生 `according`、`accordance`、`accordant`、`accordion`、`disaccord`；义项「of one's own accord」（自愿）**mid-15c.**
- **共祖（PIE \*kerd-「心」，非经法语借入）**：英 `concord`（一致）、`discord`（不和）、`record`（记录）、`chord`（弦 / 和弦）、`according`（见上）——拉丁 / 希腊直借或本族，**与法语 accord 共祖而非法语传入**（\*kerd- 词表见 etymonline *accord* 条）
  - 同根另记（**待验证**）：`courage`（← 古法 corage ← \*cor，见 [[courageux]]）、`cardiac`（← 希腊 kardia ← \*kerd-）——常见词源学归入 \*kerd-，**etymonline *accord* 条未逐一列出，未逐条直核**
- **双向互链**：本页 ↔ [[courageux]]（同出拉丁 **cor**「心」）——两页互为词族证据（hub 的「cœur / cor『心』词族」候选）
- 核对：accord v. early 12c. / n. late 13c.、\*accordare ＝ ad + cor（cordis）「be of one heart」、PIE \*kerd-、相关词 concord / discord / according / accordance / accordant / accordion / chord / disaccord / of one's own accord (mid-15c.)，均据 **etymonline 直读**（2026-10-04）；「courage / cardiac 属 \*kerd-」**待验证**（未逐条直读）。

**同义 / 搭配 / 易混**
- 搭配：`être d'accord avec qn` / `sur qch`；`se mettre d'accord`；`tomber d'accord`；`mettre d'accord`；`d'accord !`；`pas d'accord`
- 同义（应答 / 表态）：`OK`、`entendu`（说定了）、`ça marche`（行）、`tout à fait`（完全同意）、`bien sûr`（当然）
- **易混（同形异指）**：**d'accord**（同意）vs **accord**（协定、和弦）；_être d'accord_（表状态）vs _être en accord avec_（更书面「与……相符 / 一致」）
- **易混（近义应答词）**：`entendu`（侧重「说定了、一言为定」）vs `d'accord`（侧重「我同意」）vs `ça marche`（口语「成交 / 行」）
- 相关：[[courageux]]（同根 cor「心」）、[[etre]]、[[parler]]、[[meme-si]]
