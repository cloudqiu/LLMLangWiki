# paire

**释义**：一双、一对（由两个相配或成对的东西组成） ｜ ensemble de deux choses identiques ou symétriques

**例句**
- _Il a acheté une paire de chaussures._ 他买了一双鞋。
- _Une paire de lunettes coûte cher._ 一副眼镜很贵。
- _Ces deux-là font une belle paire._ 那两个人真是绝配（一对）。

**形态要点**
- 名词：`la paire`（f.）；复数 `paires`（规则加 -s）
- 搭配：`une paire de + 名词`（一双/一副……：une paire de gants 一副手套、une paire de ciseaux 一把剪刀）——量词结构，所量名词用复数（chaussures / lunettes）
- 辨析（同音词）：**paire**（一双，f.）｜ **pair**（偶数；贵族/同辈，m.）｜ **père**（父亲，m.）——三者都读 /pɛʁ/，拼写与词义完全不同
- 提示：名词 **pair** 用于 `aller de pair avec`（与……相配、并行）——这里的 pair 是「对等、同辈」

**词源 / 构词**
- 拆解：拉丁 **paria**「一对、一双」（= **par**「相等的、成对的」的中性复数——「两个相等的东西」）→ 古法语 paire → 法语 paire
- 演变：拉丁 **par**「相等的」→ 中性复数 **paria**「一对」→ 法语 paire；同根的 pair（偶数、对等）与 paire 同源而分流（据 CNRTL/TLFi 转引，2026-10-01 经检索转引；paire 具体定年待验证）
- 同族 / 派生：**pair**（偶数；贵族）、**pair**（对等——aller de pair）、**parité**（对等、均等）、**apparier**（配对）；英语一侧见下节
- 记忆钩：par-（相等）+ -ia（中性复数）＝「两个相等的东西」＝「一对」；「一双鞋」就是「两只成对的鞋」

**英法交叉核对（受影响的英语词）**
- 借入英语：**pair**（「一对」← 古法语 paire ← 拉丁 paria「成对之物」，c.1300）；**peer**（「同辈、贵族」← 古法语 per ← 拉丁 par「相等的人」——「与你对等的人」→「贵族」，c.1300）；**par**（「票面价值、标准」← 拉丁 par「相等」——「等价」义，17c）
- 共祖未借入：（无——均为拉丁 par 一系经古法语借入）
- 核对：pair ← paire ← paria；peer（贵族）← per ← par；par ← par——据 etymonline 转引（「from Old French paire … directly from Medieval Latin p[aria]」，2026-10-01 经检索转引）；注意动词 peer「凝视」出 appear，与「同辈」义无关，勿混

**同义 / 搭配 / 易混**
- 搭配：`une paire de + 复数名词`（一双/一副）；`aller de pair avec`（与……并行）；`faire la paire`（凑成一对）
- 易混（同音 trio）：**paire**（一双，f.）｜ **pair**（偶数 / 贵族，m.）｜ **père**（父亲，m.）——写错即成「父亲」
- 提示：法语「一双鞋」＝ une paire de chaussures（chaussures 复数）；「一副眼镜」＝ une paire de lunettes（lunettes 恒为复数）
