# quoi

> 收录说明：inbox 形式 `quoi` 直接为词形。本页按**疑问代词 + 关系代词**双功能办语法重点页——与 [[qui]]（主格）、[[que-penses-tu-de]] 的 que（宾格）合读，构成法语的「疑问词格位三分」。

**释义**：（1）（**疑问代词**）什么——用于**重读、独用或介词后**（Quoi ? 什么？；À quoi penses-tu ? 你在想什么？）；（2）（**关系代词**，中性、指物）……的东西——**须带介词**（ce **à quoi** je pense 我所想的事）；（3）（**感叹 / 惊愕**）什么！（Quoi ! Tu pars ?）；（4）口语里**留在原位**问「什么」（Tu fais quoi ? 你干嘛？）；（5）名词化 **le quoi**（常与 le comment / le pourquoi 对举） ｜ pron. interr. neutre « quelle chose ? » ; pron. rel. neutre, employé après préposition (« ce à quoi ») ; interj. marquant la surprise

**例句**
- _Quoi ? Tu pars déjà ?_ 什么？你这就走了？（独用疑问，重读）
- _À quoi penses-tu ?_ 你在想什么？（**介词后只能用 quoi**，不能用 que）
- _C'est quoi, ce truc ?_ 这是什么玩意儿？（口语，quoi 留在原位）
- _Je ne sais pas de quoi il parle._ 我不知道他在说什么。（间接疑问：de + quoi）
- _Il n'y a pas de quoi._ 不客气。（＝「没什么」，固定语）
- _Quoi que tu fasses, fais-le bien._ 无论你做什么，都要把它做好。（**quoi que 分写** + subjonctif，让步）

**用法要点**
- **一句话分工（本页核心）**：**qui 主格 / que 宾格 / quoi 重读·介词后**——三者同属拉丁 quid / quis 一族（见「词源」）。
- **重读 vs 非重读（关键机制）**：**que** 是**非重读（clitique）形**——紧贴动词前（**Que** fais-tu ?），元音前**省音 qu'**（Qu'est-ce **qu'**il fait，见 [[que-penses-tu-de]]）；**quoi** 是**重读（tonique）形**——独用、句末，或**介词之后**（à quoi / de quoi / avec quoi / sur quoi）。二者同出拉丁 **quid**，一强一弱，正如 **me / moi**、**se / soi**、**le / lui**、**ils / eux**（见 [[eux]]）的重读对。
- **介词后铁律**：介词 + 疑问「什么」**一律用 quoi**，绝不用 que——À quoi ? / De quoi ? / Avec quoi ?（\*À que、\*De que 不成立）。这正是关系代词用法的来源：**ce à quoi / ce de quoi / ce sur quoi**（中性先行 ce + 介词 + quoi）。
- **三语域问「什么」**：**Que fais-tu ?**（正式，que 前置倒装）｜ **Qu'est-ce que tu fais ?**（口语最常用）｜ **Tu fais quoi ?**（极口语，quoi 原位）——同义不同体。
- **qui 不省音、quoi 不省音**：只有 **que** 省音成 **qu'**——别写成 \*qu'a（见 [[qui]] 的易错点）。

**词源 / 构词**
- **拆解**：单语素——拉丁 **quid**「什么、哪件事」，是疑问代词 **quis** 的**中性形**；疑问词干 **\*kʷi-** 与关系词干 **\*kʷo-** 长期**互相渗透**（quem、quibus 即借自 quis 一支，故拉丁疑问/关系代词变格不规则）〔Ernout-Meillet《拉丁语词源词典》，2026-10-05 经检索转引〕
- **演变（CNRTL/TLFi，2026-10-05 转引）**：
  - 拉丁 **quid** → 古法语 **quei / quoi**；**ca 1050** 以**介词短语**形式首见（《圣 Alexis 传》éd. Storey, 131——**TLFi 首证**，直接引语体）
  - **ca 1170** 间接疑问（Béroul《Tristan》3412）；其后**不带介词**作疑问代词（《Rois》）；**ca 1180** 省略 / 感叹用法（Marie de France《Fables》）
  - **关系代词**：**1174-76** 带先行词（指物，古法语亦可指人）；**ca 1165** 回指上文（« i ot de quei »）；**1773** « il n'y a pas de quoi »（D'Alembert）
  - **不定关系**：**1179** « quei que »（Philippe de Thaon）；**fin XIVe-début XVe s.** « quoy que ce soit »；**1580** « quoy qu'il en soit »（Montaigne）
- **同族 / 派生（法语）**：**que**（← quid，非重读形——见 [[que-penses-tu-de]]）、**qui**（← qui，见 [[qui]]）、**quel**（← qualis，见 [[quel]]）、**pourquoi**（pour + quoi，见 [[pourquoi]]）、**comment**（← quomodo，见 [[comment]]）、**quoi que**（分写）/ **quoique**（合写「虽然」）、**n'importe quoi**（随便什么）、**quoi que ce soit**（无论什么）、**ce à quoi / de quoi**（关系）
- **记忆钩**：quid **一分为二**——弱读挤在动词前成了 **que**，重读蹦到后头成了 **quoi**；与 me/moi、se/soi 是同一套「强弱形」机制

**英法交叉核对（受影响的英语词）**
- **借入英语**：无——quoi 本身未被英语借入（英语本族疑问词自成系统）。旁支：英语 **`quid pro quo`**（1560s）、**`status quo`** 里的 **quo / quid** 是**直接借拉丁**，非经法语（见 [[pourquoi]]）
- **共祖未借入（本页核心）**：英语 **`what`** ← 古英语 **hwæt** ← 原始日耳曼 **\*hwat** ← PIE **\*kwod**——etymonline 明言 \*kwod 是 **\*kwos「who」的中性单数**，并加注「**Corresponding to Latin quid**」（正对应拉丁 quid）——故 **quoi 与 what 是同一个中性疑问词的共祖远亲**（法语走拉丁 quid、英语走日耳曼 \*hwat），**双向均非借入**；同族 **`who` · `whom` · `whose` · `which` · `when` · `where` · `why` · `how`** 亦同出 PIE **\*kʷo-**（同型：[[qui]]↔who、[[quel]]↔which、[[comment]]↔how、[[pourquoi]]↔why）
- 核对：英语侧（what ← OE hwæt ← PGmc \*hwat ← PIE \*kwod「\*kwos 的中性」，etymonline 明注正对拉丁 quid）2026-10-05 经 **etymonline 直读**；法语侧（quid、\*kʷi-/\*kʷo- 两词干渗透、TLFi 首证 ca 1050 Alexis 131 及各义项年代）2026-10-05 经 **WebSearch 转引 CNRTL/TLFi**（cnrtl.fr/etymologie/quoi 被检索引出，直连仍 sinkhole）与 **fr.wiktionary**。**待验证**：①TLFi「quoi」原条首证定年未直连（现为转引 ca 1050）；②古法 quei / quoi 拼写过渡年代未逐核

**同义 / 搭配 / 易混**
- 搭配：`Quoi ?`（什么？）｜ `À quoi bon ?`（何必呢）｜ `de quoi`（材料／手段；il n'y a pas de quoi 不客气）｜ `n'importe quoi`（随便什么／胡来）｜ `quoi que`（无论什么，+ subj.）｜ `comme quoi`（可见、大意是）｜ `Quoi de neuf ?`（有什么新闻？）｜ `sans quoi`（否则）
- **易混（核心，疑问词格位三分）**：**qui**（问**人**／关系从句**主语**——见 [[qui]]）｜ **que**（问**物**／非重读·动词前，省音 qu'——见 [[que-penses-tu-de]]）｜ **quoi**（问「什么」的**重读形 · 介词后**——本页）｜ **quel**（「哪个」+ 名词——见 [[quel]]）
- 与 [[pourquoi]] / [[comment]] 并列：pourquoi 问原因、comment 问方式、quoi 问「什么东西」——同出 \*kʷo- 一族
- **faux ami / 顺口误**：\*À que penses-tu ? 错 → **À quoi penses-tu ?**；\*De que parles-tu ? 错 → **De quoi parles-tu ?**——介词后一律 quoi
