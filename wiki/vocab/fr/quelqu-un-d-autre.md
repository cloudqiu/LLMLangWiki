# quelqu'un d'autre

**释义**：pron. indéfini **另一个人、别人、其他人** ｜ une autre personne, une personne différente

**例句**
- _Il y a quelqu'un d'autre dans la salle ?_ 房间里还有别人吗？
- _Je voudrais parler à quelqu'un d'autre._ 我想跟别人谈。
- _Ce n'est pas moi, c'est quelqu'un d'autre._ 不是我，是别人。

**形态要点**
- 代词短语：缩写 **qqn**；阴性 **quelqu'une d'autre**；复数 **quelques-uns d'autres**（罕用）
- 构词：**quelqu'un** + **d'autre**——**de 不可省**（元音前省音作 *d'*）
- 否定：否定句要换成 **personne d'autre**（没有别人）——*quelqu'un d'autre* 不能留在否定语境里

**词源 / 构词**
- 拆解（三层复合）：
  - **quelqu'un** = **quelque** + **un**。*quelque*（**XIIe s.**，由 **quel + que** 复合，*quel* ← 拉丁 **qualis**「何种的」）+ *un*（← 拉丁 **ūnus**「一」）
  - **d'autre** = **de** + **autre**。*autre* ← 古法语 **altre** ← 拉丁 **alter**「另一个、他人、相反的」
- 演变：拉丁 *qualis* + *unus* → 古法语 *quelcun / quescun* → 现代 *quelqu'un*；拉丁 *alter* → 古法 *altre* → 现代 *autre*
- 首证（诸说并列，不折中）：整体 **quelqu'un**——Académie 9e 记 **XIIIe siècle**（«Composé de l'adjectif indéfini quelque et d'un, une»）；某词典记 **XIVe**；**Nyrop《Grammaire historique》记 XVe siècle**（并指出它逐渐取代 *aucun*，因 *aucun* 转负义）。CNRTL 只给「Quelque, et un」+ 方言形（bourg. *quécun*、norm. *queuqu'un*），**未给年代**。*quelque*：**XIIe s.**。*autre*：← 古法 *altre* ← 拉丁 *alter*，**具体首证年代待验证**
- 同族 / 派生：**quelque**、**quelques**、**quelque chose**（**本库已收 [[quelque-chose]]**）、**quelqu'un**、**autrui**（他人，书面）、**autre**、**autrefois**、**autrement**
- 记忆钩：**quelqu'un（某个人）+ d'autre（别的）**——「**某个**另外的人」；注意 *de* 是这条链条的关节，**省不得**

**英法交叉核对（受影响的英语词）**
- **借入**：**无**——英语 "somebody else" 与法语无关（*some* ← 古英语 *sum*；*else* ← 古英语 *elles*）
- **共祖（非借入）**：英语 **alter**（借自拉丁 *alter*，**非经法语**）、**alteration / alternative**、**altruism**（← 法语 *altruisme* ← *autrui* ← *alter*）与法语 **autre** 共祖
- **⚠️ PIE 层面的远亲**：英语 **other** ← 古英语 *ōþer*（**日耳曼线**），与拉丁 *alter* 在 **PIE 层面同源**（\*h₂el-teros）但**路径不同**（一条日耳曼、一条拉丁）——是「远亲非直系」的样本
- **反向借入**：无

**同义 / 搭配 / 易混**
- 同义：une autre personne、**autrui**（他人，书面）
- 搭配：**quelqu'un d'autre que moi**（除我以外的人）；**personne d'autre**（没有别人，否定）；*Y a-t-il quelqu'un d'autre ?*；de la part de quelqu'un d'autre
- 易混：**quelqu'un d'autre**（别人）vs **autre chose**（别的东西）vs **les autres**（其他人）
- **易错（重点）**：**d'autre 的 de 不可省**；否定用 **personne d'autre**，不能保留 *quelqu'un d'autre*
- **语用**：法语 *quelqu'un* 可专指「**重要人物**」（*C'est quelqu'un !* 他可是个人物！）
