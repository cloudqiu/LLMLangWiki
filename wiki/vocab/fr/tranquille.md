# tranquille

**释义**：（1）**平静的、安静的、安宁的**（une rue tranquille 僻静的街）；（2）**（心境）平静的、放心的**（sois tranquille 你放心；avoir la conscience tranquille 问心无愧）；（3）**（酒）无气泡的**（vin tranquille ↔ mousseux）｜ calme, sans agitation ; serein, en paix ; (vin) sans bulles

**例句**
- _Reste tranquille, je m'occupe de tout._ 你别乱动，我来处理一切。
- _Ils mènent une vie tranquille à la campagne._ 他们在乡下过着平静的生活。
- _Sois tranquille, tout ira bien._ 你放心吧，一切都会好的。

**形态要点**
- **阴阳同形（épicène）**：un homme tranquille / une femme tranquille；复数 **tranquilles**
- **发音关键**：**-ille 读 [il]，不读 [j]**（≠ fille /fij/）——同 ville /vil/、mille /mil/ 一类的例外；口语变体 /tʁɑ̃.ki/
- 副词 **tranquillement**；动词 **tranquilliser / se tranquilliser**；名词 **tranquillité**；**tranquillisant**（n.m. 镇静剂）
- 结构：`tranquille sur`（对…放心：tranquille sur l'avenir）｜ `tranquille pour`
- 短语：`laisser tranquille`（别打扰）｜ `tranquille comme Baptiste`（泰然自若）｜ `long fleuve tranquille`（一帆风顺的人生）｜ `couler des jours tranquilles`（安度岁月）

**词源 / 构词**
- **拆解**：法语 **tranquille** ← 拉丁 **tranquillus**「平静的、安宁的」（**整词借入** + 法语屈折 -e），经**中古法语**进入
- **拉丁 tranquillus 的内部构词——诸说并存（绝不外定）**：
  - **传统说**（Watkins，etymonline 采）：**trans-**（或其加强义「极度」）+ 与 PIE **\*kʷyeh₁-**「休息」相关的成分（拉丁 quies / quiesco）→「非常平静」——**de Vaan 批评此说「语义含糊、音理可疑」**；Ernout-Meillet 称 tranquillus 为「**formation obscure** 的表达性复合词」
  - **Brent Vine**：否定 trans-「极」义（晚拉丁才见），提出古复合 trans + 前拉丁名词（\*kʷilim「阵风」）→「穿越风暴（后平静）」
  - **Sims-Williams（2020）**：拟 \*kūth.lo- / \*kʷihilo-，与日耳曼 \*hwīla-「休息」相关
- **首证（法语）**：**15 世纪**——**Académie 9e：「Emprunté du latin tranquillus, de même sens」**；fr.wiktionary 该条只写「Du latin tranquillus」，**未给年代**——两源不一
- **拉丁首证**：Plautus（*Capt.* I,1,37）、Horace（*Ep.* I,10,102）；名词化 *tranquillum* =「平静的海」（Cicéron、Tite-Live）；晚期拉丁 *tranquillitas tua* 作尊称
- **同族 / 派生（法语）**：tranquillité、tranquilliser、tranquillisant、tranquillement
- **记忆钩**：词根疑与「**休息**」（PIE \*kʷyeh₁-，拉丁 quies）相关——「平静」＝「歇着不起风浪」

**英法交叉核对（受影响的英语词）**
- **借入 / 共祖（路径两可）**：英语 **tranquil**（adj. **mid-15c**，尤指面部特征）——**或为 tranquility 的逆构，或借自古法语 tranquille，或直借拉丁 tranquillus——三说并列**（etymonline）
- **借入（英 ← 法，明确）**：英语 **tranquility / tranquillity**（n. **late 14c**，形 tranquillite）← **古法语 tranquilite**（12c.）← 拉丁 tranquillitatem ← tranquillus
- 派生英语：**tranquilize**（1620s）、**tranquilizer**（1800 / 1824 / 1956）、intranquil（1798）
- **同义异源**：英语 **calm**（← 晚期拉丁 cauma，见 [[calme]]）、quiet / still 与 tranquil **不同源**
- 核对：英语侧经检索转引 etymonline（2026-10-13）；法语侧 xve s. 据 Académie 9e 转引

**同义 / 搭配 / 易混**
- 同义：**calme**（见 [[calme]]）、**paisible**、**serein**、**silencieux**
- **辨析（与 calme 联动）**：**tranquille** = 日常「安静 / 放心」（多指环境无事、心境安然）；**calme** = 更书面 / 物理性「平静、冷静」（海面、情绪自控）——**语域不同**
- 反义：agité、nerveux、bruyant、inquiet
- 搭配：`laisser tranquille`（别打扰）｜ `avoir la conscience tranquille`（问心无愧）｜ `vin tranquille`（无气泡酒）
- 相关：[[calme]]（近义辨析——本页消解其「待收」占位）、[[sale]] / [[propre]]（同批形容词）
