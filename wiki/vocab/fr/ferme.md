# ferme

**收录说明**：inbox 的 `ferme`（与 campagne / vache / cochon 同列）判为 **n.f.「农场」**——本页以名词为纲；同形的 **adj. `ferme`「坚定的」**（直承拉丁 firmus）与 **v. `fermer`「关闭」**（1er groupe）为**不同词**，见页末「同形异义」。

**释义**：（1）**n.f. 农场、农庄**（une ferme 一座农场；ferme laitière 奶牛场）；（2）**（历史）租约、包税**（la ferme générale 旧制包税）；（3）**adj. 坚定的、牢固的**（une main ferme 坚定的手；un pas ferme 稳健的步子）；（4）**adv.**（parler ferme 语气坚定）；（5）**interj.**（命令式）「住口！/ 稳住！」 ｜ exploitation agricole ; (adj.) solide, résolu, inébranlable

**例句**
- _Mes grands-parents vivent dans une ferme._ 我祖父母住在一座农场里。
- _Il travaille à la ferme._ 他在农场干活。
- _Elle a la voix ferme._ 她的声音很坚定。
- _Ferme la porte, s'il te plaît._ 请把门关上（此处 ferme ＝ fermer 的命令式）。

**形态要点**
- 名词：`la ferme`（**f.**）；复数 **fermes**
- 形容词（**同形词**）：阴阳同形 **ferme**，复数 **fermes**
- 动词（**同形变位**）**fermer**：**1er groupe**（**不是** 3e——本批更正原设）、助动词 **avoir**、过去分词 **fermé**；现在时 **je ferme / tu fermes / il·elle ferme / nous fermons / vous fermez / ils·elles ferment**；命令式 ferme / fermons / fermez（`ferme !`「住口」即命令式）
- 同族：**fermier / fermière**（农场主）、**fermage**（地租）、**fermeture**（关闭）、**fermer**（关）、**affermer / affermir / affirmer**（「使牢固」一脉）、**ferme**（adj.）

**词源 / 构词**
- **拆解（名词）**：**派生自动词 fermer**——古法语 fermer「**牢固地立定、固定**」← 拉丁 **firmare**（← **firmus**「坚固」）→ 中世纪拉丁 **firma**「固定租额、包租」（Niermeyer：盎格鲁-撒克逊地区 **1100** 年起已见）→ 法语 ferme。TLFi 明记：**名词 ferme 派自动词 fermer**
- **演变（名词）**：`firma`「固定租额」→ 古法 ferme；首见 **约 1175**（「à ferme」租约义，B. de Ste-Maure《Ducs de Normandie》）；**1481** 包税 / 税项义；**1539**「**农村产业 / 农舍**」义（Estienne）——由「租来的地产」转为「农场」
- **拆解（形容词）**：**adj./adv. `ferme` 直承拉丁 firmus**「坚固」（< PIE ***\*dher-***「握牢」）；首见 **约 1140**（Usito 引 TLFi）／**12 世纪**（Académie 9e）——**两说**
- **史注（Littré）**：fermer「关闭」义并非直承 firmare——「使牢固」一脉主要留在 **affermer / affermir / affirmer**；名词与形容词**终点皆溯至拉丁 firmus**
- **记忆钩**：ferme「农场」＝「**包租（固定租额）的地**」——从 firmus「坚固 / 固定」出发，绕了动词 fermer 一圈

**英法交叉核对（受影响的英语词）**
- **借入英语**：**farm**（n. **c.1300**「固定付款、定额租金」← 古法语 **ferme**；v. mid-15c「租（地）」← 盎格鲁-法语 **fermer**——**农业义 1719 才出现**，旧的「出租 / 转包」金融义存于 *farm out*）；**firm**（adj.「坚固的」← 法语 ferme / 拉丁 firmus）
- **共祖未借入**：法语 ferme(adj.) 与英语 **firm**（adj.）共享拉丁 **firmus**（英语 firm 或经法语 ferme、或直承拉丁——两说）；英语 **firm**（n.「公司」）← 意大利语 **firma** ← 拉丁 firmare
- **同义异源**：英语「关（门）」用 **close / shut**（本族 / 日耳曼语）——与法语 fermer **无亲缘**
- 核对：英语侧（farm c.1300 ← 古法 ferme；farm v. mid-15c；firm ← firmus）经检索转引 etymonline（2026-10-11）；法语侧 firma 1100 / ferme 1175 / 1539 与 firmus 链据 TLFi / Niermeyer / Académie 9e / Usito 转引（**待验证**）
- **教学点**：**英语 farm ↔ 法语 ferme 同源**（英借自法，原义「租金」），但法语 ferme **另有**「坚定的」义（对应英语 firm）

**同形异义（同页速查）**
- **ferme**（n.f. 农场）← fermer ← firmare ← **firmus**
- **ferme**（adj./adv. 坚定的）← **firmus** 直承
- **fermer**（v. 关闭，1er groupe）——本页只记变位要点；日后若单独建页记 **`fermer.md`**
- **命令式 `ferme !`**（住口 / 稳住）＝ 动词 fermer 的命令式

**同义 / 搭配 / 易混**
- 搭配：`à la ferme`（在农场）｜ `ferme laitière / avicole`（奶牛场 / 养鸡场）｜ `fermier`（农场主）｜ `(adj.) main ferme`（坚定的手）｜ `(adv.) parler ferme`（语气坚决）｜ `ferme et définitif`（不可撤销、终局的——法律语）
- **易混**：**ferme**（农场）vs **fermer**（关闭）vs **ferme**（坚定的，adj.）——**同形三词**，靠词性与语境分辨；**ferme**（农场）vs **métairie / exploitation**（近义）；反义（adj.）**mou / hésitant**
- 相关：[[campagne]]（乡村域）；[[vache]] / [[cochon]]（农场动物，同批收录）
