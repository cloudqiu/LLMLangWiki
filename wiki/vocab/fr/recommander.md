# recommander

**释义**：（1）推荐、介绍（recommander qn / qch à qn 向某人推荐某人／某物；recommander un livre 推荐一本书）；（2）叮嘱、嘱咐、劝告（recommander à qn de faire qch 叮嘱某人做某事；Je vous recommande la prudence 我劝您谨慎）；（3）**se recommander** 自荐；**se recommander de qn / qch** ＝ 援引……为据、打着……的旗号（**faux ami**，见下） ｜ présenter comme digne d'être choisi ; conseiller vivement ; (pron.) se réclamer de

**例句**
- _Je te recommande ce restaurant._ 我向你推荐这家餐馆。
- _Le médecin lui a recommandé de se reposer._ 医生嘱咐他休息。（recommander à qn de + inf.）
- _On m'a recommandé un bon roman._ 有人向我推荐了一本好小说。（见 [[roman]]）
- _Il se recommande de l'autorité de son maître._ 他援引其师长的权威。（se recommander de——**不是**「推荐自己」）

**形态要点**
- 动词：不定式 **recommander** ｜ **1er groupe** ｜ 助动词 **avoir** ｜ 过去分词 **recommandé**
- 现在时六形：je **recommande** ｜ tu **recommandes** ｜ il·elle **recommande** ｜ nous **recommandons** ｜ vous **recommandez** ｜ ils·elles **recommandent**
- 变位提示：规则 -er 动词，词干 **recommand-** 全程不变；命令式 recommande / recommandons / recommandez；代词式 **se recommander**：je me recommande / tu te recommandes …
- 搭配：recommander qch **à qn**（向某人推荐某物——**间宾 à**）；recommander à qn **de** + inf.（叮嘱某人做某事）；**se recommander de qn / qch**（援引……）；**lettre de recommandation**（推荐信）

**词源 / 构词**
- **拆解**：**re-**（再、加强）+ **commander** ← 拉丁 **commendare**「托付、交人保管；荐举」＝ **com-**（共同／加强）+ **mandare**「交办、委托」——字面「**把事情交托出去**」→ 引申「荐举、褒扬」。同族：**commander**（命令、订购）、**demander**（要求——de- + mandare）、**mandat / mandataire**（委托、代理人）、**commande**（订货）、**recommandation**（推荐；推荐信）
- **演变（CNRTL/TLFi、Académie，2026-10-04 经检索转引）**：中世纪拉丁 **recommendare** ＝ re- + 古典拉丁 commendare；古法语已见 **recommander / recomander**。**法语首证年代未逐核**（TLFi「recommander」原条未直连，**待验证**）。**re- 的语义并存两说**：etymonline 记其「here perhaps an intensive prefix, or else from a sense now obscure」——**加强前缀** 或 **出已晦之义**，**两说不折中**
- **同族 / 派生（法语）**：**recommandation**（n.f. 推荐、推荐信）、**recommandable**（少用）、**décommander**（取消约定）、**commander**（命令、点单——同根异义）、**demander**（要求）、**mandat / mandataire / commande**
- **记忆钩**：recommander ＝ re（再）+ com（完全）+ mand（交托）——「**把事情反复交托给对方**」＝推荐。同根 mandare 也是 **commander（命令）／demander（要求）** 的根——「交办」三兄弟：**委托 → 命令 / 要求 / 推荐**

**英法交叉核对（受影响的英语词）**
- **同一拉丁词根 commendare，三次入英（务必分清三条路径）**：
  - **`command`**（英 v. **c.1300** ← 古法语 **comander** ← 俗拉丁 **\*commandare** ← 拉丁 **commendare**；拼写与词义后受拉丁 *mandare* 影响重塑）——**借入**（英 ← 法）；义「命令、指挥」
  - **`commend`**（英 mid-14c. *comenden* ← 拉丁 **commendare** 直借，**不经法语**；义「表扬、荐举」）——**直借拉丁**；etymonline 明记 commend 与 command 是「**doublets**（双式词）」
  - **`recommend`**（英 **late 14c.** *recommenden* ← 中世纪拉丁 **recommendare**；Merriam-Webster 另记可经盎格鲁-法语 **recommender**）——义项：late 14c.「荐举／托付」→ **1746**「劝告、建议（advise as to action）」
  - 三者 ＋ 法 recommander 全出拉丁 **commendare**（com- + mandare）——**「同一根四次落地」**：法 recommander、英 command（←法）、英 commend（←拉丁）、英 recommend（←中世纪拉丁）
- **`recommendation`**（英 early 15c. ← 古法语 **recommendation** / 中世纪拉丁 recommendationem；「letter of recommendation」约 **1500**）——**借入**（英 ← 法）；对应法语 recommandation
- **同根未借入**：英 `mandate` / `mandatory` / `demand`——均出拉丁 **mandare**「交办、委托」（其 PIE 归属或为 **\*man-**「手」→ 交手、交付，**待验证**）
- **核对**：英语侧（command c.1300 ← OF comander ← \*commandare；commend mid-14c ← 拉丁 commendare；recommend late 14c ← 中世纪拉丁 recommendare，M-W 记 Anglo-French recommender；recommendation early 15c ← OF；1746 劝告义）2026-10-04 经 **etymonline 直读 + Merriam-Webster 检索**；法语侧（recommendare ＝ re- + commendare、commendare ＝ com- + mandare）2026-10-04 经 **检索转引 CNRTL/TLFi、Académie**（CNRTL 直连仍失败）。**待验证**：①法语 recommander 首证定年（TLFi 原条未直连）；②mandare 是否确系 PIE \*man-「手」；③recommendare 的 re- 为加强前缀抑或「已晦之义」（etymonline 两说并存，不折中）

**同义 / 搭配 / 易混**
- **faux ami（本页必记）**：法 **se recommander de qn / qch** ＝「**援引**某人／某物为据、打着……的旗号」——**不是**「推荐自己」！例：Il se recommande de ses maîtres（他援引其师长）。要表达「自荐」用 **se présenter** 或 se recommander **à** qn
- 搭配：`recommander qch à qn`（向某人推荐某物）；`recommander à qn de + inf.`（叮嘱某人做）；`recommander qn`（推荐某人，如求职）；`lettre de recommandation`（推荐信）；`recommander la prudence`（劝其谨慎）；`fortement / vivement recommander`
- 近义：recommander（推荐／叮嘱）｜ **conseiller**（建议——侧重劝告）｜ **suggérer**（提议）｜ **préconiser**（主张、鼓吹——雅）｜ **vanter**（夸赞、吹捧）
- **搭配差异陷阱**：法 **recommander de + inf.**（**不用 que + subj.**），与英语 recommend **that…** / recommend **doing** 的句型不同
- 易混：**commander**（命令、点单）vs **recommander**（推荐、叮嘱）——同根近形（仅差 re-）；**demander**（要求、询问）——同根
- 相关：[[postuler]]（求职——常配推荐）、[[interesser]]（使感兴趣）、[[roman]]（例句推荐小说）、[[ecrire]]（推荐信要写）
