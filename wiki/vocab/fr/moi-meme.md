# moi-même

> 收录说明：inbox 形式 `moi-meme`（ASCII）→ 按正词法立目 **moi-même**（word 照写重音与连字符）。本页办**重读强调代词**页，与 [[mon]]（主有限定词）对比记忆。

**释义**：我自己——第一人称单数的**重读强调（réfléchi / emphatique）代词**，强调「正是我本人」 ｜ moi en personne, le moi considéré comme sujet ou objet, renforcé par même

**例句**
- _Je l'ai fait moi-même._ 这是我自己做的。（强调「亲力亲为」）
- _Je me suis blessé moi-même._ 我伤到了我自己。（反身代词 + 强调，双重出现）
- _Parle pour toi-même !_ 说你自己吧！／管好你自己的事！（toi-même 对照）
- _Elle est plus critique envers elle-même qu'envers les autres._ 她对自己比对别人更苛刻。（系列形 elle-même）

**用法要点**
- **构成**：重读代词 **moi** + **même**，用**连字符焊接**（moi-même）；**性数不变**（男女同形 moi-même）。
- **-s 只在复数加（高频拼写点）**：单数一律 **-même**（moi-même / toi-même / lui-même / elle-même / soi-même，**不加 s**）；复数才加 -s（**nous-mêmes / vous-mêmes / eux-mêmes / elles-mêmes**）。
- **重读代词全系列（与 [[eux]] 页同表）**：单数 **moi-même / toi-même / lui-même / elle-même / soi-même**；复数 **nous-mêmes / vous-mêmes / eux-mêmes / elles-mêmes**。
- **重读 vs 非重读（本页核心机制）**：**moi** 是**重读（tonique）形**，与非重读（clitique）形 **me** 成对——**me** 贴动词前（Il **me** voit 他看见我）；肯定命令式后用重读 moi（Donne-**moi** ça ! 把那个给我）；moi-même 再**叠加 même** 表强调。
- **句法位置**：①**同位强调主语**——**Moi**, je pense que…（我呢，我认为……）；②**强调「本人亲为」**——Je l'ai fait **moi-même**；③**介词后**——par moi-même（由我本人）/ de moi-même（主动地、自己）/ en moi-même（我心里）；④泛指「自己」用 **soi-même**（不用 moi-même）：On doit penser à **soi**.
- **与 [[mon]] 的分工（本页必辨）**：**mon** 是**主有限定词**——**必置于名词前**（mon livre 我的书），随**所修饰名词**的性数变化（mon / ma / mes）；**moi-même** 是**重读代词**——**独立、不修饰名词**，只指「我本人」。**一个管「所属」，一个指「人本身」。**

**词源 / 构词**
- **拆解**：**moi** + **même**
  - **moi** ← 拉丁 **mē**（第一人称代词 ego 的**宾格**）的**重读形**——同一个拉丁 mē，**非重读形**在法语里成了 **me**（〔DHLF〕：accentué → moi，inaccentué → me）
  - **même** ← 俗拉丁 **\*metipsimus**「正是本人」＝ 强调小品 **-met**（如 egomet、nosmet「正是我、正是我们」）+ 强调指示词 **ipse**「他本人」+ 最高级后缀 **-issimus**（「粗俗加强」）〔fr.wiktionary 引 CNRTL；DHLF〕
- **演变（DHLF、Académie，2026-10-05 转引）**：
  - **moi**：**842 mi → 1080 mei → 1150 moi**（〔DHLF〕）；古法语以 **mei / mi** 为主，**moi** 最早生于皮卡第（近法兰西岛），后入勃艮第并取代 mi——「moi-même」因此是「重读 + 强调后缀」的**双重强化**
  - **même**：俗拉丁 **\*metipsimu**（读 \*metessimu）→ 古法 **medisme / medesme**（**1050**《圣 Alexis 传》——DHLF 首证）→ **meisme（1080）**（类比拉丁 *metissimi*）→ **meesme** → **mesme**（ee > e）→ **même**（脱落 s；16 世纪起 s 仅存书写痕迹——Académie）〔DHLF / fr.wiktionary / Académie〕
  - **moi-même 短语**首见偏近代——fr.wiktionary 所收最早书证为 **1830**（J. Witt）——**待验证**（TLFi 原条未直连）
- **同族 / 派生（法语）**：**moi / me**（重读 / 非重读）、**mien / mienne**（独立主有代词，见 [[le-mien]]）；**même** 一族：**même**（adj./adv. 相同的）、**quand même**（还是、好歹）、**tout de même**（仍然）、**de même**（同样）、以及 **moi-même / toi-même / …-mêmes** 全系列
- **记忆钩**：-met（「正是」）+ ipse（「本人」）＝ même 的本义「**正是本人、不假他人**」——moi-même 字面「我-正是-本人」；同族西语 `mismo`、意语 `medesimo`、葡语 `mesmo` 都从 \*metipsimus 来

**英法交叉核对（受影响的英语词）**
- **借入英语**：无——moi-même 未被英语借入
- **共祖未借入（分两半看，本页核心）**：
  - 「moi」一线：英语 **`me`**（← 古英语 mē ← PIE **\*me-**，第一人称斜格词干）与拉丁 **mē → moi** **共祖非借入**；同族 **`my` · `mine`**（见 [[le-mien]]）
  - 「même」一线：**无共祖**——英语 **`same`**（← 古英语 ← 原始日耳曼 **\*samaz** ← PIE **\*semos**〔根 \*sem-「一」〕，同族德语 samt / zusammen）与法语 même（← 拉丁 **ipse**）**毫无词源关系**；英语 **`self`**（← 古英语 self ← 原始日耳曼 **\*selbaz** ← PIE **\*(s)w(e)-**）亦与 même 无关——故英语 **`myself`** 与法语 **moi-même** 只是「**功能对等**」，两条构词线彼此独立（对照 [[vie]]↔life 的「同义异源」格局）
- **旁支（拉丁 ipse 直接入英）**：英语借 **`ipse dixit`**（拉丁「他本人说过」＝ 断言）、**`ipso facto`**（拉丁「凭事实本身」）——**直接借拉丁 ipse**，非经法语 même
- 核对：英语侧（me ← OE mē ← PIE \*me-；same ← PGmc \*samaz ← \*semos；self ← PGmc \*selbaz ← \*(s)w(e)-；ipse dixit / ipso facto）2026-10-05 经 **etymonline 直读**；法语侧（moi ← mē 重读形、842 mi / 1080 mei / 1150 moi；même ← \*metipsimus → medisme 1050 → meesme → mesme → même）2026-10-05 经 **WebSearch 转引 DHLF（Le Robert）、历史语法（Darmesteter / Nyrop）、Académie 9e 与 fr.wiktionary**（CNRTL 直连仍 sinkhole）。**待验证**：①TLFi「moi-même」「même」原条首证定年未直连；②moi-même 短语的词典级首证（现为 fr.wiktionary 所收 1830 书证，非词典首证）；③古法 medisme → meisme 的中间形年代未逐核

**同义 / 搭配 / 易混**
- 搭配：`moi-même`（我本人）｜ `par moi-même`（由我本人）｜ `de moi-même`（我自己、主动地）｜ `en moi-même`（我心里）｜ `Parle pour toi-même`（说你自己吧）
- **易混（本页核心）**：**mon / ma / mes**（主有限定词「我的」，修饰名词——见 [[mon]]）｜ **moi**（重读代词「我」，与 me 对立）｜ **moi-même**（重读 + 强调「我本人」——本页）｜ **me**（非重读 clitique，贴动词前）｜ **le mien**（独立主有代词「我的那个」——见 [[le-mien]]）
- 系列对照：**moi-même / toi-même / soi-même / lui-même / elle-même / nous-mêmes / vous-mêmes / eux-mêmes / elles-mêmes**（重读代词表见 [[eux]]）
- 相关：[[mon]]、[[le-mien]]、[[eux]]、[[comme-toi]]（toi 的重读用法）
