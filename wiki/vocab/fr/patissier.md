# pâtissier

**释义**：糕点师、甜品师傅（以制作糕点为业的人；阴性 pâtissière） ｜ personne dont le métier est de fabriquer des pâtisseries

**例句**
- _Le pâtissier prépare les éclairs pour la vitrine._ 糕点师在为橱窗准备闪电泡芙。
- _Elle est pâtissière dans un grand hôtel._ 她在一家大酒店做糕点师。
- _Le pâtissier a ouvert sa propre boutique._ 这位糕点师开了自己的店。

**形态要点**
- 名词：`le pâtissier`（m.）/ `la pâtissière`（f.）；复数 `les pâtissiers` / `les pâtissières`
- 构词模式：-ier / -ière 职业名词后缀（同 cuisinier·cuisinière、jardinier·jardinière）
- 拼读：**-ss- 读 /s/**（勿读 /z/）；-ier 读 /je/（一个音节，不是 /i.je/）；â 传统读 /ɑ/、现代巴黎音多并入 /a/

**词源 / 构词**
- **拆解**：**pâte**（面团、糕点）+ -iss-（动词 pâtisser 的词干扩展）+ **-ier**（职业后缀）——「做面团的人」
- **演变**：希腊 **pastē**（παστή，「大麦粥、面团」）→ 拉丁 **pasta**（面团、面食）→ 古法语 **paste** → 法语 **pâte**（长音符 â 用于区别同音词：pâte vs patte）→ pâtisser（做糕点）→ **pâtissier**（1278 首见，作 pasticier）／**pâtisserie**（1328 首见，作 pastiserie）（据 CNRTL/TLFi，2026-10-01 经检索转引）
- **同族 / 派生**：**pâtisserie**（糕点店；糕点制作；糕点——三义）、**pâte**（面团；意面；酱）、**pâtisser**（v.）；英语一侧见下节
- **记忆钩**：pasta、paste、pastry、pâté 全是「面团」的远房亲戚——pâtissier 就是「面团师傅」

**英法交叉核对（受影响的英语词）**
- **借入英语**：**patisserie**（19c. 借入英语，拼写去长音符——英语里指「法式糕点店」，无「糕点师」义）；**patissier**（罕用，饮食写作中偶见）
- **共祖未借入**（拉丁 pasta「面团」家族，同一词根不同路径入英）：**pastry**（← paste + -ry；paste ← 古法语 paste）；**paste**（← 古法语）；**pasta**（← 意大利语——拉丁 pasta 的**再借入**，与 paste 构成双重借入）；**pâté**（← 法语，18c. 再借入英语）；**patty**（1710 首见「small pie」，← 法语 pâté ← 古法语 paste——与 pasty・pâté 同属一词的相继借入；据 etymonline，2026-10-01 经检索转引）；**pastiche**（← 意大利语 pasticcio，同出 pasta）
- **核对**：2026-10-01 经检索转引核对——CNRTL/TLFi：pâtissier 1278（pasticier）、pâtisserie 1328（pastiserie）；etymonline：patty 1710 ← 法语 pâté。英语词库尚未收录 pastry / pasta / paste / pâté

**同义 / 搭配 / 易混**
- 搭配：`pâtissier-chocolatier`（复合店招）；`le tour de main du pâtissier`（糕点师的手艺）
- 易混（一屋子「厨子」）：**le boulanger**（面包师——做面包）；**le cuisinier**（厨师）；**le confiseur**（糖果师）；**le glacier**（冰淇淋师）
- 义项提示：**la pâtisserie** 三义——店铺、行业/手艺、糕点本身；英语借走的 patisserie 只取「店铺」
