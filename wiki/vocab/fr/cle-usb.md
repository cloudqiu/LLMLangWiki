# clé USB

**释义**：n.f. **USB 闪存盘、U 盘**——带 USB 接口的可移动数据存储装置 ｜ petit dispositif de stockage de données informatiques amovible, muni d'un connecteur USB

**例句**
- _J'ai enregistré le dossier sur ma clé USB._ 我把这个文件夹存到 U 盘上了。
- _N'oublie pas ta clé USB pour la présentation._ 别忘了带 U 盘去演示。
- _Cette clé USB a une capacité de 64 gigaoctets._ 这个 U 盘的容量是 64 GB。

**形态要点**
- 名词：`la clé USB`（**f.**）；复数 **clés USB**（*clé* → *clés*，缩略语 USB 不变）
- 异拼：**clef USB**（同样为 f.，复数 *clefs USB*）——*clef* 是旧拼法，今多用于音乐义（谱号）
- 构词提示：名词 + 后置修饰语，**中间无 à**（对比 *machine à café*）

**词源 / 构词**
- 拆解：**clé**（拉丁 *clavem*）+ **USB**（缩略语，名词后置作修饰）
  - **clé**：← 拉丁 **clavem**（*clavis*「钥匙、门闩、横杆」的宾格）。**并列**：fr.wiktionary 记 **1080**（「Du latin clavem」）；**CNRTL 记 ca 1100** 作 *clef*（《罗兰之歌》Bédier 本 2762）→ **两说并列**。CNRTL 另注 *clé* 形 **1115-30** 见 Ph. de Thaon (*Comput*)，义为「解释之物」
  - **USB**：**英语** Universal Serial Bus 的缩略语，**1996** 年由 Compaq / Intel / Microsoft / NEC 等推出——**法语直接借入该缩略语**（法 ← 英）
- 演变：拉丁 *clavis* → 古法语 *clef / clié* → 现代 *clé / clef*；**clé USB** 这一复合的**首证年代待验证**（USB 1996 年才标准化，故必晚于 1996）
- 同族 / 派生：**clé** 的其余义：clé de voiture（车钥匙）、**clé à molette**（活动扳手）、clé de sol（G 谱号，作 *clef*）；复合：porte-clés（钥匙圈）
- 记忆钩：**clé** 是「钥匙」，**USB 是接口名**——「插进电脑就能开的钥匙」，即 U 盘

**英法交叉核对（受影响的英语词）**
- **借入**：英语 **clef**（n.，**1570s**，义「谱号」）← 法语 *clef*（12c.，义「钥匙；谱号；扳机」）← 拉丁 *clavis*——**英语只取了音乐义**，这是「法语常用词以一个窄义入英」的样本
- **共祖（非借入）**：英语 **clavicle / conclave / clavier / clavichord** ← 拉丁 *clavis / clavicula*——**直接拉丁借入**，非经法语
- **反向借入（法 ← 英）**：**USB** 缩略语本身直接借自英语——本词条即是「法语借英语缩略语 + 本土词 *clé* 复合」的产物
- **⚠️ 易被误认同源**：英语 **key** ← 古英语 *cǣg*（**日耳曼语**），与法语 *clé*（拉丁线）**不同源**——「钥匙」在英法两语是**同义异源**（cf. [[cle-usb]] 的对照：英 key ／ 法 clé）

**同义 / 搭配 / 易混**
- 同义：une clé de stockage；(Québec) un **bâton de mémoire**
- 搭配：**brancher / insérer / retirer / formater une clé USB**；**enregistrer sur une clé USB**
- 易混：**clé**（钥匙）vs **clé à molette**（活动扳手）vs **clé de voiture**（车钥匙）vs **clef**（旧拼 / 谱号）
- **faux ami（重点）**：英语标准说法是 **USB flash drive / USB stick / thumb drive**，**不说 "USB key"**——"USB key" 是 *clé USB* 的直译式伪英语，英语母语者会觉得别扭
