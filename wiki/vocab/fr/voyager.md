# voyager

**释义**：（1）**旅行、游历**——到远方或异地出行（voyager en France 在法国旅行；voyager pour affaires 出差）；（2）**（物）被运送、流通**（ce colis a beaucoup voyagé 这个包裹辗转多地；le vin qui voyage mal 经不起运输的酒）；（3）**（思绪、目光）游移、漂泊**（fig.：un regard qui voyage）；（4）及物（少见）：**运送（以供旅行）**（elle a été voyagée en transport adapté 用无障碍交通送她出行） ｜ faire un voyage, se déplacer loin ; (chose) être transportée ; (fig.) errer

**例句**
- _Nous aimons voyager en train à travers l'Europe._ 我们喜欢乘火车穿越欧洲旅行。
- _Il voyage souvent pour son travail._ 他常因工作出差。
- _Ce paquet a beaucoup voyagé avant d'arriver ici._ 这个包裹辗转多地才到这里。
- _Qui veut voyager loin ménage sa monture._ 想走远路就得好生养马。（谚语）

**形态要点**
- 动词（v.）：不定式 **voyager** ｜ 组别：**1er groupe** ｜ 助动词：**avoir** ｜ 过去分词：**voyagé**（用 avoir：j'ai voyagé）
  现在时：je voyage ｜ tu voyages ｜ il·elle voyage ｜ nous voyageons ｜ vous voyagez ｜ ils·elles voyagent
- **拼写变化（-ger）**：在 **a / o** 前保留 e 以维持 /ʒ/ —— nous voyageon**s**、je voyageai**s**、nous voyagerons（同 manger / nager / bouger / diriger / enlever 的 -ger 组）
- 词干始终 **voyag-**；未完成 je voyageais、虚拟 que je voyage（皆保留 e）
- 名词化亲属：**le voyage**（旅行）、**le voyageur / la voyageuse**（旅行者）、**les voyages**（复数）；口语 **bon voyage**（一路顺风）

**词源 / 构词**
- **拆解**：**voyage**（名词）+ **-er**（第一组动词 désinence）——**指名词派生动词**（fr.wiktionary 原文：「De voyage.」；TLFi：「Dér. de voyage ; dés. -er」）
- **voyage 之词源链**：晚期拉丁 **viaticum**「旅途用品、行装」——原是古典拉丁 **viaticus**（「属旅途的」）的中性名词化 ← **via**「路、旅途」（← PIE **\*wegh-**「走、运送」）。**词义由「行装」转为「旅行」**（fr.wiktionary／TLFi 记：viaticum 在晚期拉丁转指「voyage」）
  - 古法语 **voiage**（12c.），《罗兰之歌》作 **veiage**（« entrer en sun veiage »）；并存形式 veiage / veage / voiage / voiaige / veaige → 现代 **voyage**
- **演变（CNRTL/TLFi，2026-10-05 经 WebSearch 转引；CNRTL 直连失败）**：
  - **1385** 首证动词 **voyager**——Eustache Deschamps，《Œuvres》éd. G. Raynaud, t. 9, p. 80（« or fault avoir pour **voyagier** Grant argent »；此处作名词 voyagier 「旅行者」，定年仍归本词）
  - Académie 9e：「**xive siècle**. Dérivé de voyage」——与 1385 一致
  - **1749**：比喻义「（物）移动」首证（Buffon）；**1786**：*cette lettre voyagera toute la nuit*（Letourneur）；**1893**：「du vin qui ne peut pas voyager」
- **同族 / 派生（法语）**：**voyage**、**voyageur / voyageuse**（旅行者）、**revoyager**（再旅行）、**voyagiste**（旅行社从业者）、**voyager léger**（轻装出行）；**les gens du voyage**（流动人群）
- **记忆钩**：voyage ＝ **via**（路）+ -aticum（……用的）——「路上用的（行装）」→「旅行」；同一 PIE \*wegh- 根还出英语 **way / wagon / weigh / vehicle**——「路」的概念横跨两语族

**英法交叉核对（受影响的英语词）**
- **借入英语（古法语 → 英语）**：
  - **`voyage`**（n.）——**c. 1300** 作 *viage*「陆路或海路旅行」，兼指朝圣、使团、远征；← 古法语 **voiage**（12c.）← 晚期拉丁 **viaticum**。中古英语后渐专指**水路／海上航程**
  - **`voyage`**（v.）——**late 15c.** 作 *viagen*「旅行、从事」（← 古法语 **voyager**）；约 1600 起特指「水上航行」
  - **`voyager`**（n.「旅行者」）——英语保留的**法语借词**；亦指 **NASA「旅行者号」**探测器计划
  - **`bon voyage`**（一路顺风）——**1670s** 借自法语
- **共祖未借入（拉丁 via / PIE \*wegh- 线）**：**`via`**（← 拉丁 via）、**`viaticum`**、**`obvious` / `previous` / `trivial`**（皆含拉丁 **via** 构件）；更远：**`way` / `wagon` / `weigh` / `vehicle` / `vex`**（← PIE **\*wegh-**，与 via **共祖于同一个 PIE 根**，非经法语）
- **对照（同义异源）**：英语**动词**「旅行」主要用 **`travel`** —— ← 古法语 **travailler**「劳作、辛苦」（← 晚期拉丁 trepalium 刑具）；而**名词**「旅程」用**借自法语**的 **voyage**。故英语里「旅行」一词**动名不同源**，是本词条最值得记的英法纠缠
- 核对：英语侧（voyage n. c.1300 ← 古法 voiage ← 晚期拉丁 viaticum；voyage v. late 15c ← 古法 voyager；bon voyage 1670s；via ← 拉丁 via；travel ← 古法 travailler）2026-10-05 **etymonline 直读**；法语侧（voyager 1385 Eustache Deschamps、Académie 9e「xive siècle」、voyage 12c.《罗兰之歌》veiage、viaticum ← via、1749 / 1786 / 1893 各义项）2026-10-05 经 **WebSearch 转引 CNRTL/TLFi 与 Académie 9e**。
- 命名提示：英语 `voyage` / `voyager` 页尚未建；日后建页因词形不同，无须 `-en` 后缀（但 **`voyager`** 英法同形，若英语侧日后收词，按 hub 惯例英语记 `voyager-en.md` 与本页互链）

**同义 / 搭配 / 易混**
- 搭配：`voyager en` + 交通（en train / en avion / en voiture）｜ `voyager dans / à travers` + 地点（dans toute l'Europe）｜ `voyager pour affaires / pour le plaisir`（出差／游玩）｜ `voyager léger`（轻装）｜ `voyager loin`（远行）｜ `les gens du voyage`（流动人群）
- **介词要点**：**voyager en** + 交通工具；**voyager à** + 交通工具／方式（à vélo、à pied）；**voyager dans / en** + 国家／地区（在……旅行）；**voyager avec** + 同伴
- 辨析：**voyager**（长途／异地旅行，动词）｜ **se déplacer**（出行、移动，多指日常位移）｜ **partir**（出发、离开）｜ **faire un voyage**（名词式表达）｜ **errer**（流浪、漫游）｜ **parcourir**（走遍、遍历，及物）
- 易混名词：**le voyage**（旅行）↔ **la voyageuse / le voyageur**（旅行者）↔ **la journée**（**勿混**，仅形近）；**le trajet**（路程、行程段）
- 相关：[[bouger]]（更一般的「动」）；[[aller]]；`partir`（**待建**）；[[emporter]]
