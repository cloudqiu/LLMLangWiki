# ensemble

**释义**：**adv.**（1）一起、共同（partir ensemble 一起出发；Ils habitent ensemble 他们住在一起）；（2）同时 ｜ **n.m.**（1）整体、总体（l'ensemble de la population 全体人口）；（2）成套物、套装（un ensemble élégant 一套雅致的套装）；（3）乐团、合奏团（un ensemble vocal 合唱团）；（4）〈数学〉集合 ｜ l'un avec l'autre ; totalité ; costume ; groupe de musiciens

**例句**
- _Ils voyagent souvent ensemble._ 他们经常一起旅行。
- _Dans l'ensemble, le projet est une réussite._ 总体而言，这个项目是成功的。
- _Ces deux couleurs vont bien ensemble._ 这两种颜色很搭。（见 [[aller]]）

**形态要点**
- **副词**（不变）：修饰动词，置于动词后或句末（partir / travailler / vivre ensemble）；常见连诵 ils vont‿ensemble /vɔ̃.t‿ɑ̃.sɑ̃bl/
- **名词**：`un ensemble`（m.）；复数 `les ensembles`；`l'ensemble de + 名词`（……之全部）；`dans l'ensemble`（总体上）
- 名词义分层：音乐（un ensemble vocal / instrumental / de jazz——人声/器乐/爵士组合）；服装（un ensemble——上下两件一套）；数学（un ensemble 集合）；城建（un ensemble immobilier 建筑群）
- 高频组合：`aller ensemble`（相配、般配）；`tous ensemble`（大家一起——口号/歌名常用）；`on y va ensemble`（我们一起去——y 见 [[y]]）

**词源 / 构词**
- **拆解**：拉丁 **insimul**「同时」＝ **in-**（加强）+ **simul**「同时、一起」（PIE \***sem-**「一、一起」——拉丁 similis「相似」亦出此根）
- **演变**：拉丁 insimul → 古法语 **ensamble**（首证 **12 世纪**——Benoît de Sainte-Maure《诺曼底公爵编年史》「Ensemble en jostent li meiilor」〔fr.wiktionary，2026-10-03 经检索转引〕）→ 中古法语 ensemble；语音演变与 similare → sembler 同型
- **同族 / 派生（法语）**：**sembler**（好像）、ressembler（相像）、**assembler**（集合）、rassembler（聚集）、**simultané**（同时的）；意大利语 insieme、奥克语 ensem 为同源姐妹词〔fr.wiktionary，经检索转引〕
- **记忆钩**：ensemble ＝ in + simul「同一时刻」→「同一处」→「一起」；同一 simul 还长出 sembler / ressembler（显得一样）与 simultané（同时）——「一起、相似、同时」本是一家

**英法交叉核对（受影响的英语词）**
- **借入英语**：**ensemble**——副词义 **mid-15c**（together, at the same time）先入；名词义 **1703**「union of parts」（← 法语 ensemblée）；**音乐/戏剧义 1844**；**女式套装义 1927**〔etymonline，2026-10-03 直连〕——**提示原猜「音乐义 1703、套装义 1774」经检索修正**：1703 是名词首义年，音乐义 1844、套装义 1927
- **同根借入（另线）**：**assemble**（early 14c ← 古法语 **assembler**〔11c.〕← 拉丁 **assimulare**「使相似；聚集」＝ ad- + simulare ← similis）；**assemblage**（1704 ← 法语 assemblage）；**similar**（1610s ← 拉丁 similis）——与 ensemble 同出 simul / \*sem- 家族，走的是 ass- 复合线〔etymonline，直连〕
- 共祖未借入：无其他关键项（simul 家族已列）
- 核对：2026-10-03——英 ensemble 入英年代 mid-15c / 1703 / 1844 / 1927、法语源 ensemblée、拉丁 insimul = in- + simul、PIE \*sem- 据 etymonline（直连）；法语 ensamble 12c 首证与 insimul 链据 fr.wiktionary（经检索转引）；assemble / assemblage / similar 据 etymonline（直连）

**同义 / 搭配 / 易混**
- 搭配：`dans l'ensemble`（总体上）；`l'ensemble de qch`（……的全部）；`aller ensemble`（相配）；`tous ensemble`（大家一起）；`un ensemble vocal / instrumental / immobilier`（合唱团/乐团/建筑群）
- **易混**：**ensemble**（一起——副词）vs **aussi**（也——不是「一起」）vs **en même temps**（同时——时间义近）；**tout ensemble**（〈书面〉同时、一起——tout 的副词用法，见 [[tout]]）
- **faux ami**：英语 ensemble 主要作名词（乐团/套装/合奏），法语 ensemble 首先是高频副词「一起」；「我们一起去」＝ on y va ensemble（见 [[y]]）
