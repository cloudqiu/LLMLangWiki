# expliquer

> 收录说明：inbox 形式为 **`explique`**——系 **expliquer** 的直陈式现在时 1re/3e pers.（j'explique / il explique），归并到 lemma **expliquer**。

**释义**：（1）解释、说明、阐明（expliquer une règle 解释一条规则；expliquer qch à qn 向某人解释某事）；（2）说明原因、表明缘由（expliquer pourquoi… 解释为什么；Ceci explique cela 这就说明了一切）；（3）**s'expliquer** 解释清楚、表明态度；**s'expliquer avec qn** 与某人把话说清／发生争执 ｜ faire comprendre, rendre clair ; donner les raisons de ; (pron.) se faire comprendre, s'entretenir pour clarifier

**例句**
- _Le professeur explique la leçon aux élèves._ 老师给学生们讲解课文。（expliquer qch à qn）
- _Pouvez-vous m'expliquer pourquoi vous êtes en retard ?_ 您能向我解释一下为什么迟到吗？（expliquer pourquoi + 直陈式）
- _Tout s'explique : il a oublié son portable._ 一切都说得通了：他忘带手机了。（s'expliquer＝解释得通）
- _Je veux m'expliquer avec toi._ 我想跟你把话说清楚。（s'expliquer avec qn）

**形态要点**
- 动词：不定式 **expliquer** ｜ **1er groupe** ｜ 助动词 **avoir** ｜ 过去分词 **expliqué**
- 现在时六形：j'**explique** ｜ tu **expliques** ｜ il·elle **explique** ｜ nous **expliquons** ｜ vous **expliquez** ｜ ils·elles **expliquent**
- 变位提示：规则 -er 动词，词干 **expliqu-** 全程不变；**拼写要点**——词干以 **-qu-** 结尾，u 在 e/i 前仅为保 /k/ 音，故**无** -ger / -cer 型的 c/ç 变化（\*expliqons 不成立，写 nous expliquons）。元音前省音 **j'explique**（expliquer 以元音起，je → j'）；未完成 j'expliquais；将来 j'expliquerai；命令式 explique / expliquons / expliquez
- 代词式 **s'expliquer**：je m'explique / tu t'expliques / il s'explique …
- 搭配：expliquer qch **à qn**（向某人解释某事——**间宾用 à**）；expliquer que + 直陈式；expliquer qch par qch（用……解释……）；s'expliquer（解释自己）；s'expliquer avec qn（与某人交涉／争执）；cela s'explique（说得通）

**词源 / 构词**
- **拆解**：拉丁 **explicare**「摊开、展开（卷起之物）、解明」＝ **ex-**（向外）+ **plicare**「折叠」← **PIE \*plek-**「编织、缠绕」——本义「**把折叠的东西展开**」→ 引申「把复杂的事讲清」。反义运算正是 plicare「折」。同根法语：**plier**（折叠）、**compliquer**（com- + plicare「叠在一起」→ 复杂）、**explication**、**explicite**、**exploit**、**employer**、**supplier**（sub- + plicare「跪伏」）
- **演变（CNRTL/TLFi、DMF，2026-10-04 经检索转引）**：**14 世纪学界借入**（emprunt savant au latin explicare）——**非**古法语自然演变下来的通俗词，而是中世纪学者按拉丁原形「造」出的书卷词。首证记录（DMF/TLFi）：**1362-1365** Saint-Gille《Comment. A.Y. L.》；**c.1372-1374** Oresme 译《政治学》（*Pol. Arist. M.*）；**c.1377** Oresme《C.M.》；**1404** Christine de Pizan《Faits meurs Ch. V》——DMF 该条注「Doc. XIVe s. ds TLF」；名词 **explication**（n.f. 解释）同期自拉丁 *explicatio*（「清楚展示之动作」）造出
- **同族 / 派生（法语）**：**explication**（n.f. 解释、说明）、**explicite**（adj. 明确的——拉丁 explicitus「展开的」）、**explicatif / explicative**、**inexplicable**（无法解释的）、**compliqué / compliquer**（同 plicare 根）；近义动词 **éclaircir**（澄清）、**préciser**（进一步说明）、**justifier**（说明理由）
- **记忆钩**：expliquer ＝ ex（往外）+ plic（折）——「**把折着的东西摊开**」就是「解释」；反义 plier（折）＝「搞复杂」

**英法交叉核对（受影响的英语词）**
- **关键陷阱——英语 explain 与法语 expliquer 是「同义不同根」**（本页核心）：
  - 英 **`explain`**（**early 15c.**，先作 *explanen*）← 拉丁 **explanare**「弄平、摊平、讲明」＝ ex- + **planus**「平的」← PIE **\*pele-**「平、铺开」（**另一个词根！**）；多见经古法语 **esplainer**（GCIDE 亦记 esplaner / explaner）传入；拼写后受 **plain** 影响而改（etymonline 直读）。**故 explain ≠ expliquer 的同词**，而属「**造平／摊平**」那一支
  - 英 **`explicate`**（**1530s** ← 拉丁 *explicatus* ← **explicare**）、**`explicit`**（← 拉丁 explicitus「展开的」，同根）、**`explicable`**（**1550s** ← 拉丁 explicabilis）——**这几支才是法语 expliquer 的真同根**（etymonline 直读：explicate ← explicare ＝ unfold, unravel, explain）
  - 一句话：**法 expliquer（explicare）与英 explain（explanare）义近而源异；法 expliquer 与英 explicate / explicit 才是同源**——**勿因义近而误挂同源**（本库 [[competition]] 页记过同类的「分支／方向陷阱」）
- **共祖未借入**：英 `explicate` / `explicit` / `explicable` / `implication` / `complicated` / `employ` / `plait`——均出 PIE **\*plek-**／拉丁 **plicare**「折叠」这一支，与 expliquer 共祖（**非借入**）
- **核对**：英语侧（explain early 15c. explanen ← 拉丁 explanare ← PIE \*pele-，经古法 esplainer；explicate 1530s ← explicare；explicit / explicable 1550s）2026-10-04 经 **etymonline 直读/检索**；法语侧（explicare ＝ ex- + plicare、14e s. emprunt savant、首证 1362-65 Saint-Gille、c.1372-74 Oresme）2026-10-04 经 **检索转引 CNRTL/TLFi、DMF**（CNRTL 直连仍失败）。**待验证**：①TLFi「expliquer」原条首证定年（现为转引 1362-65 / DMF「Doc. XIVe s. ds TLF」）；②explicare → expliquer 是否为**纯书卷借入**而无通俗延续（TLFi 记为 emprunt savant，本次未见通俗形证据）

**同义 / 搭配 / 易混**
- 搭配：`expliquer qch à qn`（向某人解释某事）；`expliquer que + ind.`（解释……）；`expliquer pourquoi / comment`；`s'expliquer`（解释清楚）；`s'expliquer avec qn`（与某人把话说清／交涉）；`expliquer qch par qch`（用……解释……）；`cela explique / s'explique`
- 近义：expliquer（说明、讲解——最通用）｜ **éclaircir**（澄清疑点）｜ **préciser**（进一步说明）｜ **exposer**（陈述、阐述）｜ **justifier**（说明理由、为……辩护）｜ **commenter**（评注）
- **介词陷阱**：`expliquer qch **à** qn`——**间宾 à 不可省**（恰对应英语 explain sth **to** sb 的 to 亦不可省：不说 \*expliquer qn qch）
- 易混：**s'expliquer** 的「解释自己」与「与……争执（s'expliquer avec qn）」两读——由语境定夺
- 相关：[[parler]]（说话）、[[raconter]]（讲述）、[[mot]]（词语）、[[decouvrir]]（发现）、[[inventer]]（发明）
