# environ

**释义**：大约、差不多（副词，表约数）；(les environs, n.m. pl.) 附近、周边 ｜ à peu près ; (environs) alentours

**例句**
- _Il y a environ vingt personnes._ 大约有二十个人。
- _Le trajet dure environ deux heures._ 路程大约需要两小时。
- _Elle habite dans les environs de Paris._ 她住在巴黎附近。

**形态要点**
- 副词：**无性数变化**，置于数量/数字之前（environ vingt、environ deux heures）
- 名词用法：只用复数 **les environs**（m. pl.）「周边、近郊」——les environs de Paris；单数 environ 作为名词罕见

**词源 / 构词**
- **拆解**：en-（在内）+ **viron**「一圈、旋转」（← **virer**「旋转、掉头」）——字面「在一圈之内」→「在四周」→「大约」
- **演变**：virer「转」（更早来源二说：拉丁 **vibrare**「摇动」（经俗拉丁 *virare）或俗拉丁 ***gyrare**「转」——两说并存，检索未见定论，仍标**待验证**：CNRTL 仅上溯至 viron ← virer，viron 约 1225 首见）→ viron「一圈」→ 古法语 environ（10c. 末首见 evirum「在四周」）→ 副词「大约」（1273 年首见；均据 CNRTL，2026-10-01 经检索转引）；同源动词 environer「环绕」
- **同族 / 派生**：virer（转向、掉头）、virage（转弯、拐角）、environner（环绕）、environnement（环境）、les environs（周边）
- **记忆钩**：environ ＝ en + viron「一圈」——约数就是「在一圈左右」；environnement（环境）就是「环绕四周的东西」

**英法交叉核对（受影响的英语词）**
- **借入英语**：**environ**（动词「环绕」，14c. ← 古法语 environer，今已废弃/罕用）；**environs**（名词复数「周边、近郊」，1660s ← 法语 les environs——据 etymonline，2026-10-01 经检索转引）
- **平行 / 派生**：**environment**（英语自造：environ (v.) + -ment，c. 1600——据 etymonline，2026-10-01 经检索转引；复清（2026-10-01）订正：原「英语取自法语」之说未获支持——法语 environnement 的现代义系反向自英语 environment 借入〔CNRTL〕）
- **共祖未借入**：无显著同源（viron 系为法语自身演化）
- 核对：2026-10-01 清账＋复清经检索转引核对——CNRTL：environ 10c. 末首见 evirum、「大约」义 1273 首见、viron 约 1225 首见；etymonline：environs 入英 1660s、environment c. 1600（复清：英语自造说成立，法语 environnement 现代义反向借自英语〔CNRTL〕——该遗留项清除）；virer 词源 vibrare/gyrare 两说仍无定论（仍标**待验证**）

**同义 / 搭配 / 易混**
- 搭配：`environ + 数字`（environ vingt、environ deux heures）；`les environs de + 地名`；`aux environs de`（在……附近）
- 易混：**à peu près**（「差不多」——可修饰数量，也泛指「大致」，比 environ 更口语、更宽）；**presque**（「几乎」——presque vingt ≈ 快二十、environ vingt ≈ 二十左右）；**vers**（「大约」只表时间/钟点：vers midi 大约中午——environ 可表任意数量）；**les environs vs l'environnement**（周边 vs 环境/生态——后者才是英语 environment 的对应词，别倒过来用）
