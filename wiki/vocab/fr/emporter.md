# emporter

**释义**：（1）带走、拿走（随身带走）；（2）外带（餐食：`à emporter`）；（3）夺走、席卷（疾病、风暴把……夺走）；（4）**s'emporter** 发火、失控；（5）**l'emporter** 占上风、取胜 ｜ prendre avec soi (en partant) ; enlever ; (pronominal) se mettre en colère

**例句**
- _N'oublie pas d'emporter ton parapluie._ 别忘了带上你的雨伞。
- _Deux cafés à emporter, s'il vous plaît._ 两杯咖啡打包带走，谢谢。
- _Il s'emporte vite quand on le contredit._ 别人一反驳他，他就容易发火。

**形态要点**
- 动词：不定式 **emporter** ｜ **1er groupe** ｜ 助动词 **avoir**（j'ai emporté）｜ 过去分词 **emporté**
- 现在时六形：j'**emporte** ｜ tu **emportes** ｜ il·elle **emporte** ｜ nous **emportons** ｜ vous **emportez** ｜ ils·elles **emportent**（规则 -er；j' 省音）
- **三大结构（一词多义的关键）**：`emporter qch`（带走某物）；**s'emporter**（代动词：发火——s'emporter contre qqn 对某人动怒）；**l'emporter**（中性代词 le + emporter：占上风——l'emporter sur qqn/qch 胜过……）
- 分词形容词化：**emporté, e**（急躁的、易怒的——un caractère emporté）
- 对比记忆：`à emporter`（外带）vs `sur place`（堂食 / 现场）

**词源 / 构词**
- **拆解**：**en-/em-**（← 拉丁 **inde**「从那里」——副词性成分，与副词代词 [[en-pron|en]] 同源；Académie 9e 指出此处 en 即拉丁 inde）+ **porter**（← 拉丁 **portare**「搬运、携带」；古法语 porter 10c. 已见）＝「从那里把东西搬走」
- **演变**（据 CNRTL，2026-10-03 经检索转引）：古法语 **en portet**（约 **980** 年，首证；前缀与词干后拼合为 emporter〔约 1280 / 13c.〕）；词义时间线——10c.「搬运、随身带走」→ 约 1260「赢得、取得、征服」→ **1350 l'emporter**（占上风）→ 1310「强行夺走」→ 1500「武力夺取（据点）」→ 1541「带来（后果）」→ **1632 s'emporter**（发火，Corneille）
- **同族 / 派生（法语）**：porter（携带）、apporter（带来物）、rapporter（带回来）、remporter（赢走——remporter un prix 获奖）、emmener（带走人）；[[amener]]（带来人——a- + mener 的对偶结构）；英语一侧见下节
- **记忆钩**：**em-（去）vs a-（来）** 两大前缀对立——em- 系：emporter（带走物）、emmener（带走人）；a- 系：apporter（带来物）、amener（带来人）。参见 [[amener]] 的四词辨析：「跑出去的」是带走，「跑进来的」是带来

**英法交叉核对（受影响的英语词）**
- **借入英语**：**emporter 本身未借入英语**（英语没有 \*emport 一词）；但它的拉丁词干 **portare** 借了一大片——**port**（v.「搬运」1560s ← 法语 porter ← 拉丁 portare）；**portable**（early 15c. ← 法语 portable ← 晚期拉丁 portabilis）；**import**（v. early 15c.「含有……意思」← 拉丁 importare；商业义「进口」1540s）；**export**（by **1610s**，或可溯至 late 15c. ← 拉丁 exportare）；**transport**（late 14c. ← 古法语 transporter / 拉丁 transportare）；**deport**（1640s ← 法语 déporter ← 拉丁 deportare）
- **共祖未借入**：**important / importance**——见下「曲折路径」；法语侧**无法**经由 emporter 影响英语
- **曲折路径（[[important]] 词源补记）**：法语 **important** 系**意大利语借词**（15c. ← 意大利语 **importante**，其前身仍为拉丁 **importare** ＝ in- + portare；CNRTL 载法语首见 **1476、1528**——2026-10-03 经检索转引；这为 [[important]] 页「借入年代待 TLFi 核实」提供 CNRTL 线索）；英语 **important** 另作两说——etymonline 作 **mid-15c.** 直承中世纪拉丁 **importantem**，Collins 作 **16c.** 经古意大利语 **importante**——**两说并存，不折中**
- 核对：已核实（CNRTL / etymonline / Collins，2026-10-03 经检索转引）——emporter 未借入英语；port / portable / import / export / transport / deport 均承拉丁 portare 线；important 法语侧为意大利借词（1476 / 1528 首见，CNRTL），英语侧两说不一（中世纪拉丁 mid-15c. vs 古意大利语 16c.）

**同义 / 搭配 / 易混**
- 搭配：`emporter qch avec soi`（随身带走）；`à emporter`（外带）vs `sur place`（堂食）；`s'emporter contre qqn`（对某人生气）；`l'emporter sur qqn / qch`（胜过、占上风）；`un plat à emporter`（打包的菜）；`La maladie l'a emporté.`（疾病夺走了他。）
- **易混（四词辨析，见 [[amener]]）**：**emporter**（带走**物**）｜ **emmener**（带走**人**）｜ **apporter**（带来**物**）｜ **amener**（带来**人**）——em-/a-（去/来）× porter/mener（物/人）两条轴
- **faux ami**：英语没有 emporter 的对应借词（英语「带走」是 take away / take out）；别把法语 emporter 与英语 import 直接对应（import = 进口 / 意味，法语对应 importer / importer de）；`à emporter` 更接近英语 **takeaway / to go**，不是 "to carry"
