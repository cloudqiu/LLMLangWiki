# brûlant

**释义**：灼热的、滚烫的、烫手的；灼人的（阳光、沙漠）；炽热的、激烈的（情感、话题、争议） ｜ très chaud ; qui brûle au toucher ; passionné, vif

**例句**
- _Attention, la soupe est brûlante !_ 小心，汤很烫！
- _Ils marchent sous un soleil brûlant._ 他们在灼人的烈日下行走。
- _C'est un sujet brûlant en ce moment._ 这是眼下一个炽热（热门）的话题。

**形态要点**
- 形容词：阳性 **brûlant** ｜ 阴性 **brûlante** ｜ 阳复 **brûlants** ｜ 阴复 **brûlantes**（-ant → -ante 规则变化）
- 由动词 **brûler**（烧）的**现在分词**作形容词——brûler 是 **1er groupe**（je brûle / nous brûlons，过去分词 brûlé）；brûlant 亦可带补语：`brûlant de + inf.`（渴望……）
- 位置：多在名词后（une soupe brûlante）；表「紧迫、炽热」的转义多在名词前

**词源 / 构词**
- **拆解**：brûlant ＝ 动词 **brûler**（烧）＋ 现在分词尾 **-ant**（拉丁 -antem）——「正在烧的」
- **演变**：古法语 **brusler / bruller**「烧」（brûler 首证 **1120 年**，CNRTL/TLFi——2026-10-01 经检索转引）→ 现代 brûler → 现在分词形容词 brûlant；**词源本身有争议**：一说（Gamillscheg 说）出自拉丁 **ustulare**「烧焦」（ustus ← urere「烧」），再受日耳曼 br- 系「烧」词（如 burn）影响换形；另说经俗拉丁 \*brodum（沸汤，日耳曼借词，同 brew）。两说并存，此处如实标注，未武断定夺
- **同族 / 派生**：brûler（烧）、brûlure（烧伤）、brûleur（燃烧器）、brûlot（火攻船；煽动性文章）；英语一侧见下节
- **记忆钩**：brûlant ＝「正在烧的」——从 brûler 一路烧过来；现在分词 -ant 自带「持续燃烧中」的热度

**英法交叉核对（受影响的英语词）**
- **借入英语**：**broil**（v.「烤、炙」——「直接火烤」义 late 14c、「烧」义 mid-14c ← 古法语 **bruller / brusler**，即 brûler 的古形，同出本词族〔etymonline，2026-10-01 经检索转引〕）；**brûlée**（原样借入，仅存于 **crème brûlée**「焦糖布丁」← 法语 brûlé「烧焦的」——brûler 的过去分词）
- **共祖未借入**：**burn**（英语本族日耳曼词 ← PIE \*bhreu-「燃烧、沸腾」——据一说其 br- 形反过来影响了 brûler 的拼写，但 burn 本身非借入，与 brûler 亦非同源）
- 核对：已核实（etymonline，2026-10-01 经检索转引）——broil「烤」late 14c /「烧」mid-14c，均注「← 古法语 bruller，早作 brusler（11c.），来源多有争议」；crème brûlée 的 brûlée 即 brûlé

**同义 / 搭配 / 易混**
- 搭配：`une soupe / une boisson brûlante`（滚烫的汤 / 饮料）；`un soleil brûlant`（灼人的太阳）；`un sujet brûlant`（热门话题）；`brûlant d'impatience`（急不可耐）
- **易混（热度梯度）**：**brûlant**（灼热的——烫手、灼人）vs **chaud**（热的——一般）vs **bouillant**（沸腾的、滚开的——液体）vs **torride**（酷热的——气候 / 沙漠）；液体「沸点」用 bouillant 不用 brûlant
- **faux ami**：英语 burning（燃烧的 / 迫切的）义域大体对应 brûlant；但英语 **broil** 是「烤」不是「烧烫」，别与 bouillant「沸腾」混
