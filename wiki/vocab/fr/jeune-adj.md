# jeune

> **命名说明**：本页文件名为 `jeune-adj.md`（**非** `jeune.md`）——按 CLAUDE.md「同语言近形一律先用带词性后缀」的消歧规则（同 [[sur-prep]] 之例）。原因：inbox 的 **jeune**（形容词「年轻的」）与日后可能收录的 **jeûne**（n.m.「禁食」，带长音符 ê）**ASCII 转写后同为 `jeune`**，必撞名。故本页先加词性后缀预置；**日后收 jeûne 时应记为 `jeune-nm.md`**，并与此页互链。

**释义**：（1）年轻的、年少的——人或动物处于生命早期（un jeune homme 年轻人）；（2）年幼的、年纪小的——比较年龄（plus jeune que moi 比我年轻）；（3）年轻人的、青年特有的（la mode jeune 年轻人的时尚）；（4）引申「稚嫩的、不成熟的」（un vin jeune 新酒）；名词化 **les jeunes**（年轻人，指群体） ｜ qui est dans la première partie de la vie ; peu avancé en âge ; qui a l'aspect de la jeunesse

**例句**
- _C'est un jeune homme très poli._ 这是个很有礼貌的年轻人。
- _Elle est plus jeune que moi._ 她比我年轻。
- _Les jeunes adorent ce groupe._ 年轻人喜欢这个乐队。（名词化，指群体）
- _Ils se sont mariés jeunes._ 他们很年轻就结婚了。（**副词化**用法，jeunes 不配合主语）
- _Il est la deuxième plus jeune de la classe._ 他是班里第二年轻的。

**形态要点**
- 形容词（adj.）：阳性 **jeune** ｜ 阴性 **jeune**（**阴阳同形**）｜ 复数 **jeunes**（**不分阴阳，只加 -s**）
- **关键：jeune 阴阳同形**——Ce garçon est jeune / Cette fille est jeune 完全同形，是少数「阴阳性不区分」的形容词（同型：triste、facile、rouge 一类以 **-e** 结尾的形容词）
- 名词化：**un jeune / une jeune**（一个年轻人）；**les jeunes**（年轻人群体，作整体）
- 比较级（不规则的副词式）：plus jeune / moins jeune / aussi jeune **que**；le plus jeune（最小）
- **副词化**：形容词可当副词用（**jeunes** 不随主语变化）——Ils se sont mariés **jeunes**（他们年纪很轻就结婚了）
- ⚠️ **拼写陷阱**：jeune（年轻，无音符）≠ **jeûne**（禁食，n.m.，带长音符 ê）≠ **déjeuner**（午饭）——三词形近异源（见下节）

**词源 / 构词**
- **拆解**：古典拉丁 **juvenis**（adj.「年轻的」；n.「年轻人、青年」）← **PIE \*yeu-**「生命力、青春活力」（\*yeu- 的带后缀形）。同根一串：拉丁 **juvenis / iunior**、梵语 **yuvan-**、立陶宛语 **jaunas**、俄语 **junyj**、古爱尔兰语 **oac**、威尔士语 **ieuanc**——**以及日耳曼一支**的古英语 **geong**（详见英法交叉）
- **演变（CNRTL/TLFi，2026-10-04 经 WebSearch 转引）**：
  - 古典拉丁 **jŭvenis** → **通俗拉丁 \*jŏvenis**（**-uv- 在唇音前变 -ov-**，o 为开音；据 FEW t. 5, p. 95a、Fouché p. 368）→ 古法语 **juenne / juevre / juenvre / gienvle / giemble**（诸形）→ 现代 **jeune**
  - **首证（TLFi）**：**début du xiie s.**，*Alexis*（éd. Chr. Storey, Prol.：「**la sue spuse juvene**」）——⚠️ 注意：此处**抄本仍作拉丁化拼写 juvene**，非现代 jeune；TLFi 逐条记录：
    - **1160-74** Wace, *Rou*（éd. Holden, II, 1729）*geunes hons*；同书 III, 1848 *joefne pucele*
    - **ca 1140** 比较级用法表相对年龄（Geffrei Gaimar, *Estoire des Engleis*, 4261：「Quinze ans aveit li jovenur」）
    - **ca 1213** 贬义「无经验的、癫的」（*Faits des Romains*）
    - 名词化：**début xiie s.** *li vieil ot les juignurs*（*Ps. Oxford*）；**1155** Wace, *Brut*, 6752 *les juenvles*
  - 义项要点：现代「年轻」义**début xiie s.** 已见；贬义「不成熟」**ca 1213** 起
- **同族 / 派生（法语）**：**jeunesse**（n.f. 青春、青年时期）；**jeunet / jeunot**（adj./n. 口语「年轻的、小年轻」，略带亲昵或微贬）；**rajeunir**（v. 使年轻、变得年轻）；**jeune homme / jeune fille**（年轻人／姑娘）；**jeune marié**（新婚者）
- **⚠️ 形近异源（本页必记，切勿串线）**：**jeune**（年轻 ← juvenis「年轻」）与 **`jeûne`**（n.m. 禁食 ← 拉丁 **jejunium** ← **jejunus**「空腹」）／**`déjeuner`**（n.m./v. 午饭 ← dé- + jeün ← 拉丁 **jejunare**「禁食」，本义「**打破禁食**」）——**拼写仅差一个音符，词源却完全两线**（juvenis 系 vs jejunus 系），并非同源
- **记忆钩**：**年轻的 juvenis（PIE \*yeu- 生命力），禁食的 jejunus（拉丁）**——一个管「年纪」，一个管「空腹」；别把 jeune / jeûne / déjeuner 当一家

**英法交叉核对（受影响的英语词）**
- **本页核心：同一 PIE 根 \*yeu-「生命力、青春活力」，英语走了两条支流——拉丁支（借入／共祖）与日耳曼支（本土）**：
  - **拉丁支（与 jeune 同出拉丁 juvenis）**：
    - **`juvenile`**（adj. **1620s**「年轻的、青春的」← 拉丁 **iuvenilis**「属于青年的」← **iuvenis**；1660s 转「适合青年的」；名词「年轻人」1733；**juvenile delinquency 1816**、juvenile delinquent 1817；俚语 **juvie** 1941）——**直接借自拉丁**（非经法语），与 jeune **共祖**
    - **`junior`**（adj. **late 13c.**「较年轻的」← 拉丁 **iunior**，即 iuvenis 的**比较级**；置于姓名后表「小」（Jr. 1620s）；1766「地位较低的」；1862 美国「大学三年级」）——共祖
    - **`juvenescent`**（adj.「变年轻的」← 拉丁 juvenescent-）、**`rejuvenate`**（v.「使恢复青春」← re- + 拉丁 juvenis）、**`juvenilia`**（1620s「少年之作」）——共祖（**部分年代未逐核，待验证**）
  - **日耳曼支（与 jeune 同根不同支，本页重点）**：
    - **`young`** ← 中古英语 **yong** ← 古英语 **geong**「处于生命早期的；年轻的、新的」← 原始日耳曼 **\*junga-** ← **PIE \*yeu-**——同族：古撒克逊 / 古弗里斯兰jung、古诺尔斯 ungr、荷兰 jong、德语 jung、哥特语 juggs
    - ⚠️ **结论**：英语 **young** 与法语 **jeune** 都上溯 PIE \*yeu-「生命力」，但 **jeune 走拉丁 juvenis 一线、young 走日耳曼 \*junga- 一线**——**同根不同支**（distant cognates）；**谁也没借谁**。这是本页最值得记的一对（与 [[vie]]↔life、[[quand]]↔when 的「共祖非借入」同型，但更进一步：**同一 PIE 根在两语各自演化出本土词**）
- **借入英语（法语短语整体借入，近代）**：**`jeunesse dorée`**（「镀金青年」，1830 后借入 ← 法语 jeunesse dorée）；**`jeune fille`**（英语直接借入的短语，1802 首见 ← 法语 jeune + fille）；**`jeune premier`**（法剧男主角，1880s 借入）——**法语短语原样入英**，非经拉丁。**待验证**（诸短语借入年代系 etymonline 检索转引）
- **罗曼语横向（共祖同支）**：西语 **joven**、意语 **giovane**、葡语 **jovem**、加泰语 **jove**——皆出拉丁 juvenis，与法语 jeune **同支**（对比英语 young 的日耳曼支）
- 核对：英语侧（juvenile 1620s ← 拉丁 iuvenilis ← iuvenis；junior late 13c. ← 拉丁 iunior；young ← 中古 yong ← 古英语 geong ← 日耳曼 \*junga- ← PIE \*yeu-；juvenile delinquency 1816；juvenilia 1620s）2026-10-04 经 **etymonline 直读**；法语侧（étymon「latin vulg. \*jŏvenis ← 古典 jŭvenis」、-uv- → -ov- 规则 FEW 5, 95a／Fouché 368、首证 début xiie s. *Alexis*、1160-74 Wace、ca 1140 Gaimar、ca 1213、名词化）2026-10-04 经 **WebSearch 转引 CNRTL/TLFi**（cnrtl.fr/etymologie/Jeune 条目被检索引出，直连仍失败）

**同义 / 搭配 / 易混**
- 搭配：`jeune homme`（年轻人、小伙子）｜ `jeune fille`（姑娘、女孩）｜ `les jeunes`（年轻人群体）｜ `plus jeune que`（比……年轻）｜ `jeune marié / jeune mariée`（新婚者）｜ `un jeune loup`（有野心的年轻人，喻）｜ `jeune fille au pair`（互惠生）｜ `jeune cadre`（青年干部／管理人员）｜ `la jeunesse`（青春）
- **易混（形近异源，必记）**：**jeune**（adj. 年轻 ← **juvenis**）｜ **`jeûne`**（n.m. 禁食 ← **jejunium / jejunus**）｜ **`déjeuner`**（n.m./v. 午饭 ← dé- + jeün ← **jejunare**「禁食」，本义「打破禁食」）——三者形近，**juvenis 线 vs jejunus 线，不同源**
- **辨析**：**jeune**（年轻的——客观年龄）｜ **`jeunet` / `jeunot`**（口语，略带亲昵或微贬）｜ **`nouveau`**（新的——指事物新旧，非年龄，见 [[nouveau]]）｜ **`petit`**（小的——体积／年龄，见 [[petit]]）｜ **`mineur`**（未成年的；次要的——法律／比较义）
- 反义链：jeune ↔ **`vieux` / `âgé`**（年老）；jeune ↔ **`ancien`**（旧的，指物）
- 相关：[[nouveau]]（新旧轴）；[[petit]]（大小轴）；[[vie]]（jeunesse ↔ vieillesse 对：人生的两端）；[[sur-prep]]（命名消歧同型之例）
