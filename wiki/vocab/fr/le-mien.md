# le mien

> 收录说明：inbox 形式 `le mien`（多词单位）→ 文件名 `le-mien.md`，word 保留空格原形。本页办**独立主有代词**页，与 [[mon]]（主有限定词）对照记忆。

**释义**：我的（那一个）——**独立主有代词**（pronom possessif），代替「我的 + 名词」，**带定冠词** ｜ pronom possessif de la 1re personne, « celui qui est à moi »

**例句**
- _Ce livre est le mien._ 这本书是我的。
- _Ton avis compte plus que le mien._ 你的意见比我的更重要。
- _Mes grands-parents ? Les miens habitent à Lyon._ 我祖父母？我（那边一家）住在里昂。（les miens ＝ 我的家人）
- _Il a pris mon stylo ; j'ai pris le sien._ 他拿了我的笔，我拿了他的。（与 le tien / le sien 成系列）

**用法要点**
- **全系列（本页必给的表）**——独立主有代词 ＝ **定冠词 + 主有形容词的「重读形」**，**与「所有物」的性数配合**（不随所有者）：

  | 所有者 | 阳性单数 | 阴性单数 | 阳性复数 | 阴性复数 |
  | --- | --- | --- | --- | --- |
  | 我 | le mien | la mienne | les miens | les miennes |
  | 你 | le tien | la tienne | les tiens | les tiennes |
  | 他 / 她 | le sien | la sienne | les siens | les siennes |
  | 我们 | le nôtre | la nôtre | les nôtres | les nôtres |
  | 你们 / 您 | le vôtre | la vôtre | les vôtres | les vôtres |
  | 他们 | le leur | la leur | les leurs | les leurs |

- **两个高频拼写点**：①**nôtre / vôtre 带长音符**（区别于限定词 notre / votre——**notre livre** 我们的书 vs **le nôtre** 我们的那个）；②**leur 单复同形、不加 -s**（le leur / les leurs——注意 les leurs 才有 -s，le leur 无）。
- **与 [[mon]] 的分工（本页核心）**：**mon / ma / mes** 是**主有限定词**——**必跟名词**（mon livre 我的书）；**le mien / la mienne / les miens** 是**代词**——**独立、后不接名词**（Ce livre est le mien）。一个「黏」名词，一个「替」名词。
- **定冠词不可省**：le mien（单独 \*mien 不成立，除非作形容词的文言用法：un **mien** ami 我的一个朋友）。
- **口语 / 书面**：日常更常说 **à moi**（Ce livre est à moi）；le mien 偏书面或对比语境（强调「**我的那个**」）。
- **义项延伸**：复数 **les miens / les miennes** 常指「**我的家人、我的人**」（＝ mes proches）。

**词源 / 构词**
- **拆解**：**定冠词 le** + **mien**（← 拉丁 **meum**，主有形容词 **meus** 的**宾格**）
- **演变（Académie、DHLF、Nyrop，2026-10-05 转引）**：
  - 拉丁 **meum** → 古法 **meon**（**842**《斯特拉斯堡誓词》——*cist meon fradre*「我这个兄弟」、*meon vol*「我的意愿」，**最早的法语书面文献**之一）→ **mien**；阴性 **mienne** 由 mien 重造（13c）；**meon 是法语一切独立主有代词的起点**（Nyrop）
  - **重音分岔（关键）**：同一个 meum，**非重读（proclitique）→ mon**（贴名词），**重读 → mien**（独立）——**mien 与 [[mon]] 同出一词、只是重音位置不同的两副形态**（与 [[moi-meme]] 的 me / moi 同机制）
  - **其他各身靠拢**：13 世纪起 **tien / sien** 以 **mien** 为模式重造（古法本作 *tuen / suen*）；nôtre / vôtre / leur 另从 *noster / voster / illorum* 一线来
- **同族 / 派生（法语）**：**mon / ma / mes**（限定词，见 [[mon]]）、**mien / mienne**（文言形容词「我的」——un mien ami）、**les miens**（我的人）、tien / sien / nôtre / vôtre / leur 全系列；**mienneté**（罕见：「我的东西、我的特性」）
- **记忆钩**：**meum 一分为二**——挤在名词前（非重读）成了 **mon**，独立出来（重读）成了 **le mien**；正如 illos → les / eux（见 [[eux]]）

**英法交叉核对（受影响的英语词）**
- **借入英语**：无——le mien 短语未入英语
- **共祖未借入（本页核心）**：英语 **`mine`**（possessive pronoun「我的（东西）」）← 古英语 **min** ← 原始日耳曼 **\*minaz** ← PIE **\*me-**（第一人称斜格）——**与法语 mien（← 拉丁 meum ← PIE \*me-）共祖非借入**；两语都从 \*me- 长出「我的（独立代词）」，只是法语走拉丁 meum、英语走日耳曼 \*minaz（同型：[[mon]]↔my/mine、[[moi-meme]]↔myself 的共祖对照）
- **同形假朋友（本页必记）**：英语 **`mien`**（n.「**神态、仪表、风采**」，**1510s**）**不是**来自法语 mien！——etymonline：英 mien 或截自 **demean**（举止），或受**法语 `mine`**「**神色、表情**」影响而成（法语 mine 词源不明，或与凯尔特语 *min* 有关）——故 **英语 mien（神态）≠ 法语 mien（我的）**：**同形异源**（对照 [[vie]]）
- 核对：英语侧（mine ← OE min ← PGmc \*minaz ← PIE \*me-；mien n. 1510s ← demean ／ 法语 mine）2026-10-05 经 **etymonline 直读**；法语侧（mien ← 拉丁 meum、古法 meon 842 斯特拉斯堡誓词、meum 非重读 → mon / 重读 → mien、tien/sien 13c 类比）2026-10-05 经 **WebSearch 转引 Académie 9e、DHLF、Nyrop《Grammaire historique》、Anglade《Grammaire élémentaire de l'ancien français》**（CNRTL 直连仍 sinkhole）。**待验证**：①TLFi「mien」原条首证定年未直连；②Bourciez 对 meum → mien 音变的疑难（有 \*mëum 等异说，**未定论**）；③nôtre / vôtre 长音符定型年代未核

**同义 / 搭配 / 易混**
- 搭配：`le mien / la mienne`（我的那个）｜ `les miens / les miennes`（我的人、我的家人）｜ `un mien ami`（我的一个朋友——文言形容词）｜ `Ce livre est le mien / à moi`（口语）
- **易混（主有词三级）**：**mon / ma / mes**（**限定词**，跟名词——见 [[mon]]）｜ **le mien / la mienne**（**代词**，独立——本页）｜ **à moi**（口语替代：C'est à moi）——**英语 mine 一个词通吃，法语要分限定词 / 代词 / 介词短语**
- 系列：le tien（你的）｜ le sien（他的）｜ le nôtre（我们的）｜ le vôtre（你们的）｜ le leur（他们的）——**tien / sien / nôtre / vôtre / leur 诸页待建**
- 相关：[[mon]]、[[moi-meme]]、[[son]]（他 / 她的限定词）
