# compte

**释义**：（1）账户、户头；（2）计数、数目；（3）账、账目 ｜ total, dénombrement ; état des recettes et dépenses ; (banque) compte bancaire

**例句**
- _J'ai ouvert un compte à la banque._ 我在银行开了一个账户。
- _Le compte est bon._ 数目对了；账算得对。
- _Fais le compte de tes dépenses._ 把你的开销算一算。

**形态要点**
- 名词：`le compte`（m.）；复数 `comptes`（规则加 -s）
- 相关动词：**compter**（数、计算、算作——1er groupe，助动词 avoir，过去分词 compté）；注意 **conter**（讲述、叙述——与 compter 同源，是「数/算」的兄弟动词，见词源）
- 高频搭配：`se rendre compte (de)`（意识到、发觉）、`tenir compte de`（顾及、考虑到）、`un compte bancaire`（银行账户）、`un compte rendu`（报告、汇报）、`à la fin du compte / en fin de compte`（归根结底）

**词源 / 构词**
- **拆解**：拉丁 **computare**「计算、合算」＝ **com-**（共同、一起）+ **putare**「估算、结算」（本义「修剪」——「剪枝 → 理清 → 估算」）→ 名词 **computus**「计算」
- **演变**：拉丁 computus「计算」→ 古法语 **conte** / **compte**（「计算、账目」）→ 现代 **compte**；动词线一分为二：**compter**「数/算」（保留 p）与 **conter**「讲述」（脱落 p）——「数数」与「讲故事」本是一家（「点数 → 逐条讲述」），现代法语两词分工（据 TLFi，2026-10-01 经检索转引）
- **同族 / 派生**：compter（数、算）、conter（讲述）、comptable（会计、可数的）、comptabilité（会计学）、raconter（讲述——re- + a- + conter）、conte（故事）；英语一侧见下节
- **记忆钩**：compte ＝ com-（合在一起）+ put-（算）＝「合起来算」→ 账、数目；「讲（conter）」和「算（compter）」是同一颗「点数」种子长出的两根藤

**英法交叉核对（受影响的英语词）**
- **借入英语**：**count**（v. late 14c.「数、算」← 古法语 conter「数、算」，也含「讲故事」义——etymonline，2026-10-01 经检索转引；n.「计算、总数」early 14c. ← 古法语 conte）；**account**（c.1300「账目」← 古法语 acont ← a- + cont ← 晚期拉丁 computus）；**compute**（1630s ← 法语 computer ← 拉丁 computare——count 的 doublet）；**raconteur**（1817 ← 法语 raconteur ← raconter「讲述」）；**recount**（← re- + conter）
- **共祖未借入**：**tally / tell / tale**（英语「数、讲」本族词——英语 tell 的「讲述」义由「数」义而来，与法语 conter 的「数→讲」是**平行语义演化**，非同源借入）
- 核对：已核实（etymonline，2026-10-01 经检索转引）——count(v.) late 14c. ← 古法语 conter；account c.1300 ← 古法语 acont；compute 1630s；raconteur 1817；etymonline 明言「现代法语区分 compter（数）与 conter（讲），二者同源」（Modern French differentiates compter and conter, but they are cognates）
- **命名警示**：英语 count 另有 n.「伯爵」（c.1300 ← 古法语 conte ← 拉丁 comes「同伴」）——此「count 伯爵」与「count 数」**不同源**，对应法语 [[comte]]（见易混）

**同义 / 搭配 / 易混**
- 搭配：`se rendre compte de`（意识到——高频！）；`tenir compte de`（顾及）；`en fin de compte`（归根结底）；`compte bancaire`（银行账户）；`compte rendu`（报告）；`à bon compte`（廉价地、轻易地）
- **核心易混——同音三兄弟**（都读 /kɔ̃t/）：**compte**（账户、计数——本词）vs **conte**（故事、童话——le conte de fées 童话，出 conter「讲述」）vs **comte**（伯爵——le comte，出拉丁 comes「同伴、随从」）——**三词同音但词源分两族**：compte/conte 同出 computare（数→讲），comte 出 comes（伴→伯爵），勿混
- 再易混：**compter**（数、算）vs **conter**（讲述）——一个保留 p、一个脱落 p；「给我算算账」用 compter，「给我讲个故事」用 conter
