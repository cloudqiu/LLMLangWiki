# heureux

> 收录说明：inbox 里的遇到形式是 **`heureuse`（阴性）**——按 lemma 规则归并至阳性单数 **heureux**。（阴性形 heureuse 见「形态要点」。）

**释义**：（1）**幸福的、快乐的**（une enfance heureuse 幸福的童年）；（2）**幸运的、运气好的**；（3）**（事物）有利的、吉祥的**（un heureux événement 喜事 / 有喜）；（4）**侥幸的、有惊无险的**（s'en tirer heureux）｜ qui éprouve du bonheur ; favorisé par la chance ; favorable, propice

**例句**
- _Je suis très heureux de te voir._ 见到你我很高兴。
- _Ils ont eu une enfance heureuse._ 他们有过幸福的童年。
- _Nous sommes heureux que tout se soit bien passé._ 我们很高兴一切顺利。

**形态要点**
- 异形阴性：m. **heureux** ｜ f. **heureuse** ｜ m.pl **heureux**（**阳性复数同形**）｜ f.pl **heureuses**
- **h 为 h muet**——可连诵：*les‿heureux*；*un‿heureux hasard*
- 位置：性状一般**后置**（une vie heureuse），少数固定**前置**（un heureux événement / un heureux hasard）
- 副词 **heureusement**；反义 **malheureux / malheureusement**；名词化 le/la heureux(se)
- 结构：`heureux de` + 不定式｜ `heureux que` + 虚拟式
- 短语：`heureux comme un poisson dans l'eau`（如鱼得水）｜ `heureux comme un prince`｜ `avoir la main heureuse`（手气好 / 点石成金）｜ `encore heureux !`（幸好 / 那当然）｜ `heureux élu`（幸运入选者 / 心上人）

**词源 / 构词**
- **拆解**：**heureux** ← **heur**（名词「运气、命数」）+ **-eux**（← 拉丁 **-osus**）。**heur** ← 古法语 **oür / aür / eür**（12 世纪）← 通俗拉丁 **\*agurium**（= \*augurium 的变体）← 古典拉丁 **augurium**「预兆、占卜」（augur ← avis「鸟」——**观鸟占卜**）
- **首证**：
  - **heureux**：**1213**（Littré / Usito）；**Académie 9e：「xiie siècle, *euros*」**（12 世纪形 euros / eüreux）——**两说**
  - **heur（名词）**：fr.wiktionary 记 **1306**；古形 oür / aür / eür 为 **12 世纪**
- **演变**：augurium「预兆」→ 通俗 \*agurium → 古法 eür「**命数、运气（好坏皆可）**」→ 狭义化「**好运**」（残存于 *avoir l'heur de*）→ heureux「有好运的 → 幸福的」
- **关键坑（务必记住）**：**h 不是词源性的**——初始 h 于中世纪**因与 heure（← 拉丁 hora「小时」）同音而类推添加**；古人写 aür / eür **无 h**；*bonheur* / *malheur* 的 h 即「bon (h)eur / mal (h)eur」类推所致——**heureux 与 [[heure]] 无词源关系**
- **同族 / 派生（法语）**：bonheur、malheur、heureusement、malheureux、heur
- **记忆钩**：**「幸福」＝「中了好彩头」**——heureux 的底子 heur 是「运气」（观鸟占卜来的），幸福首先是「运气好」

**英法交叉核对（受影响的英语词）**
- **借入**：英语**未借入** heureux 本身——检索未见可靠书证（**待验证**）
- **共祖（同出拉丁 augurium，非法语传入）**：英语 **augury / augur**——**拉丁直借**，与法语 heur **同出但不同路**（「英法同源非同路」样本）
- **无关系**：英语 **happy** 与 heureux **无词源关系**（happy ← 中古英语 hap「运气」← 古诺斯 **happ**）——**同义异源**
- 核对：英语侧据 etymonline 检索（2026-10-13）——**状态属「转引」**；heureux 无借入一项**待验证**

**同义 / 搭配 / 易混**
- 同义：content（满意——**程度更轻、指当下**）、joyeux、ravi、enchanté；反义：malheureux、**triste**（见 [[triste]]）、malchanceux
- **辨析**：**heureux**（幸福 / 幸运——强调命数与持久幸福）vs **content**（当下满意）vs **joyeux**（欢快——外显的喜气）
- 搭配：`rendre heureux`（使幸福）｜ `trop heureux de`（非常乐意）｜ `heureux hasard`（幸运的巧合）｜ `heureux événement`
- 相关：[[chance]]（同「运气」域）、[[triste]]（反义）
