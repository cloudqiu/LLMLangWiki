# là-bas

**释义**：（1）**那边、在那边**（指较远处——与 **ici**「这里」相对）；（2）**（贬）遥远的（穷乡僻壤）**（aller vivre là-bas 去那边过日子）；（3）**（宗教 / 引申）那个世界、彼岸**（l'ici-bas 与 **là-haut** 对举） ｜ en un lieu éloigné, dans cette direction éloignée

**例句**
- _Regarde là-bas, près de l'arbre._ 你看那边，树旁边。
- _Ils sont partis vivre là-bas, au Canada._ 他们去加拿大那边生活了。
- _Ici, on est bien ; là-bas, on ne sait pas._ 这儿挺好，那边就不清楚了。

**形态要点**
- 多词单位（loc. adv.）：`là-bas`——**s 不发音** /la.ba/（变体 /lɑ.ba/）
- **空间三级（重点）**：**ici**（这里）→ **là**（那里——较近）→ **là-bas**（**那边——较远**）——法语用三级拉开距离，英语 here / there 只两级
- 对举：**ici-bas**（此世、人间）↔ **là-haut**（天上、彼岸）；**là-bas** 常指「那边（远）」
- 书写：**là 带音符**（表示 /la/ 副词义），**≠ la**（冠词 / 宾语代词——见 [[la-art]] / [[la-pron]]）

**词源 / 构词**
- **拆解**：**纯法语复合词**（**无**拉丁 *(il)lac bassus* 之说）——**là** ← 拉丁 **(il)lac**（指示副词，法语 là / ci 一对）+ **bas** ← 拉丁 **bassus**「低」（词源**存疑**：或出奥斯坎 / 凯尔特 / 希腊 *basson*）
- **演变 / 首见两说**：①**CNRTL / Usito 记 1532**（Rabelais《Pantagruel》ch. XX，「在下界」）；②**FEW 记 début xve s.**（形 la bas 1402/03，「往更低处」）——**两说并列**。义变：**「在下面」（1558–1616）→「在远处」（1833 前，Béranger）**
- **同族 / 派生（法语）**：**là**（那里 / 这）、**bas**（低 / 下部）、**ici**、**ici-bas**、**là-haut**
- **记忆钩**：là-bas 字面是「**（在）低处那边**」——从「下边」到「远处」，站在高处往下望，远的东西自然「在低处」

**英法交叉核对（受影响的英语词）**
- **同义异源**：英语「那里」用 **there**（← 古英语 *þær*，日耳曼）——与 là-bas **无亲缘**
- **借入（同族非同词）**：**bas**（法语「低」）一线进了英语——**base**（adj. late 14c「低的」← 古法 **bas** ← 晚期拉丁 bassus）、**bass**（低音）——但**无英语词借自 là-bas 本身**
- 核对：英语侧（there ← OE þær；base ← 古法 bas ← bassus）经检索转引 etymonline（2026-10-11）；法语侧 1532 / 1402-03 与 (il)lac + bassus 链据 CNRTL / Usito / FEW 转引（**待验证**）

**同义 / 搭配 / 易混**
- 搭配：`là-bas`（那边）｜ `ici-bas`（此世）｜ `là-haut`（天上）｜ `par là-bas`（往那边）｜ `voir plus loin / là-bas`（眺望远处）
- **易混**：**là-bas**（那边——远）vs **là**（那里——较近）vs **ici**（这里）——**三级空间**；**là**（副词「那里」）vs **la**（冠词 / 代词）——**音符之别**（见 [[la-art]] / [[la-pron]]）；**là-bas** vs **au loin**（遥远地，见 [[loin]]）
- 相关：[[loin]]（远）；[[la-art]] / [[la-pron]]（là vs la 音符对）；[[endroit]]（处所域）

**loc. adv.** 那边、在那边（@较远处）；引申「彼岸」（l'ici-bas）
**用法**：**s 不发音** /la.ba/；**空间三级 ici（这里）→ là（那里）→ là-bas（那边）**；对举 ici-bas / là-haut
**词源**：**纯法语复合**——là（← 拉丁 (il)lac）+ bas（← 拉丁 **bassus「低」**，词源存疑）；首见 **两说**：1532（Rabelais）vs début xve（la bas 1402/03）

**易混**：là-bas（远）vs là（近）vs ici；**là（音符）≠ la（冠词 / 代词）**
