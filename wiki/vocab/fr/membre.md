# membre

**释义**：（1）成员、会员（membre d'un club 俱乐部成员）；（2）肢体（les membres 四肢——胳膊腿） ｜ personne faisant partie d'un groupe ; bras ou jambe

**例句**
- _Elle est membre du club de lecture._ 她是读书俱乐部的成员。
- _Il a les membres longs._ 他四肢修长。
- _Les membres de la famille se réunissent chaque été._ 家人每年夏天团聚。

**形态要点**
- 名词：`le membre`（m.）；复数 `les membres`
- 两个义项共用一词：**成员**（membre d'une association / du gouvernement）与**肢体**（membres supérieurs 上肢 / inférieurs 下肢）——语境区分
- 常见：**membre fondateur**（创始成员）、**État membre**（成员国）、**membre de la famille**（家庭成员）

**词源 / 构词**
- **拆解**：拉丁 **membrum**「肢体、身体部分」（引申「部分」）——PIE **\*mems-ro** ← 根 \*mems-「肉」（同出梵语 mamsam「肉」、希腊 mēros「大腿」）
- **演变**：拉丁 membrum → 古法语 membre（Académie：**11 世纪**借入；医学文本记录 1080）→ 法语 membre；「团体成员」的比喻义：1200 年（教会「基督身体」的肢体隐喻）→ 1432 年行会 → 约 1570 年泛用「共同体成员」（据 Le Robert 史料）
- **同族 / 派生**：démembrer（肢解、瓜分——1080 年即见 desmemberr）、membrane（膜——拉丁 membrana，同出 membrum）；英语一侧见下节
- **记忆钩**：membre 双义一线牵——人是「身体」的肢体，也是「团体」的肢体；同根的 membrane（薄膜）也是「薄薄一层身体组织」

**英法交叉核对（受影响的英语词）**
- **借入英语**：**member**（约 1300 ← 古法语 membre——「肢体」义与「成员」义一并入英，英语同样双义）；**dismember**（← 古法语 desmembrer）；**membrane**（← 拉丁 membrana ← membrum——经拉丁 / 法语线）
- **共祖未借入**：无关键项（member 义域与法语完全平行）
- 核对：member 约 1300 借入（c. 1300 ← 古法语 membre，11 世纪）——据 etymonline，2026-10-01 经检索转引核实；无遗留待验证项

**同义 / 搭配 / 易混**
- 搭配：`membre de + 组织`（……的成员）；`membre fondateur / honoraire`（创始 / 名誉成员）；`les quatre membres`（四肢）
- **易混**：**membre**（成员）vs **adhérent**（会员、缴费加入者）vs **sociétaire**（社员）；**membre**（肢体）vs **articulation**（关节）vs **membre fantôme**（幻肢）
- **faux ami**：membre ≈ member（成员义完全对齐）；肢体义英语一般用 **limb**——法语 membre 义域更宽
