# trop

**释义**：（1）太、过于（trop grand 太大；trop vite 太快）；（2）太多（trop de + 名词：trop de travail 太多工作；trop de monde 人太多）；（3）（古典 / 客套义）非常、太（Vous êtes trop aimable. 您太客气了——实为强化而非过量）；（4）名词性用法：多余（en trop / de trop 多余的；un de trop 多出来的一个） ｜ plus qu'il ne faut ; excessivement ; (sens affaibli) très ; en excès

**例句**
- _Ce sac est trop lourd pour moi._ 这个包对我来说太重了。
- _Il y a trop de monde dans le métro._ 地铁里人太多了。
- _Vous êtes trop aimable._ 您太客气了。（客套义＝「非常」）

**形态要点**
- 副词位置：在形容词 / 副词**前**（trop cher 太贵、trop tard 太晚）；`trop de + 无冠词名词`（trop de bruit 太吵）；`trop… pour + 不定式`（trop fatigué pour sortir 累得出不了门，1456）；`trop… pour que + 虚拟式`（**待验证**：标准语法，本次未逐一核）
- 常用组合：`pas trop`（不太——pas trop cher 不太贵）；`un peu trop`（多了一点儿，1416）；`beaucoup trop`（实在太多，1539）；`bien trop`（实在太……，1812）；`trop peu`（太少，ca 1274）〔TLFi 年代，2026-10-03 经检索转引〕
- 名词化 / 固定短语：`en trop`（多余的——une chaise en trop 多一把椅子）；`de trop`（多余的——se sentir de trop 觉得自己多余）；`par trop`（过于——书面强调，ca 1350）；`c'en est trop`（太过分了，1655）；`c'est trop`（1450-65）；`trop, c'est trop`（够了，太过分了——现代常用）
- 发音 / 联诵：单读 /tʁo/，尾 -p **不发音**；**联诵**时 /p/ 复活转 /tʁɔp/（trop aimable /tʁɔ.pɛ.mabl/）——拼写尾 -p 是古形化石；同例 beaucoup（/bo.ku/，联诵 beaucoup‿aimable 亦出 /p/）

**词源 / 构词**
- **演变**：古法语 **trop**——**ca 1100** 两义并起于《罗兰之歌》：①「过度地」（d'une manière excessive）；②「很、非常」（tro avez tendre coer；此义 1668 年 Racine 仍用 vous êtes trop honnête）；诸年代中期线：trop par ca 1165、par trop ca 1350、un peu trop 1416、beaucoup trop 1539、bien trop 1812、trop… pour… 1456、trop de ca 1100、「过量」名词义 ca 1265〔TLFi，2026-10-03 经检索转引〕
- **拆解 / 来源**：**法兰克语 \*throp / \*thorp**「堆、群、村」（Académie 9e：11 世纪；Usito：约 1000，古低法兰克 \*thorp/\*throp「堆积、堆；村、群」；Le Monde 同）——语义走向：「村、群落」→「成堆」→「过量」〔2026-10-03 经检索转引〕
- **两说并存（中转与否）**：法兰克 \*throp 或经**通俗拉丁 troppus**（「群、群畜」）转写法语——OED（1989）持 troppus 说（记其来源不明、或即同一日耳曼源；etymonline 于 troupe 条并载）；「村 / 群 → 过量」语义桥梁的具体机制学界仍有讨论（Wiktionnaire 讨论页亦记「待解释」）——**机制细节无定论，如实并列**
- **同族 / 派生（法语）**：troupeau（畜群 ← 古法语 tropel ← \*throp）、troupe（群、队）、trop-plein（溢流口、过剩）；意大利语 **troppo** 为同源另一出口（通俗拉丁 troppus 线）
- **记忆钩**：trop 与 troupeau / troupe 同源同根——「一群」→「成堆」→「太过」。看见 trop 想「堆儿」：堆得太多＝trop

**英法交叉核对（受影响的英语词）**
- **借入英语**：**de trop**（adj.「多余的、碍事的」——法语短语整体借入：Merriam-Webster 首见 **1752**；OALD 记 mid-18th cent.；Random House 记 1750–55〔2026-10-03 经检索转引〕）；**trop**（adv.「太、过多」——英语词典收录的**书面 / 文学借词**（Collins / Random House：French，too, too much or too many；Collins 并记 Fr < ML troppus）〔2026-10-03 经检索转引〕——日常英语基本只见 de trop 固定短语，单用 trop 属文学修辞层）
- **共祖未借入**：**troupe**（n. 剧团 / 一班人）经法语 **troupe** ← 古法语 trope / trupe「一队人」——或 ← 法兰克 \*throp「聚集」（etymonline 载；OED 1989：或 ← 拉丁 troppus「群」）——与 trop 同出 \*throp 一族，但入英路径是**经法语名词 troupe**，不是 trop 借入；**troop**（军队）亦经法语 troupe 线（年代**待验证**）；**too** 与 trop **无关**（too ← 古英语 tō「到、太」，日耳曼本土线——**待验证**：未直连核对 etymonline too 条）
- 核对：已核实（TLFi / Académie 9e / Usito + etymonline / OED / M-W 转引，2026-10-03）——trop ca 1100 双义并起（《罗兰之歌》）；法兰克 \*throp/\*thorp「堆、群、村」说（Académie 9e：11c；Usito：约 1000）；troupeau ← 古法语 tropel ← \*throp（词典转引）；英 de trop 1752（M-W，作 adj.「superfluous, excessive」）；英 trop 为法语借词（Collins / Random House）。**待验证**：tropus / troppus 中转线与 \*throp 直接演变孰先孰后（OED 与 etymonline 记法并存）；too 词源未直连核

**同义 / 搭配 / 易混**
- **经典易混：trop（too——太 / 过于）vs `très`（very——很）**——`trop grand` ＝太大（越过标准，含过量 / 负面感）；`très grand`＝很大（中性强化）。`trop bien`（口语「超棒 / 太好了」）vs `très bien`（很好 / 没问题）——口语（尤其年轻语域）trop 常被当作 très 的强化使用，媒体曾专文讨论「trop 的滥用」；正式语域 trop 仍以「过量」为准〔Le Monde，2026-10-03 经检索转引〕；相关对照：`assez`（够）、`trop peu`（太少）、`pas assez`（不够）
- 搭配：`trop de + n.`；`pas trop`；`un peu trop / beaucoup trop / bien trop`；`de trop / en trop`；`par trop`；`trop… pour + inf.`；`un de trop`；`c'est trop / c'en est trop`（太过分）
- 口语链接：`trop bon`、`trop bien` 里的 trop ≈ très——正好演示口语漂移（见 [[bon]] 的 bon / bien 辨析）；`un petit peu trop`（多了一点点——见 [[petit]]）
