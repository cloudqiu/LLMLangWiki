# école

**释义**：（1）学校（aller à l'école 上学）；（2）（法国学制中）小学（école primaire / élémentaire，6-11 岁）；（3）学派、流派（l'école impressionniste 印象派） ｜ établissement où l'on enseigne ; courant, doctrine

**例句**
- _Les enfants vont à l'école à huit heures._ 孩子们八点去上学。
- _Ma sœur est encore à l'école primaire._ 我妹妹还在上小学。
- _Ce peintre appartient à l'école impressionniste._ 这位画家属于印象派。

**形态要点**
- 名词：`l'école`（f.——元音开头，冠词省音）；复数 `les écoles`
- 搭配介词：**à l'école**（在学校 / 上学）、`aller à l'école`、`entrer à l'école`、`quitter l'école`（辍学 / 放学）
- 常见复合：`école primaire / élémentaire`（小学）、`école maternelle`（幼儿园）、`école publique / privée`（公立 / 私立学校）、`école de commerce`（商学院）、`l'école de la vie`（社会这所学校）
- **法国学制链条（易混）**：école（maternelle 3-6 岁 / élémentaire 6-11 岁）→ **collège**（初中 11-15）→ **lycée**（高中 15-18）→ **université**（大学）——collège 不是「大学」、lycée 不是「学院」，勿按英语 college 对号

**词源 / 构词**
- **拆解**：拉丁 **schola**「讲学、讲学场所、学校」← 希腊 **skholē**「停止、闲暇、（用于讲学的）余暇」← **skhein**「持、止」（PIE **\*segh-**「持、握」）+ 后缀 -olē
- **演变**：希腊 skholē「闲暇」→ 希腊化时期「讲学、学派」→ 拉丁 schola（首见 Lucilius；「或系西塞罗引进的希腊借词」一说**待验证**）→ 古法语 **escole**（**11 世纪**首证，据 CNRTL / Académie 9e）→ 现代法语 école；拉丁 schola 另有一路直入古英语 scol
- **同族 / 派生（法语）**：écolier / écolière（小学生 ← 中世纪拉丁 scholaris）、scolaire（学校的、学业的——「学者词」，直借拉丁）、scolarité（学业、学籍）、scolariser（使入学）
- **记忆钩**：école 的原义是「**闲暇**」——希腊人把「有闲」当作治学的前提：skholē「闲暇」→「讲学」→「学校」；同一希腊词在各欧洲语言留下同源形式：école / scuola / escuela / Schule / school

**英法交叉核对（受影响的英语词）**
- **借入英语**：**scholastic**（adj. 1590s「经院哲学的」）← 法语 **scholastique**（14c.）← 拉丁 scholasticus ← 希腊 skholastikos「以闲暇治学的」——这一词倒是**经法语传入英语**（etymonline，2026-10-03 经检索转引）
- **共祖未借入**：**school**（英 ← 古英语 **scol** ← 拉丁 **schola**，古英语时期即已借入；中古英语 scole）与 **scholar**（← 古英语 scolere / 中世纪拉丁 **scholaris** ← schola）——二者与 école 同出拉丁 schola，但走的是**拉丁 → 古英语**直借线（另有 larhus「lore house」的意译尝试，仅见词表），**非经法语**
- 核对：école 首证 11 世纪 escole 据 CNRTL / Académie 9e（2026-10-03 经检索转引）；英 school ← 古英语 scol ← schola、scholar ← 中世纪拉丁 scholaris、scholastic 1590s ← 法语 scholastique（14c.）据 etymonline（同上）；拉丁 schola 语义（「闲暇 → 讲学 → 学校」）及 skholē ← skhein（PIE \*segh-）据 etymonline / Der Neue Pauly（经检索转引）

**同义 / 搭配 / 易混**
- 搭配：`aller à l'école`（上学）、`à l'école`（在学校）、`école primaire / maternelle / privée / publique`、`faire l'école buissonnière`（逃学）
- **易混（学制链条）**：école（小学及以下）｜ collège（初中）｜ lycée（高中）｜ université（大学）——英语 school / college / university 与法语**不完全对位**：法语 collège ≠ 大学，lycée ≠ 学院
- **faux ami**：法语 école 口语常**窄指小学**——中学生说 au collège / au lycée，大学生说 à l'université；英语 "school" 泛指一切学校（含大学：go to school）。另：「班级」是 classe、「同学」是 camarade de classe，不用 école
