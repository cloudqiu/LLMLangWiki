# diriger

**释义**：（1）**领导、管理、指挥**——居于负责地位（diriger une entreprise 管理企业；diriger un orchestre 指挥乐队；diriger un film 执导电影）；（2）**把……引向、使朝**（diriger ses pas vers 朝……走去；diriger son regard sur 把目光投向）；（3）**寄送、转达**（diriger une lettre vers 把信寄往）；（4）代词式 **se diriger vers**＝「走向、朝……去」（se diriger vers la sortie 朝出口走去） ｜ conduire, commander, gérer ; orienter, tourner vers ; (se ~) aller vers

**例句**
- _Elle dirige une petite entreprise familiale._ 她经营一家小型家族企业。
- _Il a dirigé ce film en 2020._ 他 2020 年执导了这部电影。
- _Il se dirigea vers la porte sans un mot._ 他一言不发地朝门口走去。
- _Dirigez votre demande au service compétent._ 请把申请递交主管部门。

**形态要点**
- 动词（v.）：不定式 **diriger** ｜ 组别：**1er groupe** ｜ 助动词：**avoir** ｜ 过去分词：**dirigé**
  现在时：je dirige ｜ tu diriges ｜ il·elle dirige ｜ nous dirigeons ｜ vous dirigez ｜ ils·elles dirigent
- **拼写变化（-ger）**：在 **a / o** 前保留 e 以维持 /ʒ/ —— nous dirigeon**s**、je dirigeai**s**、nous dirigerons（同 manger / nager / bouger / voyager）
- 代词式 **se diriger**（走向；可被动义：une entreprise qui se dirige bien 经营良好的企业）
- 未完成时 je dirigeais、虚拟式 que je dirige（同样保留 e）

**词源 / 构词**
- **拆解**：拉丁 **dirigere**「使成直线、排齐、引导、管理、寄送」＝ **dis-**（「分、离、各向」）+ **regere**「引导、统治、使直」（← PIE **\*reg-**「沿直线移动、统治」）。**dirigere 的过去分词**由另一路进入法语：**directus → 古法语 droit**（fr.wiktionary 明记「son participe passé a donné "droit" en français」）
- **演变（CNRTL/TLFi，2026-10-05 经 WebSearch 转引；CNRTL 直连失败）**：
  - **1381** 首证，义「faire aller dans un certain sens」（引导朝某方向，用于抽象／比喻）
  - **1495**：义「conduire d'après certaines règles」（依规则带领、管理）
  - **1656**：*diriger l'intention*（在良知决疑语境中「引导意向」）
  - **1690**：*diriger la conscience, les études*（指导良知、学业）
  - **1900**：现在分词名词化入政治语域，「dirigeant」＝掌权者（见 **dirigeant**）
  - 拉丁 **dirigere** 本身 → 意大利语 **dirigere**（De Mauro 记前 1342 年）等罗曼语同型
- **同族 / 派生（法语）**：
  - **dirigeant**（n./adj. 领导人——由 diriger 现在分词名词化，1900 起）
  - **direction**（n.f. 方向；领导层）、**directeur / directrice**（主任、校长）、**directif**（指令性的）
  - **droit**（n./adj. 权利；直的——**来自 dirigere 的过去分词 directus**，另一路，勿与 diriger 混为一谈，但同根）
  - **dirigisme / dirigiste**（n./adj. 统制经济——20c. 政治经济术语，见英法交叉）
- **记忆钩**：dirigere ＝ dis- + **regere**（「王者的引导」，同英语 **regal / regime / rule** 的 \*reg- 根）——「使排成直线」→「引向」→「领导」；同根分出法语 **droit**（直 → 权利）与英语 **direct / rectitude / regime**

**英法交叉核对（受影响的英语词）**
- **共祖（拉丁 dirigere / directus 线）**：**`direct`** —— 英语**动词** late 14c. *directen* ← 拉丁过去分词 **directus**（← dirigere）；**形容词** c. 1400「straight, undeviating」则**经古法语 direct（13c.）以及直接来自拉丁 directus 双通道**。故法语 **diriger**（动词）与英语 **direct**（形/动）同出拉丁 **dirigere**，属**共祖／部分经法语**——英语借入的是分词形 directus，法语 diriger 借入的是原形 dirigere，**同源异形**
- **借入英语（近代，法语 → 英语）**：**`dirigisme`**（n. 国家统制经济，**20c.** 借自法语，← **diriger** + **-isme**）、**`dirigiste`**（adj./n.）——英语政治经济词汇里保留的近代法语借词
- **共祖未借入**：**`regime` / `regimen` / `regal` / `regent` / `rectangle` / `rectitude` / `correct` / `erect`**（皆含拉丁 **regere / \*reg-** 根，与 diriger 同根非借入）
- 核对：英语侧（direct v. late 14c. ← 拉丁 directus；adj. c. 1400 经古法 direct + 拉丁 directus；reg- 族）2026-10-05 **etymonline 直读**；法语侧（1381 首证、1495 / 1656 / 1690 / 1900 各义项、dirigere ← dis- + regere、过去分词 directus → droit）2026-10-05 经 **WebSearch 转引 CNRTL/TLFi 与 Académie 9e**。
- 命名提示：英语 `direct` 页尚未建；日后建页因词形不同，无须 `-en` 后缀

**同义 / 搭配 / 易混**
- 搭配：`diriger une entreprise / un service`（管企业／部门）｜ `diriger un film / une pièce`（执导）｜ `diriger un orchestre`（指挥乐队）｜ `diriger son regard / ses pas vers`（把目光／脚步引向）｜ `se diriger vers`（走向）｜ `diriger qch contre qqn`（把……针对某人）｜ `diriger une enquête`（主持调查）
- **介词要点**：**diriger qch vers**（引向某处）；**diriger qch contre**（针对某人／某物：diriger une critique contre qqn）；**se diriger vers**（朝……去）；**diriger qqn à / vers**（指引某人）
- 辨析：**diriger**（领导／引向——兼「管理」与「指向」两义）｜ **conduire**（带领、驾驶；也指导致）｜ **gérer**（经营管理，偏事务）｜ **commander**（命令、指挥）｜ **orienter**（使朝某方向；引导）｜ **mener**（带领，如 mener une enquête）
- 易混名词：**direction**（方向；领导层）｜ **directeur**（领导者，人）｜ **dirigeant**（掌权者，政治语域）
- 相关：[[gouvernement]]（同出「掌舵」隐喻的管治词族，见 hub 候选）；[[courageux]]（非）、[[membre]]
