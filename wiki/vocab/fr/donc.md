# donc

> 收录说明：inbox 形式 `donc`——拼写与词典形一致，直接建页；古形 donques / doncques 已废，不另立。

**释义**：（1）因此、所以（引出推论或结果）；（2）[语气] 加强命令、请求、惊讶（Dis donc ! ／ Viens donc !）；（3）[书面/旧] 那么、于是 ｜ par conséquent ; (renforcement) marque l'insistance

**例句**
- _Je pense, donc je suis._ 我思故我在。（笛卡尔，1637——donc 引出推论）
- _Il pleut, donc je reste à la maison._ 下雨了，所以我待在家里。
- _Dis donc, tu as changé de coiffure !_ 哎，你换发型了！（语气用法，读 /di dɔ̃/ 或 /di dɔ̃k/ 均可）

**形态要点**
- 结论连接词（adv. de liaison / conj.），**无性数变化**；**位置**：① 主语与动词之间或助动词前——je suis **donc** arrivé、il a **donc** raison；② 句首——**Donc**, on part demain ?；③ 后置强调（口语）
- **读音双轨**：**/dɔ̃k/**——句首/句末、强调、或后接元音并联诵（donc il… /dɔ̃.kil/：_Il va donc à Paris_ /dɔ̃.ka.pa.ʁi/）；**/dɔ̃/**——辅音前常脱落（TLFi：par élision devant consonne）——dites donc 常读 /dit dɔ̃/，两读均可
- **语气 donc（高频）**：`Dis donc ! / Dites donc !`（喂、话说——引起注意或表示不满）｜ `Viens donc !`（来呀——缓和命令）｜ `C'est donc toi ?`（原来是你——惊讶/确认）
- 拼写史：古形 **donques / doncques** 至 17 世纪通行，现已废；勿写 \*doncque

**词源 / 构词**
- **拆解与演变**：古法语 **dunc** 首见 **980 年**（«alors»「那时/于是」义，Usito/TLFi；Académie 9e：10e s. dunc，**12e s. 表结论**，后与命令式连用）← 通俗拉丁 **\*dunc**：**dum**（亦作 **dumque**；«allons !、donc»——拉丁中强化命令，如 *dic dum*「你说呀」）× **tunc / tum**「那时」**交叉**而成（TLFi / Académie 主流说，2026-10-03 经检索转引）
- **异说（并列不折中，待验证）**：① donc 系 **adonc**（← *ad tunc*）经**首音脱落**（aphérèse）而来——可解释罗曼语普遍以 d- 对 tunc 的 t-（Wiktionnaire 说）；② ← 拉丁 **de unquam**（对应 doncques / 普罗旺斯语 doncas，比照 onques）；③ ← 拉丁 **donec**「直到」——诸说未定
- **同族 / 派生**：adonc（古语「于是」）、donques / doncques（古形）——均已废；**罗曼语平行形**：意大利语 **dunque**、加泰罗尼亚语 **doncs**、西班牙语 **entonces**（en + tonces ← tunc 系）
- **记忆钩**：笛卡尔 *Je pense, donc je suis*（1637）——donc 就是推理的「合」：前提 → **donc** → 结论

**英法交叉核对（受影响的英语词）**
- **借入英语**：无——donc 未进入英语（英语推理连接词 therefore ← there + fore 本族构词、thus ← 古英语 þus、so ← 古英语 swā，各有其源）
- **共祖未借入**：拉丁 **tunc**「那时」× 英语 **then**（← 古英语 þanne / þonne）——义近而属不同语族（拉丁 vs 日耳曼），**非共祖**，勿因义近误判；法语 donc 本身与英语任何词无借入关系
- 核对：主流说（dunc ← 通俗拉丁 \*dunc：dum / dumque × tunc 交叉）与 980 年首见（dunc；12e s. 结论义）据 CNRTL（Académie 9e）/ Usito-TLFi（2026-10-03 经检索转引）；异说（aphérèse d'adonc / de unquam / donec）据 Wiktionnaire 并列——**待验证**；读音规则（/dɔ̃k/ 与 /dɔ̃/、dis donc 两读）据 Littré 与 « Orthographe et prononciation en français »（经检索转引）。「未借入英语」为否定性结论。

**同义 / 搭配 / 易混**
- 结论侧（同义分工）：**donc**（结论——通用，位置灵活）｜ `alors`（那么——口语衔接，推理弱）｜ `ainsi`（因此——书面；另义「这样」）｜ `par conséquent`（因此——正式、强调）｜ [[c-est-pour-ca-que]]（这就是为什么——口语，引出结果从句）
- **原因侧对照（勿混方向）**：[[vu-que]]（既然/由于——引原因，口语）｜ `parce que`（因为——最通用）｜ `car`（因为——书面）｜ `puisque`（既然——前提取自已知）
- **语气 donc vs 真结论 donc**：Dis donc !（喂——纯语气）≠ Il pleut, donc je reste.（结论）
- **易混（形近）**：**donc**（结论）vs **dont**（关系代词「其、关于其」——parler de qch → dont on parle）——一字母之差、词类不同，写作常错
