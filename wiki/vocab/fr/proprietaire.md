# propriétaire

**释义**：n. ①（物权）**所有权人、物主** ②（特指）**有产者**——靠产业收益生活者 ③（引申）**（因掌握某技艺 / 知识而）享有特殊权利者** ④（形，软件）**专有的、闭源的**（*logiciel propriétaire*） ｜ personne à qui une chose appartient en propriété

**例句**
- _Je suis propriétaire de cet appartement._ 这间公寓是我的。
- _Le propriétaire a augmenté le loyer._ 房东涨了房租。
- _Ce logiciel est propriétaire, pas libre._ 这个软件是专有的，不是自由软件。

**形态要点**
- 名词：`le / la propriétaire`（**阴阳同形**）；复数 **propriétaires**
- 形容词：**阴阳同形、复数同**（un logiciel propriétaire / une licence propriétaire）
- 反义：**locataire**（房客）；近义：*possesseur*；俗语缩略：**proprio**
- 搭配介词：**propriétaire de**（……的所有者）——*être propriétaire **de** qqch*

**词源 / 构词**
- 拆解：法语**内部派生**——**propriété** + 后缀 **-aire**（← 拉丁 *-arius*）。源头拉丁 **proprietas**「所有权、特性」← 形容词 **proprius**「自己的、专属的」
- 首证：**13 世纪**（fr.wiktionary 依 **TLFi**：«XIIIe siècle, dérivé de propriété, avec le suffixe -aire»）。**⚠️ 更正记录**：另有 **1676** 年 Ménage 在《Observations sur la langue françoise》中辨 *proprietaire / propriétaireſſe* 的记载——此为**词形讨论**，**非首证**，本页不以 1676 为首见
- 同族 / 派生：**propriété**（所有权 / 地产）、**propriétaire terrien**（地主）、**copropriétaire**（共有权人）、**propriété intellectuelle**（知识产权）
- 记忆钩：**proprius（自己的）→ proprietas（所有权）→ propriétaire（拥有者）**——「属于自己的」一路变成「拥有的人」

**英法交叉核对（受影响的英语词）**
- **借入（英 ← 法 / 中世纪拉丁）**：
  - **proprietary**（形容词 **mid-15c.**，本义「教士拥有超出所需之世财」；名词 **c.1400**「物主」）← 中世纪拉丁 *proprietarius* / **古法语 *proprietaire***；「私有 / 专有的」义 **1580s** 起
  - **proprietor**（**1630s**，「殖民地特许业主」）——OED 称其「**反常构词**，17 世纪取代了词源上正当的 *proprietary*」；一般义「权利人」**1640s**
  - **property**（**c.1300**）经**盎格鲁-法语** *proprete* 改造 ← 拉丁 *proprietas*
- **共祖（非经法语）**：英语 **proper / propriety** 同出拉丁 *proprius*，多为**直接拉丁借入**
- **核对要点**：法语 *propriétaire* **阴阳同形**，英语 *proprietor / proprietress* 有性别对立；英语 *proprietary* 已窄化为「**专有技术 / 商标**」色彩（＝法语 *propriétaire* 的第 ④ 义）

**同义 / 搭配 / 易混**
- 同义：possesseur；俗 **proprio**；反义 **locataire**（房客）
- 搭配：**propriétaire terrien**（地主）、**être propriétaire de**、**propriétaire d'un chien**（狗主人）、**propriétaire d'un logement**（房东）
- **介词**：**de** 表所属（*propriétaire **de***）
- **faux ami**：英语 *proprietary* 的义域已窄化为「专有（技术 / 商标）」，而法语 *propriétaire* 首先指「**物主 / 房东**」——同一词源在英法分工不同
