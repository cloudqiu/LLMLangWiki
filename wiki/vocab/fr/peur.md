# peur

**释义**：n.f. ①**恐惧情绪**——害怕、惊恐 ②**担心、忧虑** ｜ sentiment d'angoisse, de crainte

**例句**
- _J'ai peur du noir._ 我怕黑。
- _Elle a peur de se tromper._ 她怕出错。
- _De peur d'être en retard, il est parti tôt._ 怕迟到，他很早就走了。

**形态要点**
- 名词：`la peur`（**f.**）；复数 **peurs**（规则）
- 关键搭配（**介词分工**）：**avoir peur *de*** qqch / faire qqch（怕某事 / 怕做某事）；**faire peur *à*** qqn（吓某人）；**de peur *de*** + 不定式 / **de peur *que*** + 虚拟式（以免）
- 强度阶梯：*crainte* < *peur* < *frayeur* < *terreur* < *effroi*

**词源 / 构词**
- 拆解：← 拉丁 **pavor**（宾格 **pavorem**）「惊恐、战栗」← 动词 *pavēre*「害怕、发抖」
- 演变链：*pavor*（10c.）→ *poür, pëor, pur*（12c.）→ **peur**（13c.）
- 首证（**并列冲突，不折中**）：**fr.wiktionary 记 ixᵉ siècle，881 年 *pavor***；**TLFi / CNRTL 记 2ᵉ moitié du Xᵉ siècle**（《圣莱热传》、《受难曲》）；**Académie 9e 记 xᵉ s. *pavor* ; xiiᵉ s. *poür / pëor / pur* ; xiiiᵉ s. *peur***；**Usito 记 2ᵉ moitié du 10ᵉ s. (in TLFi)** → **首现有 9c / 10c 两说并列**
- 同族 / 派生：**peureux / peureuse**（胆小的）、**apeuré**（受惊的）、**effrayant**（无词源关系，勿混）
- 记忆钩：拉丁 **pavor** 本是「**发抖**」（*pavēre*）——「怕」的原始画面是**身体在抖**

**英法交叉核对（受影响的英语词）**
- **⚠️ 同义异源（重点）**：英语 **fear**——古英语 *fær*「灾祸、突袭」← 原始日耳曼 **\*feraz**「危险」← PIE **\*per-**「尝试、冒险」。这是**日耳曼词**，**与拉丁 pavor 不同源、非共祖**——英语 *fear* 与法语 *peur* 是**典型「同义异源」**（同训不同祖）
- **共祖（拉丁 pav- 派，非经法语）**：英语 **pavid**（**1680s** ← 拉丁 *pavidus*，**直取拉丁**）、**impavid**、**pavidity**——与法语 *peur* 同出拉丁 *pavēre*，但**英语走拉丁直借**
- **反向借入**：无
- **核对要点**：*peur* 与英语 *fear* 不共祖，但 *peur* 与英语 *pavid* 共祖——**同义与同源在这一对里正好错开**，是本库「同义异源 vs 真共祖」的又一样本

**同义 / 搭配 / 易混**
- 同义（按强度递升）：**crainte**（担忧）→ **peur**（怕）→ **frayeur**（惊吓）→ **terreur**（恐怖）→ **effroi**（惊骇）；另有 **angoisse**（焦虑）
- 搭配：**avoir peur de**、**faire peur à**、**de peur de / que**（+ subj.）、**prendre peur**（受惊）、**plus de peur que de mal**（虚惊一场）
- 易混：**peur**（怕）vs **crainte**（较书面、较轻）vs **angoisse**（无具体对象的焦虑）
