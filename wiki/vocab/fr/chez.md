# chez

**释义**：（1）**在……家、到……家**——某人（或某职业者）的住所／工作处（chez moi 在我家；aller chez le médecin 去看医生）；（2）**在……那里／在……国家**（chez les Romains 在罗马人那里）；（3）**在……（人）身上、在……的作品中**（chez lui, c'est une habitude 在他身上这是习惯；chez Molière 在莫里哀笔下）；（4）**在……群体／行业中**（chez Renault 在雷诺公司） ｜ dans la maison de, au logis de ; parmi ; dans l'œuvre de

**例句**
- _Je vais chez moi._ 我回我家。
- _Elle est allée chez le coiffeur._ 她去理发店了。
- _Chez nous, on dîne à huit heures._ 在我们家，八点吃晚饭。
- _Chez Molière, l'avare est comique._ 在莫里哀笔下，守财奴是可笑的。

**用法要点**
- 介词（prép.），不变；**后面跟重读代词**（moi / toi / lui / elle / nous / vous / eux / elles）或**人／专名**（chez Pierre, chez le médecin），**不跟冠词**（≠ *dans la maison de*，后者更直白）。
- **chez + 重读代词**与**主有词 + 名词**的对立：chez moi（在我家，用 chez）↔ *ma maison*（我的房子，指建筑）；chez moi 常**连读** [ʃe.mwa]。
- 表「去／在」不区分：chez 本身不含方向（aller chez ＝ 去，être chez ＝ 在）。
- 与国名／群体：chez les + 复数冠词（chez les Français 在法国人中间）；chez + 品牌／公司（chez Renault）。
- 语域：**口语极高频**（chez moi / chez toi）；魁北克、新不伦瑞克等地常用 chez nous / vous / eux 指单数住所（见 [[french-vocabulary]] 用法）。

**词源 / 构词**
- **拆解**：**chez** ← 古法 **chiés / chiez** ← 拉丁 **casa**「房屋、小屋」的**方位格 casae**「（在）家」。关键证据：chez / 古法 chiés 词末**无元音**，正对拉丁方位格 *casae* 的 -ae 演变；而由主格 *casa* 来的名词形是古法 **chiese**（另有旁证）
- **演变（TLFi + 语法书，2026-10-05 经 WebSearch 转引）**：
  - 拉丁 **casa**「房屋」（词源不明，TLFi 记 uncertain origin）——后为 **maison** 取代而退出法语名词系统（10-11c.），却**作为介词化石存活**
  - **ca 1130** 古法 **chiés**「在……家」首证（《Couronnement de Louis》, éd. E. Langlois, 747，例 *chiés Simon*）——x-xie s. 无证
  - 义项扩展：1130「在……宅」→ **1580**「在……作品中」（chez Plutarque）→ **1592**「在……心中」→ **1681-94**「在……国／群体／时代」→ 现代诸义
  - **拼写简化**：chiés / chiez → **chez**（现代形）
  - **另说（并列，不折中）**：有研究认为 chiés 系「介词（ad / in）+ casa 的格形」的**复合** etymon（*a chiés*「到家」/ *en chiés*「在家」），语法化早于 casa 被 maison 取代；「Grammaire de la langue d'oïl」视 chez 为 *en chies* 的缩略
- **同族 / 派生（法语）**：**casa** 另出 **casal / chasal**（n. 农舍、小村）、旧名 **chièse / chèse**；地名 **La Chaise-Dieu**（1056 建，拉丁 *Casa Dei*「上帝之家」）；英语 **`casino`** 亦出拉丁／意大利 casa（小房子）
- **记忆钩**：chez 就是「**casa（房子）的化石**」——房子这个名词在法语里死了（让位给 maison），却以介词 chez 的形式**活了下来**

**英法交叉核对（受影响的英语词）**
- **借入英语**：**`chez`**（prép.，**1740** 入英 ← 法语 chez）——英语仅用于**法语风味的人名短语**（chez nous, chez Pierre），义「house of ____」；英语侧记此借入年 **1740**（etymonline）
- **共祖未借入（拉丁 casa 一线）**：英语 **`casino`**（1744 ← 意大利 **casino**「小房子」← casa）——与 chez **共祖于拉丁 casa**，经意大利语入英，非经法语 chez
- 核对：英语侧（chez 1740 ← 法 chez ← 古法 chiese ← 拉丁 casa；casino 1744 ← 意大利 casino）2026-10-05 **etymonline 直读**；法语侧（方位格 casae 说、ca 1130《Couronnement de Louis》chiés 首证、义项扩展 1580 / 1592 / 1681-94、*ad / in* 复合 etymon 另说、La Chaise-Dieu）2026-10-05 经 **WebSearch 转引 CNRTL/TLFi + 语法书**（CNRTL 直连仍 sinkhole）——**待验证**

**同义 / 搭配 / 易混**
- 搭配：`chez moi / toi / lui / nous / vous / eux`｜ `chez le médecin / le coiffeur / le boulanger`（去看／在医生、理发师、面包师处）｜ `chez les + 复数`（在……人中间）｜ `chez + 品牌`（在公司）｜ `rentrer chez soi`（回家）
- 辨析：**chez**（在……家／那里，介词 + 重读代词）｜ **`à la maison`**（在家——中性，不指定谁的）｜ **`dans la maison de`**（在……的房子里——更直白、指建筑）｜ **`auprès de`**（在……身边，书面）；**chez moi ≠ ma maison**（人 vs 建筑）
- **易混**：**chez ↔ dans**：chez 只接「人／机构」，dans 接「物／空间」（chez moi 对 dans ma chambre）
- 相关：[[dans]]（在……里，介词对照）；[[etre]]（être chez soi 在自己家）；[[aller]]（aller chez 去……家）；[[rester]]（rester chez soi 待在家）；[[sur-prep]]（介词系统）
