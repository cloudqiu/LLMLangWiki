# derrière

**释义**：**adv. / prép.** ①**在…后面、后面**（du côté opposé au devant）；**n.m.** ②**后部**（le derrière de la tête 后脑勺）；③**（委婉）臀部、屁股**（les fesses）；④（旧，军）后队（今用 *arrières*）｜ à l'arrière de ; partie postérieure ; (fam.) postérieur

**例句**
- _Le chat se cache derrière la porte._ 猫躲在门后。
- _Il est tombé sur le derrière._ 他一屁股摔倒在地。
- _Il y a un jardin derrière la maison._ 房子后面有个花园。

**形态要点**
- adv. / prép. **不变**；n.m. 复数 **derrières**（口语义少用复数）
- 复合：**par-derrière**（从后面；连字符）｜ **là-derrière**（那后面）｜ **sens devant derrière**（颠倒）
- 习语：`avoir une idée derrière la tête`（别有用心）｜ `de derrière les fagots`（上等的——如酒）
- **易混 / 近形**：**arrière**（← ad retro；`derrière` ← de retro，**同根对照**）、**dernier**（← derrain，**不同词**）、`par-derrière`
- 相关：库内 **[[dernier]]** 已有页——本页**消解法语 hub 的「derrière 待建」占位**

**词源 / 构词**
- **拆解**：← 通俗 / 晚期拉丁 **de retro**（*deretro*）＝ **de**（起点）+ **retro**「在后」（古典拉丁副词）——是对古典 retro 的**加强式**；对照 **arrière ← ad retro**（fr.wiktionary：「Du bas latin de retro, comparé à arrière (ad retro) … l'adverbe s'est substantivé」）
- **首证（两说）**：**1080**，形 *deriere*（fr.wiktionary）**vs** **ca 1100**（TLFi，*Roland*, éd. Bédier：prép.「en arrière de」；adv.「en arrière」）——**并存**；形态受 **derrain**（→ [[dernier]]）影响而定型（TLFi）
- **名词化（substantivation）**：副词 → 名词，义「与前方相对的一侧 / 后部」，特指**臀部**（le derrière ＝ les fesses）
- **同族 / 派生（法语）**：**par-derrière、sens devant derrière、derche**（俚）、**défense de derrière**
- **记忆钩**：derrière ＝ **de retro**（从后面）/ arrière ＝ **ad retro**（向后面）——**一个「从」一个「向」，同根两兄弟**

**英法交叉核对（受影响的英语词）**
- **共祖 / 借入**：英语 **rear** ← 盎格鲁-法语 *rerewarde* ← 古法 *riere*「在后」← 拉丁 **retro**——**共祖（拉丁 retro），经古法 / 盎格鲁法借入**；rear 名词「后部」（c.1600 ← *rerewarde*「后队」mid-14c）、形容词（c.1300 ← 古法 *rere*）
- **共祖**：英语 **retro- / retrograde** ← 拉丁 retro
- **借入**：英语 **derrière**（名词，委婉指臀部）**借自法语**
- 核对：英语侧经检索转引 etymonline（2026-10-13）；**与法语 hub 旧记「英 rear（借入）」一致**

**同义 / 搭配 / 易混**
- **辨析**：`derrière`（后面 / 臀部）vs **arrière**（后部 / 后方，更文学）vs `dos`（背）vs `fesses`（臀，直白）
- 介词：`derrière qqn / qqch`｜ `par-derrière`｜ `là-derrière`
- **易混**：**dernier**（最后的）——形近不同词
- 相关：**[[dernier]]**（retro 词族的另一支）、[[nord]]、[[sud]]
