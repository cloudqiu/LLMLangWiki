# savon

**释义**：n.m. ①**肥皂、香皂** ②（引申）**严厉责备**（*passer un savon à qqn* 把某人训一顿） ｜ produit détergent utilisé pour se laver

**例句**
- _Lave-toi les mains avec du savon._ 用肥皂洗手。
- _Le savon de Marseille est très doux._ 马赛皂很温和。
- _Sa mère lui a passé un savon._ 他妈妈把他训了一顿。

**形态要点**
- 名词：`le savon`（**m.**）；复数 **savons**（规则）——**同音** *savons*（= savoir 的 nous 变位）
- 搭配：**savon de Marseille**（马赛皂）、**savon liquide**（洗手液 / 液体皂）、**savonnette**（小块香皂）、**se laver au savon**（用肥皂洗）
- 习语：**passer un savon à qqn**（训斥某人）

**词源 / 构词**
- 拆解：← 拉丁 **sapo, saponem**「（高卢人用于染发的）**脂灰混合物**」（老普林尼《自然史》28, 191）——而**拉丁 sapo 本身是日耳曼借词**（← 原始日耳曼 **\*saipôn-**）
- 首证：拉丁 *sapo* 首见于 **1 世纪**老普林尼（Société Chimique de France）；法语 **vers 1180**（Alexandre de Paris, *Alexandre*, 49；TLFi）；Académie 9e 记 **xiie siècle**；Usito 记 **Vers 1180 (in TLFi)**——**三源一致**（fr.wiktionary 该页作「Date à préciser」）
- 同族 / 派生：**savonner**（用皂洗）、**savonnette**、**savonneux**（起泡的）、**savonnerie**
- 记忆钩：**日耳曼 → 拉丁 → 法语**——「肥皂」这个词在孩子（法语）之前，先在拉丁和日耳曼两代手里传过

**英法交叉核对（受影响的英语词）**
- **⚠️ 关系须精确表述（重点）**：英语 **soap**（古英语 *sape* ← 原始日耳曼 **\*saipon** ← PIE **\*seib-**「倾泻、滴」）——**日耳曼直承**
  - 与法语 **savon** 的关系是「**同源异途**」：法语 *savon* 走 **日耳曼 \*saipôn → 拉丁 sapo → 法语**；英语 *soap* 走 **日耳曼 \*saipôn → 古英语**
  - 即：**同一祖源（PGmc \*saipôn）但路径不同**——**既非「英 ← 法」借入，也不是严格意义的共祖**
- **并列存疑（照录）**：另有学者疑**拉丁 sapo 经高卢语中介**（因拉丁 -ā- 与 PGmc -ai- 音不对应）——**未定**
- **反向借入（法 → 英）**：英语 **saponify**（**1801** ← 法语 *saponification* ← *saponifier* ← 近代拉丁 *saponificare* ← *sapon-* + *facere*）；**saponaceous**（**1710**）在拉丁-英语层派生
- **待验证**：拉丁 **sebum**「油脂」是否亦出 PGmc \*saipon（etymonline 引 de Vaan **表怀疑**）

**同义 / 搭配 / 易混**
- 同义：**savonnette**（小块香皂）、**savon liquide**、**gel douche**（沐浴露）
- 搭配：**savon de Marseille**、**se laver au savon**、**mousse de savon**（皂沫）
- **faux ami**：英语 **soap** 有引申义「**肥皂剧**」（*soap opera*），**法语 savon 无此引申**（法语用 *feuilleton*）——英语的「soap opera」指当初赞助广播剧的肥皂商
