# bougie

**释义**：（1）蜡烛；（2）（汽车）火花塞（bougie d'allumage） ｜ chandelle en cire ; dispositif d'allumage

**例句**
- _Elle allume une bougie._ 她点燃一支蜡烛。
- _La bougie est sur le gâteau._ 蜡烛在蛋糕上。
- _Il faut changer les bougies de la voiture._ 得换汽车的火花塞。

**形态要点**
- 名词：`la bougie`（f.）；复数 `les bougies`；`bougie d'allumage`（火花塞）

**词源 / 构词**
- **拆解**：单语素——**地名 → 通名**：Bougie 是阿尔及利亚港市贝贾亚（Béjaïa），中世纪是蜡烛蜡贸易中心，专名转成「蜡烛」通名（如瓷器 china ← China、薄纱 tulle ← 法国城市 Tulle 同类现象）
- **演变**：港市 Béjaïa（旧称 Bougie）→ 法语 bougie「蜡烛」→ 引申「火花塞」（形状像蜡烛）（TLFi 定年：1300 年指「制烛用的精蜡」（chandelles de Bougie），1493 年经省略（ellipse）指「蜡烛」本身——2026-10-01 经检索转引）
- **同族 / 派生**：bougeoir（烛台）、bougie d'allumage（火花塞）；英语一侧见下节
- **记忆钩**：bougie 本是一座港城——中世纪欧洲的蜡烛蜡从那里来，地名就变成了「蜡烛」；火花塞形似蜡烛，借了这个名

**英法交叉核对（受影响的英语词）**
- **借入英语**：**bougie**（现代美式俚语「小资、装阔气」，← **bourgeois**「资产阶级」的缩略——**与法语 bougie「蜡烛」完全无关**，是词源陷阱！两词拼写相同纯属巧合）
- **共祖未借入**：无——英语「蜡烛」用 candle（← 拉丁 candela），「火花塞」用 spark plug，均与 bougie 无词源关系
- 核对：已核实（据 The Globe and Mail／Collins，2026-10-01 经检索转引）——俚语 bougie ← bourgeois 缩短，至少可溯至 20 世纪中叶（美式黑人俚语；1987 年见印刷例证；Collins 标缩短形为 21 世纪）；另注：英语有借自法语的旧技术词 bougie（蜡烛/医用探条义，Collins 定年 1745-55），与俚语义不同源

**同义 / 搭配 / 易混**
- 搭配：`allumer une bougie`（点蜡烛）；`la bougie sur le gâteau`（蛋糕上的蜡烛）；`bougie d'allumage`（火花塞）
- 易混：**la bougie**（蜡烛）vs **la chandelle**（蜡烛——旧式/宗教用）vs **le cierge**（大蜡烛——教堂用）；**bougie d'allumage**（火花塞，汽车）
- **faux ami / 词源陷阱**：英语俚语 bougie（小资，← bourgeois）≠ 法语 bougie（蜡烛）——拼写巧合，勿互译
