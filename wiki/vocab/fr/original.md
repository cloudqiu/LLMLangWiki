# original

**释义**：adj. ①**原作的、原件的**——非依模本而造、可作模本 ②（引申）**似无先例的**——依记忆无所本 ③（褒）**不因袭、不模仿的**（行事方式）④（褒）**新颖、独特、个人的** ⑤**古怪的、与众不同的** ｜ n.m. ①**原件、样本**——可作模本者 ②**原文**（与译文相对）③（美术）参照物 ④值得模仿的作者 ⑤**古怪的人** ｜ qui ne procède d'aucun modèle ; singulier, bizarre

**例句**
- _Ce tableau est un original, pas une copie._ 这幅画是原作，不是复制品。
- _Il a une façon très originale de voir les choses._ 他看问题的方式很独特。
- _Tu es un drôle d'original !_ 你可真是个怪人！

**形态要点**
- 形容词：阳性 **original** ｜ **阳性复数 originaux**（**不规则 -al → -aux**）｜ 阴性 **originale** ｜ 阴性复数 **originales**
- 名词：**n.m.** *un original*，复数 *originaux*
- 注意：**-al → -aux 只发生在阳性复数**，阴性仍为 *originales*（不与 -aux 类推）

**词源 / 构词**
- 拆解：**origin-**（拉丁 *origo, originis*「起源、来源、出生」）+ **-al**（← 拉丁 *-alis*）。拉丁 **originalis**「与起源相关的、最初的」← **oriri**「升起、发源」
- 演变：拉丁 *originalis* → （13 世纪入法语）。中世纪拉丁中性 *originale* 证于 **976**
- 首证（并列）：**Usito / TLFi 记 vers 1240**；**Académie 9e 记 xiiie siècle**「Emprunté du latin originalis」——两源一致指向 13 世纪，具体年约 1240。较晚义：**1269** 名词「原始手稿」；**1330**「源出作者本人」；**1657** 名词贬义「古怪的人」；**1691**「原作作者」；**1772**「初版」。fr.wiktionary 仅注「Du latin originalis」，**无年代**
- 同族 / 派生：**origine**、**originaire**、**originalité**、**originalement**、**originel**（见易混）
- 记忆钩：**origo「起源」+ -al**——「属于源头的」：源头那份是**原件**，不跟人走的是**独创**

**英法交叉核对（受影响的英语词）**
- **借入（英 ← 法）**：英语 **original**（adj.，**early 14c.**）「first in time, earliest」← 古法语 *original*（13c.）及直接 ← 拉丁 *originalis*；名词 **late 14c.** ← 古法语 *original* + 中世纪拉丁 *originale*。最初连用指「**原罪**」（*synne original*），15c 词序固定为 **original sin**；「fresh, novel（新颖）」义迟至 **1782**
- **共祖**：英语 **origin** ← 法语 *origine* ← 拉丁 *origo*；**originate** 同线
- **核对要点**：英语 *original* 的**宗教起点**（原罪）在法语里不显著；法语 *original* 的「古怪的人」名物化义（1657）与英语 *an original*（怪人）**平行发展**

**同义 / 搭配 / 易混**
- 同义：形——authentique、premier、primitif、inédit、singulier、farfelu；反义——**banal**、fréquent、copié、imité
- 搭配：**en version originale (VO)**（原声版）；**édition originale**（初版）；**bande originale (BO)**（电影原声）；**document original**（原件）
- **易混三连（重点）**：**original** vs **originel**（限宗教 / 哲学「最初的」，如 *péché originel* 原罪；*original* 则指「非复制、原作」）vs **orignal** /ɔ.ʁi.ɲal/（n.m.，**加拿大驼鹿**）——近形近音陷阱
- **faux ami**：法语 *original* 有「**古怪、奇特**」义，英语 *original* 无此色彩
