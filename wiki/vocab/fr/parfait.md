# parfait

**释义**：**adj.**（1）**完美的**——集一切品质而无缺陷（un travail parfait；la santé parfaite）；（2）**完全的、十足的**（un parfait inconnu 完全陌生的人；un parfait imbécile 十足的蠢货）；（3）数学／科学「完全的、理想的」（carré parfait 完全平方；nombre parfait 完全数；gaz parfait 理想气体）｜ **n.m.**（4）**（语法）完成体**——拉丁 perfectum 的仿译，法语中亦指 le passé composé（与 imparfait 相对）；（5）**（甜点）帕菲**——一种冻糕（1869 商业造词）；（6）**完人**（卡特里派信徒；亦泛指完美无缺的人） ｜ qui réunit toutes les qualités, sans défaut ; complet, total ; (n.m.) temps marquant l'action accomplie ; (cuisine) crème glacée

**例句**
- _Son anglais est parfait._ 他的英语无可挑剔。
- _C'est un parfait inconnu._ 这完全是个陌生人。（complet 义）
- _J'ai commandé un parfait au café._ 我点了一份咖啡帕菲。（甜点义）

**形态要点**
- 形容词（adj.）：阳性 **parfait** ｜ 阴性 **parfaite** ｜ 阳性复 **parfaits** ｜ 阴性复 **parfaites**
- 位置：**通常后置**（un travail parfait、une santé parfaite）；表「完全的、十足的」义时**前置**（un parfait imbécile、un parfait inconnu）——**前置多取「完全」义，后置多取「完美」义**
- 无 beau / nouveau / vieux 型特殊变化

**词源 / 构词**
- **拆解**：拉丁 **perfectus**「完成的、完善的」＝ **per-**（「完全、彻底」）+ **facere**（「做、造」）的过去分词——字面「**做到底的**」（per + fac- ＋ 分词 -tus）
- **演变（CNRTL/TLFi（据 Rey, DHLF），2026-10-05 经 fr.wiktionary 转引）**：
  - **1050** 首证古法 **parfit**（形容词）——wiktionary 记 1050，据 Rey（DHLF）／TLFi
  - 名词 **3e quart du xiie s.**：形容词的名物化，初义「完人、无过失之人」；**语法义 1596**（明记系拉丁 perfectum 的**仿译**）；**甜点义 1869**（商业造词）
  - 现代拼写 **parfait** 系**拉丁化回改**（受拉丁 perfectus 影响）——与英语同期的 respelling 同理，见英法交叉
- **同族 / 派生（法语）**：**parfaire**（v. 使完善、补足）；**parfaitement**（adv. 完美地；当然）；**imparfait**（adj. 不完美的；n.m. 未完成过去时）；**plus-que-parfait**（愈过去时）；**filer le parfait amour**（谈完美的恋爱）
- **记忆钩**：per-（完全）+ fac-（做）＝「**做完全了**」；同出 **facere** 的还有 [[faire]]（← facere）、**facteur**、**manufacture**、**efficace**

**英法交叉核对（受影响的英语词）**
- **同源（拉丁 perfectus）＋经古法语借入（英）**：英语 **`perfect`** ← 中古英语 **parfit**（**c. 1300**「flawless, ideal」；late 14c.「complete, full, finished」）← 古法语 **parfit**（**11c.**「finished, completed, ready」）← 拉丁 **perfectus** ← **perficere**（per + facere）
  - **关键：两语走过同一条「拉丁化回改」之路**——英语 **early 15c.** 把中古 parfit 按拉丁 perfectus **改拼**为 `perfect`；法语也把 parfit **改拼**为 `parfait`。**同一民间形（parfit）、同一正字冲动（回拉丁）、两条不同落点（英 perfect / 法 parfait）**——拼写漂移的证据
  - **⚠️ 更正 / 待验证（记录 ingest 提示与 etymonline 的分歧）**：本次 ingest 提示曾称「英语多经古法 **perfet** 借入」。**经查 etymonline「perfect」条只记古法语形 parfit**，**未见 perfet 形**；中古英语形亦记作 **parfit**（c. 1300）。**perfet 形未获本文所查诸源支持，特记并列、待核 OED / M-W**（不折中、不静默覆盖）
  - 名词 `perfect`（英 late 14c.「perfection」）、动词 *parfiten*（late 14c.）同出此线
- **借入英语的亲属词**：英语 **`parfait`**（n. 甜点帕菲）系**直接借自法语**（法语 1869 造词后传入英语）；英语语法术语 `perfect` 与法语 parfait **同源于拉丁 perfectum 的仿译**
- **共祖未借入**：英语 **`imperfect`**（mid-16c. 同经 respelling，取代中古英语 *imperfit*）、**`perfectible`**、**`perfectly`**、**`perfection`** 皆 ← 拉丁 perfectus / perfectio 一线，与法语 imparfait / parfaitement / perfection **同源**
- 核对：英语侧（perfect early 15c. respelling ← 中古英语 parfit c.1300 ← 古法 parfit 11c. ← 拉丁 perfectus ← perficere；名词 late 14c.；imperfect mid-16c. respelling）2026-10-05 经 **etymonline 直读**；法语侧（parfit 1050；名词 3e quart xiie s.；语法义 1596；甜点义 1869）2026-10-05 经 **fr.wiktionary 转引 CNRTL/TLFi（据 Rey DHLF）**

**同义 / 搭配 / 易混**
- 搭配：`un travail parfait`｜`la santé parfaite`｜`un parfait inconnu`（完全陌生的人）｜`un parfait imbécile`（十足的蠢货）｜`carré parfait`（完全平方）｜`gaz parfait`（理想气体）｜`le plus-que-parfait`（愈过去时）｜`filer le parfait amour`
- 辨析：**parfait**（完美无缺）｜ **`imparfait`**（不完美的；未完成过去时——对义词）｜ **`accompli`**（完成的、十全的）｜ **`achevé`**（完工的、完美的）｜ **`complet`**（完整的——义 2）｜ **`idéal`**（理想的）
- 易混：**parfait**（adj. 完美；n.m. 完成体时态）↔ 英语 **`perfect`**——英语 perfect 亦表「完成体」，**同源同理**（皆 ← 拉丁 perfectum）
- 相关：[[faire]]（同出拉丁 facere「做」）；[[finir]]（← finire「结束、完成」——「完成」义的另一条线）
