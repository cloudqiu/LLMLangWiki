# courrier

**释义**：n.m. ①（史）**驿使、信使** ②**邮政、信件往来系统** ③**信件、邮件**——收到的通信 ④（报刊）**«信使»类报刊名 / 栏目**（戏剧、体育、股市等，如 *le courrier des lecteurs* 读者来信） ｜ ensemble des lettres et messages envoyés ou reçus

**例句**
- _Je t'ai envoyé le dossier par courrier._ 我把文件邮寄给你了。
- _Le courrier arrive à midi._ 邮件中午到。
- _Le courrier des lecteurs est plein de réclamations._ 读者来信栏里满是投诉。

**形态要点**
- 名词：`le courrier`（**m.**）；复数 **courriers**（规则）。罕用阴性 *courrière*（旧，指女信使）
- 介词搭配：**par courrier**（以邮寄方式——**用 par，不用 en**）；**courrier électronique**（电子邮件）、**courrier postal**、**courrier du cœur**（读者情感来信栏）

**词源 / 构词**
- 拆解：法语 **← 意大利语 corriere**（13 世纪已证，义「信使」）← 中世纪拉丁 **currerius**（**1162** 热那亚已证，义「信使」）← 拉丁 **currere**「跑」+ 后缀 *-iere*（← 拉丁 *-arius*）
- **⚠️ 造词方向（重点）**：**并非由法语 courir 直接派生，而是早期从意大利语借入**（Pfeifer、TLFi 均持此说）——尽管法语 *courir* 与意 *correre* 同出拉丁 *currere*，「信使」这个词法语的造词路径是**借意**
- 首证（并列）：① fr.wiktionary / TLFi 记 **14 世纪**，中古法语形 **`corier`**；② 加泰罗尼亚语源词典 DECat 记现代形 *courrier* 迟至 **1464**，14 世纪仅见于两首据信出自意大利人之手的武功歌 → **本页并记「14 世纪形 *corier*；现代形 *courrier* 1464」**
- 同族 / 派生：**courir**（跑）、**coureur**（跑者）、**cours**、**course**；复合：**courrier électronique**（电子邮件）、**courriel**（魁北克造词，= courrier + électronique）
- 记忆钩：**currere（跑）**——「邮件」原是**跑腿送信的人**（信使），再由「人」转指「他送的东西」与「整套邮政」

**英法交叉核对（受影响的英语词）**
- **借入（英 ← 法 ← 意）**：英语 **courier**（n.）——约 **1300** 作 *corour*「快马」，**14 世纪中叶**义「信使」，经**盎格鲁-法语 *courrier*** / 古法语 *coreor* ← 意大利语 *corriere* ← 拉丁 *currere*；**1770** 又生「旅行侍从（办行程事务）」义。**路径为意 → 法 → 英，法语为中介**
- **共祖（非经法语）**：英语 **current / course / cursor / concur / excursion** 同出拉丁 *currere*（PIE \*kers-「跑」），系**直接源自拉丁**或其他路径

**同义 / 搭配 / 易混**
- 同义：**lettre**（单封信）、**mail**（电子邮件，anglicisme）、**courriel**（电子邮件，魁北克）
- 搭配：**par courrier**（邮寄）、**courrier électronique / postal**、**courrier des lecteurs**（读者来信）、**courrier du cœur**、**courrier recommandé**（挂号信）
- 易混：**courrier**（邮件 / 邮政）vs **lettre**（一封信）vs **courriel / mail**（电子邮件）
- **介词提示**：**par courrier**（不用 *en courrier*）
