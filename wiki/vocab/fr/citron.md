# citron

**释义**：（1）柠檬（un citron pressé 鲜榨柠檬汁；le jus de citron 柠檬汁；un zeste de citron 一点柠檬皮屑）；（2）（颜色）柠檬黄（jaune citron 柠檬黄） ｜ fruit du citronnier, de couleur jaune et de goût acide ; (couleur) jaune vif

**例句**
- _Je voudrais un citron pressé, s'il vous plaît._ 请给我来一杯鲜榨柠檬汁。
- _Ajoutez le jus d'un citron dans la tarte._ 往塔里加一个柠檬的果汁。
- _Elle porte une robe jaune citron._ 她穿着一条柠檬黄的连衣裙。

**形态要点**
- 名词：`le citron`（m.）；复数 `les citrons`
- 词族 / 派生：`le citronnier`（柠檬树）、`la citronnade`（柠檬水 / 柠檬汽水）、`le citron pressé`（鲜榨柠檬汁）、`citronné`（加了柠檬的，adj.）、`la citronnelle`（柠檬草；柠檬味饮品）；注意与 `la limonade`（汽水、柠檬水——走 limon 线）分家
- 搭配：`un zeste de citron`（柠檬皮屑）；`du jus de citron`（柠檬汁）；`thé au citron`（柠檬茶）；`tarte au citron`（柠檬塔）
- 关键提醒：**法语 citron ＝ 英语 lemon（柠檬）**；英语 citron（香橼）在法语是 **cédrat**——见下 faux ami

**词源 / 构词**
- **拆解**：拉丁 **citrus / citrum**——古典拉丁 **citrum** 指 thuya（香漆树类）的木材；晚期拉丁转指「**香橼树**（cédratier）的果实」；中世纪拉丁 **citrus** ＝「香橼 / 柠檬」〔CNRTL；Académie，2026-10-03 经检索转引〕；更远或与近东借词网相关（希腊 kedros「雪松」等说）——**待验证**
- **演变**：古法语 **citron** 12–13 世纪已见（《Livre des simples medecines》，「柠檬树的果实」；Académie 9e 记 14 世纪）；形式来源**两说并列**：① 由低拉丁 **citrum** 直接演变（6 世纪已见 citron 拼形，TLL 参 psalterion）；② **citrum 与 limon 交叉**而成〔CNRTL，2026-10-03 经检索转引〕
- **同族 / 派生（法语）**：citronnier、citronnade、citronné、citronnelle；**cédrat**（香橼）← 意大利语 cedrato ← cedro ← 拉丁 citrus——法语内部「柠檬」与「香橼」分道之词（cédrat 1600 年以 cedriac 形先现，1680 指树、1723 指果〔CNRTL 转引〕）
- **记忆钩**：同一棵拉丁 citrus 树，英法各摘各果——法语摘走 citron 去指「柠檬」，把「香橼」外包给意大利线的 cédrat；英语正相反。记住「法语 citron 是黄的柠檬」即不踩雷

**英法交叉核对（受影响的英语词）**
- **借入英语**：**citron**（n. late 14c（亦作 citrine, early 15c）「香橼」← 古法语 **citron**「citron, lemon」（14c.），或 ← 古普罗旺斯 citron ← 拉丁 **citrus**「香橼树」（或为 citreum mālum「香橼苹果」的指大形）；英语中 17c 前 citron 兼指「柠檬 / 青柠」，后**收窄**为「香橼」〔etymonline，2026-10-03 经检索转引〕）；**citrus**（n. 1825「柑橘属」← 现代拉丁属名 ← 拉丁 citrus「香橼树」——**拉丁直借**）；**citronella**（1858 ← 法语 citronnelle）；**citrin**（late 14c「柠檬色」← 法语 citrin ← 拉丁 citrus）
- **共祖未借入 / 另线**：**lemon**（c. 1400 lymon ← **古法语 limon**「柑橘果」（12c.）——经普罗旺斯语或意大利语 ← 阿拉伯 \*laimun / 波斯 limun；阿拉伯人 9–10c 将柠檬自印度传入黎凡特；更远或至马来语系词（巴厘 limo 等）〔etymonline，2026-10-03 经检索转引〕——与 citron **非同一词线**，英语「柠檬」义由 limon 线承担）；**lime**（青柠——同 limon / limaw 线，**待验证**）；**limonade**（1650s ← 法语 limonade / limonnade（1560s）← 意大利 limonata 或法语 limon 派生）
- 核对：已核实（CNRTL/Académie + etymonline，2026-10-03 经检索转引）——法语 citron 12–13c 已见（Académie 9e：14c），源自低拉丁 citrum / 中世纪拉丁 citrus（「与 limon 交叉」为两说之一）；英 citron late 14c ← 古法语 citron（14c.）（17c 前兼指柠檬）；英 citrus 1825 ← 拉丁直借；英 lemon c. 1400 ← 古法语 limon（12c.）← 阿拉伯 / 波斯线；法 cédrat ← 意大利 cedrato（1680 树 / 1723 果）。**待验证**：拉丁 citrus 的终极来源（kedros 关系说）；英语 lime 借入细节

**同义 / 搭配 / 易混**
- 搭配：`un citron pressé`（鲜榨柠檬汁）；`la citronnade`（柠檬水）；`un zeste de citron`（柠檬皮屑）；`jaune citron`（柠檬黄）；`tarte au citron`（柠檬塔——见 [[tarte]]、[[recette]]）
- **faux ami（头号）**：法语 **citron** ＝ 英语 **lemon**（柠檬）；英语 **citron** ＝ 法语 **cédrat**（香橼，Citrus medica）——双向都不等，翻译必须换位；历史注：16c 前英语 citron 也兼指柠檬 / 青柠，后收窄〔etymonline〕
- **易混（柑橘家族法语）**：`citron` 柠檬 ｜ `cédrat` 香橼 ｜ `orange` 橙 ｜ `pamplemousse` 葡萄柚 ｜ `mandarine` 橘子 ｜ `lime`（青柠——法语亦用，通用度**待验证**）；`limon` 在现代法语已非常用「柠檬」（被 citron 取代），只余 limonade / citronnade 的痕迹
