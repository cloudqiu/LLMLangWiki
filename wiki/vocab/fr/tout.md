# tout

**释义**：（1）adj. 全部、整个（tout le monde 所有人、tous les jours 每天）；（2）pron. 一切、所有（j'ai tout compris 我全懂了）；（3）adv. 非常、完全（tout petit 很小、pas du tout 一点也不）｜ tout, entier, complètement

**例句**
- _Tout le monde est là._ 所有人都在。
- _J'ai tout compris._ 我全都懂了。
- _Elle est toute petite._ 她非常小。

**形态要点**
- 变化：**tout**（阳单）｜ **toute**（阴单）｜ **tous**（阳复）｜ **toutes**（阴复）——作形容词/代词随名词性数变化；作**代词**时 tous 读 /tus/（s 发音），作**形容词**时 tous 读 /tu/（s 不发音）
- 副词 tout 的性数配合（特例）：修饰**辅音/嘘音 h 开头**的阴性形容词 → **toute**（une toute petite fille 很小的女孩）；修饰**元音/哑音 h 开头**的阴性形容词 → **tout** 不变（elle est tout heureuse 她非常开心）
- 高频表达：`tout le monde`（所有人，作单数）、`pas du tout`（一点也不）、`tout à fait`（完全、正是）、`tout de suite`（立刻）

**词源 / 构词**
- **拆解**：拉丁 **totus**「全部、整个」——totus 本身**来源不明**（etymonline 标 a word of unknown origin）
- **演变**：拉丁 totus → 古法语 tot / tuit（阳性复数）→ 现代法语 tout / tous；单数 tout 直承 totus，复数 tous 承古法语 tuit 的调整
- **同族 / 派生**：total（总额）、totalité（整体）、totaliser（合计）——均经拉丁 totalis（totus 的派生形容词）；英语一侧见下节
- **记忆钩**：tout「全」是高频功能词——三词性（adj./pron./adv.）+ 四形（tout/toute/tous/toutes）；副词 tout 只在「辅音开头的阴性形容词」前变 toute，其余不变

**英法交叉核对（受影响的英语词）**
- **借入英语**：**total**（adj. late 14c ← 古法语 total（14c）← 中世纪拉丁 totalis ← totus；n. mid-15c）
- **共祖未借入**：**factotum**（1560s ← 中世纪拉丁 fac totum「做一切」 ← facere + totum）、**teetotal**（1834 ← total 的 T- 重叠强调）——同出拉丁 totus，但直接取自拉丁或英语自造，非经法语 tout
- 核对：已核实（据 etymonline，2026-10-01 经检索转引）——total late 14c ← 古法语 total ← totalis ← totus；totus「来源不明」；factotum 1560s、teetotal 1834

**同义 / 搭配 / 易混**
- 近义辨析：tout（全部/整个）｜ chaque（每一，单数）｜ tous les / toutes les（每一…的复数式：tous les jours 每天）｜ entier（完整的）
- 搭配：`tout le monde`（所有人）、`tout à fait`（完全）、`pas du tout`（毫不）、`en tout`（总共）
- **易混**：`tout`（全部）vs `tous`（阳复/代词，读 /tus/）；`tout` 作副词（非常）与 `très`（很）近义，但 tout 更强调「整体、完全」（tout petit）
