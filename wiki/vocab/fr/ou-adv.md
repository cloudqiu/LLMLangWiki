# où

> 收录说明：inbox 第 332 行作 **`ou`**（无重音）——按上下文（叙事：*la rivière où … pêchait*）判为 **`où`（关系副词「哪里」）**；因与连词 `ou` ASCII 同形，按命名规则分建 [[ou-conj]] / 本页——**判定待用户确认**。

**释义**：**adv.（疑问 + 关系）哪里、在…的地方**——（1）**疑问副词**：问地点（Où es-tu ? 你在哪？；D'où viens-tu ? 你从哪来？）；引申问处境；（2）**关系副词**：引出地点从句（la ville **où** je suis né 我出生的城市），引申表时间或情形｜ où : à quel endroit ; dans lequel / auquel（relatif）

**例句**
- _Où es-tu ?_ 你在哪儿？
- _La ville où je suis né est petite._ 我出生的城市很小。
- _D'où viens-tu ?_ 你从哪里来？

**形态要点**
- 不变词
- **正字法要点（fr.wiktionary 明文）**：où 是**现代法语中唯一含「u + 重音符（grave）」的常用词**（除少数借词 / 方言）——该重音符的功能正是「**ne pas le confondre avec ou, conjonction de coordination**（区别于连词 ou）」
- 复合：**d'où**（从哪里 / 由此、因此）｜ **par où**（经由哪里）｜ **jusqu'où**（到何处）｜ **où que**（无论何处，+ 虚拟式）｜ **là où**｜ **n'importe où**（任何地方）

**词源 / 构词**
- **拆解**：拉丁 **ubi**「（所在）何处」；Académie 9e 补充：现代 où **兼收**了拉丁 **quo**（所往）、**unde**（所来，法语主要保存在 **d'où** 中）、**qua**（所经）的功能
- **首证**：**Xe siècle（10 世纪）**，形 *U*（fr.wiktionary 引 TLFi；Académie 9e 记「xe siècle. Issu du latin ubi, de même sens.」）
- **演变**：ubi「何处」→ 法语 où 吸收 quo / unde / qua 的用法，涵盖「所在、所往、所来、所经」。罗曼语同源：意 *ove / dove*、西 *donde*、葡 *onde*
- **同族 / 派生**：d'où、par où、jusqu'où、où que；拉丁 **ubique** → 英语 **ubiquitous / ubiquity**（学术借入，同源 ubi）
- **记忆钩**：那个**小重音**就是 où 的身份证——它专门用来与连词 ou 划清界限

**英法交叉核对（受影响的英语词）**
- **无对应**：英语 **where** 是日耳曼语，**非** ← 拉丁 ubi；拉丁 ubi 的英语后代仅见于学术借词 **ubiquity / ubiquitous**（← 拉丁 ubique「处处」）
- 核对：法语侧 10 世纪据 fr.wiktionary / Académie 9e（2026-10-13）

**同义 / 搭配 / 易混**
- 搭配：`d'où`｜ `par où`｜ `jusqu'où`｜ `où que`（+ subj.）｜ `là où`｜ `n'importe où`
- **易混（最高频）**：**[[ou-conj|ou]]（连词「或者」，无重音）vs où（副词「哪里」，带重音）**——同音 /u/，重音符是唯一区分；书写 / 听写第一号陷阱
- 相关：[[quand]]、[[comment]]、[[pourquoi]]（同疑问副词簇）
