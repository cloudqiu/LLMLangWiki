# eux

> 收录说明：inbox 形式 `eux` 直接为词形。本页办**第三人称重读代词**页——给全重读系列表，与 [[la-pron]] / [[en-pron]] / [[y]] 诸 clitique 页合读。

**释义**：他们——第三人称**阳性复数**的**重读（tonique）代词**（可指纯阳性或男女混合；全阴性用 elles） ｜ pronom personnel tonique de la 3e personne du masculin pluriel

**例句**
- _Je pense souvent à eux._ 我常想到他们。（**介词后必用重读形**——\*à ils 不成立）
- _Eux, ils ont compris tout de suite._ 他们呢，一下就明白了。（**同位强调主语**）
- _C'est eux qui ont raison._ 是他们有理。（c'est… qui 强调结构）
- _Elle est plus grande qu'eux._ 她比他们高。（比较从句）

**用法要点**
- **重读代词全系列（本页必给的表）**——每人对「非重读（clitique，贴动词）」与「重读（tonique，独立）」两套形：

  | 人称 | 非重读（clitique） | 重读（tonique） |
  | --- | --- | --- |
  | 1sg | je / me | moi |
  | 2sg | tu / te | toi |
  | 3sg m | il / le / lui | lui |
  | 3sg f | elle / la / lui | elle |
  | 泛指 | on / se | soi |
  | 1pl | nous | nous |
  | 2pl | vous | vous |
  | 3pl m | ils / les / leur | **eux** |
  | 3pl f | elles / les / leur | elles |

- **重读 vs 非重读（本页核心）**：**ils** 是**主语 clitique**——**必须贴在动词前**（**Ils** travaillent 他们工作），不能独用、不能作介词宾语；**eux** 是**重读形**——**独立使用**：①**介词后**（avec eux / chez eux / pour eux / sans eux）；②**同位强调**（**Eux**, ils…）；③**c'est 后**（C'est eux）；④**比较后**（plus grand qu'eux）；⑤**并列**（lui et eux）。
- **eux 的指代范围**：**eux 只指阳性复数**（或**男女混合**的「他们」）；全阴性一律 **elles**。
- **从不作直接宾语 clitique**：「看见他们」用 clitique **les**（Je **les** vois），**不用 eux**；只有强调 / 介词时才用 eux——Je **les** vois, **eux**（我看见他们了，他们嘛）。
- **叠加 -même(s)**：**eux-mêmes**（他们自己——见 [[moi-meme]]）；**eux autres**（加拿大 / 口语「他们那些人」）。
- **连音**：eux 以元音收尾，后接元音**连音 /z/**——eux aussi /ø.zo.si/、eux et moi。

**词源 / 构词**
- **拆解**：单语素——拉丁 **illos**「那些（人）」，指示代词 **ille / illa / illud** 的**阳性复数宾格**
- **演变（CNRTL、Darmesteter、Nyrop、Usito，2026-10-05 转引）**：
  - **重音分岔（关键）**：重读 **illós → 古法 els → eus → eux**（**l 元音化**：els > eus > eux）；非重读 **illos → les**——**同一个 illos，重读成了 eux、非重读成了 les**（与 [[le-mien]] 里 meum → mon / mien 同构）
  - **首证**：约 **980 年 eus**（Usito 引 GRLF）；古法语变体 **els / als / eus / aux / ax / yauls**（CNRTL——均代表拉丁 illos；X-XV 世纪例：Xe s.「Eus noieds」、XIe s.「super els metreiet」、《罗兰之歌》「Li quels d'els deuz」）
  - **句法演变**：eux 先作**强调性直接宾语 / 介词宾语**（Je les vois ; **eux** ; c'est **à eux**…）；13 世纪末起，非重读主语 il 弱化，**重读 obliques（lui, eus）逐级顶替阳性主格**（Schwan-Behrens）——此即法语**用宾格形做重读主语**的来源
- **同族 / 派生（法语）**：**ils / elles**（主语 clitique）、**les**（非重读直接宾语）、**lui / leur**（间接宾语）、**elles**（阴性重读 ← 拉丁 illas）；整套源自指示代词 **ille** 一族的 clitique / tonique 双重分化；同族 **le / la / les**（见 [[la-pron]]）
- **记忆钩**：**illos 裂成两半**——非重读挤在动词前成 **les**（或主语 ils），重读独立出来成 **eux**；正如 me → me/moi、meum → mon/mien——**法语代词系统的「重读 / 非重读」二叉树**

**英法交叉核对（受影响的英语词）**
- **借入英语**：无——eux 未被英语借入
- **共祖未借入（本页核心反差）**：英语第三人称复数 **`they` / `them` / `their`**（**c. 1200**）**借自古诺斯语**（古诺斯 **þeir / þeim / þeira**）——源自原始日耳曼 **\*thai**（← PIE **\*to-**「那个」，指示词，同族 `that`），**与拉丁 ille / illos（→ 法语 eux）毫无亲缘**——法语第三人称复数**承自拉丁指示词 ille**，英语则**北欧借词顶替了本族形**（英语本族原用 **hie**，古英语 hī / hīe，约 1400 年被 they 取代）——**两条完全不同的来路**
- **结论**：故 eux ↔ they 只是「功能对等」，**既非借入、亦非同源**（可与 [[vie]]↔life、[[comment]]↔how 的「同义异源」格局并列）。旁支：拉丁 **ille** 一线基本未入英语（英语的 this/that/these/those 全走日耳曼），ille 一族留在法语内部（il / elle / le / la / les / lui / leur / eux）。
- 核对：英语侧（they/them/their c. 1200 ← 古诺斯 þeir/þeim/þeira ← PGmc \*thai ← PIE \*to-；取代本族 OE hī / hīe）2026-10-05 经 **etymonline 直读**；法语侧（eux ← 拉丁 illos、重读 els → eus → eux ／ 非重读 → les、约 980 eus、古法变体 els/als/eus/aux、13c 末 oblique 顶替主格）2026-10-05 经 **WebSearch 转引 CNRTL、Darmesteter《Cours de grammaire》、Nyrop、Schwan-Behrens、Usito（引 GRLF）**（CNRTL 直连仍 sinkhole）。**待验证**：①TLFi 原条首证定年未直连；②古法变体 els / als / yauls 的年代分层未逐核；③13c 末「oblique 顶替主格」系转引 Schwan-Behrens，未直读

**同义 / 搭配 / 易混**
- 搭配：`avec eux / chez eux / pour eux / sans eux`（介词后）｜ `Eux, ils…`（同位强调）｜ `C'est eux qui…`（强调结构）｜ `eux-mêmes`（他们自己）｜ `eux autres`（加拿大口语）
- **易混（本页核心）**：**ils**（主语 clitique——贴动词前，不能独用，**非重读**）｜ **eux**（重读形——介词后 / 独用 / 强调，**本页**）｜ **les**（非重读直接宾语——Je les vois）｜ **leur**（非重读间接宾语——Je leur parle）｜ **elles**（阴性重读——全阴性用 elles，不用 eux）
- 系列对照：tonique **moi / toi / lui / elle / soi / nous / vous / eux / elles**（见 [[moi-meme]]）
- 相关：[[la-pron]]（第三人称 clitique 直接宾语 le / la / les）、[[en-pron]]、[[y]]（副词代词）、[[moi-meme]]（-même 系列）
