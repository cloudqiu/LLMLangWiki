# comme toi

> 收录说明：inbox 形式 `comme toi`——按多词单位（v1.5）独立建页；核心是 **comme 的比较用法**＋**重读人称代词 toi**。库内尚无独立 `toi` 页（重读代词系统见 [[la-pron]]、[[en-pron]]、[[y]]）。

**释义**：像你一样、和你一样（比较：方式 / 性质与对方相同） ｜ de la même manière que toi ; à ton instar

**例句**
- _Je pense comme toi._ 我和你想法一样。
- _Il parle comme toi._ 他说话和你一样。
- _Comme toi, j'adore ce film._ 和你一样，我非常喜欢这部电影。（comme toi 可置句首）

**形态要点**
- **构成**：**comme**（比较 / 原因 / 「作为」）+ **toi**——比较对象用**重读人称代词**（pronoms toniques）：moi / toi / lui / elle / nous / vous / eux / elles。**不用**非重读主语形 je / tu / il…——\*comme tu 不合语法（须说 comme toi）
- **comme 的三用（本页重点）**：
  1. **比较**「像、如同」（本页）——comme toi, comme moi, comme un roi；_Il court comme un lapin._
  2. **原因**「因为」（**只能置句首**）——_Comme il pleut, je reste._（见 [[parce-que]]）
  3. **「作为、当作」（表身份 / 职务）**——_Il travaille comme professeur._
- **位置**：comme toi / comme moi 可置于**句首**（Comme toi, j'adore…）或**句末**（Je pense comme toi），语义不变
- **数量 vs 方式（易混）**：**comme toi** 比**方式 / 性质**（像你一样）；比**数量**用 **autant que toi**（和你一样多）——_J'ai autant de livres que toi._
- **比较级用 que 不用 comme**：plus / moins / aussi + adj. + **que**——_Elle est aussi grande **que** toi._（**不**说 \*aussi grande comme toi）
- 语域：中性；口语高频；书面同样通用

**词源 / 构词**
- **拆解（comme）**：← 拉丁 **quomodo**「以何种方式、怎样」＝ **quo**（← qui「谁 / 什么」的夺格）+ **modo**（← modus「方式」的夺格）——本为**方式疑问副词**（「怎样」），进入罗曼语后逐步扩展出**相对 / 比较 / 时间 / 原因 / 目的 / 补语**诸值
  - 演变：拉丁 quomodo → 通俗拉丁 **\*quomo** → 古法语 **com / come** → **comme**
  - **首证**：**842**《斯特拉斯堡誓词》已见 **cum**（形式；**不**属拉丁 cum「与」一线——comme 的祖先是 quomodo，勿混）
  - 词末 **-e** 之说（**两说并存，不折中**）：一说来自配列连词 **et**（quomodo **et**「正如……一样」融合）；另有说为类比 / 增音所致——**待验证**
- **与 [[comment]] 同源（本页关键）**：法语 [[comment]]（「怎样」疑问副词）与 comme **同出拉丁 quomodo**——同一块材料的两路分配：comme 走「像 / 因为 / 作为」，[[comment]] 走「怎样」；[[comment]] 形末 **-ent** 系类比增音（如 tant / quant 等）——**该增音的确切机制待验证**
- **拆解（toi）**：← 拉丁 **te**（第二人称单数宾格 / 夺格）← PIE \*twe——受格**直接继承**；法语中 tu（主格 ← 拉丁 tu）与 te / toi（受格）分工，toi 为**重读 / 强调形**（可独立成词、可作比较项），te 为**附着形**（依附动词）
- **同族 / 派生（法语）**：comme（连词 / 副词）、[[comment]]、comme ci comme ça（马马虎虎）、comme quoi（口语「于是就有……之说」）、comme tout（口语「非常」）；toi 一族：moi / toi / lui / elle / nous / vous / eux / elles
- **记忆钩**：comme 与 [[comment]] 是 **quomodo 的两次分配**——「像 / 因为」给 comme，「怎样」给 [[comment]]；把「你」推到被比较的位置时，法语要的是**重读的 toi**（能独立站稳的那个形），而不是贴着动词的 tu

**英法交叉核对（受影响的英语词）**
- **共祖未借入（本页核心）**：英语 `how` ← 古英语 **hū** ← 原始日耳曼 \*hwo ← PIE **\*kʷo-**——与拉丁 quomodo 的 quo-（← \*kʷo-）**同干，属共祖远亲、非借入**（与 [[quand]]↔when、[[vu-que]]·[[voir]] 一线的格局同型）；英语 who / what / when / where / why 同干
- **对照（日耳曼本族，无借入）**：英 **`like`**（prep.「像」，**c.1200**）← 古英语 **gelic**「相似」（原始日耳曼 \*(ga)leika-「同形」＝ \*ga-「一起」+ \*lik-「身体、形」）——**日耳曼本族，与 comme 无词源关系**（仅语义对应：*like you* ＝ comme toi）；同族 likewise / alike / lich（现代拼写或受古北欧语 glikr 影响）
- **对照（日耳曼本族，无借入）**：英 **`as`**（**c.1200**）← 古英语 **alswa / eallswa**「完全如此」（＝ all + so），约 1400 定型——**本族**，与 comme 无词源关系；*as you* 语义上对应 comme toi
- **假同源陷阱（务必分清）**：英语 **`comment`**（n./v. 评论；n. **late 14c.**、v. **early 15c.**）← 古法 coment / 晚期拉丁 **commentum**「评论、解释」（古典拉丁义「发明、杜撰」＝ com- + \*men-「思」，PIE \*men-）——**与法语 `comment`（怎样，← quomodo）词源不相干**：英 comment 走 **commentum / \*men-** 一线，法 comment 走 **quomodo / \*kʷo-** 一线，**同形近义而来源全异**（勿因二者形似而误判为借入或同源）
- **借入英语**：comme 一系**未**整体进入英语
- 核对：how ← hū ← \*hwo ← \*kʷo-；like ← gelic ← \*(ga)leika-；as ← alswa / eallswa（c.1200，约 1400 定型）；comment（n. late 14c. / v. early 15c.）← coment / commentum ← comminisci ← \*men-，均据 etymonline（2026-10-04 经直读）。法语侧 quomodo ＝ quo + modo、\*quomo → com / come → comme、842《斯特拉斯堡誓词》cum 形式、comme ≠ 拉丁 cum、词末 -e 两说，据检索转引词源 / 语法学文献（**未得 TLFi 原文**）。

**同义 / 搭配 / 易混**
- 搭配：`comme toi` / `comme moi` / `comme lui` / `comme elle` / `comme nous` / `comme eux`；`comme un roi`（像国王一样）；`comme ci comme ça`；`comme quoi`；`comme tout`（口语「极其」）
- **易混（词性分工）**：**comme**（像 / 因为 / 作为）vs [[comment]]（怎样——疑问副词；注意勿与英语 comment「评论」同源化，见上节）
- **易混（比较结构）**：**comme**（比较方式 / 性质）vs **que**（比较级：plus / moins / aussi + adj. + **que**——_aussi grande **que** toi_）；比数量用 **autant que toi**
- **易混（原因义）**：**comme**（因——**只置句首**，见 [[parce-que]]）vs [[parce-que]]（因——回答 pourquoi）
- 相关：[[tout]]（comme tout / tout comme）、[[meme-si]]、[[comment]]、[[parce-que]]
