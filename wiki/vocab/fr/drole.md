# drôle

**释义**：**adj.**（1）**滑稽的、好笑的**（une histoire drôle 好笑的故事）；（2）**奇怪的、古怪的**——用于 **drôle de + n.** 结构（un drôle de bruit 一种怪声；un drôle de type 一个怪人）｜ **n.m.**（3）（旧／贬）**家伙、坏蛋**（un drôle 一个无赖）；（4）（奥克／普瓦图方言）**小孩** ｜ comique, amusant, rigolo ; bizarre, inhabituel, sortant du commun

**例句**
- _Elle raconte toujours des histoires drôles._ 她总讲好笑的故事。（见 [[histoire]]）
- _Il a un drôle d'accent._ 他口音怪怪的。（drôle de + n. ＝「奇怪的」）
- _Ce n'est pas drôle de travailler le dimanche._ 周日上班可不好受。

**形态要点**
- 形容词（adj.）：**阴阳同形**——阳性 **drôle** ｜ 阴性 **drôle** ｜ 复数 **drôles**；最高级 **drôlissime**
- **位置改变词义（核心）**：**后置**取本义「**滑稽的**」（un homme drôle 一个滑稽的人）；**前置**（**drôle de + n.**）取引申义「**奇怪的**」（un drôle d'homme 一个怪人）——fr.wiktionary 原例：「un zigoto drôle（滑稽的家伙）」↔「un drôle de zigoto（奇怪的家伙）」
- 无 beau / nouveau / vieux 型特殊变化

**词源 / 构词**
- **拆解**：**中古荷兰语 drol / drolle**「小妖精、小个子」→（转义）「乐天派、好伙伴」→ 中古法语 **drolle**（名词）
- **演变（CNRTL/TLFi，2026-10-05 经 WebSearch 转引）**：
  - **fin xve s.** 首证 **drolle**「bon vivant（乐天派）」——Basselin, *Vaux-de-Vire*, LIII（ds Littré）；**1549** *draule*（Fr. Habert 译贺拉斯）；**1584** *drolle*（Bouchet, *Serées*）；**1680** *drôle*（Rich.——**现代拼写**）
  - **名词义链**：「bon vivant」fin xve s. → **1652**「mauvais sujet（须提防的坏人）」→ **1688**「小坏蛋、机灵小孩」→ **1718**「personne méprisable」；**形容词义 1636**「（人）逗人笑的」→ **1664**「**drôle de + subst.**」（奇怪、可疑）——**「滑稽」义在前、「古怪」义在后的引申**
  - **词源另说（并列，不折中）**：TLFi 另记 Sainéan（*Sources* t. 1, 160-161；t. 3, 305-306）把基形（皮卡德 *droller*, *drôler*）系于 **\*tragulare**（FEW t. 13, 2, p. 174）；Littré 提斯堪的纳维亚 **troll**（恶灵），但以其音义皆有难处为疑，而倾向弗拉芒 **drol**、德语 **drollig**、英语 **droll**
- **同族 / 派生（法语）**：**drôlement**（adv. 滑稽地；非常）；**drôlerie**（n.f. 滑稽事／笑料）；**drôlet / drôlette**（小可爱）；**drôlissime**；**drôle de guerre**（「奇怪的战争」，1939-40）；**c'est encore drôle**（魁北克：「还没完」）
- **记忆钩**：drolle「小妖精」→「小丑、逗乐的人」——**从「妖」到「逗」**的语义滑移

**英法交叉核对（受影响的英语词）**
- **借入英语（法语 → 英语）**：英语 **`droll`**（adj. **1620s**「waggish, deliberately facetious, comical」）← 法语 **drôle**（**1580s**「odd, comical, funny」），法语中亦作名词 **drolle / draule**「merry fellow, buffoon」——**借入**（etymonline 直读）
  - **同线的回借派生词**：英语 **`drollery`**（**1590s**）← 法语 **drôlerie**（16c.，← drôle + -erie）——**英 ← 法**
  - **深源（并列，不折中）**：法语 drôle「possibly ← 中古荷兰 **drol**「fat little fellow, goblin」**或**中古高地德语 **trolle**「clown」」，最终「← 古诺斯语 **troll**」（etymonline）——若此说成立，则英语 **`troll`** 与法语 drôle / 英语 droll **在古诺斯语 troll 处共祖**（**待验证**层级）
- **共祖未借入**：英语 **`troll`**（n.1，← 古诺斯 troll）——与 drôle 的深源相通（**若**中古荷兰 drol ← troll 之说成立）；现代英语里 `droll`（滑稽）与 `troll`（巨魔／网络挑衅）**分立**，勿混
- 核对：英语侧（droll 1620s ← 法 drôle 1580s；drollery 1590s ← 法 drôlerie 16c.；深源 ← 中古荷兰 drol / 中古高地德 trolle / 古诺斯 troll）2026-10-05 经 **etymonline 直读**；法语侧（TLFi：fin xve s. drolle「bon vivant」Basselin；1549 draule；1584 drolle；1680 drôle；形容词义 1636「qui fait rire」；1664「drôle de + subst.」；名词义 1652 / 1688 / 1718；另说 Sainéan \*tragulare）2026-10-05 经 **WebSearch 转引 CNRTL/TLFi**

**同义 / 搭配 / 易混**
- 搭配：`une histoire drôle`（好笑的故事）｜`drôle de + n.`（奇怪的……：un drôle de bruit / un drôle de type）｜`ce n'est pas drôle`（不好受／不好玩）｜`un drôle`（旧：坏蛋）｜`drôle de guerre`（假战／奇怪的战争）
- 辨析：**drôle**（滑稽的；奇怪的）｜ **`comique`**（喜剧的、滑稽的）｜ **`amusant`**（好玩的）｜ **`rigolo`**（口语：好笑的）｜ **`marrant`**（口语：逗的）｜ **`bizarre`**（奇怪的——drôle 的「奇怪」义近此）｜ **`étrange`**（奇异的）
- **位置即词义（核心易错）**：后置 drôle ＝「滑稽」（un homme drôle）；前置 **drôle de** ＝「奇怪」（un drôle d'homme）——**法语形容词前置引引申义的典型样本**
- **faux ami**：英语 **`droll`** 借自法语 drôle，但英语 droll 偏「刻意逗趣的、滑稽的」且**书面／旧**，与法语 drôle 的日常高频（且带「奇怪」义）**义域不完全重合**
- 相关：[[histoire]]（une histoire drôle）；[[triste]]（与 drôle 的「逗乐」义相对）
