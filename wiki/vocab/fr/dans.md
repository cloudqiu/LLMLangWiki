# dans

**释义**：（1）（空间）在……里、在……内（dans la cuisine 在厨房里）；（2）（时间）在……之后、过……就（dans deux jours 两天后）；（3）（状态 / 处境）处于……中（dans le doute 在疑虑中）；（4）（方式 / 范围）在……方面（dans l'ensemble 总体上） ｜ à l'intérieur de ; (temps) après, au bout de ; en état de

**例句**
- _Le chat dort dans la cuisine._ 猫在厨房里睡觉。
- _Je partirai dans deux jours._ 我两天后出发。
- _Dans le doute, abstiens-toi._ 拿不准就别做。（谚语：有疑则止）

**形态要点**
- 介词：读 /dɑ̃/——**词尾 -s 不发音**；但后接元音起头词时**必须联诵**出 /z/：dans‿un livre 读 /dɑ̃.zœ̃ livʁ/
- **dans vs en（空间）**：**dans** + 冠词 / 限定词 + 名词（dans la cuisine、dans mon sac——强调「某物的内部」）；**en** + 无冠词名词 / 阴性国家·大区 / 材料 / 状态（en France、en bois、être en classe）——「在（某国 / 某状态）」用 en，具体容器内部用 dans（例外语感：dans la France d'aujourd'hui「当今的法国」——此时指「法国这一实体内部」，非常规用法）
- **dans vs en（时间——头号大坑）**：**dans + 时段 ＝ 「……之后」**（未来某时点：dans deux jours 两天后；dans cinq minutes 五分钟后）；**en + 时段 ＝ 「用……时间」**（完成某动作所花时长：en deux jours 用两天；Il l'a fini en cinq minutes 他五分钟就做完了）——两句型**不可互换**（记忆钩：**d**ans = **d**eadline（期限）／ **en** = durée（时长））（多条语法源，2026-10-03 经检索转引）
- 时间另用（五个介词五义）：**il y a + 时段 ＝ 「……之前」**（il y a deux jours 两天前——与 dans deux jours 恰成反对，见 [[il-y-a]]）；**depuis**（从某时起持续）、**pendant**（一段过程内）、**pour**（预定一段时间）——见 [[longtemps]]、[[bientot]]
- 固定表达：`dans le doute`（在疑虑中）；`dans l'ensemble`（总体上）；`dans le but de`（为了）；`dans l'immédiat`（眼下）；`dans un sens`（某种意义上）

**词源 / 构词**
- **拆解**：晚期 / 通俗拉丁 **deintus**「在里面」＝ **de**「从」+ **intus**「在内」（intus 的另一个后继 → 古法语 **enz**，与 denz 并行）；dans 的出发点义「从内部」渐变为「在内部」（CNRTL，2026-10-03 经检索转引）
- **演变**：deintus → 古法语 **denz**（副词，约 **1112** 首见，义「在里面」）→ 约 **1170** 起作**介词**表地点 → 13 世纪起表时间「在……期限内」→ 1667 起表身心状态；**dans 在 16 世纪中叶前都罕用**，此后逐步取代 dedans 与 en（因后二者缩合形式不便）——（CNRTL，2026-10-03 经检索转引）
- **同族 / 派生（法语）**：**dedans**（里面——de + dans 强化，可作副词 / 名词：le dedans 内部）；**au-dedans (de)**（在……内部）；古语 **denz / enz** 已并入现代词形；对照 **hors de**（在外）为其反义构词
- **记忆钩**：dans = **d**（de）+ **ans**（intus 的继承）——「从里面」说出「在里面」；denz 的 -s 今天不发音，却在联诵时「现形」（dans un /dɑ̃.zœ̃/）——一条语音化石

**英法交叉核对（受影响的英语词）**
- **借入英语**：无——介词属语法词（封闭类），不构借词；拉丁 deintus 未见产出英语词
- **共祖未借入**：英语 **in**（← 古英语 in / inne ← 原始日耳曼 \*in ← PIE 根 **\*en**「在内」——etymonline，2026-10-03 经检索转引）与拉丁 **in** / **intus**（dans 的构成材料）**同出 PIE \*en**——「英语 in ／ 拉丁 in·intus 共祖」；拉丁 in- 前缀另见于 **import / intrude / anoint** 等英语借词（etymonline：in-「into, in」from PIE root \*en，同上）
- 核对：已核实（etymonline，2026-10-03 经检索转引）——英 in ← 古英语 in / inne ← PIE \*en「in」；拉丁 in- 同出该根；dans 侧 deintus / denz / 1112·1170·13c.·1667 各段落据 CNRTL（2026-10-03 经检索转引）；dans vs en 时空两条对立据多条语法源（同上）。**待验证**：无重大遗留

**同义 / 搭配 / 易混**
- 搭配：`dans la cuisine`（在厨房——见 [[cuisine]]）；`dans le doute`（在疑虑中）；`dans deux jours`（两天后——见 [[bientot]]）；`dans l'ensemble`（总体上）；`dans la vie`（生活中）
- **易混（时间介词总表——重点记坑）**：`dans deux jours` 两天**后** ｜ `il y a deux jours` 两天**前** ｜ `en deux jours` **用**两天 ｜ `depuis deux jours` 已持续两天 ｜ `pendant deux jours` 持续两天——五个说法五个义（见 [[il-y-a]]、[[longtemps]]）
- **faux ami / 母语干扰**：英语 "in two days" 有歧义（既可「两天后」也可「两天内干完」），法语**必须**按义选 dans / en——高频写作错点；另法语国家前用 en（en France），**不**用 dans（除非「在法国境内某处」或「当今之法国」等特殊语境）
- 提示：口语中 dans 常轻读一带而过；书写注意与 `d'en`（de + en）、`dent`（牙）区分——「dans deux jours」勿写作 d'en deux jours
