# calme

**释义**：（1）**adj. 平静的、安静的、冷静的**（la mer est calme 海面平静；reste calme 保持冷静；un enfant calme 安静的孩子）；（2）**n.m. 平静、安宁**（le calme avant la tempête 暴风雨前的平静；le calme de la nuit 夜的宁静）；（3）**calme plat** ＝ 风平浪静 / 毫无生气 ｜ tranquille, sans agitation ; absence d'agitation, de bruit

**例句**
- _La mer est calme ce matin._ 今早海面平静。
- _Restez calme, tout va bien se passer._ 保持冷静，一切都会好的。
- _Après la tempête, le calme est revenu._ 暴风雨过后，一切归于平静。

**形态要点**
- 形容词：**阴阳同形** calme；复数 **calmes**
- 名词：`le calme`（m.）——不可数
- 固定短语：`garder son calme`（保持冷静）｜ `le calme plat`（风平浪静 / 一潭死水）｜ `en tout calme`（安安静静地）｜ `le calme avant la tempête`（暴风雨前的平静）
- 派生：**calmer**（使平静 / 平息）、**se calmer**（冷静下来）、**calmement**（平静地）；**chômer**（停工 / 歇业——与 calmer 同源的 **doublet**，← 奥克语 caumar，**早于** calme）

**词源 / 构词**
- **拆解**：希腊 **kauma**「酷热」（← **kaiein**「烧」）→ 晚期拉丁 **cauma**「午间炎热、炎热时的歇息」→ 俗拉丁 **\*calma** → 奥克语 / 伊比利亚语 **calma** → 法语 **calme**——经**奥克语**（Wiktionary）或**伊比利亚语**（CNRTL：因意大利语 calma **缺「热」义**，判非法经意大利语）传入
- **演变**：名词首见 **1418**（Caumont《Voy. d'outremer》，义「风完全停息」；CNRTL）；另记 **xve s.**（Wiktionary）——**两说**；义项：「无扰、安宁」**1671**（Pomey）；`calme plat` **1704**（Trévoux）
- **词源竞争说**：Ménage 另拟希腊 **malakos** → **malacia**「海之平静」——**并列存录**
- **同族 / 派生（法语）**：calmer、se calmer、calmement、chômer（同源 doublet）
- **记忆钩**：calme 的起点竟是「**酷热**」——希腊人把「正午最热时的**歇凉**」叫 *kauma*，词义一路滑向「（歇凉时的）**平静**」

**英法交叉核对（受影响的英语词）**
- **借入英语**：**calm**（adj. late 14c，用于海；n. c.1400；v. late 14c）——**借入**，**路径不定**：「或经古法语 **calme**，或直接借自古意大利语 **calma**」——两者同出晚期拉丁 **cauma**（etymonline 转引）
- **共祖未借入**：无显著对例（cauma 的英语后代基本都走法语 / 意大利中介）
- **同义异源**：英语「安静」另有 **quiet / still**（← 拉丁 quietus / 本族 still）——与 calme 不同源
- 核对：英语侧（calm late 14c，路径两可）经检索转引 etymonline（2026-10-11）；法语侧 1418 / xve s. 与 \*calma 链据 CNRTL / Académie 9e / Wiktionary 转引（**待验证**）

**同义 / 搭配 / 易混**
- 搭配：`garder son calme`（保持冷静）｜ `le calme plat`（风平浪静）｜ `en tout calme`（安安静静）｜ `retrouver son calme`（恢复平静）｜ `calme olympien`（泰山崩于前而不变色的镇定）
- **易混**：**calme**（平静的 / 冷静的）vs **tranquille**（安静的——更日常、偏「无事打扰」）vs **silencieux**（无声的）vs **serein**（安详的）；反义 **agité / nerveux**（不安的 / 焦躁的）
