# présentateur

> 收录说明：inbox 本批并列收进 `presentateur` 与 `presentatrice`——两者是同一职业的阳/阴性形式，按「词形变化归并同一 lemma」合为一页，以阳性 **présentateur** 为 headword，阴性 présentatrice 见「形态要点」。

**释义**：（电视 / 电台 / 演出）主持人、节目主持人 ｜ personne qui présente une émission (télé, radio)

**例句**
- _La présentatrice anime l'émission du soir._ 女主持人主持这档晚间节目。
- _C'est un présentateur très connu._ 这是位很有名的主持人。
- _Les présentateurs lisent le journal télévisé._ 主持人播报电视新闻。

**形态要点**
- 名词：`un présentateur`（m.）／ `une présentatrice`（f.）；复数 `présentateurs`／`présentatrices`
- 规律：**-teur → -trice** 是阴性施事名词的标准变化（同 acteur/actrice、directeur/directrice、instituteur/institutrice）——记一条，一串词都会变

**词源 / 构词**
- **拆解**：présent-（présenter「展示、呈上」的词干）+ **-ateur / -atrice**（施事名词后缀 ← 拉丁 -ator / -atrix「做……的人」）
- **演变**：拉丁 **praesentare**「呈上、展示」← **praesens**「在场的」（prae-「在前」+ esse「在」）→ 古法语 presenter → 法语 présenter → 加施事后缀成 présentateur（「把节目呈现给观众的人」；已核：TLFi 记 1484 年首见〔原义「荐举圣职者」〕，「广播电视主持人」义 1962 年〔Rob.〕；Académie 9e 记 15e siècle——2026-10-01 经检索转引）
- **同族 / 派生**：présenter（展示、介绍）、présentation（展示、介绍、演出）、présent（在场的、礼物）、présentatrice（女主持）；英语一侧见下节
- **记忆钩**：présentateur ＝ 「把节目『呈上来』的人」——présenter（呈上）＋ -ateur（人）；présent（在场/礼物）是同一词根

**英法交叉核对（受影响的英语词）**
- **借入英语**：**presenter**（「主持人、播报员」——英式英语广播电视用语；已核〔etymonline，2026-10-01 经检索转引〕：系 present + -er 的英语自构词，与法语 présentateur 属平行构词而非借入——本义「呈交者」mid-15c. 已见，「广播主持人」义 1967 年）；**present**（v.「呈献、提出」与 adj.「在场的」与 n.「礼物」——三义同出古法语 presenter / present ← 拉丁 praesentare / praesens）；**presentation**（已核：晚 14c. ← 古法语 presentacion / 中世纪拉丁 praesentationem——etymonline）
- **共祖未借入**：**presence**（← 拉丁 praesentia，经古法语——与 présentateur 同出 praesens「在场」，但属经法语整体借入，与法语本词为亲属而非来源）
- 核对：已核实（2026-10-01 经检索转引）——presenter 系英语自构（present + -er），本义 mid-15c.、广播义 1967（etymonline）；presentation 晚 14c. ← 古法语 presentacion（etymonline）；法语 présentateur 1484 年首见、主持人义 1962（TLFi）。

**同义 / 搭配 / 易混**
- 搭配：`le présentateur du journal télévisé`（新闻主持人）；`une présentatrice de télévision`；`présenter une émission`（主持一档节目）
- 易混：**le présentateur**（偏播报类主持——新闻、正式节目）vs **l'animateur**（偏互动/带动气氛的主持——综艺、广播 animateur radio）；**le chroniqueur**（评论员、专栏作家）
- **faux ami**：英语 presenter 更接近法语的 animateur（「带动者」），而法语 présentateur 更偏「播报员」——两者分工不完全重合
