# entrée

> 收录说明：inbox 形式为短语 **`en entree`**——编译为名词 lemma **entrée**（entrer 的过去分词名词化）；**en entrée**＝「作为头道菜」（介词 en + 名词短语）。此归并**待用户确认**。

**释义**：（1）入口、门口（l'entrée du musée 博物馆入口）；（2）进入、入场（entrée en scène 登场；entrée libre 免费入场）；（3）入场券 / 入场权（l'entrée est payante 门票收费）；（4）（餐）头道菜、前菜（crevettes en entrée 虾作头道菜） ｜ endroit par où l'on entre ; le fait d'entrer ; premier plat d'un repas

**例句**
- _L'entrée du musée est à droite._ 博物馆的入口在右边。
- _L'entrée est payante._ 入场收费。（[[payant]]）
- _En entrée, je prends une salade._ 头道菜我要一份沙拉。

**形态要点**
- 名词：`l'entrée`（f.——元音开头，省音）；复数 `les entrées`
- **双身份**：entrée 同时是动词 **entrer** 的过去分词（阴性）——作过去分词时与助动词 **être** 连用并性数配合：_elle est entrée_（她进来了）
- 常见短语：`porte d'entrée`（大门）、`entrée libre / gratuite`（免费入场）、`entrée de gamme`（入门级）、`entrée en matière`（开场白、引言）、`entrée en scène`（登场）、`avoir ses entrées`（有门路、可自由出入）

**词源 / 构词**
- **拆解**：**entrée** ＝ 动词 **entrer** 的过去分词 **entré(e)** 名词化（阴性——「进入（的动作、位置）」）← 拉丁 **intrare**「进入」← **intra**「在内」（etymonline：enter ← 古法语 entrer ← 拉丁 intrare ← intra，2026-10-03 直连核实）
- **演变**：拉丁 intrare → 古法语 entrer → 过去分词名词化 → 现代法语 entrée；「头道菜」义由「（宴席的）入场、开场」引申——上菜的头一道即「入席菜」。**法语首证年代检索未得**（fr.wiktionary 标 « Date à préciser »）——**待验证**
- **同族 / 派生**：entrer（进入）、rentrer（返回）、rentrée（开学、回归）、entrée de gamme、porte d'entrée；构词模型同 [[produit]]（← produire 的过去分词名词化）
- **记忆钩**：头道菜为什么叫 entrée——它是这顿饭的「入场式」；菜序：entrée（头道）→ plat（主菜）→ dessert（甜点）

**英法交叉核对（受影响的英语词）**
- **借入英语**：**entrée / entree**（n. **1724** 首见于英语，义「歌剧 / 芭蕾的开场曲」；更早中古英语已借作 **entre**「进入」；烹饪义 **1759**——etymonline 原文：the dish which was introductory to the main course（**主菜前的入门菜**——与今法语同义）；「自由出入权」义 1762）；**entry**（**c. 1300** ← 古法语 **entree**）；**entrance**（n. **1520s** ← 法语 **entrance** ← entrer）；**enter**（v. ← 古法语 entrer ← 拉丁 intrare ← intra）
- **共祖未借入**：—（intrare 一线入英语者均经法语或法语-拉丁线）
- 核对：已核实（etymonline，2026-10-03 直连）——entree 1724（歌剧 / 芭蕾开场义）/ 烹饪义 1759（原义「入门菜」）/ entry c. 1300 / entrance(n.) 1520s ← French entrance ← entrer ← Latin intrare ← intra。**faux ami 重点**：**美式英语 entrée ＝ 主菜**（由 1759 年的「入门菜」义漂移而来——漂移年代 etymonline 未载，**待验证**）；**法语 entrée 始终是头道菜**（在主菜之前）——学习者第一陷阱。法语 entrée 首证年代**待验证**

**同义 / 搭配 / 易混**
- 搭配：`l'entrée du musée`；`entrée libre`（免费入场）；`l'entrée est payante`；`crevettes en entrée`；`entrée en scène`（登场）；`porte d'entrée`；`entrée de gamme`
- **餐序辨析**：**entrée**（头道菜 / 前菜——正餐第一道）→ **plat (principal)**（主菜）→ **dessert**（甜点）；反义：**sortie**（出口——l'entrée et la sortie）
- **faux ami**：法语 entrée（头道菜）≠ 美式英语 entrée（主菜）——美式菜单上写 entrée 的是主菜；英式传统用法与法语更近（地区差异**待验证**）
- 链：[[payant]]（收费的）· [[crevette]]（虾——en entrée 常见菜）· [[cuisine]]（烹饪）
