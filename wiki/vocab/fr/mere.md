# mère

**释义**：（1）母亲、妈妈（mère de famille 家庭主妇、母亲）；（2）（喻）母体、根源（maison mère 母公司；carte mère 主板；langue mère 母语） ｜ femme qui a mis au monde un enfant ; ce qui est à l'origine

**例句**
- _Ma mère cuisine très bien._ 我妈妈做饭很好吃。
- _C'est bientôt la fête des Mères._ 母亲节快到了。
- _Cette entreprise est la maison mère du groupe._ 这家企业是集团的母公司。

**形态要点**
- 名词：`la mère`（f.）；复数 `les mères`；对应阳性 **père**（父亲）
- 复合词：`grand-mère`（祖母 / 外祖母）、`belle-mère`（岳母 / 继母）、`mère de famille`、`maison mère`（总公司）、`carte mère`（主板）、`mère patrie`（祖国母亲）、`la fête des Mères`（母亲节——Mères 复数大写）
- 用法提示：当面称呼母亲说 **maman**（口语）；mère 偏叙述 / 正式（ma mère）——一般不用 mère 直接呼唤

**词源 / 构词**
- **拆解**：**mère** ← 中古法语 mere ← 古法语 **mere** ← 拉丁 **matrem**（**mater**「母亲」的**宾格**——法语名词多承拉丁宾格形式）（fr.wiktionary 明证）← PIE ***méh₂tēr**（亲属词后缀 \*-ter-，源自儿语 \*mā-）
- **演变**：PIE \*méh₂tēr → 拉丁 mater（宾格 matrem）→ 古法语 mere → 现代法语 mère；法语首证年代检索未得（fr.wiktionary 标 « Siècle à préciser »）——**待验证**
- **同族 / 派生**：maternel（母亲的）、maternité（母性；产院）、matrice（子宫；矩阵）、matriarcat（母权制）、matricide、matrimonial、grand-mère、belle-mère；英语一侧见下（maternal / matrix / matter 同一拉丁根）
- **记忆钩**：mater 一线 = 「母」：maternel（母亲的）· maternité（母性）· matrice（子宫）· matière（物质——「母、源」）· alma mater（母校＝「慈母」）——一个根串起半个学术词汇表

**英法交叉核对（受影响的英语词）**
- **借入英语**：**maternal**（adj. **late 15c.**「母亲的」← 古法语 **maternel**（14c.）← 俗拉丁 **\*maternalis** ← 拉丁 **māternus** ← **māter**，etymonline 直连核实）；**maternity**（← 法语 maternité / 中世纪拉丁 maternitas）；**matrix**（← 拉丁 matrix「子宫」，mater 派生；入英年代**待验证**）；**alma mater**（拉丁短语借入）等同一拉丁根
- **共祖未借入**：**mother**（n. 古英语 **modor** ← 原始日耳曼语 **\*mōdēr** ← PIE **\*mater-**「母亲」——日耳曼**本族词**，与拉丁 māter **共祖而未借入**；etymonline 取 PIE 形 \*mater-，今通行重构为 \*méh₂tēr；-th- 拼写始自 16c. 初）；**matter**（c. 1200 ← 古法语 matere / 拉丁 **materia**——etymonline 引 de Vaan、Watkins：materia ← **māter**「源、母」——「物质」本义「母、源头之物」）
- 核对：已核实（etymonline + fr.wiktionary，2026-10-03）——maternal late 15c. ← 古法语 maternel（14c.）← 俗拉丁 \*maternalis ← 拉丁 māternus ← māter；mother ← OE modor ← PGmc \*mōdēr ← PIE \*mater-（共祖）；matter c. 1200 ← 古法语 matere / 拉丁 materia ← māter（引 de Vaan & Watkins）。法语 mère ← 拉丁 matrem ← PIE \*méh₂tēr、读音 /mɛʁ/（fr.wiktionary 转引；首证年代标 « Siècle à préciser »——**待验证**）

**同义 / 搭配 / 易混**
- 搭配：`mère de famille`；`la fête des Mères`（母亲节）；`maison mère`（母公司）；`carte mère`（主板）；`langue mère`（源语、母语）；`grand-mère`（祖母）；`mère célibataire`（单身母亲）
- **同音三连 /mɛʁ/**：**mère**（母亲）｜ **mer**（海——n.f.，← 拉丁 mare）｜ **maire**（市长——n.m.，「le maire / la maire」）——三词同音不同义，听写必考（mer / maire 词源细节**待验证**）
- 易混：mère（母亲）vs **mer**（海）vs **maire**（市长）——拼写与阴阳性区分；mer 阴性、maire 阳性，mère 阴性
- 链：[[frere]]（兄弟）· [[mon]] / [[son]]（主有形容词——ma mère / mon père 的性数配合）
