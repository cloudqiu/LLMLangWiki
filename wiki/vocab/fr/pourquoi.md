# pourquoi

**释义**：（1）（**疑问副词**）为什么——Pourquoi pleures-tu ? 你为什么哭？（问原因、目的）；（2）**间接疑问**——Je ne sais pas pourquoi elle a refusé 我不知道她为什么拒绝了；（3）**c'est pourquoi**（连词短语）因此、所以（表**结果**）；（4）**pourquoi pas ?** 为什么不呢（表同意或建议）；（5）**pourquoi faire ?** 为了做什么？／干吗？（＝ dans quel but）；（6）**名词化 le pourquoi**（m.，常在 le pourquoi et le comment 中＝缘由、原因） ｜ adv. interr. « pour quelle raison ? » ; loc. c'est pourquoi « voilà pourquoi, donc » ; n.m. le pourquoi « la raison, le motif »

**例句**
- _Pourquoi pleures-tu ?_ 你为什么哭？（直接疑问，主谓倒装）
- _Pourquoi est-ce qu'il est parti ?_ 他为什么走了？（与 **est-ce que** 配合，口语最常用）
- _Je ne sais pas pourquoi elle a refusé._ 我不知道她为什么拒绝了。（间接疑问，**不倒装**）
- _Il pleut, c'est pourquoi nous restons à la maison._ 下雨了，所以我们待在家里。（c'est pourquoi ＝ 因此）
- _— On y va ? — Pourquoi pas !_ ——我们去吗？——为什么不呢！
- _Pourquoi faire ?_ 干吗？／为了做什么用？（口语，＝ dans quel but）

**形态要点**
- **副词**：**不变化**（无性数配合）
- **疑问位置**：句首——**Pourquoi + 主谓倒装**（Pourquoi pleures-tu ?）或 **Pourquoi est-ce que + 陈述句**（口语最常用）；口语有时后置（Tu pleures pourquoi ?，非正式）
- **间接疑问**：从句首、**不倒装**——Je ne sais pas **pourquoi** elle est partie
- **名词化 le pourquoi**（m.，**不变**）：le pourquoi et le comment（缘由与方式）——常与 [[comment]] 对举
- **与 parce que 的分工（本页必记）**：**pourquoi 提问**（Pourquoi ? 为什么？）／**parce que 作答**（Parce que… 因为……）——与英语 **why / because** 的分工完全同构；间接问「为什么」用 pourquoi，答「因为」用 parce que；表「因此」用 **c'est pourquoi**（＝ c'est pour ça que，见 [[c-est-pour-ca-que]]）
- 拼读：/puʁ.kwa/——pour 的 **-r** 保留，与 quoi 连读；勿与 pour quoi faire 的停顿混

**词源 / 构词**
- **拆解**：**pour**（介词 ← 拉丁 **pro**「为、代、因、以……换取」，古法另有 **por / pur** 形）＋ **quoi**（疑问兼关系代词 ← 拉丁 **quid**「什么」，**qui** 的**中性形**，词干 **\*kʷo-**）——字面「**为了什么**」；古法语拼作 **por quoi / pur quei**（pour 的旧形 por/pur + quei/quoi）
- **演变（TLFi / Académie，2026-10-04 转引）**：
  - **ca 1050** 直接疑问 **pur quei**（《圣 Alexis 传》131「Filz Alexis, pur quei portat ta medre ?」；444）——**TLFi 首证**
  - **12 世纪初** 间接疑问 pur quei（Benedeit《圣布伦丹》468）
  - **ca 1165** 关系用法「pour lequel, pour laquelle」（Benoît de Sainte-Maure《特洛伊传奇》49）
  - **1174-76** **名词化 le purquei**（Guernes de Pont-Sainte-Maxence《圣托马斯》2359）
  - **1250-70** 关联关系用法「c'est pourquoi」（Guillaume le Vinier）
  - **1580** *c'est pourquoy*（Montaigne）
  - **Académie française（9e éd.）**：「**xie siècle, purquei, porqueit ; xiie siècle, pourquoi**」——现代拼写 **pourquoi** 定型于 **12 世纪**
- **同族 / 派生（法语）**：**pour**（← pro）、**quoi**（← quid）、**pourquoi** 本身即「介词 + 疑问代词」的复合（同类复合：**à quoi**、**de quoi**、**n'importe quoi**、**sur quoi**）；上位疑问词族 **qui · que · quoi · quel · quand · comment · pourquoi**——同出 **\*kʷo-**（见 [[qui]]）
- **记忆钩**：pourquoi ＝ pour（为了）+ quoi（什么）＝「为了什么」——构词思路与英语「for + what」一致，但英语最终选了日耳曼的 why（见下节）

**英法交叉核对（受影响的英语词）**
- **共祖未借入（本页核心）**：英语 **`why`** ← 古英语 **hwi**（＝ **hwæt**「what」的**工具格**，本义「借何物、以何手段」）← 日耳曼副词 **\*hwi**（同族：古撒克逊 hwi、古诺斯 hvi）← PIE **\*kwi-**（\*kʷo- 的方位格，见希腊 pei「何处」）——与法语 pourquoi（← pro + quid，词干同出 \*kʷo-）**共祖远亲、双向均非借入**（同型：[[quand]]↔when、[[qui]]↔who、[[comment]]↔how）
  - why 义项年代（etymonline）：**c. 1300** 名词「原因、理由」；**mid-14c** 感叹「哎呀」（表惊讶/强调）——另注 why 与 **how 是同一 \*kʷo- 词干分化的双式**
- **借入英语（直接借自拉丁，非经法语）**：**`quid pro quo`**（**1560s** ← 拉丁，字面「something for something」，quid ＝ qui 的**中性**「什么」，pro ＝「代、为」）——**与 pourquoi 的两个成分（pro + quid）完全相同**，但英语**直接借自拉丁**，未经法语 pourquoi（etymonline）
- **对照成分**：法语 **pour** ← 拉丁 **pro**（英语另有拉丁借词成分 **`pro`**、**`pro bono`**、**`quid pro quo`**——均直接借拉丁）；法语 **quoi** ← 拉丁 **quid**；而英语的 **for / what** 属日耳曼族，**不在这条拉丁线上**
- **罗曼语同源（共祖，横向对照）**：西语 **por qué**、意语 **perché**、葡语 **porque / porquê**、加泰 **per què**——与法语 pourquoi 同构（介词 + 疑问词）
- 核对：英语侧（why ← hwi ＝ hwæt 工具格 ← \*hwi ← PIE \*kwi-；义项 c. 1300 名词 / mid-14c 感叹；why 与 how 为 doublet；quid pro quo 1560s ← 拉丁）2026-10-04 经 **etymonline 直读／检索转引**；法语侧（pour ← pro；quoi ← quid；TLFi 首证 ca 1050 pur quei 圣 Alexis 131/444、12c 初 Benedeit 468、ca 1165 Troie 49、1174-76 le purquei 2359、1250-70 c'est pourquoi、1580 Montaigne；Académie「xie s. purquei, porqueit / xiie s. pourquoi」）2026-10-04 经 **WebSearch 转引 CNRTL/TLFi 与 Académie française**（cnrtl.fr/etymologie/pourquoi 被检索引出，直连仍 sinkhole）。**待验证**：①TLFi「pourquoi」原条首证定年未直连（现为转引 ca 1050）；②古法 **pour** 的 por / pur 形选择与其年代未逐核；③1174-76 名词化与 1250-70 c'est pourquoi 的书证系二次转引，未直读 TLFi 原条

**同义 / 搭配 / 易混**
- 搭配：`Pourquoi ?`（为什么）｜ `Pourquoi pas ?`（为什么不呢）｜ `C'est pourquoi…`（因此）｜ `Pourquoi faire ?`（干吗）｜ `Pourquoi donc / pourquoi diable ?`（究竟为何）｜ `le pourquoi et le comment`（缘由与方式）
- **易混（核心，问答分工）**：**pourquoi**（问「为什么」——疑问副词）｜ **parce que**（答「因为」——从属连词，**本库待建页**）｜ **c'est pourquoi**（因此、所以——表**结果**）｜ **c'est pour ça que**（[[c-est-pour-ca-que]]——同义，偏口语）｜ **vu que**（[[vu-que]]——「既然」，表**已知的原因**）
- 与 [[comment]] 分工：**pourquoi 问原因**，**comment 问方式**；与 [[quand]] 分工：pourquoi 问「为何」，quand 问「何时」
- 相关：[[comment]]、[[quand]]、[[c-est-pour-ca-que]]、[[vu-que]]、[[raison]]、[[savoir]]、[[qui]]、[[que-penses-tu-de]]
