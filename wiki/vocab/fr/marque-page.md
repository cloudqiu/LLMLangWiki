# marque-page

**释义**：（1）书签（夹在书页间标记阅读位置的小物件）；（2）（网络）书签、收藏夹条目 ｜ petit objet glissé entre les pages d'un livre pour marquer l'endroit de la lecture ; favori (informatique)

**例句**
- _J'ai mis un marque-page à la page 42._ 我在第 42 页夹了张书签。
- _Elle collectionne les marque-pages des librairies._ 她收集书店的书签。
- _Le navigateur conserve tous vos marque-pages._ 浏览器保存你所有的网页书签。

**形态要点**
- 名词：`un marque-page`（**m.**）；复数 **`des marque-pages`**（加 -s——检索核实：Wiktionnaire / Lexique flexionnel / Question Orthographe 均记 marque-pages；不变说未见支持；1990 拼写改革也不并写 marquepage）
- **复合词**：marque（动词 **marquer** 的第三人称单数形式）+ page——「标记页面（之物）」；因第一成分是动词形式，复合名词取**阳性**（同 porte-bagages、abat-jour 型——Académie 9e 明言 marque 系 marquer 的动词形式）
- 连字符保留：写 **marque-page**（不写 marquepage）

**词源 / 构词**
- **拆解**：**marque**（marquer「标记」的动词形式）+ **page**（← 拉丁 **pagina**「书页、纸页」〔原义与「固定、编织」相关（pangere）——一说原指葡萄藤行 / 棚架〕；古法语 page 12c. 已见——Académie 9e / CNRTL）
- **演变**：复合词，**Académie 9e（2024）：XX 世纪**；Usito（GRLF）：20 世纪中叶——晚近新构词；同模型平行构词：西语 marcapáginas（marcar + páginas）、德语 Lesezeichen（lesen + Zeichen）
- **同族 / 相关（法语）**：marquer（标记）、marque（记号、品牌）、marqueur（记号笔）；数字义同 favori（浏览器收藏）；同义词 signet（见下）
- **记忆钩**：marque-page ＝「（标）记页面」——动词 + 名词的复合，一眼看清构词；对应德语 Lesezeichen 也是「读书记号」同款思路

**英法交叉核对（受影响的英语词）**
- **借入英语**：无——marque-page 未进入英语（英语对应词 bookmark 系自构）
- **共祖未借入 / 平行构词**：**bookmark**（n. **1838-40**：bookmarker 1838、bookmark 1840（etymonline；OED 最早例 1833，注「英语内部复合」）＝ **book + mark** 英语自构复合——与法语 marque-page 是「同模型平行构词」（名词 + 标记），**互不借贷**；德语 Lesezeichen 同理）
- 核对：已核实（Académie 9e / Usito / etymonline / OED，2026-10-03 经检索转引）——marque-page 20 世纪复合（Académie 9e；Usito 记 20 世纪中叶）；英 bookmark 1840（etymonline；OED 1833 最早例）与法语无借贷关系

**同义 / 搭配 / 易混**
- **同义**：**signet**（书中缎带书签——本义「小印章」← 拉丁 **signum** + 指小 **-et**：ca 1280「小印章」→ 1348「呢绒商印记」→ 1377「（经文书中）小缎带」→ 1718「书脊缎带书签」（Académie）——CNRTL；发音 [siɲɛ]）；数字义：favori（收藏）
- 搭配：`mettre / glisser un marque-page`（夹书签）；`un marque-page magnétique / en cuir`（磁性 / 皮质书签）；`ajouter aux marque-pages`（加入浏览器收藏）
- **易混**：**marque-page**（通用「书签」）vs **signet**（书内缎带 / 更书面、词更老）；别把 marque-page 拆读为「品牌（marque）页面（page）」
- 阅读簇：[[roman]]（小说）、[[liseuse]]（阅读器）、[[etagere]]（书架）、[[librairie]]（书店）
