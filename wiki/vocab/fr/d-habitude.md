# d'habitude

**释义**：loc. adv. **通常、平常**（= *normalement, habituellement, ordinairement*）；固定式 **comme d'habitude**（像往常一样） ｜ ordinairement, habituellement

**例句**
- _D'habitude, je me lève à sept heures._ 我通常七点起床。
- _Comme d'habitude, il est en retard._ 像往常一样，他又迟到了。
- _D'habitude, elle prend le bus._ 她平常坐公交。

**形态要点**
- 副词短语（locution adverbiale），**不变**；fr.wiktionary 与 lalanguefrancaise 标**口语色彩**；另有作 locution adjectivale 的用法
- 位置灵活：可置句首（*D'habitude, je…*）或句末
- 固定式：**comme d'habitude**（＝像往常一样；口语常缩作 *comme d'hab*）
- **h muet**：*d'habitude* 可与前词连诵（*comme d'habitude* /kɔm da.bi.tyd/）

**词源 / 构词**
- 拆解：**de**（介词）+ **habitude**（名词）——元音前省音作 **d'**；**habitude** ← 拉丁 **habitudo**「习性」，出自动词 **habitus** ← **habere**「持有、拥有」（PIE **\*ghabh-**）
- 首证：
  - **habitude** 本身：**xivᵉ siècle（14c）**（Académie 9e，fr.wiktionary 引）；拉丁 *habitudo*
  - **d'habitude（凝固短语）**：**未取到明确首现日期 → 待验证**。现存书证仅 19–20c（Erckmann-Chatrian **1864**、Giraudoux **1916**、Méric **1930**）；**Gallicagram 显示 1800 起有使用**。DMF 有 *habitude* 及 *avoir acoustumé de* 类古式，但**未见凝固的 *d'habitude***
- 同族 / 派生：**habitude**（习惯）、**habituel / habituelle**（通常的）、**habituellement**（通常，书面）、**habituer**（使习惯）、**s'habituer à**（习惯于）
- 记忆钩：**habere（持有）→ habitude（持有的状态）→「习惯」**；*d'habitude* 直译即「**按习惯（来说）**」

**英法交叉核对（受影响的英语词）**
- **借入（英 ← 法）**：英语 **habit**（n.，**early 13c.**「宗教 / 教士特有的衣着」）← 古法语 *habit, abit*（12c.）← 拉丁 *habitus*；「**习惯做法**」义 **early 14c.**；「一般衣物」义 **late 14c.**
- **共祖 / 直取拉丁**：英语 **habitual / habituate / habitation / inhabit** 及动词 **habit**（**mid-14c.**「居住」← 古法语 *habiter* ← 拉丁 *habitare*）——**皆拉丁 habere 家族**
- **待验证**：英语 **habitude**（旧词「习性」）与法语 *habitude* 同源（拉丁 *habitudo*）——**借入年代未取得**
- **核对要点**：**英语 habit 走了「衣着 → 习惯」两条义**，而法语 *habitude* 只剩「习惯」一义（法语的「衣着」是 *habit* 但今多指「礼服 / 燕尾服」）——**同源词在两语各留一支**

**同义 / 搭配 / 易混**
- 同义：**habituellement**（书面，语域高）、**ordinairement**、**généralement**、**normalement**、**de coutume**
- 搭配：**comme d'habitude**（像往常一样）、**plus que d'habitude**（比平时更）、**comme d'hab**（口语缩写）
- 易混：**d'habitude**（通常——口语）vs **habituellement**（通常——书面）；**d'habitude** vs **d'ordinaire**（通常——稍书面）
- **faux ami**：英语 *habitude*（罕用）≠ 常用英语 *habit*——英语母语者会把 *d'habitude* 直译成 "by habit" 而失掉「通常」这一频度义
