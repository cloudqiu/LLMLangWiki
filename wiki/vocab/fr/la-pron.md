# la

> 命名说明：本页文件名为 `la-pron.md`——la 按词性分页：冠词页 [[la-art]]（`la-art.md`）、本页为直接宾语代词；与 là（副词「那里」）近形，日后收 là 记为 `la-adv.md`（见 hub 命名登记表）。
> 收录说明：经用户确认（2026-10-01），inbox 的 `la` 即**宾语代词**用法（如 Je la vois.）——本页承载该用法全貌。

**释义**：她、它——第三人称阴性单数**直接宾语代词**（代替阴性单数的人或事物）：Tu connais Marie ? — Oui, je la connais. ｜ pronom personnel COD, 3e personne du singulier féminin

**例句**
- _Je la connais bien._ 我很了解她。
- _Cette lettre ? Je l'ai déjà lue._ 这封信？我已经读过了。（元音前省音 l'；过去分词配合 lue——COD 前置时配合）
- _Ne la réveille pas !_ 别叫醒她！（否定式：代词仍在动词前）
- _Regarde-la !_ 看它！（肯定命令式：代词后置、连字符连接）

**形态要点**
- **代替谁**：第三人称阴性单数直接宾语（人与物皆可）——Marie → la；la lettre → la；复数用 **les**（le / la / les 一组）
- **位置**：动词前（je **la** vois）；复合过去在助动词前（je **l'ai vue**）；否定包夹（je **ne la** vois **pas**）；不定式前（je vais **la** voir）；肯定命令式后置加连字符（Regarde-**la** !），否定命令式仍前置（Ne **la** regarde pas !）
- **省音**：元音或哑音 h 前 → **l'**（je l'aime / je l'ai vue）
- **配合（高频考点）**：复合过去中，直接宾语前置（含 la / l'）时过去分词与该宾语性数配合——je l'ai **vue**（阴性）、je les ai **vues**（阴性复数）；对比间接宾语 lui / leur——**不配合**（je lui ai parlé）
- **代词叠用顺序**：me / te / se / nous / vous → le / la / les → lui / leur → y → en（Il me la donne. 他把它给我；Je lui en parlerai. 我会跟他谈这个——y / en 见 [[y]]、[[en-parler]]）

**词源 / 构词**
- **拆解**：拉丁 **illa**——指示代词 ille / illa / illud「那个（人 / 物）」的阴性宾格（illam）；与定冠词 la（[[la-art]]）**同源**：同一个 illa，一条线语法化为冠词、另一条（宾格）线固化为宾语代词
- **演变**：拉丁 illa（illam）→ 古法语 la（**9 世纪**见诸文本——据 CNRTL / Académie「LE」条，2026-10-01 经检索转引）；指示词的「指点」义弱化、位置固化于动词前 → 现代法语 clitique（附着于动词的代词）
- **同族 / 派生**：le / la / les（直接宾语三件套）、lui / leur（间接宾语）、moi / toi / nous / vous；冠词 le / la / les（[[la-art]]）；英语一侧见下节
- **记忆钩**：la ＝「她」——je la vois 的字面语序「我-她-看」，跟英语 I see her 呈镜像；la 与 lui 的分工：「见」她 → la（直接）、「跟」她说话 → lui（间接）

**英法交叉核对（受影响的英语词）**
- **借入英语**：无——附着代词系统没有进入英语（英语 her 是独立词、位于动词后）
- **共祖未借入**：英语 **she / her** 属日耳曼词，与拉丁 illa 无关；但语法功能可对照：英语 her 一词兼表「她（直接宾语）」与「对她（间接宾语）」，法语用 la / lui 两词区分——**英语母语者学法语的头号代词陷阱**
- 核对：la（代词）与冠词同出 illa，年代同据 CNRTL / Académie（9 世纪）——经检索转引

**同义 / 搭配 / 易混**
- 搭配：`je la vois / je l'aime / je l'ai vue`；`La voilà !`（她来了 / 找到了！——la 前置于 voilà）；`Regarde-la / Écoute-la`（命令式后置）
- **核心易混——la vs lui**：**la**（直接宾语——voir qn → la voir）｜ **lui**（间接宾语——parler à qn → lui parler）；「对他 / 她做某事（à + 人）」一律用 lui
- 再易混：**la**（宾语代词，无重音）vs **là**（副词「那里」，带重音）vs **l'a**（l' + a——il l'a vue 与 il la vue 音同、拼写各异）；**la**（冠词）vs **la**（代词）——见 [[la-art]]
- **faux ami**：英语 I see her → 法语 je **la** vois（代词前置！）；英语 I talk to her → je **lui** parle（不能译成 je la parle）
