# table

**释义**：（1）**桌子**——家具，有平板与腿（la table de la cuisine 厨房桌）；（2）**板、平板**——扁平的面（table d'ardoise 石板；table de dissection 解剖台）；（3）**台**——为特定用途而设的平面（table de nuit 床头柜；table de cuisson 灶台）；（4）**表格、一览表**——按行列排布的信息（table des matières 目录；table de multiplication 乘法表）；（5）**餐桌、饭菜**——引申指共同进餐（se mettre à table 入席；aimer la table 讲究吃） ｜ meuble formé d'un plateau posé sur des pieds ; surface plane ; liste d'informations disposées en lignes et en colonnes ; ensemble des convives ou des mets

**例句**
- _Nous nous mettons à table à huit heures._ 我们八点入席吃饭。
- _Le dictionnaire est posé sur la table._ 词典放在桌上。（见 [[dictionnaire]]）
- _Consultez la table des matières du chapitre._ 请查阅本章目录。（见 [[chapitre]]）
- _Ils ont joué cartes sur table._ 他们摊了牌（坦白相待）。

**形态要点**
- 名词（n.f.）：`la table`（阴性）；复数 **les tables**；无不规则变化
- 拉丁 **tabula** 本为阴性，法语沿袭阴性——同为拉丁第一变格 -a 的「板」类名词（同 [[lumiere]] ← luminaria、[[bibliotheque]] ← bibliotheca）在法语里多为阴性
- 常见搭配：`se mettre à table`（入席）／`desservir / débarrasser la table`（收拾桌子）／`table ronde`（圆桌；亦指「圆桌会议」）／`table basse`（茶几）／`table de nuit`（床头柜）／`table des matières`（目录）／`table de multiplication`（乘法表）／`jouer cartes sur table`（摊牌）／`faire table rase`（一扫而空，另源）
- 构词力：`table` 可作复合词首（table-bureau 等）与词根（见下「同族 / 派生」）

**词源 / 构词**
- **拆解**：拉丁 **tabula**「板、木板；写字板；清单；画板」——本义「小块平板」（词源**不明**：etymonline 记「a word of uncertain origin」，与翁布里亚语 *tafle*「在板上」相关；无反溯到可靠 PIE 词根）
- **演变（CNRTL/TLFi，2026-10-05 经 le-tresor-de-la-langue.fr 转引）**：
  - **1050 tabla**「平面，带一腿或多腿，用于承放菜肴」（TLFi « Étymol. et Hist. » 首证原文：« 1050 tabla « surface plane, à un ou plusieurs pieds, destinée à recevoir les mets » »）
  - 古法语 *table / tabel*（etymonline 谓 **11 世纪**已见）→ 现代法语 **table**；词形自拉丁几乎原样承袭，仅 -ŭ- 脱落、-a 保留
  - **关键替换事件**：通俗拉丁（高卢与意大利）中 **tabula 取代了古典拉丁的 mensa「餐桌」**——mensa 只在罗马尼亚语 *masă*、伊比利亚语 *mesa* 存活下来，法语中仅余木工术语 **moise**（「横梁」，另源）。故法语「桌」是 tabula 一线，与西语 mesa / 罗语 masă **不同源**
  - **义项链**：「板」→「承放的平面/桌」→「台」→「表格、目录」→「饭菜、共餐」
- **同族 / 派生（法语）**：**tableau**（画；表；黑板）；**tabler**（依靠、据此；tabler sur）；**tablette**（小板；平板电脑；巧克力块）；**tabuler / tabulation**；**retable**（祭坛画）；**établi / établir**（工作台／建立——虽出拉丁 *stabilire*，拼写与语义受 table 类词影响）；**entablement**（柱顶盘）；复合词 table de nuit / table ronde / table des matières / tennis de table / vin de table
- **记忆钩**：table 就是一块「板」——「板」→「桌」→「表」；英语 table 走的是同一条拉丁路线，所以两语的 table 在很多义项上能对号（这是本词最省力的记忆点）

**英法交叉核对（受影响的英语词）**
- **借入英语**：**`table`**（n.）——Middle English ← 古法语 **table / tabel**（11 世纪，「board, square panel, plank; writing table」），另有**古英语本土形 tabele**（← 日耳曼语 **\*tabal**，经拉丁 tabula 而来自古英语时期）；「家具—桌子」义约 **1300** 出现。注意：**英语原有的「桌」是 `board`**（古英语 bord），table 借入后与 board 分工（board 退守「板、董事会、膳食」义）。（英语词库未收 `table`）
- **共祖 + 双重来源**：英语 table 与法语 table **同出拉丁 tabula**；而英语一侧同时有「古英语 tabele（日耳曼中介）」与「古法语 table」两条线汇合——是「同一个拉丁词经两条路进英语」的样本
- **不经法语（直接拉丁）入英语**：**`tabular`**、**`tabulate`**、**`tabulation`**（← 拉丁 tabula）；**`tabula rasa`**（拉丁「擦净的板」＝白板，16c. 入英）；**`entablature`**（← 意/法，建筑柱顶盘）
- **反向回流（法 ← 英）**：无（table 这一线英语另有本土来源，非回借）
- **法语借词入英语（同类）**：**`tableau`**（1690s ← 法语 tableau）、**`table d'hôte`**（1610s ← 法语「主人家的桌」＝套餐）、**`tableau vivant`**——均法语输出（词库未收，记于此备核）
- 核对：英语侧（table / board）2026-10-05 **etymonline 直读**；法语侧（TLFi « 1050 tabla » 首证、tabula 取代 mensa 之说）2026-10-05 经 **le-tresor-de-la-langue.fr 转引 CNRTL/TLFi**（cnrtl.fr 直连 sinkhole，Wiktionnaire 该页仅注「(Date à préciser)」）

**同义 / 搭配 / 易混**
- 搭配：`se mettre à table`（入席）｜ `à table`（吃饭啦——招呼语）｜ `table des matières`（目录）｜ `table ronde`（圆桌／圆桌会议）｜ `table de nuit`（床头柜）｜ `faire table rase de qqch`（把某事物一扫而空，源自 *table rase* 刮净的写字板）｜ `jouer cartes sur table`（摊牌）｜ `tenir table ouverte`（待客常开）
- 辨析：**table**（桌子；表格）｜ **`bureau`**（办公桌；办公室——「书桌」法语多用 bureau，不用 table）｜ **`établi`**（工作台）｜ **`tableau`**（画；黑板；图表——**勿与 table 混**，tableau 是「板」的另一派生）｜ **`plan`**（平面；平面图）
- **faux ami**：法语 **table** 与英语 **table** 大体同义（桌／表格），但**分布相反**——英语 table 更常用于「表格」，法语 table 日常更常用于「餐桌/饭桌」；英语「书桌」是 desk（＝法语 bureau），法语 table 不指书桌
- 相关：[[dictionnaire]]（sur la table 的例）；[[cuisine]]（la table de la cuisine）；[[chapitre]]（table des matières）；[[lumiere]]、[[bibliotheque]]（同为拉丁 -a 阴性借词，可对照性别规律）
