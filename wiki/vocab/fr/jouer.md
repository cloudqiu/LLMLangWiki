# jouer

> 收录说明：inbox 里的遇到形式是 **`jouais`**（直陈式未完成过去时 je / tu 形）——按 lemma 规则归并至不定式 **jouer**。

**释义**：（1）**玩**（儿童游乐）；（2）**jouer à + 游戏 / 运动**——参加（遵守其规则）：*jouer aux cartes / au foot*；（3）**jouer de + 乐器**——演奏：*jouer du piano*；（4）**出牌**（jouer une carte）；（5）**下赌注、冒险**（jouer de l'argent / sa vie）；（6）**演戏、扮演**（jouer un rôle / une pièce）；**假装**；（7）**欺骗**（jouer qqn）；**se jouer de** 嘲弄 / 轻视；（8）**（机械）活动自如**｜ se livrer à un jeu ; (à) pratiquer un jeu ; (de) jouer d'un instrument ; interpréter, miser

**例句**
- _Les enfants jouent dans le jardin._ 孩子们在花园里玩耍。
- _Elle joue du piano depuis dix ans._ 她弹钢琴十年了。
- _Il joue au tennis tous les dimanches._ 他每周日打网球。

**形态要点**
- 动词（变位要点）：不定式 **jouer** ｜ 组别：**1er groupe**（完全规则 -er）｜ 助动词：**avoir** ｜ 过去分词：**joué**
  现在时：je joue ｜ tu joues ｜ il·elle joue ｜ nous jouons ｜ vous jouez ｜ ils·elles jouent
- **介词搭配（核心语法点）**：**jouer à + 游戏 / 运动**（参与其规则）；**jouer de + 乐器**（演奏）——法语最高频错误点之一
- 代动词：**se jouer de qqn**（嘲弄 / 轻视）
- 派生：**joueur / joueuse**（玩家）、**jouet**（玩具）、**jeu**（游戏）

**词源 / 构词**
- **拆解**：拉丁 **jocari**（异体非异相动词 **jocare**），古典义「plaisanter, badiner（开玩笑、戏耍）」，为 **jocus**「笑话、游戏」的派生（jocus 亦生法语 **jeu**）。晚期拉丁中 *jocare / jocari* 语义扩为「s'amuser, se divertir, jouer」，**取代了古典的 ludere**（拉丁形已见于 Plaute）
- **首证**：**约 1100**，义「se distraire, s'amuser」、亦「jouer aux échecs」；**1225** 见「jouer d'un instrument」与「mettre en action」；**1265**「se mouvoir avec aisance」；派生词 **jouet** 仅 13 世纪起
- **语义演变**：**jocus（玩笑、言语戏谑）** vs 拉丁 **ludus（有组织的身体游戏）**——是 *jocus* 而非 *ludus* 经演变产生法语 *jeu*，覆盖一切「玩」义。中古形：joer / jöer / juer
- **同族 / 派生（法语）**：**jeu**（← 拉丁 jocum）、**jouet**、**joueur / joueuse**、**joujou**、**jongler**、se jouer de
- **记忆钩**：**「玩」源自「玩笑」**——不是拉丁 ludus「竞技」，而是 jocus「戏谑」长成了法语的 jouer / jeu

**英法交叉核对（受影响的英语词）**
- **共祖（非借自法语）**：英语 **joke**（n. 1660s 作 *joque* ← 拉丁 **iocus**；v. 1660s ← 拉丁 *iocari*）——英语**直接借拉丁**，与法语 jouer **共祖**（同出 iocus），但**不是**借法语
- **借入（英 ← 法）**：英语 **juggle**（late 14c. *jogelen*，系 juggler 的逆构），兼部分借古法 **jogler**（今法 *jongler*）；链：古法 jogler ← 晚期拉丁 *ioculare* ← 拉丁 **ioculari**「to jest」← **iocus**；juggler ← 盎格鲁-法 *jogelour* ← 拉丁 *ioculator*——**本库英语页 [[juggle]] 已存在，双向互链**
- 同族：jocose / jocular / jester / jewel / joker（拉丁 iocus 派系）
- 核对：英语侧经检索转引 etymonline（2026-10-13）；法语侧 1100 / 1225 / 1265 据论文转引（**待验证**）

**同义 / 搭配 / 易混**
- 搭配：`jouer à + 运动 / 牌戏`（jouer au foot / aux cartes / aux échecs）｜ `jouer de + 乐器`（jouer du piano / de la guitare）｜ `jouer un rôle`｜ `jouer un tour à qqn`（捉弄）｜ `se jouer de qqn`｜ `jouer avec le feu`｜ `c'est joué`（成了 / 定了）
- 同义：s'amuser、se divertir、interpréter（演奏 / 扮演）、miser（下注）
- **易混**：**jouer à vs jouer de**（运动 / 游戏 vs 乐器——最高频错误点）；jouer vs se jouer de
- 相关：**[[juggle]]**（英语侧同源——经古法 jogler 借入）
