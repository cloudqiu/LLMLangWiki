# endroit

**释义**：（1）**地方、地点、位置**（à cet endroit 在这个地方；à quel endroit ? 在哪儿？）；（2）**（物体的）部位**（le point sensible à cet endroit 该处的痛处）；（3）**à l'endroit** ＝ **正面（朝外）、顺向**（反义 **à l'envers** 反面 / 逆向）；（4）**à l'endroit de qqn** ＝ 对某人（＝ envers，**书面 / 法律语**） ｜ lieu, emplacement déterminé ; côté d'une chose qu'on présente à la vue

**例句**
- _Range ce livre à sa place, pas à cet endroit._ 把这书放回原位，别放这儿。
- _Mets ton pull à l'endroit._ 把毛衣正着穿（反面是 à l'envers）。
- _Il s'est montré courtois à l'endroit de ses invités._ 他对客人彬彬有礼（书面）。

**形态要点**
- 名词：`l'endroit`（**m.**）；复数 **endroits**
- 固定短语：`à l'endroit`（正面朝外）↔ `à l'envers`（反面朝外）｜ `par endroits`（有些地方、零星地）｜ `d'un endroit à l'autre`（从这个地方到那个地方）｜ `à l'endroit de qqn`（对某人——书面）
- 与 **envers** 的对立：本义「en droit」（正面）→ 名词「地方」

**词源 / 构词**
- **拆解**：拉丁 **in directum**（或 in + directo）← **directus**「直的」（**dirigere**「使直、指引」的过去分词）→ 古法语 **endreit**（＝ en + droit）→ 现代 endroit
- **演变**：拉丁 directus → 古法 endreit；**先作副词 / 介词**用（「正好、恰好」——là endreit、or endreit），**12 世纪起名词化**为「地方」；首见 **1121**（Wikimanche，义「确定之地」）——**转引待验证**（TLFi 精确日期未直核）
- **词源竞争说**：Dictionnaire de Trévoux（1771）引 Nicot，主张源 **indirectum**——**旧说，今主流不取**（并列存录）
- **同族 / 派生（法语）**：**droit**（直的 / 权利）、**adroit**（灵巧的）、**maladroit**（笨拙的）、**adresse**（地址 / 灵巧）、**dresser**（竖起 / 列出）、**redresser**（弄直）——皆 **directus / dirigere** 一族
- **记忆钩**：endroit ＝ en + droit（「在直的方向上」）——先指「正面 / 恰好」，再由「那个正好的点」名词化为「地方」

**英法交叉核对（受影响的英语词）**
- **借入英语（同族非同词）**：**endroit 本身无英语借词**；与它**同词根 droit** 的是 **adroit**（adj.「灵巧的」← 法语 *adroit* < *à droit*，17c 借入）——**注意 adroit 源自 droit 而非 endroit**；**direct / dress / address** 则经拉丁 directus / dirigere（部分经古法语 dresser）入英，亦非经 endroit
- **共祖未借入**：英语 **direct**（← 拉丁 directus）与法语 endroit 同出 directus 一族，但系拉丁直入
- **同义异源**：英语「地方」用 **place / spot**（← 拉丁 platea / 中古英语）——与 endroit **无亲缘**
- 核对：英语侧（adroit 17c ← 法 adroit；direct ← 拉丁 directus）经检索转引 etymonline（2026-10-11）；法语侧首见 1121 与 in directum 链据 Wikimanche / Académie 9e 转引（**待验证**）
- **faux ami 提示**：**英语无 endroit**——「地方」别说 *endroit* 直译成英语词

**同义 / 搭配 / 易混**
- 搭配：`à cet endroit`（在此处）｜ `à quel endroit ?`（在哪儿？）｜ `à l'endroit`（正面）↔ `à l'envers`（反面）｜ `par endroits`（零星地）｜ `à l'endroit de qqn`（对某人——书面）
- **易混**：**endroit**（具体的地点 / 部位）vs **lieu**（场所，更抽象 / 正式——*avoir lieu* 举行）vs **place**（位置 / 广场）vs **[[partout]]**（到处）；**à l'endroit** ↔ **à l'envers**（正 / 反）
- 相关：[[partout]]（处所副词域）；[[dans]]（介词）
