# casser

**释义**：（1）打碎、打破（casser un verre 打碎杯子）；（2）弄断、折断（casser une branche 折断树枝）；（3）毁坏、破坏 ｜ briser ; mettre en morceaux ; rompre

**例句**
- _J'ai cassé un verre._ 我打碎了一只杯子。
- _Il a cassé sa jambe en skiant._ 他滑雪时摔断了腿。（se casser）
- _Ne casse pas ce jouet !_ 别把这玩具弄坏了！

**形态要点**
- 动词：不定式 **casser** ｜ **1er groupe** ｜ 助动词 **avoir** ｜ 过去分词 **cassé**
- 现在时六形：je **casse** ｜ tu **casses** ｜ il·elle **casse** ｜ nous **cassons** ｜ vous **cassez** ｜ ils·elles **cassent**
- **代词式 se casser**（折断）：se casser la jambe / le bras（摔断腿 / 胳膊）——过去分词配合：elle s'est cassé la jambe（se 为间宾不配合）
- 口语：**casser les pieds à qqn**（烦扰某人、让人受不了）；**se casser**（俚语「走人、离开」）；**casser la croûte**（吃点东西、垫垫肚子）

**词源 / 构词**
- **拆解**：拉丁 **quassare**「剧烈摇动、砸碎」＝ **quatere**「摇动」的**反复体**（-t- → -ss- 反复尾）——「反复摇 → 摇碎 → 打碎」；PIE ***kwet-**「摇动」
- **演变**：拉丁 quatere「摇」→ 反复体 quassare「砸碎」→ 古法语 **quasser / casser**（qu- / c- 并存）→ 现代法语 casser（古法语既有「打碎」义，也有「撤销、宣布无效」义，后者来自同形的 cassare）
- **同族 / 派生（法语）**：casse（n.f. 打碎、破损；n.m. 撬锁行窃——口语）、cassure（裂口、断口）、cassant（易断的、脆的；生硬的）、fracasser（砸碎、打碎——fra- 加强）、casse-tête（拼图、难题——「绞尽脑汁」）；英语一侧见下节
- **记忆钩**：casser 的祖先「摇」到「碎」——反复地摇就是砸碎；同根的英语 quash / squash 也藏着「摇碎」的手感

**英法交叉核对（受影响的英语词）**
- **借入英语**：**quash**（v.——第二义「打碎、捣碎」early 14c. ← 古法语 **quasser / casser**「打破、毁坏」← 拉丁 quassare「砸碎」〔etymonline，2026-10-01 经检索转引〕）；**squash**（v.「压碎、挤烂」← 俗拉丁 \*exquassare ← ex- + quassare「砸碎」）；**cask**（n.「木桶」mid-15c. ← 法语 casque / 西班牙语 casco「陶片」← 俗拉丁 \*quassicare ← quassare）
- **共祖未借入**：**concussion**（← 拉丁 concutere ← com- + quatere「摇」，与 casser 同出 quatere 但直承拉丁，非经法语）；**discuss / discussion**（← 拉丁 discutere ← dis- + quatere「摇散 → 讨论」，同根非经法语）
- 核对：已核实（etymonline，2026-10-01 经检索转引）——quash 是「两个拉丁词合并」：「撤销、宣布无效」义 ← 中世纪拉丁 quassare / 晚期拉丁 cassare ← cassus「无效」；「打碎」义 ← 拉丁 quassare「砸碎」← quatere 反复体——后者即 casser 之源；法语的 quasser/casser 后来统作 casser

**同义 / 搭配 / 易混**
- 搭配：`casser un verre / une assiette`（打碎杯子 / 盘子）；`se casser la jambe`（摔断腿）；`casser en morceaux`（打碎成块）；`casser les pieds à qqn`（烦扰某人，口语）；`casser la croûte`（吃点东西，口语）
- **易混（「破 / 断」家族）**：**casser**（打碎、弄断——最常用，及物或 se casser）vs **briser**（打破、打破——更书面/抽象：briser le silence 打破沉默）vs **rompre**（断裂、断绝——正式：rompre les relations 断绝关系）vs **fracasser**（砸碎——力度更强）
- **faux ami**：casser ≈ break（对齐）；英语 quash 的「撤销、镇压」义（另一拉丁词）与 casser 的「打碎」义**同形异源**——别把 quash「撤销」当成「打碎」
