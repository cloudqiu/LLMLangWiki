# même si

**释义**：即使……、即便……（引导让步从句：尽管事实如此，结果不变——Même si tu insistes, je ne viendrai pas.） ｜ locution conjonctive introduisant une concession ; équivaut à « bien que » + indicatif

**例句**
- _Même si tu insistes, je ne viendrai pas._ 即使你坚持，我也不会来。
- _Même si on est vaincu, on n'a pas mal joué._ 即使输了，我们打得也不差。
- _Il sort tous les jours, même s'il pleut._ 他每天出门，即使下雨也去。（même si + il → 缩合 **s'il**）

**形态要点**
- **locution conjonctive**（连词短语）：**même si + 直陈式**——核心规则：même si 后**接直陈式**（présent / imparfait / plus-que-parfait，即 si 假设句的时态系统），**不接虚拟式**
- 时态搭配：même si + 现在时 / 复合过去时（事实性让步）→ 主句任意时态；même si + **未完成过去时** → 主句**条件式**（假设性：Même s'il pleuvait, je sortirais.）；même si + 愈过去时 → 主句条件式过去时
- 缩合：si 在 il / ils 前变 **s'**（même **s'il** pleut, même **s'ils** viennent）
- **对照句法（不通用）**：**même si + 直陈式**（事实 / 假设性让步）vs **bien que / quoique + 虚拟式**（让步——主句为事实）vs **quand bien même + 条件式**（纯假设）vs **malgré + 名词**
- **même 三身份**（本短语的语法背景，详见词源节）：形容词「相同的」（le même livre）／副词「甚至」（même pas）／连词构件「即使」（même si）

**词源 / 构词**
- **拆解（même）**：通俗拉丁 ***metipsimus**「（我 / 你 / 他）本人」＝强调后缀 **-met**（如 egomet「我本人」）+ **ipse**「自身、本人」+ 最高级后缀 **-issimus**——Académie 9e 即记此形（「proprement “(moi, toi, lui)-même en personne”」）；另有词源学文献（Körting）并列记载 **semetipsimus** 作平行（类推）构形——两形并存记录（Académie 9e / Körting，2026-10-03 经检索转引）
- **演变（même）**：通俗拉丁 \*metipsimus → 古法语 **meïsme → mesme → même**（Académie 9e 记 **11 世纪**）；同族罗曼语：espagnol mismo、italien medesimo、portugais mesmo；**si** 为直接继承拉丁连词 **sī**「如果」（与副词 si ← 拉丁 **sic**「如此」、肯定词 si ← sic 同形异源）
- **même 三身份的来源**：祖义「……本人」→「同一个（人 / 物）」的同一性 →（极端情形也纳入）「甚至」——「相同」（形容词）与「甚至」（副词）两义皆自「同一」引申；« même si » ＝「就算是在……的情形下也一样」
- **记忆钩**：même 的祖先 \*metipsimus 拆开就是「-met（本人）+ ipse（自身）＋最高级」——「正是他本人」→「同一个」→「甚至」；même si 的让步逻辑：在「最极端的同一情形」下结果也不变

**英法交叉核对（受影响的英语词）**
- **借入英语**：无——même si 为句法组合，未整组借入（英语对应手段为 even if / even though）
- **共祖未借入 / 重点否定项**：英语 **same** 与 même **无词源关系**——same ← 原始日耳曼语 ***samaz**「相同」（PIE 词根 ***sem-**「一、共同」，同族拉丁 similis / simul 属比较文献所记的远亲同根），中古英语的 same 更可能直接来自**古北欧语 samr**（取代了本土的 ilk）；même 属拉丁 **ipse** 家族（\*metipsimus）——两词仅在「语义上对应」（同表「相同」），词源上分属不相干的词根；**切勿**把 même 与 same 挂钩（常见错误联想）
- 核对：已核实（etymonline，2026-10-03 经检索转引）——same ← PGmc \*samaz ← PIE \*sem-，经古北欧语 samr 入中古英语；même ← 通俗拉丁 \*metipsimus（-met + ipse + -issimus），ipse 家族与 PIE \*sem- 无关联——「同义异源、无借入」；si ← 拉丁 sī（连词）为直接继承——**拉丁 sī 自身起源两说并列**（旧指示词冻结形 \*se-i vs 源自副词 sic「如此」——Ernout & Meillet 记 sic 说最通行），不折中；另：法语副词 / 肯定词 si（« si grand »／« — Tu viens ? — Si ! »）另源拉丁 sic，TLFi（经 Usito 转引）记 **842** 年首见（斯特拉斯堡誓言），与连词 si 同形异源（2026-10-03 经检索转引）

**同义 / 搭配 / 易混**
- 搭配：`même si + indicatif`（核心）；`même s'il en a envie`（即使他想）；书写注意 **s'il / s'ils** 缩合；位置灵活——引导从句可前置（Même si…, 主句）或后置（主句, même si…）
- **易混（让步家族）**：**même si**（+ 直陈式，事实 / 假设性让步）vs **bien que / quoique**（+ 虚拟式，语义相近但**不换用**；少数作者允许 bien que + 直陈以强调事实，规范以虚拟式为是）vs **quand bien même**（+ 条件式，纯假设）vs **malgré**（+ 名词）
- **易混（même 相关）**：**même si**（即使）vs **tout de même**（仍然、还是——« C'est tout de même bizarre. »，见 [[tout]]）vs **quand même**（同「仍然」；口语也作反对语）；**même**（甚至——副词：« Même lui le sait. »）vs **même si**——别丢 si
- **faux ami**：même si ≠ "same if"——对应英语 **even if / even though**；英语 even if（假设）与 even though（事实）的分工，法语由 même si 一词 + 时态承担
