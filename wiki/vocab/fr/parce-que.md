# parce que

> 收录说明：inbox 形式 `parce que`——按多词单位（v1.5）独立建页；`que` 在元音前省作 **qu'**（parce qu'il）。与 [[vu-que]]（引原因·已确证事实）、[[c-est-pour-ca-que]]（引结果）同处因果一族。

**释义**：因为（最常用、最中性的原因连词；**唯一能直接回答 pourquoi 的**） ｜ conjonction de subordination marquant la cause ; introduit une cause **inconnue de l'interlocuteur**

**例句**
- _Je reste à la maison parce qu'il pleut._ 因为下雨，我就待在家里。（注意省音 **parce qu'**）
- _— Pourquoi tu ne viens pas ? — Parce que je travaille._ ——你为什么不来？——因为我在上班。（**回答 pourquoi**，可置句首）
- _Il n'est pas venu parce qu'il était malade._ 他没来，因为他病了。

**形态要点**
- **词性**：从属连词（conjonction de subordination），引导**原因状语从句**，后接**直陈式**（l'indicatif）
- **省音**：parce que 在元音开头词前一律省作 **parce qu'**——parce **qu'**il / **qu'**elle / **qu'**on（\*parce que il 不合语法）
- **语序**：回答 pourquoi 时**可置句首**（— Pourquoi ? — Parce que…）；陈述句中通常**后置**（主句 + parce que + 从句）；可被 **c'est… que** 强调——_C'est parce qu'il est malade qu'il n'est pas venu._
- **拼写**：parce **并写成一个词** + que 分写——**勿与 `par ce que` 混**（par + 指示代词 ce que「通过……所说的」：_Je vois par ce que vous me dites…_ 我从您所说的看出……；Académie 9e 专条提醒二者须区分）
- **语域与分工（本页重点）**：

  | 连词 | 性质 | 引什么原因 | 回答 pourquoi？ | 位置 |
  | --- | --- | --- | --- | --- |
  | **parce que** | 从属 | 对方**未知**的原因（提供信息） | **是**（唯一） | 主句前后皆可；回答时可置句首 |
  | `car` | **并列**（coordination） | 对**前句**的解释 / 理由；偏书面 | 否 | 只能接在后句之前（第二分句） |
  | `puisque` | 从属 | **已知 / 共识**的前提（推断、论证） | 否 | 主句前 |
  | `comme` | 从属 | 众所皆知的原因 | 否 | **必须置于主句之前** |
  | [[vu-que]] | 从属 | **已确证的事实** | 否 | 惯常后置 |

- **car vs parce que（语义对照）**：_Il doit être malade, **car** il ne sort plus._（**说话者的推理**）vs _Il ne sort pas **parce qu'**il est malade._（**事实的原因**）——car 关涉**说话人**，parce que 关涉**动作**
- 病句警示：\*Puisque / \*Comme / \*Car il est malade.（回答 pourquoi 只能用 parce que）；\*C'est puisque… que（强调只能用 c'est parce que… que）

**词源 / 构词**
- **拆解**：**par**（← 拉丁 **per**「通过、经由」）+ **ce**（← 拉丁 **ecce + hoc**，指示代词「这」）+ **que**（← 拉丁 **quod / quid**，从属连接词）——字面「**由于这一点**」＝ par + ce（通过这一点）＋ que 引出从句
- **演变**：古法语 **por ço que / pour ce que**（同义，11–12 世纪极常见）→ 早期**par ce que**（Académie 9e 记 **XII 世纪**；另有研究记 par co que 已见于约 **1110** 的《Cumpoz》——**转引，待验证**）→ **并写** parce que；《罗兰之歌》（约 1100）v. 1004 见 *por ço que*（**该例为目的义**「为了……」，非原因义——勿当原因首证）；**15 世纪仍见分写 par ce que**，语法化「彼时尚未完成」（Linx / Fagard 研究转引）；**16 世纪** Frantext 有明确原因用例（Thenaud 1515-1519；Rabelais《Gargantua》1542）；Vaugelas 仍视 pource que 与 parce que 并存，后 parce que 淘汰 pource que（Littré 记）
- **同族 / 派生**：pource que（古 / 废）；par ce que（指示代词分写，同音近形）；同族因果连词见 §形态要点表
- **记忆钩**：parce que ＝ **par + ce + que**「**通过这一点**（＝因为这一点）」——先指「这一点」，再「因为」它

**英法交叉核对（受影响的英语词）**
- **平行构式，非借入（本页核心）**：英语 **`because`**（连词，**late 14c.**）← 短语 *bi cause*（＝ by + cause），义「by cause, for the reason that」；早期常接 **that** 或 **why**。成分为英语自构——by（← 古英语 bē / bi ← 原始日耳曼 \*bi ← PIE \*bhi）+ cause（**c.1200** ← 古法 cause ← 拉丁 causa「原因；诉讼」，其自身来源不明）。etymonline 明注其「**Modeled on French *par cause***」——**结构上仿法语，但成分与词源均为英语自构，非法语借入**（勿误作借入）；缩写 **'cause**（写作）**mid-15c.**
  - 注意：etymonline 对照的是 **par cause**，而非本页的 **parce que**（par ce que）——法语侧另见旧式 par cause que「因为」；**两式的对照关系未逐核（待验证）**
- **对照（并列性原因连词）**：英 **`for`**（连词「因为」）与本页对照的 `car` 功能平行（书面、并列性、不回答 why-式提问）；for ← 古英语 for ← 原始日耳曼 \*fura，与法语 pour / par 无借入关系（pour ← 拉丁 pro 为共祖远亲）
- **共祖未借入**：成分 que ← 拉丁 quod / quid 与英语 that（本族 ← 古英语 þæt）义近而源异；par ← 拉丁 per 与英语 for（见上）无借入关系
- 核对：because late 14c.、'cause mid-15c.、cause c.1200 ← 古法 cause ← 拉丁 causa、by ← 原始日耳曼 \*bi ← PIE \*bhi，均据 etymonline（2026-10-04 经直读）；「Modeled on French par cause」为 etymonline 原话。「未借入英语」为**否定性结论**，无年代可核。

**同义 / 搭配 / 易混**
- 搭配：`parce que + 直陈式`；`Pourquoi… ? — Parce que…`；`C'est parce que… que…`；省音 `parce qu'il / qu'elle / qu'on`
- 同义（原因连词）：`car`（书面·并列）、`puisque`（既然——已知前提）、`comme`（因——只置句首）、[[vu-que]]（鉴于——已确证事实）、`étant donné que`
- **易混（同音近形，写作失分点）**：**parce que**（因为）vs **par ce que**（par + ce que：_Je vois par ce que vous dites_）——**并写 / 分写之别**
- **易混（因果方向）**：[[vu-que]] / parce que（引**原因**）｜ [[c-est-pour-ca-que]]（引**结果**，所以……）｜ [[donc]]（连接副词「因此」，可插句中）
- **易混（推论 vs 事实）**：`puisque`（推理：_Il ne m'aime pas **puisqu'**il ne m'a pas salué_——此处 parce que 不自然）vs parce que（事实原因）
- 相关：[[pourquoi]]（疑问副词「为什么」——parce que 是其标准答语）、[[comme-toi]]（comme 的比较义）、[[comment]]
