# rembourser

**释义**：偿还、退还（钱款）；（保险/机构）报销；（退货）退款 ｜ rendre (de l'argent) à quelqu'un ; restituer une somme ; couvrir des frais

**例句**
- _Je te rembourse les 20 euros demain._ 我明天把 20 欧元还你。
- _L'assurance te remboursera les frais médicaux._ 保险公司会给你报销医疗费。
- _Il s'est fait rembourser son billet de train._ 他退掉了火车票，拿到了退款。

**形态要点**
- 动词：不定式 **rembourser** ｜ **1er groupe** ｜ 助动词 **avoir**（j'ai remboursé）｜ 过去分词 **remboursé**
- 现在时六形：je **rembourse** ｜ tu **rembourses** ｜ il·elle **rembourse** ｜ nous **remboursons** ｜ vous **remboursez** ｜ ils·elles **remboursent**（规则 -er，无拼写变化）
- 高频结构：**se faire rembourser**（让人给自己退款——「被退款 / 拿到退款」）；`rembourser qch à qqn`（把某款项还给某人）；`être remboursé de qch`（得到……的报销）
- 派生名词：**le remboursement**（偿还、退款——demander un remboursement 申请退款）

**词源 / 构词**
- **拆解**：**re-**（回、返还）+ **embourser**「把钱放进钱袋」＝「把钱塞回（人家的）钱袋 → 偿还」；embourser 又＝ **en-**（放入）+ **bourse**「钱袋」
- **演变**：**bourse** 古法语形式 **borse**（12c.）← 晚期拉丁 **bursa**「皮袋、钱袋」← 希腊 **byrsa**「皮、皮囊」（Académie 9e / CNRTL，2026-10-03 经检索转引）；**rembourser** 首证 **1262**（TLFi 经 Usito 转引，义「放回钱袋」；另有辞书作 1444——两说并存，已如实记录）；货币义「偿还借款」14 世纪（Académie 9e）；**remboursement** 1432（转引）
- **同族 / 派生（法语）**：bourse（钱袋；奖学金；交易所 la Bourse）、boursier（领奖学金的学生）、remboursement（偿还）；**débourser**（垫付——dé- + bourse，与 rembourser 同根反向）；英语一侧见下节
- **记忆钩**：rem-bours-er ＝「再塞回钱袋（bourse）」——bourse 正是英语 purse 的老表亲（同出拉丁 bursa，见下节）；把谁的钱袋塞回去，就是「报销 / 退款」

**英法交叉核对（受影响的英语词）**
- **借入英语**：**reimburse**（v.「偿还、退款」**1610s** ＝ re-「回」+ **imburse**〔**1530s**，「放进钱袋、支付」〕← 法语 **embourser** ← 古法语 em-「in」+ borser ← borse「钱袋」← 中世纪拉丁 bursa〔etymonline，2026-10-03 经检索转引〕）；**disburse**（v.「支出、支付」**1520s** ← 古法语 **desbourser**〔13c.〕＝ des- + bourse，现代法语作 débourser）；**bourse**（英 n.「证券交易所」**1845** ← 法语 bourse「交易所」，原义「钱袋」——1590s 先有「商人聚会处」义）
- **共祖未借入**：**purse**（钱包 ← 古英语 purs ← 中世纪拉丁 bursa——与法语 bourse 同出拉丁，不经法语）；**bursa**（生理「囊、滑囊」1788 ← 中世纪拉丁 bursa mucosa）；**bursar / bursary**（← 中世纪拉丁 bursarius）
- 核对：已核实（etymonline / Académie 9e / Usito 引 TLFi，2026-10-03 经检索转引）——英 reimburse 1610s ← re- + imburse 1530s ← 法语 embourser ← bourse ← 中世纪拉丁 bursa ← 希腊 byrsa「皮」；法语 rembourser 首证 1262（TLFi）与 1444（另说）并存；**待验证**：1444 一说所指（本义还是货币义）未明

**同义 / 搭配 / 易混**
- 搭配：`rembourser qch à qqn`（把款项还给某人）；`se faire rembourser`（拿到退款）；`rembourser un prêt`（还贷）；`rembourser un billet / un article`（退票 / 退货退款）；`être remboursé sur son [[compte]]`（退款打进账户）；`remboursement sous 48 h`（48 小时内退款）
- **易混（「还」的三张脸）**：**rembourser**（还**钱**、报销——把钱塞回钱袋）vs **rendre**（还**物**——rendre un livre 还书、rendre l'argent 还钱（口语）；「还钱」正式说法仍是 rembourser）vs **restituer**（归还——正式语域，restituer un objet volé 归还赃物）
- **faux ami**：rembourser ≈ reimburse 基本对齐；但注意英 **bourse** 不是「钱包」而是「证券交易所」，英「钱包」是 **purse**——同一个拉丁 bursa 的三支分流：法 bourse 保「袋」义并引申「奖学金／交易所」，英 purse 承古英语借形守「钱包」，英 bourse 走「交易所」义
