# paysage

**释义**：（1）**风景、景色、景观**（étendue de pays que l'œil embrasse）；（2）**风景画、风景画类**（peinture de pays）｜ étendue de paysage ; genre pictural

**例句**
- _Le paysage de montagne est magnifique en automne._ 秋天的山间风景很美。
- _Ce peintre est célèbre pour ses paysages._ 这位画家以风景画闻名。
- _Le paysage politique a changé après l'élection._ 选举后政治格局发生了变化。（隐喻用法）

**形态要点**
- `le paysage`（m.）；`un paysage` → `des paysages`
- 同音近形页 **`paysagé`**（形容词 / 过去分词）——建页时须避让近形（本库命名规则），本页保留 `paysage.md`
- 派生：**paysagiste**（景观设计师）、**paysager**、**paysagisme**、**architecture du paysage**、**paysage sonore**（声景）

**词源 / 构词**
- **拆解**：**pays + -age** ← **pays**（← 拉丁 **pagus**「乡村地区」）+ 后缀 **-age**（表集合 / 行为）
- **首证**：**1549**，Beaux-Arts（Robert Estienne 词典，「mot commun entre les painctres」画家间通用语），疑为**枫丹白露画派**所造以指「风景画」；演变：1551；1556「一地的整体」；1573「目力所及的成片地域」（据 TLFi）
- **存疑**：另有资料提 **1493 Molinet** 一处，但**未证实**（theses.fr 另称实际首现可能比 1549 早约 20 年）——**标存疑**
- **-age 的语义**（集合还是行为）多源说法不一——**未定**
- **记忆钩**：paysage＝「**乡下（pays）的东西**」——先指「画出乡野的画」，再指「眼前的乡野」

**英法交叉核对（受影响的英语词）（关键）**
- **calque（仿造，非借入）**：英语 **landscape** **不是**从 paysage 来的——`landscape` ← 荷兰语 **landschap**（c.1600 画家术语，1598 首记），日耳曼构词 *land + -schap*。二者**概念借用、词形各自造**——**既非借入也非共祖，而是 calque 关系**（日耳曼用 land，罗曼用 pays ← pagus）
- **借入**：英语 **paysage** 确有借入形式（罕见 / 文雅，共入），**借自法语**；但英语常用词是 landscape
- 核对：英语侧经检索转引 etymonline（2026-10-13）

**同义 / 搭配 / 易混**
- **辨析**：`paysage`（风景）vs `pays`（国家 / 地区）vs [[campagne]]（乡下）vs `site`（景点）
- 搭配：`paysage urbain / rural / sonore`｜ `à perte de vue`（一望无际）；**易混**：`paysagé`（形容词）
- 相关：[[campagne]]、`vue`（待收）
