# contrôler

**释义**：（1）检查、核查、检验（contrôler les billets 查票）；（2）控制、抑制（contrôler ses émotions——口语常见，「支配」义规范语言学家仍建议用 maîtriser） ｜ vérifier, examiner ; maîtriser（emploi critiqué）

**例句**
- _Le contrôleur contrôle les billets dans le train._ 检票员在火车上查票。
- _On contrôle la qualité des produits avant l'expédition._ 发货前会检验产品质量。
- _Elle essaie de contrôler ses émotions._ 她努力控制自己的情绪。

**形态要点**
- 动词：不定式 contrôler ｜ 组别：1er groupe ｜ 助动词：avoir ｜ 过去分词：contrôlé
- 现在时：je contrôle ｜ tu contrôles ｜ il·elle contrôle ｜ nous contrôlons ｜ vous contrôlez ｜ ils·elles contrôlent
- 变位提示：规则 -er 动词（同 parler 型）；**ô 全变位保留**——1990 年正字法改革只在 i、u 上删长音符号，â ê ô 一律保留（勿写 ~~controler~~）
- 名词化：**le contrôle**（n.m. /kɔ̃.tʁol/，检查；控制）；派生 **contrôleur / contrôleuse**（检查员、检票员；也指「控制器」）

**词源 / 构词**
- **拆解**：**contrôle**「双份对照账簿」+ **-er**——contrôle 来自 **contre-**（拉丁 **contra**「对着」）+ **rôle**（中世纪拉丁 **rollus / rotulus**「羊皮纸卷、名册」）：为核查原账册另抄一份「**反卷**」（contre-rôle），两账对照核验；contre-rôle → contrôle 系**音节缩并（haplologie）**
- **演变**：中世纪拉丁 **contrarotulare**（1298 已见，Latham）→ 盎格鲁-诺曼语 **contre roller**（约 1310，爱德华二世内府条令）「以第二本账核对账目」→ 古法语 conteroller（1437）/ controoler（1446）/ contreroler（1541，加尔文）/ controler（1563，龙萨）→ 1636 拼作 controler（Monet）→ 1740「在金器上打戳记」→ 现代 contrôler「检查、核查」（据 CNRTL / Académie française，2026-10-03 经检索转引）
- **同族 / 派生（法语）**：contrôle（检查；控制）、contrôleur / contrôleuse（检查员）、contrôlable / incontrôlable（可核查的 / 无法控制的）；同语义场 [[compte]]（账——同属「核账」语境）
- **记忆钩**：contrôle 的字面是「**反卷**」——一本账 ＋ 对着核的第二本账，「对账」→「检查」；「控制」义是 20 世纪从英语回流

**英法交叉核对（受影响的英语词）**
- **借入英语**：**control**（v. early 15c. *countrollen*「核对、查验；管制」）← 盎格鲁-诺曼语 / 古法语 **contreroller** ← 中世纪拉丁 **contrarotulus**「副本名册」（contra「对着」+ rotulus ← **rota**「轮」）——即「以副本账簿核账」的查验做法（etymonline，2026-10-03 经检索转引）；**controller**（职名 **contrerollour**，约 1310 已见）；**control**（n. 1580s ← 动词）；**roll / role** 与之共祖（← 拉丁 rotulus / rotula）
- **共祖未借入**：**roll**（← 古法语 rolle ← 拉丁 rotula「小卷、小轮」）——contra / rota 一系拉丁共祖，非由 contrôle 传入
- 核对（**faux ami 核心**）：法语 contrôler **保留「核查、检验」本义**（contrôler les billets 查票）；英语 control 的「支配、掌控」义 **mid-15c.** 自「查验」义发展出来（etymonline；另见笼统作 16c. 的说法——**两说并列**，以检索到的 etymonline mid-15c. 为准）。法语「支配」义 **1662 年（帕斯卡）仅见孤例**，或系借自英语 to control；**1903 / 1910 年起重新通行**（se contrôler 等）——**Académie française 至今认为「支配」义宜用 maîtriser / commander，contrôler 只作「核查」**（CNRTL + Académie，2026-10-03 经检索转引）

**同义 / 搭配 / 易混**
- 搭配：`contrôler les billets / les passeports`（查票 / 查护照）、`contrôler la qualité`（检验质量）、`contrôler ses émotions / sa colère`（控制情绪 / 怒火——见 faux ami）、`contrôle des connaissances`（学业考核）、`contrôle technique`（车检）、`sous contrôle`（在掌控中）
- **faux ami（本页重点）**：法语 **contrôler** ≈ 英语 **check / monitor / inspect / verify**；「控制（支配）」义规范用 **maîtriser**（掌控情绪、局势）、**commander**（支配）、**diriger**（领导）——把英语 control 的「支配」义直译成 contrôler 属英语式用法（Académie 判为 anglicisme）
- **易混（近义四件套）**：contrôler（核查——检查并确认）｜ vérifier（核实——查验真伪）｜ surveiller（监视、看管——盯着而不一定查）｜ maîtriser（掌握、控制住）
- 名词对照：**le contrôle**（检查；控制）｜ **le contrôleur**（检票员、检查员；控制器）
