# 部分冠词（article partitif）：为什么 `c'est de l'art` 里要加 `de`？

> 归档自 2026-10-05 的整理（原文见 `raw/部分冠词（article partitif）.md`）。提问背景：`c'est de l'art` 里的 `de` 是「随便加的」吗？

## 回答

`de` 不是随便加的——它是**部分冠词（article partitif）** `de l'` 的一部分。

`de l'art` 是两样东西合在一起：

| 部分 | 作用 |
| --- | --- |
| `de` | 部分冠词的**前半部分** |
| `l'` | **定冠词的省音形式**（`art` 元音开头：`l'art`） |

法语部分冠词有四种形式，都表示**不可数的、不确定的量**（相当于英语的 *some* 或不加冠词）：

- **du** = de + le → *du pain*（一些面包）
- **de la** = de + la → *de la musique*（一些音乐）
- **de l'** = de + le/la 在元音或哑音 h 前 → *de l'eau*、*de l'art*
- **des** = de + les（复数）

所以 `de l'art` ＝「一些艺术 / 艺术这种东西」。

**为什么这里要用部分冠词？** 关键在于 `c'est` 后面接的是**抽象名词或不可数名词**，表示性质与类别，而非某个具体、可数的对象：

- `C'est de l'art.` → 这是艺术（一种性质、一种「艺术性」）——用部分冠词
- `C'est un art.` → 这是一门艺术（当成一个可数类别）——用不定冠词

前者强调「这属于艺术这个范畴 / 这种特质」，后者强调「这是一门具体的技艺」。日常听到的 `c'est de l'art` 多半是第一种：**「这就是艺术啊」**，带点感叹。
