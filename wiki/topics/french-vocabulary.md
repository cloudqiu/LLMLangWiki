# 法语词汇（Vocabulaire）

## 概述

本库的**法语**词汇管理系统（2026-10-01 建立），与英语系统 [[english-vocabulary]] 同构分轨、独立收词与计数：

> `raw/vocab-fr-inbox.md` 收词（用户）→ `wiki/vocab/fr/` 逐词编译与富化（LLM）→ 词族 / 易混 / 主题综合（持续）→ 复习双轨：SRS 子牌组 `#flashcards/fr` + Claude 按需出题。

词条富化含：IPA、词性、**阴阳性与复数**、**形态要点**（动词：不定式·组别·助动词·过去分词·现在时六形，不列表格）、双语释义、例句（含翻译）、词源/构词（对照 **CNRTL（TLFi）** 核实）、**英法交叉核对**（受影响的英语词：借入 vs 共祖）、同义/搭配/易混（含 faux amis）；不确定信息标「待验证」；`learning` 字段（new → learning → known）跟踪掌握度。

## 怎么用

1. **收词**：追加到 `raw/vocab-fr-inbox.md`（一行一个，可附来源/例句；**重音、撇号照写**）；或会话口述——Claude 先**原样**记入 `raw/vocab-fr-capture-YYYY-MM-DD.md` 再编译。
2. **编译**：说「**ingest vocab-fr**」→ 去重、逐词建/更新词条（每批 20-50 词）、更新本页、记 log（`ingest | vocab-fr: …`）。
3. **复习**：SRS 刷卡（法语卡在 `flashcards/fr` 子牌组，可只复习法语）；想测验就说「考我：最近 20 个法语 new 词」→ Claude 出题，产物落 `output/`。

## 结构约定

- 词条路径：`wiki/vocab/fr/<word>.md`（小写 lemma；**不逐条进 index.md**）
- **lemma 规则**：动词→不定式（遇到 `suis` 归并到 `être`）；名词→单数、不带冠词（阴阳性进 `gender` 字段）；形容词→阳性单数；代词式动词带 se（`se laver` → `se-laver.md`）；多词表达取词典 headword
- **文件名一律 ASCII 转写**（重音只留在 `word` 与正文/卡片里）：

  | 法语字符 | 转写 | 例 |
  | --- | --- | --- |
  | é è ê ë | e | école → `ecole.md` |
  | à â | a | là → `la.md`（与 `la` 撞名 → 消歧） |
  | î ï | i | île → `ile.md` |
  | ô | o | tôt → `tot.md` |
  | ù û | u | où → `ou.md`（与 `ou` 撞名 → 消歧） |
  | ç | c | français → `francais.md` |
  | œ æ | oe / ae | cœur → `coeur.md` |
  | 撇号 ' ’ | - | l'air → `l-air.md`；aujourd'hui → `aujourd-hui.md` |
  | 连字符 | 保留 | peut-être → `peut-etre.md` |
  | 空格（多词单位） | - | avoir l'air → `avoir-l-air.md` |

  理由：Obsidian 按 basename 解析链接，而 é / œ 存在 NFC/NFD 两种编码——ASCII 化杜绝重影页面。

- **命名消歧**（basename 必须**全库唯一**；建页前先扫全库，含 `templates/`——`concept.md`、`source.md` 等本身就是法语词）：
  - 跨语言同名（décor / decor、hospice、turquoise、compétent / competent；反向例 [[detective]]）：**后建页者**加语言后缀——法语后建用 `-fr`（`decor-fr.md`）、英语后建用 `-en`（`detective-en.md`），两页互链
  - 同语言近形（ou / où、a / à、la / là、sur / sûr、du / dû、cote / côte / coté）：**一律先用带词性后缀的名字**（`ou-conj.md` / `ou-adv.md`），避免「先到先得」的任意性，并登记下表
  - **Windows 保留名**（con / prn / aux / nul / com1-9 / lpt1-9）加后缀（`con-adj.md`、`aux-prep.md`）
- 标签：`src/<来源>`、`domain/<领域>`；语言由 frontmatter `lang: fr` 标记
- **英法交叉核对**（v1.6.1，每词条必做）：查出受该法语词影响的英语词——**借入**（英 ← 法：路径、年代、拼写/读音漂移、词义异同）与**共祖**（同源非借入）分清，反向回借（法 ← 英）可留意；英语词库已收录则双向互链（参见 décor ↔ [[decor]]）；无网络标「待验证」
- 闪卡：`## 闪卡 #flashcards/fr` 内**多行双向卡**；正面＝词（照写重音），背面＝释义＋形态＋词源摘要；阴阳性 / 变位可加挖空卡（`==…==`）。**单独成行的 `?` / `??` 是插件分隔符**，正文避免
- 发现方式：全库按标签自动发现（卡片集中在 `wiki/vocab/fr`）

- **候选（2026-10-03）**：**北日耳曼海事层 skip「船」**（[[equipe]] · équiper · équipage · équipement ＋ 英 equip（1520s ← 法语 équiper）· equipment · **ship / skipper**（同出 ON skip / OE scip））——**équipe ↔ team 同义异源**（team ← OE tēam ← PIE \*deuk-「引导」，1846 才得运动义）；与「法兰克语借词层」并列的**另一种日耳曼地层**（诺曼海事借词）
- **候选（2026-10-03）**：**pensare / pendere「称重」词族**（[[que-penses-tu-de]] · `penser`（**待建**）· pensée ＋ 英 pensive（14c. 借入）· pension / pendant / suspend / suspense / poids）——pensare「称量」→「思考」（反复态）；**penser ↔ think 同义异源**（think ← 日耳曼 \*thankjan）——由 [[que-penses-tu-de]] 触发，待收 penser / pensée 后评估建页
- **候选（2026-10-04）**：**quisque「各别」／ qualis「何种」**（[[chaque]] · [[quel]] · chacun（未收）＋ 英 each（**非借词但语义受 quisque 影响**——etymonline 明记 each 今义「各别」系受拉丁 quisque 语义模型）、quality / qualify / qualitative（qualis 借入））——「同一个 quisque 既给罗曼语 chaque 又给英语 each 做语义模型」的教学点；由 [[chaque]] / [[quel]] 触发
- **候选（2026-10-04）**：**vicis「轮次、交替」**（[[fois]] · parfois / toutefois / à la fois ＋ 英 vicissitude（**共祖，但承「更迭」义非「次」义**）· vice- / vice versa）——「次」义只活在法语；英 time（「次」义）系日耳曼 **同义异源**；同音易混 fois / foie / foi；由 [[fois]] 触发
- **候选（2026-10-04）**：**titulus「铭牌、题署」**（[[titre]] · titrer / titulaire / intituler ＋ 英 title（借入，**英语保留 -l- 而法语 titre 异化去 -l-**，同型 marbre ← marmor）· entitle（← 法 intituler）· titular · tittle / tilde）——由 [[titre]] 触发
- **候选（2026-10-04）**：**errare「游荡、迷途」**（[[erreur]] · errer / erroné ＋ 英 error（借入）· err / errant / aberrant / erroneous）——「迷路 → 弄错」；**两说并存**：TLFi 该条只列名词 error、未提 errare，etymonline 明言 ← errare；由 [[erreur]] 触发
- **候选（2026-10-04）**：**scribere「刻划」**（[[ecrire]] · écrit / écriture / écrivain ＋ 英 scribe / script / describe（借入）· manuscript（共祖拉丁直借）；英 **write** ← 日耳曼 \*writan **同义异源**——与法语 écrire 同训不同源）——由 [[ecrire]] 触发
- **候选（2026-10-04）**：**subinde「随即、屡屡」**（[[souvent]] ＋ 意 sovente（**借自**古法 suvent / sovent——罗曼语内部逆向借词））——拉丁 **saepe** 在 Peregrinatio Aetheriae 后消失、由 subinde 接替其「经常」义（据 Löfstedt，TLFi 引）；英 often ← 日耳曼 \*ufta- **同义异源**；由 [[souvent]] 触发
- **候选（2026-10-04）**：**retro「在后」**（[[dernier]] · derrière / arrière ＋ 英 rear（借入）· retro- / retrogade）——\*deretranus（de retro + -anus）→ derrain → dernier；由 [[dernier]] 触发
- **候选（2026-10-04）**：**juvenis「年轻」三支**（[[jeune-adj]] · jeunesse / vieillir ＋ 英 juvenile / junior（**共祖，拉丁支**）· young（**PIE \*yeu- 共祖，日耳曼支**））——**同根不同支**的标本（juvenis 拉丁支 vs geong 日耳曼支）；由 [[jeune-adj]] 触发
- **候选（2026-10-04）**：**adjutare / juvare「助」**（[[aide-moi]] · aider / aide ＋ 英 aid（借入，← 古法 aide）· adjutant / adjuvant（共祖拉丁直借））——**同一 adjutare 两条入英路径**（经古法 aid ／ 直接拉丁 adjutant）须分清；juvare ↔ iuvenis（young）是否同根**未定论**（etymonline 仅记 possibly）；由 [[aide-moi]] 触发
- **候选（2026-10-04）**：**parce que ↔ because：平行构式**（[[parce-que]] · [[pourquoi]] · [[comme-toi]]（comme 的原因义，**只置句首**）· [[vu-que]] · [[c-est-pour-ca-que]] · [[donc]] ＋ 英 because（**bi cause ← 仿法语 *par cause*，非借入**——etymonline 明注 modeled on French；注意 etymonline 对照的是 par cause，非 par ce que，**待验证**））——原因 / 结果连接簇的英法对照；由 [[parce-que]] 触发
- **候选（2026-10-04，跨轨）**：**拉丁 gutta「一滴」英法双边**（`gouttière` 未收 · `goutte` 未收 ＋ 英 **[[gutter]]**（借入 ← 古法 goutiere；**印刷义「订口」1841**，与 [[halftone-dot]] 印刷簇可并）· gout（共祖））——屋檐 → 排水沟 → 社会底层（1818 喻义）；英语侧建页日已与本候选挂钩；由英 [[gutter]] 触发
- **候选（2026-10-04，跨轨）**：**PIE \*widhewo-「被分开者」**（`veuve` 未收 ＋ 英 [[widow]]（印刷义「寡行」1904））——**共祖非借入**：widow 走日耳曼支、veuve ← 拉丁 vidua 走拉丁支——与 vie↔life、souvent↔often 同型的「同义异源」标本；由英 [[widow]] 触发
