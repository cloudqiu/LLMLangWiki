# 英语词汇（Vocabulary）

## 概述

本库的英语词汇管理系统（2026-10-01 建立）。分工：

## 怎么用

1. **收词**：把生词追加到 `raw/vocab-inbox.md`（一行一个，可附来源/例句）；或在会话中口述「这批词：…」——Claude 先**原样**记入 `raw/vocab-capture-YYYY-MM-DD.md` 再编译。
2. **编译**：说「ingest vocab」→ 去重、逐词建/更新词条（每批 20-50 词）、更新本页、记 log。
3. **复习**：已装 SRS（见下节）——每日 `Ctrl+P → "Review Flashcards from all notes"` 刷卡；想测验就说「考我：最近 20 个 new 词」→ Claude 出题（cloze / 翻译 / 辨析），产物落 `output/`（示例：[[2026-10-01-vocab-quiz-01]]）。

## 结构约定

- 词条路径：`wiki/vocab/en/<word>.md`（小写 lemma；**不逐条进 index.md**）
- **多词词条（2026-10-01 新增约定，因收进 wore on / in sight 而立）**：短语动词与习语同样每词一页，文件名把空格换成连字符（kebab-case），如 `wear-on.md`、`in-sight.md`；frontmatter 的 `word` 保留原样空格（`"wear on"`）；**lemma 取词典 headword，不取遇到形式**——inbox 里的 `wore on` 归并到 `wear on`（同 `unraveling` → [[unravel]] 之例）；pos 用 `phr. v.` / `idiom` 等标注；闪卡正面照写多词 headword。（schema v1.5 已把本条并入 CLAUDE.md §3.4。）
- 标签：`src/<来源>`（如 src/reading、src/书名-slug，标注在哪读到的）、`domain/<领域>`（如 domain/tech、domain/finance，工作/专业领域）——按需取用
- 闪卡：词条「闪卡」小节内**多行双向卡**（`word` ⏎ `??` ⏎ 释义＋词源摘要的背面），小节标题带 `#flashcards/en` 标签——插件凭标签发现卡片、复习时同屏显示词源；法语姊妹系统用 `#flashcards/fr`（见 [[french-vocabulary]]）——牌组树可选 en / fr 分语种刷卡，「all notes」则两语混合；**模板页不写标签**（防 SRS 把占位卡解析成幽灵卡）
- **同名陷阱**：多词词条与单词词条可能只差一个连字符（[[in-sight]] vs `insight`、[[wear-on]] vs `wear`）——建页前先 grep 是否已有近形页面，避免误建重页
- 发现方式：全库按标签自动发现（卡片集中在 `wiki/vocab/en`）

- **候选（2026-10-01）**：「直到 / 到」虚词簇 **unto · until · till**——三者同出日耳曼语「直到」义（un- ← 哥特语 und），中古英语中 unto 与 until 一度同义；待 until、till 收词后建一页对照（含 unto / onto 拼写易混）。当前已在 [[unto]] 词条内先行记录
- **候选（2026-10-01；2026-10-04 更新）**：**希腊医学／科学构词零件**（endo- / metr- / hyster- / -osis / -itis / **haemo- · hemato- · -emia**（[[heme]]，2026-10-04）**／ -toxin**（[[endotoxin]]，2026-10-04））——由 [[endometriosis]] 触发的可复用零件库：拆得动 endometriosis，就同时拿下 endometritis、adenomyosis、myometrium、hysterectomy 等一串词（含 -osis 病名 vs -itis 炎症的易混）；2026-10-04 扩员：**endo- 零件**同时支撑 [[endometriosis]] 与 [[endotoxin]]，**haima「血」零件**支撑 [[heme]] / hemoglobin / -emia 一串——**已可评估建页**
- **候选（2026-10-04）**：**PIE \*ghos-ti-「客与敌同根」簇**（[[hospice]] · [[hostility]] ＋ host / hotel / hospital / hospitality / hostel / guest / hostage / 希腊 xeno-——「如何对待陌生人，就有了旅馆、医院，也有了敌意」）——**并含本库首例跨页并存记录**（[[hospice]] 记 \*ghos-pot- vs etymonline 根条目 \*ghos-ti-，两页互见、待回补）；由 [[hostility]] 触发
- **候选（2026-10-04）**：**「英语里的古法语借词层」样本组**（本批 8 词：[[sturdy]]（← 古法 estourdi / estourdir——且借入后**法语义走「心不在焉」、英语走「结实」**）· [[mince]]（← mincier）· [[fortify]]（← fortifier）· [[vigilant]]（← vigilant）· [[hostility]]（← hostilité）· [[vehement]]（← vehement）· [[tribe]]（← tribu）· [[premise]]（← premisse））——与法语 hub 的「**法兰克语借词层**」候选**对举**：一条是罗曼语（古法）向英语的借层、一条是日耳曼语向法语的借层，方向与年代皆可对照；由本批整体触发
- **候选（2026-10-04）**：**拉丁 lens / lentis「扁豆」两面**（[[lentil]]（扁豆，← 古法 lentille ← 拉丁 lenticula）＋ **lens**（透镜，1690s **直借**拉丁 lens——因形似扁豆得名））——**同一拉丁词在英语一分为二**；法语侧 [[lentille]] 一旦建页则**一词兼指扁豆与透镜／晶状体**，与英语的分工正好相反；由 [[lentil]] 触发
- **候选（2026-10-04）**：**营养与食品科学簇**（[[micronutrient]] · [[fortify]]（**1939** 起「添加营养素」义与军事义并存）· [[fermentation]] · [[amino-acid]] · [[lentil]] · [[heme]] ＋ macronutrient / nutrient / protein——本批营养／可持续题材的核心组；由 [[micronutrient]] / [[fortify]] / [[fermentation]] 触发
- **候选（2026-10-04）**：**拉丁 libra「天平」vs liber「书」两条线**（[[deliberate]] ← deliberare ← librare「称量」← **libra**「天平」＋ equilibrium / Libra ／ 对照 library ← **liber**「书」→ librarium）——**两线形近而源分，勿混**；由 [[deliberate]] 触发
