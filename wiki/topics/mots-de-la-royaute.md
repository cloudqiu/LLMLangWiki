# 「王室词汇」词族 —— rex 与 princeps 两条词根

## 概述

法语「王室内阁」看似一个词族，实际是**两条互不相干的词根线**。本页由 [[roi]] / [[princesse]]（2026-10-03 收录）与 [[reine]] / [[prince]]（2026-10-03）、[[royal]]（2026-10-01）触发，清 hub [[french-vocabulary]] 的「reg- 词族」长期候选：

| 词 | 词根线 | 拉丁来源 | 法语首证 | 备注 |
| --- | --- | --- | --- | --- |
| [[roi]] | **rex 线** | rex / regem ← regere「引导」 | **ca 880**（rex，《圣欧拉莉颂歌》） | PIE \*reg-「沿直线→引导、统治」；10c. rei → 12c. roi |
| [[reine]] | rex 线 | regina（rex + -ina） | 11c.（reïne，三音节） | 14c. 缩为 /ʁɛn/；「蜂王」义 1751 |
| [[royal]] | rex 线 | regalis | 12c.（roial） | 英 royal / regal **双重借入**（见下） |
| royaume（待收） | rex 线（regalis 派生线） | 待收词后核 | — | 同线：règne ← regnum、régner ← regnare、régicide ← rex + caedere |
| [[prince]] | **princeps 线** | princeps ＝ primus + capere | 12c. | 「取第一位者」；PIE \*kap-「抓取」 |
| [[princesse]] | princeps 线 | prince + -esse | **ca 1175** | 「公主」与「王后」词根都不同——页内「关键坑」 |

**关键结论**：**roi / reine / royal（/ royaume）＝ 拉丁 rex / reg-「统治」**；**prince / princesse（/ principe / principal）＝ 拉丁 princeps ＝ primus + capere「取首位」**。两线在语义上同属王室词汇，在词源上**毫无亲缘**——中文都带「王」字，最易误串。

## 脉络（坑点与对照）

- **语义陷阱**：[[reine]]（王后 / 女王——rex 线）vs [[princesse]]（公主 / 王妃——princeps 线）：中文「王后 / 公主」像同族，法语词源分属两系统。
- **辨线看词干**：rex 线——roi / reine / royal / royaliste / régner / règne / régicide / régalien；princeps 线——prince / princesse / princier / principauté / principe / principal。
- **英语侧小结**（详见各词条「英法交叉核对」）：
  - rex 线入英：**royal**（mid-13c ← 古法语 roial）与 **regal**（拉丁 regalis 直借）＝**双重借入**；**reign** ← 古法语 reigne ← 拉丁 **regnum**——注意 reign 的词源是 **regnum**（统治 / 王国），**不是** regina，别拿 reine 去对；**viceroy** ← 法语 **vice-roy**（1520s，整组法式构词入英）；rex / regalia / regicide 为拉丁直借层。
  - princeps 线入英：**prince**（c. 1200 ← 古法语）、principal / principle / principality（同出 princeps）。
  - **义同源不同（重点警示）**：英 **king**（← 古英语 cyning ← 日耳曼 \*kuningaz，一说 cynn「家族」+ -ing）与 **queen**（← 古英语 cwēn ← PIE \*gwen-「女人」）与法语 roi / reine **零词源关系**——义对义、源不对源（页内已各记）。

## 开放问题

- **royaume / royauté 收词后补全 rex 线全图**（règne / régner 亦可期待）——届时本页升 `mature`。
- 文化语汇可并入日后主题页：蜂王（la reine des abeilles）、王饼（la galette des rois，主显节）、« Le Petit Prince » 等。
- 英语侧扩展：realm（← 古法语 reaume，与 royaume 同线）、royalty（← 古法语 roialte）可在 royaume 收词后一并核对。
